# 3 技术要求

# 3.1 加工依据

双方签订签署完整的质量技术协议或更改确认单。

# 3.2 通用要求

<!-- page: 3 -->

3.2.1 甲方提供的质量技术协议、技术交底及更改确认单经乙方会签并返甲方后生效， 当质量技术协议内容更改时，甲方应以书面形式将更改后的质量技术协议或更改确认单 提供给乙方，乙方自接到之日起执行，五日内将签署完整的质量技术协议或更改确认单 扫描后返甲方。更改确认单是质量技术协议的附件，与本质量技术协议具有同等法律效 力。

3.2.2 乙方制定的工艺方案应落实双方签署的外协质量技术协议及更改确认单的所有 内容。投产前，应组织工艺评审，可邀请甲方参加；如工艺方案有更改，乙方应重新进 行工艺评审，评审通过后才能投入首件生产。

3.2.4 乙方提供产品合格证和相关检测报告（包括化学成分、低倍、力学性能和超声波 检查等）。

3.2.5 若产品不符合本质量技术协议要求，乙方应以书面形式通知甲方，经甲方同意后， 办理相关手续方可继续进行生产。若发生批次性或重大质量问题应按甲方要求归零。

# 4 生产过程中的质量控制要求

# 4.1 锻件过程质量控制

4.1.1 乙方用于生产和检测的设备、工艺装备、仪器仪表、计量器具等应鉴定合格，周 期鉴定的测量设备及仪器仪表应在有效鉴定周期内。

4.1.2 乙方应严格质量管理，加强生产全过程质量控制，在生产过程中形成的所有质量 控制记录完整有效。质量记录填写要准确、清晰；如需更改，可采取划改盖章（或签名） 的方式。产品的原始记录由乙方保存，保存时间至少为15 年。

4.1.5 首次承制锻件生产应进行首件鉴定，应邀请甲方参加，首件鉴定通过才能进行批 量生产。

4.1.6 在生产及运输过程中，应注意产品防止划伤、磕碰、锈蚀等缺陷。交付时应对产 品进行包装，运输过程中防磕伤，防变形。

4.1.7 禁止选用和使用禁用工艺；限用工艺应严格控制使用，在一定条件下，采取措施 经验证后，有条件使用。
