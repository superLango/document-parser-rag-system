# 1 范围

本规范规定了TC25钛合金环锻件的技术要求、验收规则和锻件的检验试验方法等。

本规范适用于采用α+β两相区锻造的TC25钛合金环形锻件（以下简称锻件）的验收。

# 3 技术要求

# 3.1 制造方法

# 3.1.1 冶炼工艺

合金采用真空自耗电弧炉熔炼，熔炼次数应不少于三次，最后一次熔炼稳定阶段的压强不大于5Pa。自耗电极不允许使用钨极氩弧焊焊接。

# 3.1.2 复验

锻件用原材料应符合规范191.ST.3要求，经入厂复验合格后方可投产使用。

# 3.1.3 加工方法

环形锻件采用轧制成形。

# 3.3 锻件的交货状态

3.3.1 锻件经双重退火，按规定的图纸进行粗加工，经超声波探伤检验合格后交付。

3.3.2 锻件应按炉批进行热处理。

热处理制度：950℃~970℃（温度允许在β转变温度下30℃~50℃范围内调整），保温1h~4h（时间按锻件实际厚度确定），空冷：530℃~570℃，保温6h，空冷。

# 3.5 低倍组织

3.5.1 在每批锻件取样做低倍组织检查。

3.5.2 锻件的纵向低倍流线，应基本沿受检截面的外形分布。

3.5.3 低倍试片表面应无肉眼可见的缩孔痕迹、裂纹、夹杂物和偏析等冶金缺陷。

3.5.5 低倍组织上存在异议，应以该区的高倍组织为准。

在每批锻件取样做高倍组织检查。锻件的高倍组织应符合附录B中图B.1的2~4级（按照No1054-1976标准中图3σ）。供需双方提供×200和×500图片。

# 3.7 形状、尺寸及公差

锻件的形状、尺寸及形位公差应符合供需双方会签的锻件图纸或合同规定的尺寸及公差要求。

# 3.8 无损检验

# 3.8.1 超声波检查

锻件粗加工后，应按HB20159进行超声波水浸探伤检验，验收平底孔直径为 $ \Phi1.0\mathrm{mm}。 $ 采用直探头纵波检查时，底反射损失超过正常值的 50%，应属不符合要求。

# 3.8.2 X射线检查

半成品零件应逐件按 GJB1187A 进行 X 射线检查，不允许存在高密度夹杂，不允许存在大于 0.3mm 的其他缺陷。

# 3.9 β转变温度

供方应提供每批次锻件β转变温度的实测数据。

# 3.10 表面质量

锻件表面经机加工后不允许存在裂纹、嵌入的氧化皮、翻皮、折叠等缺陷。锻件表面粗糙度应满足超声波水浸探伤的要求。

# 4. 质量保证规定

# 4.1 质量控制

4.1.1 锻件在试制、转厂或改变主导工艺时，应按HB5402的规定进行鉴定、定型，然后方可投入生产。

4.1.2 锻件主导工艺过程的生产条件应按 GJB 904A 进行准备和控制。

4.1.3 锻件应采用定型的锻造工艺生产，当改变主导工艺时应事先征得需方和设计方的同意。

# 4.2 质量一致性检验

# 4.2.1 组批

锻件应成批提交验收，每验收批应由同一熔炼炉号、同一图号、同一投产批号、同一热处理炉批的锻件组成。

# 4.2.2 检验项目、取样数量和试样方法

# 4.2.3 锻件的复验和判定规则

4.2.3.1 当化学成分分析结果不合格时，允许重新取样对不合格元素进行重复分析，复验结果仍不合格，该批锻件判为不合格。

4.2.3.2 解剖件力学性能试验不合格时，允许取双倍数量的试样对该不合格项目进行复验。复验结果只要有一个试样不合格，则该批锻件判为不合格。试样环上力学性能试验不合格时，允许从受检试样上取双倍数量的试样对该不合格项目进行复验，复验结果中只要有一个试样不合格，则该锻件判为不合格。允许试样环不合格锻件单件报废（应在质量证明书上注明不合格原因），其他性能合格的锻件重新组批交付。若能确定是由于热处理不当造成的不合格，允许将受检试样件与锻件一起重新热处理一次，然后进行本规定的力学性能、高低倍组织和氢含量试验，合格后允许交货，并将两次试验结果填入质量证明书中。

4.2.3.3 锻件解剖件的低倍组织、高倍组织检验不合格时，该批锻件判为不合格。锻件试样环高倍组织检测不合格，该件锻件判为不合格。

4.2.3.4 超声波检验、X射线检验不合格时，根据不合格的具体情况判该批或该件锻件为不合格。若锻件缺陷部位经精确标定并在后续加工中可保证被彻底清除，则该锻件可视为合格，

4.2.3.5 尺寸、外形或外观质量检验不合格时，该锻件判为不合格。

# 4.3 检验方法

# 4.3.1 化学成分分析

化学成分分析按 GB/T 4698（所有部分）或 HB7716（所有部分）进行，仲裁按 GB/T 4698进行。

# 4.3.2室温拉伸

室温拉伸试验按 GB/T 228.1 进行。

# 4.3.3 冲击

室温冲击试验按GB/T 229进行，采用缺口深度为2mm的U型缺口试样。

# 4.3.4 硬度

布氏硬度试验按 GB/T 231.1 进行。

# 4.3.5 高温拉伸

高温拉伸试验按 GB/T 228.2 进行。

# 4.3.6 高温持久

高温持久试验按 GB/T 2039 或 HB 5150 进行。

# 4.3.7 热稳定性

热稳定性试验按 GB/T 228.1 进行。

# 4.3.8 低倍组织

低倍组织检验按 GB/T 5168 进行。

# 4.3.9 高倍组织

高倍组织检验按 GB/T 5168 进行。

# 4.3.10 形状和尺寸检验

锻件形状和尺寸检验应用相应精度的测量工具进行。

# 4.3.11 超声波检验

超声波检验按 HB20159 进行。

# 4.3.12 X射线检验

X射线检验按 GJB1187A进行。

# 4.3.13 β转变温度

β转变温度按HB6623进行。

# 4.3.14 表面质量

锻件表面质量检验采用目视进行。
