# K180-2项目喷管壳体毛坯技术要求

# 1 范围

本要求规定了喷管壳体毛坯原材料、加工制造、检验等方面的技术要求，适用于K108-2项目或K108-5项目喷管壳体毛坯制造。

# 3 技术要求

# 3.1 原材料

牌号：30CrMnSiA，符合GB/T 3077-2015相关要求。

# 3.2 加工要求

承制方应按照经双方签署确认后的工艺文件进行毛坯的制造，工艺过程包括但不限于加热、锻造、正火、高温回火、切取试件、理化检测、粗加工、超声波探伤等。毛坯应按批进行管理，每批应由同一金属冶炼炉原材料、同一锻造方法、同一热处理制度、同一热处理炉次的制备的毛坯组成。锻造毛坯应符合附图1要求。经粗加工后的毛坯外形尺寸应满足附图2要求，图中未注线性尺寸公差按GB/T1804-m执行，未注形位公差按GB/T1184-K执行。

# 3.4 低倍

符合GB/T 226-2015，横向酸浸试样上不允许有肉眼可见的白点、银亮斑点、缩孔、气泡、空洞、翻皮、裂纹、夹杂物等。

# 3.5 断口

符合GB 1814-79，断口不允许有白点、分层、石状断口、层状断口和萘状断口等缺陷。

# 3.6 超声波探伤

按照 GJB1580A 接触法进行探伤，应符合 A 级要求。

# 3.7 表面质量

粗加工后，表面不允许存在肉眼可见的裂纹、折叠等缺陷，允许有凹坑、压伤存在，其深度不超过1mm。必要时可使用5~10倍的放大镜进行目视检查。

# 5 交付状态

喷管壳体毛坯的交付状态应为“锻造+正火+高温回火+粗加工+超声波探伤”。毛坯应刻制标识，标识内容包括但不限于：顺序号、批号、生产年代号、承制方代号，标识应牢固可靠，字迹清晰，刻制位置、字体及大小由承制方自定。

每次进行交付时，承制方应按批提供理化检测试件，试件尺寸：30mm×30mm×120mm，试件应按附图1要求在本体上截取，提供的试样数量应不小于8件，试件应刻制与毛坯相同批次标识后同毛坯一并交付。

# 6 文件资料

承制方进行交付时，应按批提供相关纸质证明材料，包括但不限于：

（1）原材料原厂合格证。

（2）生产记录（包含锻造加热仪表记录、热处理仪表记录等）；

（3）化学成分、机械性能、硬度、低倍组织、断口检验或试验报告；允许承制方委托具有CNAS或CMA认证的第三方检测机构进行检测，但必须提供第三方检测机构的CNAS或CMA认证证书复印件。

（4）形状和尺寸（包含锻造毛坯和粗加工后的毛坯）、表面质量检验记录。

# 7 包装

产品应具有可靠包装，确保无淋雨、锈蚀等风险，保证运输及装卸过程无倾倒、滚落等风险。
