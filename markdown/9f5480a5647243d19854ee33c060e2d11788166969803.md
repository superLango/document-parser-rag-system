# 3、产品技术状态控制

甲方委托乙方进行201变形铝合金产品锻件制造工作，乙方严格按照产品定型图样及技术条件进行生产。技术状态不得随意变更。设计图样及技术要求变更时甲方应以书面形式通知乙方，乙方按通知要求及时进行更改。

# 4、制造要求

# 4.1 一般要求

乙方根据设计图样及本协议相关要求绘制锻造毛坯图，锻造毛坯图需经甲方会签方可用于生产，并提供给甲方一份。

4.2 乙方制订工艺方案后，由甲方参与进行工艺评审；经乙方制订工艺方案锻造的锻件经甲方试制合格，每种锻件首批生产及其主导工艺（包括毛坯选择、材料定额计算、影响锻件组织和性能的环节及热处理工艺

# 4.4 具体要求

# 4.4.2 组批规则

按设计图及标准规定的组批原则进行组批生产、交付及验收。每批组批数量不超过50件（不含解剖件）。

# 4.4.3 材料要求及提供方式

用于加工锻件的原材料由乙方提供。材料满足 5A06-GB/T 3191要求允许使用 5A06-GB/T 3190改锻为 5A06-GB/T 3191合格后使用。原材料具备相应有效的质量证明文件，投产前经乙方复验合格，方可进行锻件加工。乙方必须保证使过程不发生换料和错混料现象。锻件交付甲方前 100%进行分光（或光谱直读）检查。乙方交付锻件时提供化学成分检测试料，并注明。

# 4.4.4 锻件供应状态

锻件供应状态为O态（退火）状态交付。

# 4.4.5试料

锻件按标准规定提供甲方复验用试料，试料状态与产品一致，且按标准规定取自同批锻件，具体数量及取样部位见双方会签锻件图纸。

I类件每批100%取专用试料进行三向拉伸性能检测，专用试料双方各半，另外每批应至少有1个解剖件，用于验证产品一致性。解剖件检测内容包括：低倍、流线、力学性能（包括解剖规定的各部位力学性

# 4.4.6力学性能

锻件力学性能满足QJ502B2014标准规定检测三向力学性能，每个方向各至少包含2根试料，厚度小于70mm的锻件可不做高向力学性能。乙方将剩余的1/2复验料发甲方，由甲方进行入厂复验。具体各类锻件力学性能测试要求如下：

a) 锻件力学性能满足标准规定。锻件Ⅰ类锻件100%每件取横、纵、高三向拉伸力学测试，每个方向至少2根试料，同时每批按解剖图取1件解剖，解剖位置及数量见解剖图；

b）Ⅱ类锻件每批横、高、纵方向按解剖图取样位置进行检测，每个方向数量不少于2根，试料取试方向见双方会签图纸。

c）其他类锻件每批解剖1件锻件进行力学性能检测，具体见解剖图和数模。

# 4.4.8 表面质量

a) 锻件应经表面酸洗后交付。

b) 铝合金锻件表面不允许有肉眼可见的裂纹、分层、折叠和锻造引起的机械损伤等；非加工表面不允许有粗糙的暗斑和白斑，但允许有氧化色。

c) 锻件表面允许有凹坑、压伤存在，但其深度不得超过该尺寸下偏差的1/2的绝对值数值尺寸（尺寸长度单位同偏差）。

d) 锻件所有非加工表面上所有缺陷均应去除掉。去除深度不得超过该尺寸下偏差的1/2的绝对值数值尺寸（尺寸长度单位同偏差）。

e) 锻件表面质量满足超声波探伤要求；

f）乙方交付甲方后，甲方对锻件进行 100%进行荧光检测，乙方认可甲方检测结果。

# 4.4.9 显微组织

显微组织不允许有过烧。

# 4.4.10 低倍组织

每批抽1件检测低倍组织，低倍组织应是均匀的变形组织，不允许有裂纹、气孔、折叠、偏析集聚和非金属夹杂物等缺陷，低倍试样由乙方制好后同锻件产品一同交付甲方，具体要求如下：

a)每批抽1件解剖检测低倍组织，首批或工艺有重大变更时多投1件解剖件供需各半检测低倍流线，流线符合QJ502B2014要求。

b)低倍组织不允许有裂纹、气孔、折叠、偏析集聚和非金属夹杂物等缺陷。

# 4.6 质量履历记录要求
