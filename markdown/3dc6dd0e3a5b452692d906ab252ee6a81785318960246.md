# 水浸超声检测曲面修正方法

# 1  范围

本文件规定了在使用特定探头的条件下进行水浸超声纵波检测时采用修正值补偿进行曲面修正的 方法。

本文件适用于曲率半径不大于125mm的变形合金锻件及曲率半径不大于200mm的粉末高温合金盘锻 件凸面的曲面修正。

# 2  规范性引用文件

下列文件中的内容通过文中的规范性引用而构成本文件必不可少的条款。其中，注日期的引用文 件，仅该日期对应的版本适用于本文件；不注日期的引用文件，其最新版本（包括所有的修改单）适 用于本文件。

HB/Z 34  发动机盘件超声检测

AETM28  盘环件水浸超声检测

AETM144  粉末高温合金盘锻件超声分区聚焦检测

AETM772  锻件超声检测用水浸聚焦探头要求和测试方法
