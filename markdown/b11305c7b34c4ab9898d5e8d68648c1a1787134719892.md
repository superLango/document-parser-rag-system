# 3 技术要求

# 3.1 原材料

# 3.1.1 合格供应商

锻件用原材料生产单位应属于黎明公司的合格供应商：宝钛（902厂）、西部超导、湖南金天。供方应严格贯彻410JX（通用）-D-001中1.2.2条对锻件用原材料合格供应商的年限控制要求。

# 3.1.2 冶炼方法

<!-- page: 3 -->

合金采用真空自耗电弧炉熔炼方法生产，熔炼次数应不少于二次。最后一次熔炼稳定阶段的炉内压强应不大于 5Pa。所采用的冶炼方法应在合同和质量证明书中注明。

# 3.1.3 其他要求

锻件用原材料应符合Q/S10-0342-2004，原材料经复验合格后方可投产。

# 3.2 锻件

# 3.2.1 理化件选取和分配

每验收批锻件在相当于铸锭头部的锻件上设置加高试验环（20mm）作为理化件，试验环与同批锻件经过相同的热处理后切下，供货方在1/2试验环上完成出厂检验后，另1/2试验环打上相应标志随同批锻件发往订货方进行入厂理化检验。

# 3.2.2 理化检验项目

在试验环上按 Q/S10-0533-2004 要求进行化学成分、室温拉伸、硬度、 400℃拉伸、400℃持久和高低倍组织检验。

# 3.2.4 本体硬度检验

锻件逐件在交付图标记位置进行本体硬度检验，检验位置为圆周方向均布的4点。硬度值符合HB（d）≥3.3mm的要求，记录不同位置的实际硬度值并逐点在质量证明单中注明。交付的锻件表面应不带有硬度测试痕迹。

# 3.2.5 超声探伤要求

锻件逐件进行超声波检验，按 Q/S10-0105-2004 中的 A 级验收。

# 4. 锻件的控制与管理要求

4.1 供货方在锻件试制前应进行工艺方案评审；试制批锻件出、入厂检验及加工合格后，由订货方组织进行锻件质量评审。

4.2 锻件生产主导工艺应按 AETF324A 要求进行确认、认可和批准，并形成主导工艺控制卡，批准后主导工艺不能随意更改，其更改须按 AETF324A 要求履行相应程序。主导工艺的规定按照 AETF324A 中的定义及相关管理文件（如主导工艺控制卡）。

4.3 供货方锻件图纸和取样图纸应经过订货方和设计方会签方可用于生产。会签后供货方形成的正式图纸发往订货方存档。当供货方需对图纸更改时，应将更改单及改后的图纸发往订货方和设计方重新会签。

4.4 订货方对质量证明书内容进行确认。

4.5 锻件的工艺准备要求、特殊过程确认、关键过程、首件鉴定、对外协作、不合格品处理、现场跟产、产品验收等本协议未明确的具体规定按

YnG5-W0421《某型号项目供应商管理办法》的要求执行。不合格品管理按 S25.JT.Z0034《某型号发动机不合格品管理规定》的要求执行。质量信息管理按 S25.JT.Z0035《某型号发动机质量信息管理规定》的要求执行。工程验证机阶段的质量管理按 S25.JT.Z0037《某型发动机（工程验证机阶段）质量保证大纲》的要求执行。供应商质量管理按 SS002《供应商质量管理要求》的要求执行。
