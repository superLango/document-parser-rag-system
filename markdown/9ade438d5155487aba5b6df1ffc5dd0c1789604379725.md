# 1 主题内容和适用范围

本技术条件规定了4714联轴器产品34CrNi3Mo及40CrNiMoA锻件的技术要求、检验方法和验收规则。

# 3 制造

# 3.1 冶炼和浇注

3.1.1 锻件用钢应采用电炉冶炼，经需方同意也可以采用保证质量的其它方法冶炼。冶炼时应采取措施，使钢水中的气体含量尽可能低。

3.1.2 钢水在浇注时应进行真空除气或真空碳脱氧。

# 3.2 锻造

3.2.1 钢锭上部和下部均应有足够的切除量，以确保成品锻件无缩孔、疏松、严重的偏析和其他有害缺陷。

3.2.2 采用的锻造方法必须尽可能使整体锻件得到均匀的组织结构。锻压机应有足够的吨位，以使锻件的整个截面锻透。锻件的轴线应与钢锭的中心线大致重合。

# 3.2.3 锻件应有足够的锻造比。

<!-- page: 4 -->

# 3.3 热处理

3.3.1 锻后热处理为正火+回火处理，处理后按锻件供货图进行粗加工，并达到一定的粗糙度以保证进行无损探伤检测。

# 3.3.2性能热处理

锻件在第一次粗加工后进行性能热处理，性能热处理为调质，力学性能应符合表2规定。

# 3.3.3 去应力热处理

锻件在性能热处理后及随后的粗加工和打中心孔后，锻件应在低于最终回火温度15-20℃下去除应力，去应力处理保温后，锻件应随炉缓慢冷却。

# 3.4 机械加工

3.4.1 锻件在性能热处理之前，锻件的所有外表面进行第一次粗加工。

# 3.4.2 第二次机械加工

锻件在性能热处理之后去应力处理前进行第二次粗加工。

3.4.3 锻件去应力后加工至订货图样规定尺寸、公差和粗糙度要求。

3.4.4 供方在锻件制造和包装过程中不得进行焊接。

4.2.2 拉伸试验

拉伸试验按 GB/T228规定的方法进行。

# 4.2.3 冲击试验

冲击试验按 GB/T229规定的方法进行。

# 4.2.4 硬度检查

硬度试验按GB/T231.1规定的方法逐件进行布氏硬度检查。当试样同时做拉伸冲击和硬度试验时，其每点硬度值不作为验收依据，但应记录在合格证书中，报告用户。

规定如下：

1) 长度大于或等于1500mm的锻件在两端检查硬度，小于1500的锻件在中间部位检查；

2）外圆直径大于或等于600mm的圆形外表锻件在硬度检查部位外圆表面沿圆周相隔120度检查三点硬度，外圆直径小于600mm时任意测一点；

3）同一锻件上各点硬度差不得超过30个布氏硬度单位。

# 4.2.5 取样部位、方向和数量

锻件的力学性能试样的取样部位和方向按订货图样规定，且供方应为需方留有进行复验所需的试样。如无特殊要求，锻件应逐件进行性能检验，每件在本体取一套切向试样，小型棒类锻件取一套纵向试样。每套试样包含一个拉伸和三个冲击试样。

# 4.2.6 重复试验

当力学性能试验中任何一项不符合本技术条件要求时，应取双倍试样对不合格项目重新试验。但试验如有白点，锻件报废不得重试。

当重试结果仍不合格时，则该锻件应判别为不合格，允许对锻件重新热处理，但其淬火次数总计不得超过三次。

重新热处理的锻件应视为新的锻件做取样试验。

# 4.3 无损检验

# 4.3.1 一般要求

锻件应无裂纹、白点、缩孔折叠、严重的锭型偏析和非金属夹杂物偏聚等缺陷。

# 4.3.2 超声波检查

应按GB/T 6402对锻件进行超声波检验，应由具有二级以上证明的探伤人员进行。其验收标准如下：

a.当量直径 $ \phi 2 \mathrm{mm} $以下的单个分散缺陷可不计，但杂波幅度应低于当量直径 $ \phi 2 \mathrm{mm} $反射波波高的 50%。单个分散的缺陷定义：相邻两缺陷之间距离大于其中较大缺陷当量直径的5倍以上的缺陷；

b.当量直径大于或等于 $ \phi 2 \mathrm{mm} $的缺陷应记录其轴向、径向和切向位置，并报告需方；

c. 不允许有密集缺陷区存在；

d.不允许有当量直径大于或等于 $ \phi 5 $的缺陷存在。

# 4.4 金相检验

# 4.4.1 晶粒度

锻件按 GB/T6394 测定晶粒度，实际晶粒度不应粗于 4 级。

# 4.4.2 非金属夹杂物

非金属夹杂物检验按GB/T10561附录A图A1进行评定，锻件的A、

# 4.5 尺寸、公差和表面粗糙度检查

锻件的尺寸、公差和表面粗糙度应符合订货图样的规定。

# 5 验收及合格证书

5.1 按本技术条件所规定的各项要求对交货的锻件进行检查，经检查合格的锻件应予验收。

5.2 必要时可进行供需双方共检，供方应向需方验收人员提供必要的方便条件，以便需方人员进行现场工作。

5.3 需方在验收试验中或以后加工、试验中发现锻件不符合本技术条件和订货合同中规定的补充技术要求条款时，需方应及时通知供方，供方应对锻件质量负责，锻件是否可判定合格，最后由双方协商解决。

5.4 供方应向需方出具合格证书，其内容包括：

a.订货合同号；

b. 图样代号；

c. 熔炼炉号和熔炼方法；

d.热处理炉号

e.锻件号；

f.各项检查结果；

g. 各次热处理的实际温度，保温时间和冷却方法(热处理表盘)；

h.交货锻件的实际尺寸。

# 6 标志和包装

6.1 标志

供方应在交货的锻件上用钢印打印下列标志：

a.订货合同号；

b. 图样代号；

c.熔炼炉号；

d.锻件号。

6.2 包装

锻件应妥善包装，确保运输过程中无损伤丢失和混乱。对于已加工的内孔应采取措施，确保内孔表面不锈蚀。
