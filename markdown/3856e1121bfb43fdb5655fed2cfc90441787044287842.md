# 1 目的

为确保产品的超声波探伤检测的可靠性，由合格的超声波检测人员、使用合格的设备，并按规定的程序要求以及相应的验收准则进行评定，特制订本规程。

# 2. 适用范围

本规程适用于紧凑型聚变能实验装置（BEST）新一代屏蔽用高硼钢的超声波检验。

# 3 参考文件

本规程引用的以下标准和文件，凡是文件中注明版本的引用标准，仅所注版本适用于本技术条件。凡未注明版本的引用标准，为最新版本（包括所有的修改单）适用于本规程。

# 4 检验人员

超声检测人员应取得IS09712或甲方认可的标准取得资质等国家或行业认可的Ⅱ级或Ⅱ级以上资格证书，并在有效期内。Ⅱ级或Ⅱ级以上的检测人员才能编制检测规程，并签发报告、结果评定和解释检测结果；规程审核由Ⅲ级人员完成。

超声检测人员在检测时必须持有合格的资格证书，并且在订货方要求时能出示其证书。Ⅱ级或Ⅱ级以上的无损检验人员方可解释检测结果。

# 5 被检区域

全部覆盖工件的体积，工件形状尽可能避免检测盲区。

<!-- page: 4 -->

# 6 检验时机

超声波检测在最终热处理后的精加工状态进行，如精加工状态存在无法检测的盲区，可提前至半精加工状态检测。

# 7 表面处理

扫查面应无油漆、无疏松氧化皮、无干耦合介质及其它可能影响超声波在被检测件中传播、有碍探头自由移动、或引起判断误差(由于声波转换造成的干扰波)的表面杂质和不平整。除另有规定外，表面粗糙度Ra不得超过6.3μm。

# 8 设备和材料

# 8.1 仪器

采用A型脉冲反射式超声波探伤仪，可选用以下或其它符合ISO22232-1标准的超声波仪器。

型号：CTS-9002+，EPOCH650

设备需在以下情况时按照 EN 12668-1 来校验：

设备验收时；

修理后；

至少每年一次。

# 8.2 探头

超声波检验探头频率，应是锻件在规定的检测灵敏度下达到最佳信噪比。探头应符合ISO22232-2的规定。探头频率为0.5~6MHz，如果因为材料衰减原因也可使用频率较低的探头。晶片最大允许尺寸在10~40mm之间。检测近表面时，可采用双晶探头。

# 8.3 耦合剂

耦合剂（包括添加剂）应对受检材料无害，耦合介质的性能，在整个检验过程中必须保持稳定。检验结束后应将耦合剂从工件表面去除。对奥氏体和镍基合金材料，氟和氯含量的和不超过200ppm，硫含量不超过200ppm。耦合剂要有良好的润湿性，在标定和检测时要使用相同的耦合剂。

可采用CG-08或相同类型的专用耦合剂。

<!-- page: 5 -->

# 8.4 参考试块

# 8.4.1 参考试块的材料可以是

a) 被检部件的延长段；

b) 材料牌号和热处理状态与被检部件相同的余料；

c) 声学特性、晶料大小与被检部件相近的材料。

# 8.4.2 参考试块表面要求

参考试块的表面粗糙度应与被检部件相当，但不能优于被检件，否则应进行表面补偿。

# 9 操作技术

# 9.1 探头与仪器组合性能测试

探头与仪器组合性能测试应按照标准 NF EN12668-3 要求进行。

# 9.2 扫查覆盖

扫查应覆盖 100%的区域，且探头连续移动的重叠区不得小于 20%。

# 9.3 扫查速度

探头的移动速度不得超过 150mm/s。

# 9.4 扫查要求

锻件在两个互相垂直的面上进行 100%扫查，按 EN10228-4 表 21b 要求。

# 9.5 缺陷尺寸的测量

采用以下-6dB方法进行缺陷尺寸的测量：

<!-- page: 6 -->

探头从获得缺陷最大回波处开始沿两个相互垂直的方向移动，直到缺陷幅度下降6dB。这四个-6dB的位置确定了缺陷深度处缺陷的长度L和宽度1，这便是缺陷的标准尺寸（见图2）。对于圆钢缺陷的尺寸只能在轴线方向测定。

<!-- image: page 6 -->

*图2*

# 9.6 缺陷分类

缺陷的标准尺寸与缺陷深度处声束-6dB的宽度做比较。

当缺陷至少有一个标准尺寸大于等于缺陷深度处-6dB宽度时称为条形缺陷。

当缺陷的标准尺寸小于等于缺陷深度处-6dB宽度时称为点状缺陷。

当点状缺陷最大回波对应的空间距离大于 40mm 时，称为孤立点状缺陷。

当点状缺陷最大回波对应的空间距离小于等于 40mm 时，称为密集点状缺陷。

# 10 灵敏度的设置和校验

# 10.1 线性调节

直探头采用标准试块或上、下底面平行的工件来调节线性。

# 10.2 灵敏度调节

# 10.2.1 直射波检验

回波声压公式结合底面反射法（底波法），缺陷回波法进行实操计算，灵敏度校准，缺陷定量或采用 DGS 曲线进行探伤。

# 10.2.2 时基和灵敏度校核

在下列情况，应校验灵敏度：

工作开始和结束时；

操作人员怀疑有误差时；

<!-- page: 7 -->

每4个小时校验一次。

如果校验时测得的误差值≤2dB，则可认为该次检验结果为正常；如＞2dB，则在上次校验后，该次校验前所检验的所有工件都应进行复检。

# 10.3扫查要求

扫查前应编制详细的锻件扫查图（附录B），现场操作应严格按扫查图执行，扫查时，基准灵敏度的基础上提高6dB进行扫查。

# 10.4温度差

检验时，校验试块和检测表面间的温差应在 14℃之内。

# 12 检验记录和报告（报告模板见附录1）

检验记录和报告至少应包括以下内容：

a. 生产单位；

b. 被检工件名称、编号、规格、材质；

c. 检测设备：探伤仪、探头、试块；

d. 检测规范：技术等级、探头频率、和检测灵敏度；

e. 检测结果及质量分级、检测标准名称和验收等级；

f. 检测人员和审核人员签字及其技术资格；

g. 检测日期。
