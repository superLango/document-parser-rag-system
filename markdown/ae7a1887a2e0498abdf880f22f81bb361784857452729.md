# 一、目的

本技术条件规定了“紧凑型聚变能实验装置”（以下简称BEST）项目下屏蔽包层系统所采购的奥氏体不锈钢锻件316L(N)的技术规范与要求。

# 二、适用范围

适用于BEST项目包层中所使用的单个重量不超过10吨的316L(N)锻件。

# 四、制造工艺

为了满足本规范中对结构和夹杂物含量的要求，冶炼方法可采用真空感应+电渣的二次重熔的冶炼工艺来完成。也可以采用二次冶金处理氩氧脱碳（AOD）或真空氧脱碳（VOD）来完成。重熔过程应包括电渣重熔（ESR）或真空电弧重熔（VAR）

# 5.2 铁素体含量和磁导率

使用经 Pryce 和 Andrews 修改的 Schaeffler 图(图 RMC 1341.2, Section 3, RCC-MR 2007)评估铁素体含量应小于或等于 0.5%。

产品在退火后，在室温下测量其相对磁导率。测量值应低于或等于1.03。测试应按照ASTM A342进行。

另外，也允许使用磁导率仪(Foerster, Ferromaster等)。在这种情况下，设备的类型、商标和相关性(该材料、厚度、形状等)应由供应商提供。材料证书应提供其校准证书的类型、商标和副本。

# 5.3 结构

检测方向：沿锻造方向进行显微检查。结构必须是均匀的。

# 5.3.1 晶粒尺寸

根据EN ISO 643确定的晶粒尺寸等级应等于或大于3级。测定取样应紧挨力学测试取样位置。

# 5.3.2 非金属夹杂物

数量和定义应符合ASTM E45标准。

- 微观杂质(用显微检测方法检测的原生杂质)：适用方法 D。

-A、B、C、D类的等级数最多为2。

-宏观杂物(外源夹杂物，矿渣或耐火材料)：严格禁止。

测试样品应从每个锻件的一侧取样。

# 六、制造

# 6.1 制造方案

在开始制造之前，供应商应制定一份制造计划。该计划应包括以下内容：

- 熔炼工艺的确定；

- 铸造或锻造零件的图纸、热处理、无损检测和交货的轮廓图；

- 中间热处理和最终热处理对机械性能的条件；

- 验收试验样品在零件上的位置；

- 样品上试验样品的位置的尺寸图。

各种热处理、抽样和无损检测操作应按时间顺序进行。经采购方批准后方可生产。

# 6.2交货条件

# 6.2.1 固溶处理

固溶处理应包括保持温度在 1050°C和1150°C之间，然后进行水冷却。记录热循环，并在试验报告中提供相关记录。

# 6.2.2 表面条件

在交付状态下，表面应经机加工，金属表面不得留有任何油污或油脂的残留。

表面粗糙度Ra平均值应小于等于6.3μm。使用符合EN ISO 4288规范的粗糙度测量方法。

# 七、力学性能

# 7.1 要求

室温拉伸参考 EN ISO 6892-1:2009 进行，高温拉伸试验参考 EN ISO 6892-2:2011 进行。

测试记录数值应包括：

- 0.2%偏移时的屈服强度，单位为MPa

- 1%偏移时的屈服强度，单位为 MPa

- 抗拉强度，单位为 MPa

- 断裂后的延伸率百分比

- 断裂后面积的百分比减少

# 7.2 取样和测试

# 7.2.1 取样规则

a) 试样应在锻造后进行固溶热处理后进行取样。试样应从以下部分进行切割：锻件本身或从与零件整体连接的延伸部分或多余材料中

b) 按炉批规则取样。一批来自同一熔炼号、经过同一制造生产工艺、同炉热处理且尺寸相近的部件。

c) 样品应适当标记。测试样品的大小应足以提供足够的测试样品供所有测试和复试使用。

6

<!-- page: 7 -->

d) 测试样品应这样切割：使其轴线与主要锻造方向垂直，且轴线与最近处理表面(表面)之间的距离为：

如果厚度大于 40 毫米，则为 20 毫米；

如果厚度小于 40 毫米，则为厚度的二分之一。

e) 试样测试相关区域与其他处理表面之间的距离不得小于：

如果厚度大于40毫米，则为40毫米；

如果厚度小于40毫米，则为该厚度。

f) 如果零件的形状不允许这样做，应尽可能获得上述给定值。试验样品应具有圆形横截面。其正常直径应为10mm。对于小于20mm厚的锻件，圆柱形试验样品可由具有矩形横截面的样品代替。

# 7.2.2批次定义

批次的定义为同炉钢锭经同种工艺、同一热处理炉次生产的锻件（具有相近的几何外形、尺寸）。单件重量不大于1000kg的锻件可以组批，但每批总重不大于3000kg。特别的，每件用于屏蔽块本体的锻件均应单独组成一批。一个批次应包括直径d、厚度e和横截面S等，并按照以下定义：

$$```latex
d_{max}/d_{min} \leq 1.1 \quad e_{max}/e_{min} \leq 1.1 \quad S_{max}/S_{min} \leq 1.25
```$$

# 7.3 再处理

因一个或多个力学测试结果不达标（力学测试结果不达标不允许进行复测）而被拒绝的零件可以进行重新处理（根据6.2.1进行固溶热处理）。试验报告中应描述重新处理的条件。只允许进行一次重新处理。

# 八、表面检查

在生产和加工的所有阶段，应对表面进行彻底检查，以检查金属的完好性。

# 8.1 渗透检查

零件应完好无损，无氧化皮、无水垢、污渍、撕裂、划痕或其他有害缺陷。交货时需提交最终检查报告。

应按照EN10228-2的要求对每个板进行100%液体渗透检查。所有暴露在真空中的表面都必须使用经采购方书面批准的液体渗透剂。

# 九、体积检查

每个产品均应按照 EN 10228 第4部分进行 100%的超声波检测。验收标准根据厚度确定，应采用标准 EN 10228-4中定义的标准。用于结构应用的锻件采

用质量等级3。该检测应在零件形状允许进行满意检测的情况下进行。检测应按以下优先顺序执行：

在最终机加工之后；在为获得机械性能而进行热处理之后，无论是否随后进行机加工。零件的整个体积都应接受超声波检测。应按照标准EN10228-4第12.4节中定义的100%扫描覆盖范围进行检测。所考虑的厚度范围以及根据被检测零件厚度确定的验收标准，应采用标准EN10228-4中针对常规探头所定义的标准。其他锻件验收也按照该标准的3级执行。

# 十、去除不可接受区域

锻造厂可以通过研磨来消除表面缺陷，前提是保持零件的尺寸公差。

在研磨后，应进行液体渗透检验。检验标准应按照“八、表面检查”一章中规定的标准进行。

不得进行焊接修复。

# 十一、尺寸检测

尺寸应按照图纸的要求进行检查。主要尺寸应记录在案。测量值应在图纸上给出的公差范围内。

# 十二、标记

标记应通过压印或采购方指定的其他可接受的方式进行。

标记至少应包括：

-采购商名称或标志（JLYX）

-与质量记录相关的牌号或唯一识别号

-熔炼炉号或批号

-成品物料规格

-热处理炉号和件号

-合同号或订单号（提前联系需方要求）

提供对生产控制所需信息的文档的清晰参考的标记或代码是可接受的。随零件提供的样品应按照采购订单的规定进行标记。

另成品标记前供方应提前提供需方标记内容清单，经许可后方可进行标识
