# 4.4.2 性能热处理

锻件成品以固溶处理交货，固溶处理的加热温度为 1040℃~1070℃ 。保温 足够时间后，锻件应采用水淬或其它的冷却方式冷却到 260 ℃以下，冷却速率应 足以避免碳化物析出。

所有热处理的过程（包括热处理保温温度及其偏差、保温时间和冷却方法 等）应记录并列入质量证明文件。保温阶段的温差应不超过 ±10℃ 。

因进行热处理而产生的氧化皮，应用酸洗或其它适当的方法除掉。

温度的检测通过与锻件接触的热电偶进行，热电偶在锻件上位置及热处理 过程应记录并列入材料质量证明文件。

# 5 取样及理化检验

# 5.1 取样

试验用料应在交货状态的锻件上切取，切下的试料标明主加工方向并作标 记，取样只允许用机械加工方法。试料应具有足够的尺寸，以便截取全部试验 和可能进行的复试所需的试样。

由于锻件形状的限制，试样的轴线与主加工方向平行，即纵向取样。

硬度试验试样取自室温拉伸试样附近。

试样轴线到锻件热处理表面的距离为 20mm 。

试样有效部分到其他热处理表面的距离应≥ 40mm 。试样具体取样位置详见 附图。

应对每批锻件进行成品分析，成品分析试样应取自拉伸试样的相邻区域。

# 5.2 批次及理化项目

组批规则：一批中的所有锻件都应具有相近的尺寸，且均须来自同一熔炼炉 号、经受相同的形变过程并作为同一炉料中的一部分共装一炉进行热处理。

每批应不超过 10000kg 。

对于热处理单个重量≤ 2250kg 的锻件，每批做一组试验；单个重量＞ 2250kg 的锻件，每批中的每一个锻件应做一组试验。

# 5.4 重新热处理

# 6 机加工

锻件应在热处理前进行粗加工，使其符合本大纲 4.3 节所述锻件图规定的热 处理尺寸。热处理后进行半精加工和精加工。精加工后其尺寸和粗糙度应符合 订货文件和图纸的要求，且能够满足表面质量和无损检测的要求。

只允许采用机械加工方法分割锻件。

# 6.1 半精加工

锻件按 PK-ZL-NDT-UT-2601349 《超声波检验规程》中的要求，加工至半 精加工规定的尺寸及表面粗糙度。

# 6.2 精加工

半精加工探伤合格后，按采购图和采购合同的规定对锻件进行精加工。最 终机加工后的锻件进行无损检测。

锻件在精加工完成后，应按采购申请单尺寸及公差进行检验。锻件的尺寸 公差和表面粗糙度应满足采购图纸及合同规定。

# 7 表面质量和尺寸检验

在锻件制造的过程中，应非常仔细地检查锻件表面。机加工后的锻件表面 不允许有起鳞、裂纹、槽痕或其它有损于锻件使用的缺陷。

尺寸检查应按订货文件和图纸的要求进行，所有尺寸及允许偏差都应符合 订货文件和图纸的规定。

# 8 无损检测

# 8.1 目视检测

应对锻件的所有可见部位进行目视检测。

材料应完好，无氧化皮、裂纹、孔隙、夹砂或其他任何有害使用的缺陷。 材料的表面粗糙度，应满足无损检测的要求。

具体检验按 PK-ZL-NDT-VT-2601349 《目视检验规程》执行，检验规程应明 确需报批后方可实施。

# 8.2 渗透检测

交货锻件应进行 100% 面积的液体渗透检测。具体的无损检测方法和验收标 准按照《奥氏体不锈钢锻件无损检测技术条件》（ DFHM-NDE-V7-013-2023 ） 的规定执行。

具体检验按 PK-ZL-NDT-PT-2601349 《渗透检验规程》执行，检验规程应明 确需报批后方可实施。

# 8.3 超声波检测

交货锻件应进行 100% 体积的超声检测。具体的无损检测方法和验收标准按 照《奥氏体不锈钢锻件无损检测技术条件》（ DFHM-NDE-V7-013-2023 ）的规 定执行。

具体检验按 PK-ZL-NDT-UT-2601349 《超声波检验规程》执行，检验规程应

# 9 缺陷的清除和修补

表面质量检验发现的表面缺陷可用磨削或机加工方法进行清除，缺陷清除 后，锻件尺寸应符合订货文件和图纸的规定。磨具应为仅含碳化硅、氧化铝或 金刚石磨料的磨具，且磨具未使用过或此前仅在 300 系列不锈钢材料上使用 过。缺陷清除后，凹痕和周围表面应平滑过渡；缺陷清除区域应按《奥氏体不 锈钢锻件无损检测技术条件》（ DFHM-NDE-V7-013-2023 ）的规定进行液体渗 透重新检验。

清除缺陷后的材料尺寸仍应符合交货尺寸的规定。

锻件不允许进行任何补焊。

# 10 标识

锻件、存档材料（如有要求）和试料等应做出清晰可见的标记。在无损锻 件使用性能的前提下，交货锻件应至少标记以下内容：

1) 供应商名称或商标；

2) 材料牌号；

3) 熔炼炉号；

4) 热处理炉号、批号和锻件号；

5) 零件代号（如有）；

6) 合同号或订单号。
