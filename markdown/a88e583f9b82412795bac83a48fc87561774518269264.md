# 总则：

1、甲方：成都飞机工业（集团）有限责任公司

乙方：无锡派克新材料科技股份有限公司

2、本协议作为 FA飞机锻件经济合同的正式附件，在 FA飞机锻件经济合同签定（盖章）后正式生效。

3、本协议按照商务合同要求，由成都飞机工业（集团）有限责任公司与制造商无锡派克新材料科技股份有限公司直接签订。

4. 设计方为成都飞机设计研究所。

# 一、甲方的主要职责：

1、甲方负责向乙方提供锻件生产所需的设计依据，并将生产期间技术状态变更的更改依据及时传递给乙方，如由于零件数模更改未及时通知乙方更改相应锻件数模和毛坯图纸造成锻件、模具报废由甲方承担。

2. 甲方负责以书面《锻件协调更改信息传递单》（参见附件模板）的形式传递技术状态变更信息。

3. 甲方负责对乙方设计的锻件数模（3D）进行确认，并会签其锻件毛坯图纸（2D）。

4. 甲方有权对乙方提供的锻件或粗加工件的外观质量、尺寸及公差、理化性能和超声波探伤进行入厂复验。

5、甲方、设计方有权全程参与乙方锻件试制过程控制与鉴定，以确保锻件满足工程设计的要求。

6、甲方应将锻件的理化性能复验结果、试加工结论，并结合乙方的试制鉴定报告，发出锻件固化工艺的综合结论，并及时以书面形式（锻件试制鉴定书）传递给乙方。

7、甲方、设计方根据乙方生产情况，派出跟产人员负责协调处理乙方生产中出现的问题、监督乙方对制造依据的执行情况，并负责解答甲方、设计方所提供文件的疑问。

<!-- page: 3 -->

8、对关键件、重要件的锻件，甲方、设计方及甲方、设计方的顾客方代表有进入乙方进行现场记录和工作的权利，包括派出常驻或流动的质量验收代表。

c. 锻件数量、供应（交付）状态；

# 三、技术要求：

1、钢锻件用原材料技术要求：原材料棒材45A、30CrMnSiA应符合技术规范 GJB1951-94《航空用优质结构钢棒规范》；附件表1中45钢采用45A钢代替。棒材应逐支进行超声波探伤检测，且应符合GB/T4162中A级要求。棒材应为无发纹电渣钢棒。

2、钛锻件用原材料技术要求：原材料棒材棒材TC4应符合技术规范GJB1538-92（≤Φ150mm）《航空结构件用钛合金棒材规范》、XJ-CL-4B（Φ210mm）《飞机鸭翼转轴梁用TC4钛合金棒材技术条件》；棒材应逐支按相应规范的要求进行超声波探伤检测，合格棒材用于锻件生产。

3、钢锻件技术要求：材料为 30CrMnSiA 钢锻件按HB5024-89《航空用钢锻件》标准进行制造与验收，45A 钢锻件按GJB5040-2001《航空用钢锻件规范》标准进行制造与验收。

4. 钛锻件技术要求：材料为 TC4 的钛锻件按技术条件（规范）ZZQB903-017《TC4钛合金锻件技术规范》进行制造与验收。

5. 锻件的供应（交付）状态按表1执行。

6. 锻件的外形、尺寸及公差等具体要求按会签的锻件毛坯图纸执行。

7、I、II、III类锻件理化试验用解剖件的抽取数量要求按附件表1进行；对I类锻件应逐件（含解剖件）在锻件所带专用试料上进行理化试验。具体的取样检验项目及其试样切取位置、数量按甲方、设计方会签的锻件毛坯图纸中的理化取样

# 9、超声波探伤：

9.1、钢模锻件及钛合金锻件的超声波探伤由甲方在锻件粗加工后按产品图（数模）的规定进行，乙方认可甲方的探伤结果。若有疑义，甲、乙双方协商。

9.2、钢自由锻件的超声波探伤由乙方粗加工后按锻件毛坯图纸的要求进行（如有需求）。

# 10、锻件组批：

10.1、钢锻件组批：按同一锻件图号（或代号）、同一熔炼炉号（子炉号）、同一投产批号组批。锻件应成批提交验收。

10.2、钛锻件组批：按同一熔炼炉批棒材、同一生产批、同一热处理批、同一图号（或代号）的锻件组批。锻件应成批提交验收。

10.3、对于完全对称的左、右件，若采用同一熔炼号的材料，在同一生产周期制造，工艺完全一致，且属同一热处理炉批（次），允许按同一锻件图号处理，组成同一批提交验收，理化试验解剖件只抽左件，但质量证明书（合格证）应分别协具。

# 11、组批数量

原则上不得低于附件表1中的最小组批数量。

# 12、锻件标记

按锻件毛坯图纸指定位置打上印记（钢印、气动打标或激光标刻，字迹应清晰可见）。

12.1、钢锻件：印记内容至少包含锻件图号和代号、热处理炉批号、投产（生产）批号、熔炼炉号（子炉号）、材料牌号、流线（纤维）方向（对于自由锻件以及模锻件流线为关键特性的应用油漆笔或采用钢印等方式注明锻件的流线（纤维）方向）、承制单位检印。

12.2、钛锻件：印记内容至少包含锻件图号和代号、热处理炉批号、投产（生产）批号、熔炼炉号（子炉号）、材料牌号、锭节号或顺序号（Ⅱ类锻件）、流线（纤维）方向（对于自由锻件以及模锻件流线为关键特性的应用油漆笔或采用钢印等方式注明锻件的流线（纤维）方向）、承制单位检印。

# 12.3、标记深度应≤0.2mm。

16、锻件的生产工艺停产超过1年（从上一批甲方同材料锻件锻造生产结束之日开始计算）则需重新进行技术认证，技术认证形式按甲方技术部门及设计方要求进行，完成技术认证后才能重新启动锻件批量生产及交付。
