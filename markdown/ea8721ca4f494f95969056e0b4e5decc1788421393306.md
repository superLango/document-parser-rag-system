# 4.4 交货状态和热处理

锻件的热处理应在温度受到监测和温度已校准的炉内进行。

锻件应在粗加工后进行淬火加回火处理，并以淬火加回火处理状态交货：

——奥氏体化温度应在 850℃ 和 925℃ 之间；

——水淬；

——为达到性能要求，选择在 635℃~665℃ 之间某一名义温度 下保温进行 回火，随后在静止空气中冷却。选择的名义温度加上最大允许偏差不得低于 635℃ ；

# 4.4.3 试料的模拟焊后热处理

锻件完成淬火加回火处理后，应按 5.1 节所述取样位置切取模焊试料，并对 模焊试料进行模拟焊后热处理。试料模拟焊后热处理制度为：

—— 400℃ 以上，升温和冷却速率： ≤55℃/h ；

——保温温度： 615±5℃ ；

——保温时间：至少 16h 。

试料进炉时，炉温应不超过 400℃ 。

模拟焊后热处理记录应列入质量证明文件。模拟焊后热处理记录应包括热 处理保温温度、保温时间、加热和冷却速率等。

# 6 机加工

锻件热处理后需进行半精加工及半精加工探伤，半精加工探伤结束后进行 精加工。

# 6.1 半精加工

锻件按 PK-ZL-NDT-UT-2410041-1 《超声波检验规程》中的要求，加工至半 精加工规定的尺寸及表面粗糙度。

# 6.2 精加工

<!-- page: 18 -->

半精加工探伤合格后，按采购图和采购合同的规定对锻件进行精加工。最 终机加工后的锻件进行无损检测。

锻件在精加工完成后，应按采购申请单尺寸及公差进行检验。锻件的尺寸 公差和表面粗糙度应满足采购图纸及合同规定。

# 7 表面质量和尺寸检验

# 7.1 表面质量检验

在锻件的制造过程中，应检查锻件的所有表面。最终机加工后的锻件表面 不允许有起鳞、裂纹、槽痕或其它有损于锻件使用的缺陷。

# 7.2 尺寸检验

最终机加工后，锻件的尺寸和外形应符合订货文件和图纸的规定。

# 8 无损检测

# 8.1 目视检测

机加工后的锻件表面不允许有起鳞、裂纹、槽痕或其它有损于锻件使用的 缺陷。

精加工完成后，锻件应按《目视检验规程》中的要求对锻件进行表面质量 检查。具体检验按 PK-ZL-NDT-VT-2410041-1 《目视检验规程》执行。

# 8.2 超声检测

给水接管应在淬火加回火处理等所有后续热处理结束并经过半精加工后及 精加工后进行超声检测（覆盖 100% 体积）相关检测方法和验收标准应符合 《 ZHX44300018100B44DS 蒸汽发生器给水接管、人孔座、水平支承连接板用 18MND5 锻件采购规程》中表7 的规定。

缺陷部位的清除应按照 RCC-M M2119 第 8 章的要求进行。

打磨缺陷后对零件表面进行磁粉检验，试验方法按照 RCC-MMC5000 要求， 验收标准如下 :

1) 尺寸大于或等于 1mm 的任一缺陷应予以记录。

2) 以下情况缺陷锻件应予拒收：

——线性显示 ;

——边缘间距小于 3mm 的 3 个或 3 个以上排成行的显示，或边缘间距 3mm 到 6mm ，其分布长度大于 15mm 的显示。

若两个临近缺陷显示的间距小于较小缺陷显示长度的两倍，则把这两个显 示看作一个显示。总的显示长度应为两个长度之和加上两个显示的间距。

若缺陷位于磁粉不可达区域，可用液体渗透检验代替，试验方法按照 RCC- M MC4000 要求，验收标准如下：

1) 尺寸大于或等于 1mm 的任一缺陷应予以记录。

2) 以下情况缺陷锻件应予拒收 :

——线性显示 ;

——尺寸超过 2mm 的圆形显示 ;

——边缘间距小于 3mm 的 3 个或 3 个以上排成行的显示 ;

——在 100cm 2 的矩形区域内有 5 个或 5 个以上的密集显示。该矩形长边不 大于 20cm ，且位于缺陷评定最严重的部位。
