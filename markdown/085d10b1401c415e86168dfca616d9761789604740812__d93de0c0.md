# 1. 主题内容和适用范围

本技术条件规定了4714产品钛合金（TC4）自由锻件的技术要求。本技术条件适用钛合金（TC4）自由锻件的制造与验收。

# 2. 品种及供货状态

2.1 锻件的外形尺寸及允许偏差应符合需方提供的锻件订货图要求。

2.2 供应状态：固溶+时效处理，表面应机械加工，其光洁度应符合超声波探伤的要求。

3. 引用标准

# 3. 引用标准

3.3 GB/T 229-2007《金属材料夏比摆锤冲击试验方法》

4.1 合金采用真空自耗电弧炉熔炼，熔炼次数不少于两次。

4.5 锻件表面不允许有裂纹，折迭等缺陷，对上述局部缺陷在不影响零件实体尺寸的前提下允许用打磨方法清理。

4.6 锻件最终应在 $ \alpha+\beta $区锻造，经热处理后其纵剖面上的流线、宏观组织和显微组织应符合下列规定：

4.6.1 锻件的流线按中心呈放射状。

4.6.2 不允许有裂纹、气孔、夹杂、偏析及其它冶金缺陷。

4.6.3 宏观组织按 HB5224-1982《航空发动机盘用 TC4 钛合金模锻件》中图1“TC4钛合金宏观组织分类评级图”评定，锻件应不大于4级（宏观组织腐蚀剂：5%HF，20%HNO3，75%H2O）。

4.6.4 显微组织按HB5224-1982《航空发动机盘用TC4钛合金模锻件》中图2“TC4钛合金显微组织分类评级图”评定，锻件应不大于5级。

4.7锻件应逐个进行超声波探伤，超声波探伤方法和标准锻件按HB/Z37-82《变形钛合金圆饼及盘件超声波检验说明书》（或GB/T5193-2007《钛及钛合金加工产品超声波探伤》中AA级进行验收）。

4.8 锻件应提供 $ \alpha+\beta/\beta $相变温度，并在合格证上注明。

5. 验收规则和试验方法

5.1 锻件要逐个进行外形尺寸和表面质量的检查。

5.2锻件由供方检验，并保证产品质量符合本标准要求，且供方应为需方留有进行复验所需的试样毛坯，试样应与锻件本体相连。

5.2.1锻件要逐件进行性能检验，检查本标准第4.4、4.6和4.7条规定的项目。力学性能试样在每件零件毛坯轮缘部位取切向试样，每项性能取两个。

5.2.2 在锻件试环上每隔120°打一点硬度，总计3点。

5.3 力学性能试验方法

室温拉伸试验按 GB/T 228-2002 进行

室温冲击试验按 GB/T 229-2007 进行

室温硬度试验按 GB/T 231-2002 进行

5.4化学分析方法按GB/T 4698-1996进行。

5.5 重复试验

# 5.5重复试验

5.5.1 第一次试验结果有一项力学性能不合格时，如果这不是由于冶金缺陷或热处理不当造成的，则应在原受检件上对不合格项目重取双倍试样进行重复试验，结果仍有一个试样不合格时，则该锻件应报废。

5.5.2 若能确定力学性能不合格是由于热处理不当造成的，则允许供方重复热处理一次，重复热处理后应重新检验各项力学性能和显微组织。

5.5.3 重复试验合格的锻件，第一次试验的结果必须同时填入合格证。

5.6 已检验合格的锻件，在随后的加工和使用的任何阶段，如发现为本技术条件不允许的冶金来源的缺陷时，供方应负责退换。

5.7 需方如发现复验结果与本标准不符时，应在收到锻件的8个月内向供方提出，由供需双方协商解决。

6. 标志、合格证、包装和运输

6.1 每个锻件均应打上合金牌号、锻件号、熔炼炉号、锭节号、锻造批次和承制厂检验印记。

6.2 每批锻件应附有合格证、化学成分、力学性能、超声波探伤、高低倍组织检查报告，写明承制单位、批号、熔炼炉号、锻造批次、锻件名称（或锻件号）、数量、质量、合金牌号、供应状态、本标准号及各项试验结果。

6.3 包装、运输、保管按 GB/T 8180-2007 执行。
