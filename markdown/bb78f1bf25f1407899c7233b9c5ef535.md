# 20CrMnTiH棒材订货技术协议

# 1 范围

本协议规定了20CrMnTiH棒材的技术要求和质量要求等。

本要求适用于供无锡派克新材料科技股份有限公司20CrMnTiH棒材，要求规定了棒材的尺寸、外形、重量及允许偏差、技术要求、试验方法、检验规则、包装、标志和质量证明书等。

# 2 引用标准

下列文件中的条款通过本标准引用而成为本标准条款，凡是不注明日期引用文件，其最新版本适用于本技术标准。

GB/T3077 合金结构钢

GB/T10561钢中非金属夹杂物含量的测定标准评级图显微检验法

GB/T6394金属平均晶粒度测定方法

GB/T702热轧钢棒尺寸、外形、重量及允许偏差

GB/T2101型钢验收、包装、标志及质量证明书的一般规定

GB/T17505 钢及钢产品交货一般技术要求

GB/T 4162 锻轧钢棒超声检测方法

GB/T 34474-2025 钢中带状组织的评定方法

# 1. 尺寸、外形及允许偏差

# 1.1. 寸及允许偏差

钢材直径尺寸在订单合同中注明，允许偏差应满足GB/T702中2组规定；棒材的不圆度按照GB/T702标准的规定。

# 2.7. 高倍组织：

2.7. 高倍组织：

不得有过热过烧组织，带状组织<2级（按GB/T 34474-2025评定），晶粒度≥6级（按照DIN50601检测）。

# 2.8. 超声探伤

钢材应100%进行超声探伤，不得有白点、气孔、缩孔、裂纹、折叠、夹杂残留物等缺陷，按GB/T 4162 A级检测和验收。

若原材料表面状态无法探伤，需保证我司改锻后成品符合 GB/T 4162 A级要求。

# 3. 检验规则

# 3.1. 验与验收

钢材出厂的检查和验收由供方质量技术监督部门执行。

# 3.2. 组批规则

钢材应按批检查和验收，每批由同一牌号、同一熔炼炉号、同一加工方法、同一尺寸、同一交货状态、同一热处理炉次的钢材组成。

# 3.3. 复验与判定规则

圆钢的复验与判定规则应符合GB/T17505标准要求。

# 4. 包装、标志和质量证明书

钢材的包装、标志和质量证明书应符合GB/T2101的规定。

# 4.1. 责任和义务

本协议各方未经允许，不得向第三方透露。

其它未尽事宜执行YB/T2011和GB/T3077。
