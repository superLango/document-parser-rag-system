# 前 言

根据 KWS17 发动机研制要求，参照 D-WS17 发动机型号标准 Q/017.2406-2013 《 TC8-1 合金转接环锻件技术条件（暂行）》、《钛合金在俄罗斯飞机及航空航天上的应用》而编制。

本标准与 Q/017.2406-2013 主要技术指标区别在于：

1) 室温力学性能指标变更为 R m ： 980MPa~1180MPa ， R P0.2 ≥ 875MPa ， A ≥ 10% ， Z ≥ 25% ；

2) 500 ℃力学性能指标变更为： R m ≥ 620MPa ， A ≥ 10% ， Z ≥ 25% ；

3) 增加 250 ℃力学性能指标： R m ：实测（≥ 750MPa ）， R P0.2 ：实测（≥ 638MPa ）， A ≥ 10% ， Z ≥ 25% ；

4) 热暴露试验后，室温力学性能指标变更为： R m ：980MPa ~ 1180MPa， R P0.2 ≥ 875MPa ， A ≥ 10% ， Z ≥ 25% ；

本标准由 KWS17 发动机总设计师单位中国航发贵阳发动机设计研究所归口。

本标准主要起草单位：中国航发贵阳所、黎阳。

本标准主要起草人：尹翔、张安琴、罗文飞、林筠、李昌。

本标准首次发布。

# TC8-1 合金转接环锻件技术条件

# 1 范围

本标准规定了TC8-1 钛合金转接环锻件的要求、试验方法、质量保证规定、交货准备 和说明事项。

本标准适用于航空发动机转接环、封严篦齿环用TC8-1 钛合金环锻件的订货与验收。

锻件用合金采用三次真空自耗电弧炉熔炼。锻件用棒材应符合Q/S17.1902 的规定， 棒材应经复验合格后方可投产使用。

# 3.3 交货状态

3.3.1 锻件应经热处理后交货，其热处理制度为：双重退火（920℃～950℃）±10℃， 保温1h～2h 后空冷；（570℃～600℃）±10℃，保温1h～2h 后空冷。

3.3.2 锻件热处理前应采用碱爆+酸洗或化学铣削工艺清除表面氧化皮、润滑剂残留物和 硬化层，经需方同意，也可采用吹砂。

# 3.5 低倍组织

3.5.1 锻件的低倍组织应符合GJB 2218A-2018 图1 中的1 级～5 级。

3.5.2 不允许有目视可见的裂纹、偏析、分层、空洞、金属和非金属夹杂等冶金缺陷。 当有质疑时，选1 件做高倍检查，其结果符合3.6 时，视为合格。

# 3.6 高倍组织

锻件显微组织应符合GJB 2218A-2018 图3 中的1 级～6 级。

# 3.7 超声波检验

锻件经粗加工后应进行超声波检查，按GB/T 5193 A1 级。

# 3.8 形状、尺寸

锻件的形状和尺寸应满足锻件图样的要求。

# 3.9 外观质量

3.9.1 锻件表面上不允许有过烧裂纹或影响材质的其它缺陷存在，发现后锻件应予报废。

3.9.2 粗加工后供应的锻件表面应洁净、无目视可见的裂纹、分层和外来夹杂，允许有 个别细小的压痕、局部黑皮、凸起、压坑和擦伤缺陷，其深度不超过实际加工余量的二分 之一。环形件的表面粗糙度Ra 值不大于3.2μm。

# 3.10 腐蚀检验

半成品应100%进行腐蚀检验，不允许有目视可见的裂纹、折叠、夹杂、缩孔、气孔 及其他冶金缺陷，允许用10 倍放大镜检查，当有异议时，检查高倍组织，其结果符合3.6 时，视为合格。

# 4 质量保证规定

# 4.1 检验分类

本标准规定的检验为质量一致性检验。

# 4.2 质量一致性检验

# 4.2.1 组批规则

锻件应按批提交验收，每验收批应由同一图号、同一熔炼炉号、同一投产批号、同一 制造方法和同一热处理炉批的锻件组成。最终热处理状态供应的Ⅱ类锻件，还应由同一热 处理炉次的锻件组成。

锻件应按批提交验收，每验收批应由同一图号、同一熔炼炉号、同一投产批号、同一 制造方法和同一热处理炉批的锻件组成。最终热处理状态供应的Ⅱ类锻件，还应由同一热 处理炉次的锻件组成。

# 4.2.2 检验项目

4.2.2.1 质量一致性检验项目、取样数量以及相应要求和检验方法的章条号应符合表3 的规定。

4.2.2.2 锻件的取样部位按锻件图样或专用技术文件的规定。

# 4.2.3 判定与复验规则

4.2.3.1 化学成分分析结果不合格时，允许重复取样对不合格元素进行复验，复验结果 仍不合格时，该批判为不合格。

4.2.3.2 力学性能检验结果不合格时，允许在同一试验件上切取双倍数量的试样对不合 格项目进行复验；复验结果仍不合格时，允许在本标准规定的范围内重复热处理后重新提 交验收；若仍不合格，该批锻件判为不合格。重复热处理仅允许进行一次。

4.2.3.3 低倍组织、高倍组织检验结果不合格时，该批锻件判为不合格。

4.2.3.4 锻件的形状、尺寸和外观质量不合格时，该件不合格。

# 4.3 检验方法

# 4.3.1 化学成分分析

化学成分分析按GB/T 4698（所有部分）进行。供方可按原材料的分析结果报出化学 成分。

# 4.3.2 硬度试验

布氏硬度试验按GB/T 231.1 进行。

# 4.3.3 室温拉伸试验

室温拉伸试验按GB/T 228.1 进行。

# 4.3.4 室温冲击试验

室温冲击试验按GB/T 229 进行。

# 4.3.5 高温拉伸试验

高温拉伸试验按GB/T 228.2 进行。

# 4.3.6 高温持久试验

高温持久试验按GB/T 2039 进行。

# 4.3.7 热稳定试验

热稳定试验按GB/T 228.1 进行。

# 4.3.8 低倍组织检验

低倍组织检验按GB/T 5168 进行。

高倍组织检验按GB/T 5168 进行。

# 4.3.10 超声波检验

超声波检验按GB/T 5193 进行。

# 4.3.11 形状、尺寸检验

形状、尺寸采用适宜精度的测量工具进行测量。

# 4.3.12 外观质量检验

锻件外观质量采用目视进行。

# 4.3.13 腐蚀检验

半成品零件腐蚀检验和氢含量检验按专用技术文件进行。

# 5 交货准备

# 5.1 包装、运输和贮存

锻件的包装、运输和贮存等按GB/T 8180 规定进行。

# 5.2 标志

每个锻件上应标印合金牌号、熔炼炉号、锻件图号和热处理炉批号，按锭节号管理时， 还应标刻锭节号。

# 5.3 质量证明书

每批锻件应附有供方质量检验部门签发的质量证明书，其上注明：

a) 供方名称；

b) 需方名称；

c) 合同号、本标准号；

d) 锻件图号或代号、锻件名称、材料牌号、类别、交货状态和热处理制度；

e) 原材料产地、冶炼方法、熔炼炉号、锻件投产批号或代号、最终热处理炉批号、 数量；

f) 本标准和合同协议所规定各项目的检验结果和结论(如重复试验还应包括各次检 验结果)；

g) 质量监督部门印记；

h) 包装日期。
