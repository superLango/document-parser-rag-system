# 前 言

本文件按照GB/T1.1-2020《标准化工作导则 第1部分：标准化文件的结构和起草规则》的规定起草。

本文件依据 GB/T 11821 《照片档案管理规范》、GB/T 11822 《科学技术档案案卷构成的一般要求》、GB/T 18894 《电子文件归档与电子档案管理规范》、EJ/T 1225 《核电文件档案管理要求》并结合公司实际情况制定的。

本文件对核电设备、部件、零件或原材在采购阶段的竣工文件的编制及提交均进行了相应规定。

本文件自实施之日起，核电产品的原材料（包括成品及半成品）的采购须将本文件在分包合同或技术协议中加以引用。

本文件由东方电气集团东方锅炉股份有限公司技术创新中心协同创新管理部提出并归口。

本文件起草部门：东方电气集团东方锅炉股份有限公司质量检验部。

本文为首次发布。

# 3 竣工文件编制

# 3.1 竣工文件的作用

竣工文件是设备制造的过程文件、记录、报告，是设备质量控制的追溯文件，可以作为设备在安装、调试、在役或退役过程中的被查资料。

# 3.2 竣工文件的编制

凡采购合同中规定需要提交竣工文件的原材料或零部件，供应商均需按照此标准编制竣工文件，并提交采购方进行审查。竣工文件应主要包括原材料的采购、制造、检验、试验和返修等活动产生的相关质量证明。

供应商在设备制造过程中须重视竣工文件的收集与归档，保证编制的竣工文件内容真实、完整、准确，字迹清晰可读，具有可追溯性，编制格式统一，便于检索查阅。

文件的载体和书写材料应符合耐久性的要求，不能使用易褪色的书写材料（如热敏纸、铅笔、圆珠笔、红墨水、纯蓝墨水、复写纸等），不得使用修正带或涂改液。

文件中若存在图片（包括报告中使用的图片）必须使用彩色打印。

文件不能涂改，确因需要修改时应采用杠改，并由供应商相关责任人签名确认，并注明日期。

文件应在左边（纵向打印）或上边（横向打印）留足足够的装订空间，幅面大于A4尺寸的文件材料统一折叠成A4尺寸，图纸以手风琴风箱式折

<!-- page: 5 -->

叠，标题栏露在右下脚；幅面小于A4尺寸的文件材料应粘贴在A4纸上，若该文件材料背面有内容，须保证背面内容清晰可读具有可复制性。

对于能够明确区分所属机组的设备，应以机组为单位编制竣工文件，例如：某项目下的某设备明确分别属于1号和2号机组，则应按照1、2号机组分别编制竣工文件。

原则上，供应商应向采购方提交竣工文件原件，如存在复印件，须在符合性声明中承诺复印件与原件的内容一致，且复印件必须清晰可读具有可复制性，并在每页复印件空白处上加盖提供复印件单位有效印章（公章、质保章、质检章）或档案证明专用章。

对于竣工文件中的检验试验报告、记录等，供应商应填写规范，明确结论是否合格（如适用），对于不适用的签字栏、盖章栏及空白栏等应划线（斜杠杠除），不得空缺。

# 3.3 竣工文件的结构

每份竣工文件由封面、目录及内容构成。供应商在每份竣工文件中建立目录，文件目录细化到页码。

竣工文件中的文件按目录顺序编制，文件一般应按质量计划中工序顺序放置；若无质量计划时，按照生产时间先后顺序排列放置。

# 3.5 竣工文件的整理

<!-- page: 8 -->

竣工文件收集完整后，为便于后续的装订、查阅和保管，文件的厚度不宜超过4cm；竣工文件太厚应进行分卷，分卷后应确保各卷封面页卷标的正确性。例如：一份竣工文件分成3卷，则各卷封面页的卷标分别为1/3、2/3、3/3。须提前完成分卷，以便质量监督人员审查。分卷后应对各卷的每一页（包括封面页）从1（或001）开始编页号，各卷不能连续编页号，每卷中的页号不重号、不断号。对于材料厂家竣工文件页码要求打在中间；对于东方锅炉提供给客户的竣工文件单面文件页号打印在右石下角，双面文件正面页号打印在右下角，背面页号打印在左下角。

# 3.6 竣工文件的审查

设备、零部件（包括原材料）发运前，供应商应确保相应的竣工文件已经完成，在分批次或分儿段发运的情况下，应确保竣工文件中适用部分己完成，提交经供应商编审批的竣工文件并通知设点方质量监督人员审查。只有在得到质量监督人员审查认可后，供应商方可启动设备发运。

质量监督人员应按照合同及本标准的规定对竣工文件的格式及内容的完整性和符合性进行审查，发现问题应及时督促供应商纠正，审查无意见后在竣工文件中质量计划页签署姓名日期，若无质量计划则在竣工文件封面签署姓名日期。质量监督人员的审查盖章不代表最终文档验收，对文档验收过程中发现的问题，供应商应积极配合整改，原则上在收到问题一个月内完成整改，或每月反馈整改进展直至完成整改。

# 3.7 竣工文件的扫描

竣工文件经质量监督人员审查认后，须按卷彩色扫描制作成PDF格式的电子文件。扫描电子文件应字迹清晰可读，与纸质文件的页数和内容完全一致，不缺页；扫描后的文件应旋转至正常方向，保证能正常阅读；无视觉上的偏斜，无明显的黑边、黑线、黑点，扫描分辨率为400dpi（照片扫描按照3.4中相关要求）。

# 3.8 竣工文件的提交

竣工文件、射线底片（若有）、影像文件（若有）在设备、零部件（原材料）发运时同时提交。
