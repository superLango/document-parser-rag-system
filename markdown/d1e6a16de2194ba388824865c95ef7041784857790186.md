# 主题：关于进一步加强核电“四新”供方质量管控的通知

为进一步加强对核电“四新”供方质量管控，明确相关部门职责及质量管控要求， 特制定本通知。具体要求如下：

# 一、核电“四新”供方管控范围

本通知适用于公司核电“四新”供方质量管控，管控范围为核岛设备的核质保级 物项和服务（不包括第三方复验及理化试验外委等服务）以及常规岛设备本体的承压 零部件（包括整体扩散部件）。

# 二、定义

“四新”供方指“新供方”、“新产品”、“新材料”、“新工艺”，具体解释 如下：

（ 1 ）“新供方”：指为公司核电项目首次供货的供方；或曾供过货，但供货已中 断 3 年以上重新供货的供方。

（ 2 ）“新产品”：指成熟供方首次提供自身此前未为公司供货过的物项或服务的 情况。

（ 3 ）“新材料”：核岛设备指公司首次使用的材料或零部件，包括材料牌号变化 或原材料技术条件中关键参数发生重大变化等情况。常规岛设备指公司首次使用的材 料和零部件，包括材料牌号和标准变化。

（ 4 ）“新工艺”：核岛设备指对前期已有加工经验的同一或同类物项，外委供方 制造加工工艺方法发生重大变化，或原材料和零部件供方制造加工工艺发生重大变化 的情况。常规岛设备指对前期已有加工经验的同一或同类物项，外委供方和扩散供方 制造加工工艺方法发生重大变化。

# 四、“四新”供方的识别及信息传递

# 4.1 识别

# 4.1.1 核岛设备“四新”供方识别

对于材料和零部件“四新”供方识别，由核电装备事业部技术人员在编制项目材 料申请单时识别“新材料”“新工艺”情况，并在涉及“新材料”“新工艺”时将识 别情况填入材料申请单对应物项特殊要求。核电装备事业部采购人员在材料和零部件 采购合同定标时，识别该供方涉及“四新”类型（“新供方”“新产品”“新工艺” “新材料”），将相关信息填入“四新”供方管控清单（附件 1 ）。

对于工序性“四新”供方识别，生产管理部 / 德阳管理部负责在开展工序外委任务 策划时，组织核电装备事业部技术人员配合识别该供方涉及“四新”类型（“新供方” “新产品”“新工艺”），将相关信息填入“四新”供方管控清单（附件 1 ）。

# 4.1.2 常规岛设备“四新”供方识别

对于材料和零部件“四新”供方识别，由容器研发部技术人员在编制材料初估 / 材 汇时识别“新材料”情况，并在涉及“新材料”时将识别情况填入材料初估 / 材汇对应 物项特殊要求。核电装备事业部采购人员在材料和零部件采购合同定标时，识别该供 方涉及“四新”类型（“新供方”“新产品”“新材料”），将相关信息填入“四新” 供方管控清单（附件 1 ）。

对于工序性“四新”供方识别，生产管理部 / 德阳管理部负责在开展工序外委任务 策划时，组织核电装备事业部技术人员配合识别该供方涉及“四新”类型（“新供方” “新产品”“新工艺”），将相关信息填入“四新”供方管控清单（附件 1 ）。

生产管理部、德阳管理部负责按项目建立并动态更新“四新”供方管控清单，并 及时传递至核电装备事业部、质量保证部、质量检验部等。

质量保证部项目质保负责人收集汇总核电装备事业部、生产管理部、德阳管理部 提交的项目“四新”供方管控清单，按项目合同要求将相关信息提交顾客，并对各部 门“四新”供方管控措施实施情况进行监督。

对多个项目批量化生产的同一设备，可结合具体情况多个项目统一建立“四新” 供方管控清单，但须明确适用的具体项目。

# 五、“四新”供方管理要求

# 5.1 供方准入及评审

“新供方”准入时应加强供方资格审查，尤其对供货业绩审查（原则上应有同类 产品业绩），确保准入的供方工艺技术可靠，能稳定提供所需物项和服务，国内供方 应开展源地评价。

# 5.2 供方过程控制

对核电“四新”供方过程控制原则如下：

“新供方”重点关注其资质、相关业绩、质量保证体系及技术能力等内容，进行 全过程重点管控。

“新产品”供方重点关注其历史供货业绩质量管控水平以及“新产品”技术方案 适配性及成熟度。

“新材料”供方重点关注和控制材料工艺性能的成熟度和试验验证。

“新工艺”供方重点关注和控制其新工艺方案的评审验证、以及批量制造的首件 检查验证。

材料和零部件“四新”供方过程控制通用要求见附表 1 ，工序性外委“四新”供方 过程控制通用要求见附表 2 。核电装备事业部、生产管理部、德阳管理部可结合项目要 求和实际情况，在通用要求基础上进一步制定采取相关管控措施。

# 六、其它规定

1 、核电装备事业部、生产管理部、德阳管理部根据本通知要求梳理完善内部管理 制度，进一步明确核电“四新”供方管控在部门内部接口及工作流程，并将该制度提 交质量保证部备案。

2 、核电装备事业部、生产管理部、德阳管理部应在与供方签署合同后，及时将合 同涉及“四新”情况传递至供方，提醒供方关注并督促供方按照公司要求及供方内部

3 、若顾客有特殊要求，核电装备事业部、生产管理部、德阳管理部应组织供方予 以满足；当顾客特殊要求与本通知要求冲突时，执行顾客特殊要求。

4 、对核电“四新”供方管控的实施证据由实施部门保存备查。
