# 航天固体火箭发动机用超高强度钢锻件规范

# 1 范围

本规范规定了航天固体火箭发动机用超高强度钢锻件的要求。

本规范适用于30Si2MnCrMoVE、31Si2MnCrMoVE和30Cr3SiNiMoVA热轧锻件。热轧环件也可参考使用本规范。

# 3.9 超声检测

3.9 超声检测锻件应进行超声检测，检测结果应符合 GJB 1580A-2004 中A级的规定。需方有特殊要求时应在合同注明。

# 3.10 尺寸、外形、重量

3.10.1 锻件的尺寸及允许偏差应符合双方签订的图纸的要求。图纸中未作规定时，按下列规定执行：

a) 自由锻件的加工余量及公差应符合GB/T21470的要求；

b) 模锻件的加工余量及公差应符合GB/T12362的要求；

c) 热轧环形件机械加工余量及公差应符合 JB/T 10478 的要求。

3.10.2 锻件的外形应符合订货图纸的加工要求，锻件的两端切斜角应不大于 $ 15^{\circ} $ ，不允许有飞边毛刺。

3.10.3 锻件应以理论重量交货,锻件密度按 $ 7.86\mathrm{g/cm}^{3}. $

# 3.11 外观质量

3.11.1 锻件表面应进行清理，其表面状态应满足锻件图样的要求；锻件表面不允许有过烧裂纹和影响材质的其他缺陷存在。

3.11.2 在锻件的加工表面上，裂纹、折迭、嵌入和成片的氧化皮应全部清除，其他缺陷则允许不清除，但应保证锻件留有不小于三分之一的公称加工余量。

3.11.3 在锻件的非加工表面上允许存在因锻造操作或机械碰撞造成的凹坑、缺肉、压伤等分散缺陷，但裂纹、夹杂、折迭、氧化皮、划痕、折皱应全部清除，但应保证锻件的单面最小极限尺寸，清除宽度不得小于深度的8倍。缺陷的清除处应圆滑。

# 4.2.3 判定和复验规则

4.2.3.1 当化学成分分析结果不合格时，允许重新取样对不合格元素进行分析，若重新分析结果仍不合格，则该炉判为不合格。

4.2.3.2 锻件的力学性能、硬度、非金属夹杂物、晶粒度、显微组织等某项检验结果不合格时，允许从该批锻件(包括初试不合格的锻件)中取双倍数量的试样进行该项目的复验，复验结果中有一个试样不合格，则该批锻件判为不合格。对力学性能、硬度和晶粒度、显微组织检验不合格的锻件允许供方重新热处理(重新热处理次数不超过两次)后，作为新的一批提交验收。

4.2.3.3 锻件的低倍检验不合格时，允许从该批锻件中(包括初试不合格的锻件)中取双倍的试样进行复验(白点除外)，复验结果中有一个试样不合格，则该批锻件应判为不合格。

4.2.3.4 对超声检测、尺寸、外形及外观质量检验不合格的锻件，则单件判为不合格。

# 4.3 检验方法

# 4.3.1 化学成分

化学成分分析取样按 GB/T 20066 规定进行，化学成分分析方法按 GB/T 223.5、GB/T 223.11、 GB/T 223.13、GB/T 223.19、GB/T 223.23、GB/T 223.26、GB/T 223.58、GB/T 223.59、GB/T 4336、 GB/T 20123 的规定或通用的方法进行，但仲裁分析时应按 GB/T 223.5、GB/T 223.11、GB/T 223.13、 GB/T 223.19、GB/T 223.23、GB/T 223.26、GB/T 223.33、GB/T 223.58、GB/T 223.59 的规定进行。

# 4.3.2 硬度

布氏硬度试验按GB/T231.1的规定进行。

# 4.3.3 室温拉伸

拉伸试验用试样的取样和试样制备按 GB/T 2975 的规定，试验方法按 GB/T 228.1 的规定进行。

# 4.3.4 室温冲击

冲击试验用试样的取样和试样制备按GB/T2975的规定执行，冲击试验方法按GB/T229的规定进行，采用2mm摆锤刀刃。

# 4.3.5 断裂韧度

断裂韧度试验按GB/T 4161的规定进行。

# 4.3.6 低倍

低倍试样制备按 GB/T 226 的规定进行，30Cr3SiNiMoVA的低倍组织缺陷按 GB/T 1979评定； 30Si2MnCrMoVE和31Si2MnCrMoVE低倍组织的评定按 GJB 9443进行。

# 4.3.7 非金属夹杂物

非金属夹杂物检验按GB/T10561-2005中A法进行。

# 4.3.8 晶粒度

晶粒度的检验按GB/T 6394的规定进行。30Si2MnCrMoVE和31Si2MnCrMoVE晶粒度显示方法按氧化法进行；30Cr3SiNiMoVA晶粒度显示方法按直接淬硬法进行。
