# 1. 概述

本技术要求对不锈钢板、 Inconel617 棒材、板材等原材料提出了 执行标准、技术要求、检验及取样、供货范围、包装运输与存储、计 量、文件、验收、质量保证、质保期、售后服务等方面要求，并规定 了供货商的职责和供货范围，作为大五金原材料采购合同的技术附件。

本技术要求提出的是最低限度的要求，并未对所有技术细节作出 规定，也未完全陈述与之有关的所有规范和标准。供货商应提供符合 本技术要求及其它未列出的有关工业标准、规范和导则要求的优质设 备（或系统）。

本技术要求的解释和修改权归采购方所有。

# 2. 供货范围

# 2.1 供货产品

（ 1 ）供货产品规格及数量详见表 17-1 。

（ 2 ） Inconel617 材料提供与表 17-1 清单中所用同批次复验用料。

# 2.2 供货状态

（ 1 ）镜面不锈钢钢板经固熔退火并镜面抛光后带保护膜状态交 货；

（ 2 ） Inconel617 棒材为固溶退火态；

（ 3 ） Inconel617 板材为固溶退火态；

（ 4 ） 1J22 软磁合金：原材料选用冷轧带材，按照表 17-1 中尺寸 切割后，进行磁性能热处理，热处理制度可参考 GB/T14986.3-2018 附录 A 或供货商自定，具体以磁性能达标为准。

# 3.2.2 力学性能

材料力学性能满足上述标准中的要求，不做特殊要求。

# 4. 材料要求

所有采购的原材料必须都有材料质量证明文件，材料质量证明文 件应包含有关材料标准所要求的全部试验结果的报告。材料试验报告 应列举出产品标准的编号和年份号，说明材料是按该产品标准的要求 制造、取样、试验和检查，并且符合表 17-1 中相关执行标准要求， 具体要求如下。

# 5. 制造要求

原材料制造、尺寸及其允许偏差应符合相关标准的要求。

# 6. 检验和验收

原材料入厂后均按照标要进行入厂复验，不锈钢板进行化学成分 复验、 Inconel617 （ N06617 ）钢板进行化学成分复验、 1J22 软磁合金

<!-- page: 10 -->

进行化学成分及磁性能复验， TU2 无氧铜进行化学成分复验，复验合 格后作为到货验收的依据。

# 6.1 表面质量和外观检查

检查到货原材料应有良好的质量和外观，表面是否光洁平整，无 划伤、磕碰等缺陷。检查钢管应有良好的质量和外观，表面状态满足 第 3.2.2 ）节的要求。注意检查镜面钢板的表面，表面不得有划伤， 板与板之间做好防护隔开。

# 6.2 到货尺寸检查检验

应按技术要求中所列的相关条款及技术要求检验，各项检验的方 法应符合相关现行国家标准和行业标准，或者采用经供应方与采购方 协商认可的方法。

# 6.3 到货验收

供货商有义务配合采购方采购人员和入库检验员对到货产品进 行清点入库。产品上的标识与质量证明文件需一一对应。

# （ 1 ）文件

材料检验人员必须在材料验收时检查质量证明文件，必要时进行 网上查询及二维码扫描，确保证明文件真实有效，并同时核对材料的 牌号、规格及质量，确保满足产品要求。

# （ 2 ）材料的标志

在材料的表面应有如下标记：标准号、牌号（包括后缀）、型号、 批号、钢厂名称或商标。钢材具体规定按标准要求。交货状态，奥氏 体不锈钢均需进行固溶处理。在制造过程中使标记保持到最终加工装

<!-- page: 11 -->

配完成，保证不混料。

# （ 3 ）材料的外观质量

原材料表面不允许有裂纹、气泡、夹杂、结疤、折叠等影响使用 的缺陷。薄钢板表面应光滑、平整、无污物。

# 7. 标记和标识

按照第 6.3 条 2 ）材料标志的及相关标准中的要求对原材料进行标 记和标识，确保原材料的可追溯性。

# 8. 文件和记录

随物项提供一套包含所有材料的出厂合格证书和质量证明文件 及电子版的材质证明书的清单，按照表 17-2 要求填写。质量证明文 件包括但不限于：

（ 1 ）制造厂名称；

（ 2 ）订货合同编号；

（ 3 ）标准编号、钢号、炉号、批号、数量；

（ 4 ）热处理报告（如有）；

（ 5 ）几何尺寸检测报告；

（ 6 ）各项检验结果，检验单位检验验人员签章；

（ 7 ）产品质量证明文件。

<!-- page: 12 -->

# 9. 包装、储存和运输

原材料表面应清洁无污物，包装应能保证钢材在贮存、运输过程 中不被碰伤、划伤、弄脏。原材料的运输应保证材料安全抵达目的地， 材料的装车方法应能保证运输安全。

# 9.1 包装

原材料外表面需要简易包装，避免在装卸、运输过程中对原材料 造成划伤、磕碰等缺陷。钢管需放置在包装箱内，每根钢管应单独包 装，钢管之间用垫板隔开，垫板选用较软材质，避免在装卸、运输过 程中对钢管造成划伤、磕碰等缺陷。

# 9.2 运输

运输过程中产品严禁出现磕碰、划伤等有损产品质量的现象，运 输费用供货商承担。运输地点为中国原子能科学研究院。

# 9.3 贮存

成品应贮存在专设的贮存库房，库房应保持干净、通风、并具有 防火、防潮、防尘、防水措施。

# 10. 安装

不涉及。

# 11. 调试

不涉及。

# 12. 质量保证要求

# 12.1 供货商资质及质量保证要求

（ 1 ）供货商需在中华人民共和国境内具有独立的法人资格；

（ 2 ）供货商需按照 GB/T19001 建立质量保证体系，供货商须执 行采购合同中规定的质量保证要求，编制必要的管理，必要时提交采 购方备案；

（ 3 ）供货商需具备有一定供货经验，且需提供近两年类似业绩。

# 12.2 质量控制

产品发货前供货商提供可编辑版产品质量证明书的清单及产品 质量证明文件 PDF 版供采购方审查。采购方审查通过后予以发货。

# 13. 知识产权要求

不涉及。

# 14. 进度要求

合同签订后 30 个自然日完成供货。

# 15. 验收

原材料验收形式为到货验收，根据第 6.3 条内容要求验收，各项 检验结果与所对应的要求相符合则视为合格，可以接收；不符合则视 为不合格，拒收。

# 16. 保密要求

(1) 供货商应对本项目内容做受控管理，严格控制知悉范围；

(2) 未经采购方书面许可，供货商严禁将本文件及项目内容以任 何形式泄漏至第三方；

(3) 供货商的保密义务在本合同 / 任务 / 委托期满、解除、终止后 仍然有效；

(4) 供货商泄密导致采购方损失，供货商应承担相应法律责任。
