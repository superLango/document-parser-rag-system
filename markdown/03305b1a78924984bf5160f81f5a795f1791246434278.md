# UNS N08825-1 电渣锭采购协议

# 1 内容与适用范围

本技术协议规定了 UNS N08825-1 电渣锭的要求、质量保证规定和交货准备等。本技术协议适用于供无锡派克 UNS N08825-1 电渣锭的制造及验收。原材料应满足 ASTM B564 的相应要求。

在本协议中，INCOLOY 825-1、INC825-1视为与 UNS N08825-1 同一种材料，按相同要求执行。

# 2. 引用标准

下列文件中的条款通过本标准的引用而成为本标准的条款。凡是不注日期的引用文件，其最新版本适用于本技术标准。

ASTM B564镍合金锻件规范

ASTM E1473镍、钴和高温合金的化学分析试验方法

ASTM B880镍、镍合金和钴合金化学分析限制的一般要求

GB/T 38939镍基合金 多元素含量的测定 火花放电 原子发射光谱分析法（常规法）

ASTM E1019 采用燃烧和惰性气体熔融技术测定钢、铁、镍及钴合金中碳、硫、氮和氧含量的标准试验方法

ASTM E340金属和合金宏观浸蚀的标准实施规程

# 3 尺寸、外形、重量及允许偏差

单个电渣锭的重量与采购要求的重量偏差不超过（+5%/-2%）。

# 4. 技术要求

# 4.1 制造过程

原材料冶炼应采用电弧炉熔炼（EAF）或中频炉熔炼，二次精炼使用钢包精炼炉（LF）和真空除气炉（VD）、氩氧脱碳炉（AOD）或真空脱碳炉（VOD）；原材料需二次重熔，可用电渣重熔（ESR）或真空电弧重熔（VAR）等方法。原材料采用的冶炼方法应在合同和质量证明书中注明。

# 4.4.2 非金属夹杂

供方应保证电渣锭经需方锻造（锻比≥4）后，按照DIN 50 602进行检验，锻件的非金属夹杂物满足K3≤40的要求。

# 4.5 超声波探伤

供方应保证电渣锭经需方锻造（锻比≥4）后，成品超声波探伤满足 ASME B16.34, Appendix IV 的要求。

# 4.6 表面质量

表面不能有肉眼可见的裂纹、折叠、分层、夹伤及影响使用的其它有害缺陷存在。不合格的表面缺陷允许打磨清除，打磨宽深比≥6，不允许进行任何焊补。

# 6 检验规则

# 6.1 检查和验收

电渣锭出厂的检查和验收由供方质量技术监督部门进行。

供方必须保证交货的电渣锭符合本标准或合同的规定。

# 6.2 组批规则

每验收批由同一材料牌号、同一熔炼炉号、相同制造过程的电渣锭组成。

# 6.3 取样数量及取样部位：

每批电渣锭的取样数量及取样部位应符合本协议第5条的规定。

# 7 包装、标志及质量证明书

应采用合理的包装方式，防止在运输过程中产生磕碰等质量事故。

质保书至少包含以下内容：

材料牌号；

——熔炼和成品分析报告；

试验检验标准（覆盖本技术要求的所有标准）；

——表面质量检查报告；

——重量均一性检查报告；

——外观检查记录；

——需方标准号；

——熔炼炉号和生产批号；

——供应商标识；

——采购订单号；

8 未尽事宜，双方及时协商解决。
