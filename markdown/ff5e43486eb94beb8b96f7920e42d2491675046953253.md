# 1. 3. 1. 2 取样要求

第1.2节中锻件尺寸均为净尺寸，需要生产单位考虑加工余量、取样余量。

2A14 铝合金锻件取样要求均参照 Q/Y 767-2017中“4.2.3 取样规则”执行，保护罩参照 QJ502A-2001执行，具体要求如下：

1）在各部段锻件1/2壁厚本体处取样，进行力学性能检测。

2）在锻件本体上沿圆周均匀分布的4个象限位置分别取环向、轴向、径向拉伸力学性能试验。每处取样应保证三个方向，每个方向各切取三个试样。控制舱靠近下方取样（小端），三级尾段靠近下方取样（大端）。保护罩允许采用多件整体锻造再分割的方法制造，在整体锻件取样即可。

3）窗口位置后续进一步和设计确定窗口位置后选取。每处取样应保证三个方向，每个方向各切取两个试样。

# 1. 3. 2 显微组织

锻件的显微组织中不允许有过烧。

# 1. 3. 3低倍组织

锻件的低倍组织不允许有肉眼可见的裂纹、分层、偏析聚集或非金属夹杂物等缺陷。低倍组织中的氧化膜缺陷按 Q/Y 767-2017 或者 QJ502A-2001 要求执行。

# 1.3.4 表面质量

锻件表面不允许存在裂纹、分层、折叠和锻造引起的机械损伤等缺陷；锻件应经粗加工后交付，加工表面上允许有压伤存在，其深度不超过单边加工余量的1/3。

# 1. 3. 5 超声波检测

1）锻件的超声波检测应在热处理后进行；

2）各部段锻件要求全部进行超声波检测，检测方向为径向方向；

3）锻件超声波检测应符合GB/T 6519-2013中的A级规定。

# 1.3.6 质量控制

# 1. 3. 6. 1判定规则

2A14 铝合金锻件判定规则均参照对应锻件标准要求执行。

1. 3. 6. 2 锻件生产方应按要求保存锻件质量跟踪所必须的原始记录（如组织性能报告单、工艺卡、超声波探伤记录等）备查。

# 2.3 低倍组织

锻件的低倍组织不允许有肉眼可见的裂纹、分层、偏析聚集或非金属夹杂物等缺陷。低倍组织中的氧化膜缺陷按 Q/Y 767-2017 或者 QJ502A-2001 要求执行。

# 2.4 表面质量

锻件超声波检测应符合GB/T 6519-2013中的A级规定。
