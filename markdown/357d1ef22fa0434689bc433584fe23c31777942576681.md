# 4. 质量保证

# 4.1 检验责任

（1）供方应按照本协议要求完成所有的检验，并提供检验报告；

（2）供方在生产过程中不允许隐瞒制造缺陷、质量问题或隐患，不允许提交有缺陷的产品，如果产品在发货后经需方检验，或在需方现场装配、试验和运行过程中出现不符合图纸或本协议，如是供方的责任，供方应无条件负责并对因此对需方造成的直接经济损失予以赔偿并补废；

（3）供方所有的试验设备和检验装置均应符合相关标准规定，按相关规定在规定的时间内经过校准；

（4）供方应提供工艺流程给需方确认，在生产过程中应严格执行此流程。如果工艺需要变更时，应及时通知需方，并须要双方确认。关键生产检验设备变更、生产地点变更或原材料供应商变更时也应及时通知需方，并须要双方确认；

（5）供方在生产过程和验收过程中发现的偏差在产品交付前必须提交详细的偏差分析报告，并须获得需方技术部门的书面批准，偏差批准不代表供方对交付有缺陷的产品免责；

（6）需方在对产品进行复验时，如发现产品不符合本协议或图纸要求时，供方应对质量负责，双方对检验记录和结果意见不一致时，可由双方确认的有资质的专业机构检验。检验结果对双方都有约束力，检验费用由责任方负担；

（7）锻件的生产不允许供方外包给分供方，需方有权对产品的制造、检验和验收等全过程进行监造，为保证监造工作的顺利进行，供方应向需方的监造人员提供必要的便利条件，锻件需双方确认有专业资质的检测机构进行检测；

（8）需方有权对本协议的所有检验项目进行检验。需方有权对供方跟本项目相

# 5. 包装、标志、运输和贮存

锻件验收合格后进行防锈包装，包装箱应做到防潮，防水，防止运输过程中产生机械变形和损伤。包装箱内除产品外，还应附有产品标签、装箱清单、产品合格证及产品质量证明书，产品在存放和运输过程中，应防止金属制件生锈和沾染油污。产品在装卸、运输和试验时不得敲打、碰撞和冲击。
