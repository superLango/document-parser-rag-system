# 1 主题内容与适用范围

本技术条件规定了燃气轮机同步自动离合器齿轮、轴类、螺栓类锻件技术要求。

本技术条件适用于25Cr2MoVA和40CrNiMoA锻件的制造与验收。

# 3 技术要求

# 3.1 制造

# 3.1.1 冶炼和浇注

（1）锻件用钢应采用钢包精炼，经需方同意也可采用保证质量的其他方法冶炼。

（2）钢水在浇注中应进行真空处理，以去除有害气体，特别是氢在真空处理的过程中，真空系统的能力必须大到在开浇后的两分钟内

1

<!-- page: 4 -->

就能将初始增高的压强降至低值，通常应低于133Pa。

# 3.1.2 锻造

（1）钢锭上部和下部均应有足够的切除量，以确保成品锻件无缩孔、疏松、严重的偏析和其它有害缺陷。

（2）采用的锻造方法必须尽可能使整体锻件得到均匀的组织结构。锻压机应有足够的吨位，以使锻件的整个截面锻透。锻件的轴线应与钢锭的中心线大致重合。

（3）锻件应有足够的锻造比。

# 3.1.3 热处理

（1）锻后进行正火处理，正火后应回火，随后应空冷或炉冷。

# （2）性能热处理

锻件在第一次粗加工后进行调质处理，轴类及轴齿轮锻件应在垂直状态下进行性能热处理。

# （3）去应力处理

锻件在性能热处理后及随后的粗加工和打中心孔后，锻件应在低于最终回火温度15-20℃下去除应力。

（4）半精工后精加工前去应力处理。

# 3.1.4 机械加工

（1）锻件在性能热处理前对所有外表面进行第一次粗加工。

# （2）第二次机械加工

锻件在性能热处理后去应力处理前进行第二次粗加工，带中心孔的锻件按需方订货图样规定尺寸和公差打中心孔(留出中心孔精镗余量)。

（3）锻件去除应力后加工至订货图样规定尺寸、公差和粗糙度要求。带中心孔的锻件按3.2.5第（2）条规定的形位公差要求精镗中心孔，并用不掩盖缺陷的方法研磨或抛光中心孔表面，使表面粗糙度Ra值为1.6μm。

（4）供方在锻件制造和包装过程中不得进行焊接。

# （5）硬度检验

锻件靠近两端外圆柱表面上及锻件中间外圆的三截面每隔 90° 打一点硬度，总计12点。每截面4点硬度差不超过30HB。轴向硬度差不超过40HB。

# 3.2.3 无损检验

# （1）一般要求

锻件不得有裂纹、白点、缩孔、折叠、过度的偏析及超过允许的夹杂和疏松。

# （2）磁粉检验

磁粉检验按 JB/ZQ6101 标准规定的方法进行检验。

$ \textcircled{1} $零件精加工后，由需方对要求检验的部位表面进行磁粉检验，供方应保证检验结果符合以下要求：

轴齿轮及轴类零件的轴颈部位、承受推力的轴向推力面和其他需要检验的表面精加工后进行磁粉检验，不允许有大于1.5mm的任何缺陷显示，在 $ 2 5 \mathrm{c m}^{2} $面积上不允许有超过5个小于或等于1.5mm的缺陷显示。（磨削加工产生的表面缺陷由需方负责）。同一条母线上两个缺陷之间小于其较大缺陷长度的5倍时，按一条连续缺陷处理。

$ \textcircled{2} $磁粉检验后应充分退磁处理，退磁后磁粉检验表面的最大磁场强度不超过 $ 1 0 0 0 / 2 \pi \mathrm {A} / \mathrm {m} $。（空气中相应磁感强度为 $ 2 \times1 0^{-4} \mathrm {T} $）

# （3）超声波检验

超声波检验按 JB1581 汽轮机转子超声波探伤方法检验规范规定方法进行。

超声波检验在锻件调质处理后进行。(带中心孔的轴齿轮及轴类锻件检验需在打中心孔前进行)。

必要时由供需双方联合检查，其验收标准如下：

a. 当量直径 $ \phi 2 \mathrm{mm} $以下的单个分散缺陷可不计，但杂波高度应低于当量直径 $ \phi 2 \mathrm{mm} $幅度的 50%。

b. 单个分散的缺陷定义为：相邻两缺陷之间距离大于其中较大缺陷当量直径的10倍以上的缺陷。

c. 不允许存在当量直径大于 $ \phi 3. 2 \mathrm{mm} $的任何缺陷。分散的当量直径 $ \phi 2 \sim \phi $ 3.2mm的所有缺陷均应记录其轴向、径向和周向位置并报告给需方，其各部位允许的数量见下表：

# （4）中心孔检验

带中心孔的锻件应进行中心孔检验

中心孔验收标准如下：

a. 长度等于或大于1.5mm的缺陷应记录其轴向和周向位置并报告需方；

b. 在窥腔仪检查的一个视野内，不允许有3个长度大于1.5mm的可见缺陷或9个长度小于1.5-3mm的可见缺陷；

c. 分散的、长度为1.5-3mm缺陷不允许超过7个/m；

d. 位于同一母线上的两个缺陷的距离小于其中较大缺陷长度5倍时，按一条连续缺陷处理；

e. 不允许长度大于3mm的可见缺陷及非金属夹杂物组成的密集区；

f. 不允许有任何撕裂状的分叉缺陷。
