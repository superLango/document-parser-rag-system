# 5 对供方的停工令管理

# 5.1 由东方武核发出的停工令

当东方武核发现供方制造活动中出现但不限于下列情况时，东方武核可以下达停工通 知：

 通知点管理不善，出现超越顾客或其代表设定的 H 点制造的情况；

 有特殊资格要求的活动由未获得相应资格的人员实施；

 使用未经验证或已知有不可纠正缺陷的设备、材料；

 擅自变更设计文件；

 继续制造将导致重大返工或修理；

 使用未经过批准的工艺文件和作业指导书；

 制造过程中出现重大质量问题或重大质量风险；

 对于重复出现的问题没有采取纠正措施或采取的纠正措施没有效果。

# 5.2 由东方武核传递的停工令

国家核安全监管单位、顾客、集团公司 / 股份公司下达的停工通知，由东方武核传递至 供方。

供方收到停工通知后，应立即停止相应产品制造，并将产品置于安全状态。未收到复 工通知前，不得开展任何相关工作。

# 7 变更与澄清

<!-- page: 7 -->

设计和工艺变更：东方武核对供方发出的对设计和工艺文件进行修改的通知。

# 7.1 术语

技术变更申请（ TA ）：供方向东方武核发出的，对技术文件内容进行技术调整或修改 的请求。

技术澄清要求（ CR ）：供方向东方武核发出的，对技术文件中未作规定或规定不清楚 的技术内容提出进一步说明和澄清的要求。

# 7.2 东方武核向供方下达的设计和工艺变更

东方武核向供方下达设计变更有两种形式：

 升版采购技术规格书、图纸或其他设计文件

 发出设计和工艺变更通知单

供方收到东方武核的技术和工艺变更后，应立即组织评审：

 评审结果为 “ 可实施 ” 时，应修改相应制造工艺文件，确保制造满足技术和工艺变更 后的要求；

 评审结果为 “ 不可实施 ” 时，须在 3 个工作日内向东方武核回复意见并说明原因和处 理建议，由东方武核采购部组织进行协调，其结果有以下三种情况：

 指令供方实施设计和工艺变更

 修订设计和工艺变更

 撤销设计和工艺变更

# 7.3 供方向东方武核申请的技术变更

供方填写 TA 单，通过通信渠道发送至东方武核，东方武核采购部接收、转发技术部 并予以跟踪。东方武核技术部通过 “ 设计和工艺意见反馈单 ” 回答，由采购部发送供方执行。

# 7.4 供方向东方武核提出的设计澄清

供方填写 CR 单，通过通信渠道发送至东方武核，东方武核采购部接收、转发技术部 并予以跟踪。东方武核技术部通过 “ 设计和工艺意见反馈单 ” 回答，由采购部发送供方执行。

# 8 质量保证分级

# 8.1 质量保证分级的目的

为实现规范中规定质量提供足够的置信度而对质量保证活动要求进行划分，质量保证 等级的划分是确保在有限资源条件下，对重要物项和服务进行更严格的质量控制及确认， 同时确保所有物项和服务符合技术条款的要求。

# 8.2 质量保证分级的原则

以物项的失灵或服务中的差错对安全和可利用率所造成的影响为依据，并按照物项和 服务对安全和可利用率的影响程度和重要程度来进行分级控制，原则上，安全等级高和重 要程度高的物项和服务，则质量保证等级高。

# 8.3 质量保证分级的确定

质量保证等级分为 QA1 级、 QA2 级、 QA3 级和 QNC 级。

具体物项和服务的质量保证分级，由东方武核通过合同或“质量保证分级清单”向供 方下达。

# 11 质量计划

# 11.1 质量计划的编制要求

 对于 QA3 级及以上的零部件（含铸锻件、板材、管材、见证件）和设备的下列活动都 应编制质量计划：

—制造、检查和试验等活动；

—由于不符合项处理导致的修理、返工等活动。

 对于 RCC-M 、 ASME 等规范管辖范围内焊接材料的制造和 / 或复验，应编制质量计划。

 对于分包的单一工序或部分工序，需编制单独的质量计划，或者可在原质量计划分包 工序所在的备注栏中文字说明分包情况（手写备注时应签署姓名及日期）。

 针对东方武核采购的成品标准件，供方的制造活动可以不编制质量计划，但有特殊要 求的入厂复验或第三方检验等活动，需编制质量计划。

# 11.2 质量计划的内容

为证明核安全设备制造中所要达到的质量要求、所需进行的制造、检验及试验等活动 得到定义并执行，而制定的对制造中拟执行的制造、检验及试验等质量相关活动的列表， 即质量计划。

质量计划的内容应包括：

a) 封面（包括项目名称（包含机组名称）、制造单位名称、质量计划名称及编码、文 件状态、版本、签署栏等）

b) 引用合同 / 订单和设备技术规格书编码

c) 设备名称和编号、零部件名称和图号、章节号、章节标题、章节版本

d) 安全等级、质保等级、功能等级（如有）、屏障等级（如有）

e) 按操作流程逐一列出所有的工序，至少应包括：工序序号、工序工作内容 ( 包括检 查和试验内容 ) 、适用文件、检查点（供方、东方武核、顾客等相关方选取的检查点，供方 在质量计划中的设点数量和级别不得低于东方武核）、检查点设置方日期及签字栏、报告 记录栏、备注栏等信息

# 11.3 质量计划的使用阶段

<!-- page: 11 -->

 初始阶段：初编的质量计划经供方内部审核、批准但尚未生效并投入执行；

 执行阶段：已经生效的质量计划在生产过程中被逐序执行并填写签字；

 完工阶段 : 执行、签字并填写完毕的质量计划。完工阶段的质量计划将纳入完工报 告并成为其组成部分。

# 11.4 质量计划的审查

供方编制的 QA2 级及以上的零部件（含铸锻件、板材、管材、见证件）和设备质量计 划，由东方武核审查后报顾客审查确认。

供方编制的 QA3 级的零部件（含铸锻件、板材、管材、见证件）和设备质量计划，如 属于《民用核安全设备监督管理条例》（中华人民共和国国务院令第 500 号）监管目录范 围内的物项，由东方武核审查后报顾客审查确认；如不属于《民用核安全设备监督管理条 例》监管目录范围内的物项，由东方武核审查后报顾客备案。

RCC-M 、 ASME 等规范管辖范围内焊接材料的制造和 / 或复验的质量计划，由东方武 核审查后报顾客审查确认。

由于不符合项的处理导致的修理、返工等活动，需要编制相应的跟踪质量计划，供方 审查确认后报东方武核采购部备案。

《民用核安全设备监督管理条例》监管目录范围内的物项的质量计划，由供方编制、 东方武核审查、顾客审查确认后由供方报送至国家核安全监管部门，具体按《民用核安全 设备监督管理条例》执行。

# 11.5 质量计划的变更

# 11.5.1 变更的原因

经批准的质量计划是供方、东方武核和顾客对物项进行控制和监督的主要依据，原则 上不允许随意变更。如需变更，应重新提交东方武核审查或备案。由于下述情况发生，需 要变更已生效的质量计划，应根据变更原因，分别重新提交东方武核审查或备案。

a) 质量计划编制依据文件内容变更，导致质量计划中的工序、内容或要求发生改变；

b) 根据制造质量的趋势，各见证方认为需要对质量计划内容及控制点进行调整时；

c) 由于技术澄清、技术变更的原因，导致质量计划需要做相应的变更；

d) 实际执行中，发现质量计划局部内容错误或存在不合理部分需要变更；

e) 由于不符合项的处理导致的修理、返工等活动，需要增补相应的跟踪质量计划，作 为原质量计划的补充。

<!-- page: 12 -->

# 11.5.2 变更方式

# a) 修改升版

由于 11.5.1 条第 a) 、 b ）条原因引起的变更，原则上需要升版质量计划，并重新提交 东方武核审查认可。

# b) 变更划改

由于 11.5.1 条第 c ）、 d ）条原因引起的变更，或个别由于第 a) 、 b ）条原因引起的局部 变更，应先提交《质量计划变更审批单》，经东方武核审查确认后，直接划改变更。划改 人在划改处签字，标注划改原因或划改依据，《质量计划变更审批单》作为相应质量计划 的附件一并保存。

# c) 补充编制

由于 11.5.1 条第 e ）条原因引起的变更，需重新对修理或返工补充编制质量计划，经 东方武核审查选点后，提交顾客备案。

# d) 直接划改

质量计划执行过程中发现明显笔误（错别字、明显的数字错误、质量计划版本、质量 计划 / 设备 / 零部件名称内外不一致、引用的内部文件有误）、个别工序增加各方见证点、增 加内控工序、出现由于拆分导致的数量变化等情况，供方可以在质量计划上按要求直接划 改和签署。

# 11.5.3 应用方式

a) 如制造活动尚未开始，则用新升版的质量计划代替已生效的质量计划实施；

b) 如制造活动已开始但尚未完成，则新旧生效的质量计划同时保留，未执行的活动按 新生效的质量计划执行；

c) 如修改涉及变更的制造活动已经完成，则保存原质量计划及记录不变，并在原质量 计划中对变更内容进行备注说明。

# 11.6 质量计划检查点设置原则

原则上物项的安全、质保、功能、屏障和监造等级越高、制造厂的工艺成熟度越低、 对设备质量影响越大的工序，其选点数量应越多、控制程度越严格。实际选点时，根据不 同供方具体情况调整选点数量和监督的力度，供方可参考以下选点原则设置检查点，具体 选点在东方武核、顾客等相关方审查质量计划过程中确定。

a) 国家核安全监管部门对质量控制点设置有要求时，应首先满足国家核安全监管部门

<!-- page: 13 -->

要求，东方武核选点不低于国家核安全监管部门和顾客选点。技术条件、设备规格书对质 量控制点设置有要求时，可在本要求规定的基础上，参考技术条件、设备规格书的要求进 行选点。

b) 先决条件或开工授权检查、切取试样、力学性能试验、焊接、热处理、无损检验、 尺寸检查、功能试验、最终清洁包装、质量计划关闭或完工报告审查等工序选为 W 点。熔 炼分析、硬度试验、成品化学分析、金相检验、晶间腐蚀试验等工序根据具体情况选为 R 点或不选点。

# 12 见证管理

检查点：指所制造物项相关方（供方质量控制部门、东方武核、顾客等）及国家核安 全监管部门在制造过程中设置的希望被通知并进行见证和检查的活动，检查点分为：停工 待检点（ H 点）、现场见证点（ W 点）及记录审查点（ R 点）。

# 12.1 停工待检点（ H 点）

H 点是制造过程中的一项关键工序，供方应以书面形式提前 15 个工作日 ( 国外 90 天 ) 发出 H 点检查见证通知单，并提前 5 个工作日 ( 国外 30 天 ) 确认。

H 点见证为强制执行，没有东方武核见证人员的出席或以书面通知放弃该 H 点的监督， 供方不得进行该点及后续操作。在计划的时间见证人员未到达见证现场，供方再次发出通 知，并把该点的操作往后推。

# 12.2 现场见证点（ W 点）

W 点是制造过程中的一项关键工序，供方应以书面形式提前 15 个工作日 ( 国外 90 天 ) 发出 W 点检查见证通知单，并提前 5 个工作日 ( 国外 30 天 ) 确认。

在顾客未明确表示不出席 W 见证点的情况下，不得执行该工序及后续工序。

# 12.3 文件（记录）审查点（ R 点）

供方在工序完成后及时将相关记录和资料 ( 包括制造技术文件、合格证明文件、检查和 试验结果记录等 ) 提交东方武核。

东方武核在确认质量记录达到规定要求后，在相应的质量计划上签字，或以函件的形 式予以认可；如果认为设备制造文件或见证记录的内容不符合规定的要求，供方对相应的 文件进行补充完善。

# 12.4 见证点申报

W 点、 H 点见证通知单内容至少应包括：

<!-- page: 14 -->

 零部件名称；

 章节、工序、工序名称；

 质量计划编号、版本；

 见证时间、地点、负责人。

见证点申报表的格式可参考附录。

某些特殊情况下，可以便捷的方式直接通知（如用电话、微信等通知方式）控制点的 监督见证，书面见证点申报表在一个工作日内补充给东方武核。

# 12.5 W 点和 H 点的放弃

a) 东方武核明确 W 点和 H 点的放弃后，供方可以独立执行，但供方应在该 H 、 W 点 工序完成后作为 R 点提供相关记录和资料 ( 包括制造技术文件、合格证明文件、检 查和试验结果记录等 ) 供东方武核审查确认，先决条件检查、取样等无报告和记录 产生的工序除外。

b) 东方武核决定放弃的 H 点见证，需以书面形式通知顾客。东方武核明确 W 点和 H 点的放弃后，应通知供方人员在质量计划中备注“ XX 单位放弃见证”字样和“书 面通知的函号或放弃审批单编号”。

# 12.6 多次重复工作完成的单一工序见证

a) 数量较多的原材料、零件（如板材、管材、小锻件、管配件等），当使用一份质量 计划，一个工序针对很多数量原材料、零件时，这种通过多次重复工作完成的单 一工序，应通过多次通知及检查完成。其每一次工作都应通过记录单进行记录， 在所有工作完成并符合要求后才可以完成该工序的控制点签字。

b) 如因见证时间冲突，且难以重新安排见证，对于多次重复工作完成单一工序的见 证，可以采取抽查方式完成见证和控制点签字，此时应在见证记录及质量计划上 注明见证范围。

# 12.7 多次重复的相同工序见证

a) 数量较多的原材料、零件（如板材、管材、小锻件、管配件等），当使用同一质量 计划，质量计划复印多次，分批次进行重复工序时，每批次均应发生见证通知。 每批次见证点见证，均应满足程序要求并进行控制点签字。

b) 如因见证时间冲突，且难以重新安排见证，可以按批次数量抽查见证 W 点和 H 点。

c) 未抽查见证的质量计划相应工序，如有相应报告产生，可以转为 R 点进行控制，

<!-- page: 15 -->

先决条件检查、取样等无报告产生的工序除外，但不需要执行放弃审批。

d) 数量大、批次多、可通用互换的材料、零部件、组件、设备等进行连续性生产作 业时，可仅对首批次材料、零部件、组件、设备的开工检查、检测检验、功能试 验、出厂试验等工序选点见证，其他批次可选为 R 点或不选点。但应对制造过程 进行巡检，并按巡检内容填写质量监督记录（记录巡检数量、批次）。

# 12.8 持续时间很长工序的见证

持续时间很长的焊接、热处理、 PT 、 UT 、试验等工序，当选为 W 点时，可以不进行 整个操作过程旁站见证。但必须检查工序开始实施条件是否符合要求、监督重要操作参数 和步骤是否符合要求；当选为 H 点时，原则上应全过程见证。

# 12.9 签点日期

a) H 、 W 点见证时，各见证方应先完成质量计划前面 R 点的审查签点，有逻辑关系 的前序 R 点未签，不能执行后续 H 、 W 点工序及见证；无逻辑关系的前序 R 点， 如因报告未出或其它特殊情况，前序 R 点未签可以进行后续 H 、 W 点工序操作和 见证签点，签点时应在 H 、 W 点工序“备注栏”备注“ XX 序 R 点报告未提交审 查”，同时签名及备注日期，日期应为 H 、 W 点见证日期；在后续完成报告审查后， 见证人员应在质量计划对应 R 点栏及时完成签署姓名和日期，日期应为报告审查 完成日期； R 点签署日期不得早于供方报告审批日期。

b) 完成 H 、 W 点见证并核实相应报告（如有）合格后，在质量计划相应栏签字放行， 原则上，见证点签署日期应为工序执行完成日期。见证点的签点移植时，也应移 植其原始日期。

c) 对 H 、 W 点，供方 QC 和 QA 人员签署的日期应满足不早于工序完成日期（可以 是起止日期）； R 点签署日期应满足不早于报告批准日期；有前后逻辑顺序的工序， 前序签署的日期不晚于后序签署的日期；所有工序签署的日期不得晚于质量计划 关闭日期。

# 12.10 R 点的函审

对于 R 点的签点释放，如果审查不在现场进行，可以通过函件认可形式替代相应质量 计划中的签署。

# 12.11 报告的出具

对于有报告产生的工序，供方原则上应在该工序完成后的三个工作日之内出具报告。

# 12.12 不符合项

若在工序执行过程中发生不符合项，应将不符合项编号标注在相应工序的“备注”栏 中，原则上相应的 H/W/R 点需要待不符合项报告关闭后方可签署放行（签署日期为执行见 证的日期）；如果产生的 NCR 不能关闭，但不影响本工序其他工作和后续相应工作，可以 在 NCR 工序“备注”栏中备注说明相应情况或注明按已审查通过的 NCR 报告中的限制条 件执行，然后签署放行。通过 NCR 清单跟踪、关闭 NCR 。

原材料阶段产生的不符合项，在不符合项报告关闭前，原则上该原材料不允许交付。 见证质量计划关闭或完工报告审查时，存在 NCR 需交付东方武核验证关闭或在后续工序 进行验证关闭等情况，可以进行有条件签署放行，此时质量计划“备注”栏中备注说明按 已审查通过的 NCR 报告中的限制条件执行，然后签署放行。通过 NCR 清单跟踪、关闭 NCR 。

# 13 不符合项的管理

供方负责在不符合项报告中对缺陷（或怀疑缺陷）和判定依据进行描述并审核后发布， 这些审核应确保：

 不符合项的填写清楚完整、准确；

 附件的检验报告内容齐全、简图正确清晰；

 缺陷已经准确定位，相关描述详实可靠；

 相关判据适用。

完工报告应采用大于或等于 70 克的 A4 纸打印、复印并扫描成 PDF 格式。完工报告 左侧应留出足够的装订空间。完工报告中所有手写内容应采用耐久性强的书写材料书写。 纸质版的完工报告不允许双面复印。若完工报告中加盖供方的印章，则印章内容必须完整、 清晰。 PDF 文件所有扫描页面的排放应符合阅读习惯。具体要求如下：

# 15.2.1 纸质版文件

(1) 文件、图纸应为原件，原件的特征一般为：所有记录为当事人亲笔所写、签字及 标注日期清晰准确、公章应采用红色鲜章印章；

(2) 如确定无法提供原件，须有原件存放声明（或符合性声明）、清晰的鲜章，含彩色 内容的页面须提供彩色复印件；

(3) 所有的记录必须字迹清楚、图样清晰、图标整洁，如无需签字项应划 “/” 进行标识， 不得空缺签字栏。文件不能涂改，应采用杠改，每处修改由责任人签署确认；

(4) 所有记录必须用合适的材料制成 ( 包括签名必须用碳素墨水钢笔和签字笔等 ) 。如有 易褪色材料（如复写纸、热敏纸等）形成的文件，应附一份复印件，复印件页码与原件保 持一致；

(5) 复印、打印文件的字迹、线条和清晰度应符合要求；

(6) 所有文件预留大于 1.5cm 的装订距离。

# 15.2.2 电子文件的整理要求

(1) 提交电子版质量证明文件时，应与纸质文件一一对应，需要靠颜色辨识数据信息 的文件应彩色扫描、打印；

# 16 进入的权利

# 16.1 东方武核、顾客

在正常的工作日，东方武核、顾客代表有权利进入供方及其下游的各个供方的制造场 地、办公室进行相关监督、检查或监查活动，范围包括设计、制造、检查及试验、采购、 管理及记录查阅等。供方应向他们提供必要的信息及协助使其顺利完成活动。东方武核、 顾客的源地见证活动不减轻供方确保其产品质量合格的责任。

# 16.2 国家核安全监管单位

供方应提供服务便利，使国家核安全监管部门人员能顺利开展其在供方场所的相关 QA/QC 活动。

# 17 记录和报告

供方须建立并执行质量保证记录制度。该制度必须能保证保存足够的记录，以便提供 影响质量的活动的证据和说明物项运行前状况的基准数据，必须为记录的鉴别、收集、编 入索引、归档、贮存、保管和处置作出规定。

适用的记录必须注明日期，并经授权人员签字、盖章或作其他鉴定后方能生效。这些 记录可以是原件或复印件。所有的记录必须字迹清楚、内容完整，并按所记述的物项进行 标识。每项记录应有明显的标识信息，以便辨别该项记录所对应的物项或活动。

# 供应商防造假管理具体要求

本要求依据东方电气（武汉）核设备有限公司《防造假管理》（ DFWH-QA-MH-1401 ） 制定，适用于为公司提供物项的采购供方，供方需严格遵照本要求开展防造假相关工作， 确保供货及服务过程的真实性、合规性。

# 一、建立防造假管理机制

1. 供方需按公司要求，建立完善自身防造假管理机制，明确防造假工作职责、流程和 管控措施；

2. 供方需将防造假管理要求传递至自身下游各级分包方，确保全供货 / 服务链条落实防 造假管控。

# 二、实体质量及管理行为防造假基本要求

# （一）严禁各类实体质量造假行为

（一）严禁各类实体质量造假行为

1. 不得擅自更改、伪造与产品质量有直接关系的证明报告，包括但不限于水质报告、 设备精度鉴定报告、试验 / 检查报告、焊接评定及焊接质量报告、质量证明书等制造完工报 告。

2. 不得向东方武核提供冒牌产品，或未经东方武核及顾客同意的贴牌产品。

3. 不得存在产品以次充好、厂家混料 / 换料等影响产品实体质量的造假行为。

# （二）严禁各类管理造假行为

1. 不得出现冒名顶替签名、印章造假、数据填报造假、事后补填记录等行为。

2. 未出席相关见证点的，不得签署对应报告或记录。

3. 不得伪造供方评价、培训、监督评估等记录，不得虚报质量相关资源和配置。

4. 特种作业人员不得无证上岗，不得违反“三按”作业要求开展生产操作。

5. 不得使用无效、超期的设备、工具、量具进行作业；不得违规处理质量问题，不合 格品未经东方武核许可不得入库、转序。

6. 发现质量问题后，不得隐瞒不报、不如实报告或不按规定流程报告。

# 三、质量证明文件及检测报告相关防造假工作

（一）原材料质量证明文件真伪及合规性管控

<!-- page: 27 -->

1. 向东方武核提交的原材料、外购件质量证明文件需 100% 保证真实、合规，文件格式 统一、印章清晰可追溯，试验项目完整、结果符合标准及合同要求。

2. 严禁对质量证明文件进行遮挡修改后复印、涂改数据等行为，原则上质量证明文件 不允许涂改，确需修改的须按规范流程执行。

3. 若为经销商 / 代理商供货，需配合东方武核完成原材料质量证明文件的真伪核查，确 保文件可追溯、信息真实。

# （二）第三方检测报告真伪及合规性管控

1. 供方自身委托第三方检测机构出具的检测报告，需由供方完成 100% 真伪核查；向东 方武核提交的所有第三方检测报告（含分包商提交的），需配合东方武核完成真伪核查工 作。

2. 第三方检测报告相关的检测机构须具备合法有效资质，资质覆盖对应检测项目；报 告公章真实、数据准确，检测工作确已实际开展，严禁资质作假、公章造假、数据造假。

3. 配合东方武核通过第三方检测机构官网、电话 / 邮件、供方对接核实等方式核查报告 真伪，按要求提供核实渠道或书面核实结果。

# 四、报告与原始记录一致性核查工作

# （一）自查要求

1. 供方需对自身产生的所有报告与原始记录开展 100% 一致性自查，报告类型包括但不 限于：产品 / 原材料质量证明书 / 合格证、无损检测报告、尺寸检查报告、热处理报告、焊 接记录、水压试验报告、理化试验报告、清洁度检查报告等。

2. 供方需按每本质量计划填写一份《报告一致性自查记录表》，如实记录核查结果，签 字确认并留存。

3. 自查过程中需重点核查以下内容，确保无造假情况：

（ 1 ）同一厂家相同类型报告格式一致；

（ 2 ）报告内容正确、完整、合理、清晰可读；

（ 3 ）报告内容、数据、结论与原始记录完全一致；

（ 4 ）同一人出具 / 签发的不同报告中签名、日期一致；

（ 5 ）报告 / 原始记录划改内容属实、规范，无随意涂改；

（ 6 ）质量计划、报告中的签字时间逻辑合理。

4. 对于酸洗钝化报告、标识检查 / 确认报告、清洁度检查报告、目视检查报告等无原始 记录的报告类型，需通过自身巡检、质量监督等方式保证报告真实性，无需另行开展一致 性自查。

# （二）配合东方武核核查要求

1. 供方需配合东方武核质量监督人员、放行检查人员开展报告与原始记录一致性抽查 工作，东方武核将按每份质量计划 / 本次放行检查涉及报告的 5% 比例（向上取整）抽查原 始记录。

2. 若东方武核在抽查中发现疑问，供方需配合开展 100% 原始记录核查，并按要求提供 相关资料，留存核查记录。

3. 供方需按东方武核要求，在经核查无误的报告上配合完成盖章、签字等确认工作。

# 五、质量证明文件存疑及问题处置

1. 若供方提交的质量证明文件、第三方检测报告等被东方武核质疑真实性，或存在文 件缺失情况，供方需配合东方武核按顾客管理程序要求开启不符合项报告，并按不符合项 管理程序完成处置。

2. 若东方武核对物项材质存疑，需采用手持式合金分析仪开展实物核查时，供方需配 合完成实物核查工作，提供必要的协助。

3. 对于不纳入完工报告的 QNC （或相应等级）物项的质量证明文件，供方需按要求整 理提供，确保文件完整，配合东方武核完成存档备案工作。

# 六、培训及人员管理要求

1. 供方需组织参与东方武核质量安全环保部开展的《防造假管理》程序文件培训宣贯， 确保相关工作人员熟练掌握防造假管理要求，培训每年至少参与一次。

2. 供方需自行组织内部防造假相关培训，覆盖所有相关岗位人员，确保工作人员明确 自身防造假工作职责，杜绝造假行为。

3. 供方需建立人员资质管理台账，特种作业人员、检测人员等关键岗位人员须具备有 效资质证书 / 授权书，严禁无证上岗，配合东方武核开展人员资质核查工作。

# 七、造假行为的相关责任

1. 若供方被发现存在质量造假事实，东方武核将根据《供应商管理办法》三色名单管 理规定进行考核。

<!-- page: 29 -->

2. 供方发生造假或涉嫌造假问题时，需按东方武核要求暂停相关活动，配合东方武核 质量安全环保部、采购部开展调查工作，按要求提交相关资料，接受东方武核的调查处理 结果。

3. 因供方造假行为给东方武核造成损失的，东方武核将按合同约定追究供方的相关责 任。

# 八、其他要求

1. 供方需按东方武核要求，在采购合同履行过程中，严格承接东方武核的防造假管理 要求，确保全流程合规。

2. 供方需配合东方武核开展的防造假工作检查、考核，按要求整改检查中发现的问题， 及时反馈整改进度和结果。

供方需建立防造假工作台账，记录自身防造假自查、整改、培训等相关信息，台账保 存期限需满足东方武核合同质保期要求，且不早于项目最终验收证书签字日期。
