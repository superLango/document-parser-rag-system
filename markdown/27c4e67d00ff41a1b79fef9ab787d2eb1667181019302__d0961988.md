# 引言

根据科研管理部任务安排，针对第五代军用涡扇发动机研制需要，特编制 GH4169D 静叶、机匣等用环形锻件质量控制要求，以加强环形锻件毛坯冶金质量控制。GH4169D 环形锻件按本要求的相关规定检验合格后，方可安排进行零件试验、部件试验和装机试验，以保证发动机零部件试验与装机运行安全。

# 1 范围

本文件规定了GH4169D合金环形锻件的要求、验证、包装、运输和贮存等。

本文件适用于高推重比军用涡扇发动机静叶环及机匣等用 GH4169D 合金环形锻件（以下简称锻件）。

# 3.1.1 冶炼方法

合金采用真空感应熔炼+电渣重熔+真空电弧炉重熔的三联冶炼工艺生产，所采用的冶炼方法应在合同和质量证明书中注明。

# 3.1.2 复验

锻件用原材料应按 FTE1.JT.34 复验合格后方可投产。

# 3.2 化学成分

3.2.1 锻件的化学成分应符合表1的规定。

3.2.2 锻件化学成分允许偏差应符合 GJB 5307 的规定。

# 3.3 加工方法

锻件采用轧制工艺制成，锻件最后一火的锻造加热温度不高于 1060℃。

# 3.4 交货状态

锻件按以下状态之一交付，交货状态应在合同和质量证明书中注明：

——A状态：锻态；

——B状态：预处理+固溶处理；

C状态：预处理+固溶处理+时效处理。

# 3.5 热处理

锻件按3.5.1、3.5.2和3.5.3分别进行热处理。对用于焊接结构环形锻件的力学性能试样，除进行锻件的热处理外还需按3.5.4进行热处理。

注：加热温度为金属实际达到的温度，保温时间为锻件最大截面热透后的保温时间。

# 3.5.1 预处理

将锻件加热至 860~880℃，在选定温度±10℃保温16h后空冷。

# 3.5.2 固溶热处理

将锻件加热至 945~982℃，在选定温度±10℃保温1h后空冷或油淬或水淬。

# 3.5.3 时效热处理

先加热至 788℃±10℃，保温至少 8h；然后以 56℃/h的速度冷却至 704℃±10℃，保温至少 8h后空冷。

# 3.5.4 焊接结构环锻件消除应力热处理

3.5.4.1 对用于焊接结构环锻件的力学性能试样，除需按 3.5.1、3.5.2 和 3.5.3 进行热处理外，还应在热处理炉中加热至 760℃，保温 8h；然后以 45～65℃/h 的速度冷却至 649℃；再炉冷至 260℃；最后，炉冷或空冷至室温。

3.5.4.2 对于焊接组件，在真空炉中加热至 315℃，保温 30min；接着加热至 425℃，保温 30min；然后加热至 540℃，保温 30min；继续加热至 650℃，保温 30min；最终加热至 760℃，保温 8h。然后，以 55℃/h 的速度冷却至 649℃保温，总时间 3h；以不高于 55℃/15min 的速度冷却至 260℃；最后，炉冷或空冷至室温。

# 3.6 力学性能

3.6.1 以C状态交货的锻件硬度应符合表2的规定。

3.6.2 从以 C 状态交货的锻件或试验环上切取弦向试样、从以 B 状态交货的锻件或试验环上切取弦向试样经 3.5.3 时效处理后、从以 A 状态交货的锻件或试验环上切取弦向试样经预处理+固溶处理+时效处理后，测试力学性能，应符合表 2 的规定。

# 3.7 低倍组织

3.7.1 从锻件或试样环上切取的横向低倍试样（低倍试样应为最终热处理状态）上，不应有目视可见的疏松、针孔、裂纹、缩孔、偏析、夹渣和夹杂等冶金缺陷。

3.7.2 从以C状态交货的锻件或试验环上切取弦向试样、从以B状态交货的锻件或试验环上切取弦向试样经3.5.3时效处理后、从以A状态交货的锻件或试验环上切取弦向试样经预处理+固溶处理+时效处理后，检查暗腐蚀区、白斑或浅腐蚀区，按Q/S10-0102执行。

# 3.8 高倍组织

# 3.8.1 显微组织

从以C状态交货的锻件或试验环上切取弦向试样、从以B状态交货的锻件或试验环上切取弦向试样经3.5.3时效处理后、从以A状态交货的锻件或试验环上切取弦向试样经预处理+固溶处理+时效处理后，检验显微组织，应符合Q/S10-0102的规定。

# 3.8.2 晶粒度

从以C状态交货的锻件或试验环上切取弦向试样、从以B状态交货的锻件或试验环上切取弦向试样经3.5.3时效处理后、从以A状态交货的锻件或试验环上切取弦向试样经预处理+固溶处理+时效处理后，测定平均晶粒度，应为4级或更细。其中，矩形环锻件允许有个别2级晶粒；异形环锻件允许有个别1级晶粒。

# 3.9 超声波检验

锻件应逐件按 Q/S10-0104 进行超声波检验，矩形环锻件缺陷显示的波幅应不大于直径 1.2mm 当量平底孔所显示的波幅。异形环锻件缺陷显示的波幅应不大于直径 2.0mm 当量平底孔所显示的波幅。

# 3.10 形状、尺寸

锻件的形状、尺寸和公差应符合供需双方签定的图样的规定。

# 3.11 外观质量

3.11.1 锻件表面不允许有过烧、裂纹和影响材质的其他缺陷；局部缺陷可以用打磨的方法清理，但清理的深度不允许超过该处加工余量之半。

3.11.2 锻件表面允许有个别细小的压痕、擦划痕，但其深度应不超过该处加工余量的1/3。

3.11.3 锻件粗加工后表面粗糙度Ra值应不大于3.2μm，并应满足超声波探伤要求。

# 4 质量保证规定

# 4.1 质量控制

4.1.1 锻件在试制、转厂或改变主导工艺时应按HB5402的规定进行鉴定、定型，然后方可投入批生产。

4.1.2 锻件主导工艺过程的生产条件应按 GJB 904A 进行准备和控制。

4.1.3 当供方生产工艺有重大改变时，应预先征得需方技术主管部门的同意，并根据需要进行全面性能和工艺试验，其冶金质量不能低于定型批质量水平；必要时，需方可查看供方的制造生产工艺和本标准所要求的各项试验结果，但双方应予保密。

# 4.2 质量一致性检验

# 4.2.1 组批规则

锻件应成批提交验收，每批原则上应由同一图号、同一熔炼炉号、同一投产批和同一热处理炉批的锻件组成。

# 4.2.2 检验项目

4.2.2.1 质量一致性检验项目、取样数量及相应要求和检验方法的章条号见表3。

4.2.2.2 锻件的取样部位按锻件图样或专用技术文件的规定。

4.2.2.3 II类锻件每批取一个锻件或试验环进行理化检验。供方可按原材料的分析结果报出化学成分。

# 4.2.3 判定与复验规则

4.2.3.1 化学成分分析结果不合格时，允许重新取样对不合格元素进行复验，复验结果仍不合格时，该批判为不合格。

4.2.3.2 力学性能某项检验结果不合格时，允许在同一试验件上切取双倍数量的试样对不合格项目进行复验；复验结果仍不合格时，允许在本标准规定的范围内重复热处理后，重新提交验收；若仍不合格，该批锻件判为不合格。重复热处理允许进行一次。

4.2.3.3 低倍组织、显微组织或晶粒度检验不合格时，该批锻件判为不合格。

4.2.3.4 超声波检验不合格时，该锻件判为不合格。

4.2.3.5 尺寸、外形或外观质量检验不合格时，该锻件判为不合格。

# 4.3 检验方法

# 4.3.1 化学成分分析

化学成分分析按 GB/T 223 和 GJB 5404 进行。

# 4.3.2室温拉伸试验

室温拉伸试验按 GB/T 228 进行。

# 4.3.3 高温拉伸试验

高温拉伸试验按 GB/T 4338 进行。

# 4.3.4 高温持久试验

高温持久试验按 GB/T 2039 进行。

# 4.3.5 硬度试验

布氏硬度试验按 GB/T 231.1 进行。

# 4.3.6低倍组织检验

低倍组织检验按 GB/T 14999.2 和 Q/S10-0102 进行。

# 4.3.7 高倍组织检验

4.3.7.1 显微组织检验按 GB/T 14999.4 和 Q/S10-0102 进行。

4.3.7.2 晶粒度检验按 GB/T 6394 进行。

# 4.3.8 超声波检验

超声检验按 Q/S10-0104 进行。

# 4.3.9 形状、尺寸检验

形状、尺寸检验采用通用的测量工具进行。

# 4.3.10 外观质量检验

外观质量采用目视检验。
