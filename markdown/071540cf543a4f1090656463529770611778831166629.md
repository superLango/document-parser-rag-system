# 前 言

本程序根据 GB/T 19001 - 2016 idt ISO 9001 ： 2015 《质量管理体系 要 求》、 HAF003 《核电厂质量保证安全规定》、《招远核电项目一期工程质 量保证大纲》 (HTC/CW PQAP -143019/143020-2023) 及顾客特殊要求，并结 合公司实际情况，对《招远项目 1 、 2 号机组 LOT40 汽轮发电机组质量计 划控制程序》 A 版修订而成。

本程序由质量管理部归口。

本程序起草部门：质量管理部

# 1 目的

为了便于中广核工程有限公司、哈汽公司及哈汽公司供方在招远项目 1 、 2 号机组 LOT40 汽轮发电机组制造过程中对产品质量进行监督和跟踪，以确保产品的制造质量。

# 2 范围

本程序规定了《招远项目 1 、 2 号机组 LOT40 汽轮发电机组质量保证大纲》（工作 令号 143019 、 143020 ）范围内的设备质量计划的编制与管理。

# 3 术语和定义

本程序采用 HTC/QM 《质量手册》、 HTC/PQAP -143019/143020-2023 《招远项目 1 、 2 号机组 LOT40 汽轮发电机组质量保证大纲》、购买方外发程序《设备制造质量监督》 （ PJ-30P-500-R ）的术语和定义，并增加下述定义：

3.1 产品质量计划：指产品进行制造、检查、试验和验证的一种计划性文件。公司内 通常指零部件制造过程中的重要工艺过程及工序的检查内容要求的文件。

# 3.2 监督点

监督点的级别关系从高到低为： H 点、 W 点、 R 点。

3.2.1 R 点：指制造过程中的记录审查点，供方应及时发布报告并提交质量监督人员审 查。

3.2.2 W 点：指制造过程中的通知见证点，如果购买方设备监造人员明确不出席或没 有按双方约定的出席时间出席，公司及相关供方可以独立执行。

3.2.3 H 点：是制造过程中的一项关键工序，是停工待检点。除非购买方设备监造人员 出席见证或书面通知放弃该 H 点，否则公司及相关供方不得进行该道工序及后续操作。 除非事先获得书面授权。

# 4 职责

# 4.1 质量管理部

a）负责编制本项目质量计划控制程序，并对质量计划程序执行过程进行监督考核；

4 职责 4.1 质量管理部 a ）负责编制本项目质量计划控制程序，并对质量计划程序执行过程进行监督考核； b ）负责质量计划清单的汇总工作，并将最终批准的质量计划清单上传至 OA 系统 核电质量信息平台上。 4.2 核电工程部 a ）负责与购买方 / 业主协调、传递质量计划工作相关信息及资料； b ）负责将质量计划见证点通知单编号并传递给顾客 / 业主，并对监造过程进行协调 处理。

# 4.2 核电工程部

a）负责与购买方/业主协调、传递质量计划工作相关信息及资料；

b）负责将质量计划见证点通知单编号并传递给顾客/业主，并对监造过程进行协调处理。

# 4.3 设计部门

a）负责按职责分工要求，编制采购质量计划清单；

b）负责对供方质量计划更改意见的落实进行确认。

# 4.4 采购部门

a）负责向供方传递公司、顾客/业主的有关质量保证要求、技术文件、适用的标准，责成供方编制设备或零部件质量计划；负责对供方质量计划更改意见的落实进行确认；

b) 负责将采购设备或零部件质量计划传递到工艺部门/设计部门、质量检验部会签；

c）负责国内、外供方见证点通知及见证手续办理工作，并协调供方组织见证工作；

d) 负责将最终批准的质量计划上传到OA系统核电质量信息平台上，负责对核电质量信息平台上的质量计划版本进行更新。

# 4.5 工艺部门

a）负责编制职责范围内的质量计划清单；

b）负责编制职责范围内的设备或零部件质量计划及执行过程中对涉及到质量计划内容方面的问题的处理；

c ）负责按工艺职能对供方编制的质量计划进行审核会签；负责对供方质量计划更 改意见的落实进行确认；

d ）负责外购铸、锻件质量计划清单的编制工作，负责编制锻造、热处理、表面处 理等工艺的质量计划；

e）负责将最终批准的质量计划上传到OA系统核电质量信息平台上，负责对核电质量信息平台上的质量计划版本进行更新。

# 4.6 质量检验部

a）负责审核确认公司及供方质量计划中的质量见证点及相应内容；负责对会签质量计划更改意见的落实进行确认。

b）负责收集关闭的质量计划，并归入产品质量档案；

c）负责编制公司内部探伤工艺文件，并对供方编制的探伤工艺文件进行确认；

d）负责对质量计划中理化检验、性能试验等厂内所有见证点的实施工作。

# 4.7 生产部门

负责见证点工作的组织、负责见证通知及见证手续办理工作。

# 4.8 生产部

a）负责组织下达公司内生产指令（生产作业计划、生产任务单等），实施生产调度、在制品管理等生产管理活动；

b ）负责公司内部生产资源能力平衡并与相关部门确定厂内承揽加工量，与其签订 产品制造委托书，提供生产支持，对保证按期、按质、按量完成合同负责；

c ）负责制定生产作业计划、生产需求原材料计划，并对计划执行情况进行考核； 负责依据本项目技术准备计划和生产准备计划将质量计划预编制时间填入质量计划清 单中，同时将质量计划纳入到技术准备计划中。 4.9 供方根据本程序要求编制质量计划并提交哈电汽轮机审核，并按照审核通过后的 质量计划开展生产和服务，具体质量计划编制要求需符合本程序要求。

4.9 供方根据本程序要求编制质量计划并提交哈电汽轮机审核，并按照审核通过后的质量计划开展生产和服务，具体质量计划编制要求需符合本程序要求。

# 5.1 质量计划清单的编制

# 5 工作程序

5.1 质量计划清单的编制 各责任部门负责编制职责范围内质量计划清单，经部门主管领导批准后提交质量管 理部，质量管理部负责质量计划清单整理汇总并提交核电工程部，由核电工程部报购买 方 / 业主认可。

a ）公司内制造的零部件（含主机分厂、动装分厂、重装分厂、叶片分厂、冷作分 厂、金工分厂、采购部外协件及自动控制分公司和辅机工程公司的非采购部套）由工艺 部负责牵头编制质量计划清单；

b ）辅机工程公司、设计部、自动控制分公司负责按各自承担的采购部套（主要指 配套件）编制质量计划清单；

c）设计部负责编制外购原材料（铸锻件、热处理、表面处理）质量计划清单；

d）若质量计划清单发生变更，清单编制部门应更新后提交质量管理部；

e）质量计划清单格式（见附件1）内容包括，图号、质保等级、质量计划名称、质量计划编码和预编制完成时间；

f）质量管理部负责质量计划文件编码的编制工作；

f ）质量管理部负责质量计划文件编码的编制工作； g ）生产部负责依据本项目技术准备计划和生产准备计划将质量计划预编制时间填 入质量计划清单中，同时将质量计划纳入到技术准备计划中；

h ）生产部、核电工程部依据质量计划清单对编制、修订执行不及时考核，质量管 理部对质量计划执行过程中的管理问题进行考核，质量检验部对未按见证要求和提交质 量证明文件进行考核。

5.2 质量计划的编制、审核、会签、批准、更改、归档

5.2.1 公司内质量计划的编制、审核、会签、批准、更改、归档

5.2.1.1 工艺部门按工艺职责分工及质量计划编制的要求，编制职责范围内的质量计 划。当产品零部件制造过程由多道不同专业的工序完成，质量计划涉及多个工艺部门进 行编制时，按主要工序对质量计划进行拆分编制，如：铸锻件毛坯、焊接件焊接质量计 划及加工质量计划可分开编制。如无法拆分，由承担主要工序的工艺责任部门总成。质 量计划经各工艺部门和质量检验部审核，公司主管副总工程师或工艺部经理批准后，转 核电工程部与购买方业主沟通，经购买方批准后方可执行。

# 5.2.1.2 质量计划的更改

5.2.1.2.1 若质量计划中的主要检查内容、依据文件、标准、工艺文件等发生变更，此 时质量计划需要更改，由原编制部门进行更改升版，质量计划升版前，升版人员应确认 对应产品生产状态，若升版内容对产品生产制造有影响，应及时向生产部门传递信息， 暂停产品受影响工序的生产制造，并在升版完成后，及时将质量计划上传至核电信息平 台并通知相关生产部门。并按本程序第 5.2.1.1 条重新履行审批手续下发执行，并对核

电信息平台上的质量计划进行升版替换，保证其有效性。

5.2.1.2.2 若质量计划中的作业序号、依据文件的版本、内部编码等较小的修改，不涉 及到购买方的见证点，此时质量计划需要修改，由原编制部门填写“质量管理体系文件 更改通知单”（见附件 2 ），经各工艺部门和质量检验部，并将更改后的质量计划及更 改单上传到核电信息平台上，同时提交核电工程部，由核电工程部提交购买方备案。同 时原编制部门将正在运行的质量计划杠改，填写更改记录，同时将“质量管理体系文件 更改通知单”附在此质量计划后，待质量计划关闭后随此质量计划归档保存。

5.2.1.3 质量计划随工序流转，最后一序关闭后由质量检验部收回，归入产品质量档案。

5.2.2 供方质量计划的编制、审核、会签、批准、更改、归档

5.2.2.1 采购部门负责将采购产品的采购合同技术协议、图纸、标准文件及质量计划的 编制要求传递到供方，由供方进行编制产品生产实施质量计划，供方编制完成后由采购 部门依据采购合同技术协议、图纸、标准文件进行复查，并将其作为采购部门编制的采 购质量计划的一部分，产品采购质量计划编制完成并经采购部门编制、审核后，依次传 递到工艺部门或设计部门、质量检验部进行会签，会签完成后，经主管副总工程师批准， 最终由采购部门将会签后的质量计划扫描版，经由 OA 质量计划审批流程提交质量检验 部及核电工程部，由核电工程部提交购买方审核确认，购买方审查批准后传递到供方执 行，并由采购部门将批准后得质量计划上传到核电信息平台。

5.2.2.2 供方编制的质量计划需要更改时，供方需对质量计划进行升版，质量计划升版 前，升版人员应确认对应产品生产状态，若升版内容对产品生产制造有影响，应及时向 生产部门传递信息，暂停产品受影响工序的生产制造，并在升版完成后，及时将质量计 划传递至相关生产部门。并按本程序第 5.2.2.1 条重新履行审批手续后下发执行。

5.2.2.3 产品制造完成后，采购、外协部门负责将关闭后的质量计划从供方收回，并上 报质量检验部归入产品质量档案。

5.2.3 只有当质量计划的审查结论为 ACC 或 AEN ，公司 / 供方才能开始相应的开工制 造。结论为 AEN 的质量计划，必须在意见工序之前完成质量计划的升版并提交购买方 审查认可。否则，公司 / 供方应及时采取补救措施，购买方保留拒收的权利。（ ACC ： 表示对文件审查无意见； AEN ：表示除 DRCS 中提出的意见外可接受，适用于只需作 些小修改的文件。）

特殊情况，对于不符合项返修质量计划、紧急采购设备 / 部件 / 原材料的质量计划， 或其他紧急的返修质量计划，购买方质量监督人员预审无意见后在质量计划封面或首页 签字，视同生效并可以执行。预审签字后，需在五个工作日内正式提交购买方，否则已 预审的质量计划不得继续执行。

5.2.4 任何对质量计划的修订都必须经过购买方审查认可后才能执行，购买方对质量计 划是否需升版有决定权，基本要求如下：

a ）增加、删除等修改质量计划，将导致购买方监督点的变化，影响购买方质量监 督控制，以及设备制造工序或工艺有重大调整，必须升版质量计划并提交购买方审查认 可。

b ）增加、删除等修改质量计划（如删除或降低供应商的监督点等），不影响购买 方的监督控制，可以不升版质量计划，但必须通过购买方质量监督人员在质量计划相应 位置签字确认后方可执行。对于质量监督人员跑点监督的情况，若质量计划有修改，质 量监督人员可在下次见证时在质量计划相应位置签字确认。

c ）购买方质量监督人员在监督过程中发现质量计划存在关键工序遗漏等原则性问 题，应升版质量计划并提交购买方审查认可。

d ）购买方质量监督人员在设备制造过程中如临时需要增加、删除、变更监督点， 且不涉及其他修改时，通报我司并在相应修订处签字确认，可以不升版质量计划。

e ）其它情况，购买方质量监督人员认为有必要升版质量计划时，可要求升版并提 交审查认可。

5.2.5 质量计划未经购买方认可前不能进行相关的生产制造活动。

# 5.3 质量计划编制及执行原则

# 5.3.1 质量计划编制执行原则

5.3.1.1 依据《招远项目 1 、 2 号机组 LOT40 汽轮发电机组质量保证大纲》的要求，质 保等级为 C1b 、 C2 级的物项及对应质保等级的设备、部件及原材料需编制质量计划， 质保等级为 C3 级的物项原则上不需要编制质量计划，但针对一些新设计、制造工艺较 复杂的物项及购买方有特殊质量管理要求的其它物项也可编制质量计划。

对于 E 类不符合项的返修处理，如涉及承压焊缝（含堆焊）的焊接返修、增加热 处理、增加 NDE （目视检查除外）、重新取样、增加性能试验（包括水压、水力、电 气试验等）的情况，应编制返修质量计划，并提交购买方审查认可；对于其它不符合项 的返修，由购买方根据实际返修活动来确定是否编制返修质量计划。对于已有通用返修 质量计划或原有质量计划已包含返修工序的情况，可以不用专门编制返修质量计划。

5.3.1.2 对于分级为 C1b 及 C2 类的采购 / 外协物项，提交完工文件供购买方监造人员审 查时，需同时提交见证后经签字的质量计划。 C1b 类采购物项公司见证点（ W/H ）出席 率不低于 70% ， C2 类采购物项公司见证点（ W/H ）出席率不低于 50% 。

5.3.1.3 公司设置见证点的级别、出席率不能低于购买方。

# 5.4 质量计划的执行

质量计划的执行要优先符合购买方外发程序《设备制造质量监督》（ PJ-30P-500-R ） 及购买方其它特殊要求。

5.4.1 质量计划编制部门需在相关制造活动开始前三个月将质量计划编制完成并经公 司各部门审核后报核电工程部，由核电工程部报购买方驻厂监造人员，得到驻厂监造人 员认可后，由核电工程部正式报给购买方，购买方批准后，质量计划方可执行，质量计 划未经购买方认可不能进行相关的生产制造。

5.4.2 如 W 、 H 点为试验项目，进行试验的生产部门通常应在试验前两个月，至少在 试验前 1 个月内提交试验程序给核电工程部，由核电工程部提交给购买方及驻厂监造代 表；如此序外协则由外协部门提前两个月提交试验程序给核电工程部，由核电工程部提 交给购买方及驻厂监造代表。

5.4.3 “质量计划”中规定的质量控制点（ H 、 W 、 R ）应在长票中注明。

# 5.4.4 质量计划的传递与使用

5.4.4.1 核电工程部负责将购买方确认后的质量计划批准函及质量计划以 OA 流程的传 递给编制部门，并由质量计划编制部门（工艺部、采购部、自动控制分公司等部门）上 传至公司内部核电信息平台上。质量计划所涉及的首序部门负责将相应质量计划输出打 印实施。质量计划与产品件使用时要一一对应，即相应的质量计划对应相应的产品件。

5.4.4.2 两件及以上同一产品件的质量计划实施时，如螺栓、螺帽、管板等成批生产件， 在加工过程中如需分件跨车间 / 分厂转序时，上序生产部门应将执行中的质量计划复印 件随产品（每件对应一份质量计划）一同转入下序生产部门。

5.4.4.3 封闭在本部门的“质量计划”，应随长票一并运行，需检查员和监造代表检查 的监造点，应经相关人员签字确认，责任部门将关闭后的“质量计划”与相关记录一并 提交给质量检验部检查员。

5.4.4.4 跨部门的“质量计划”，应随“工序完工转送单”一起转至下序部门，随长票 一并运行，需检查员和监造代表检查的控制点，应经相关人员签字确认，责任部门将关 闭后的“质量计划”与相关记录一并提交给检查员。

5.4.5 关闭后的“质量计划”由质量检验部存档。供方编制的质量计划关闭后由责任供 方随完工报告等质量证明文件一同传递给哈汽公司质量检验部。

# 5.6 产品质量监造

# 5.6.1 见证点要求

5.6.1.1 质量计划中记录见证点（ R 点）的要求：购买方在有疑义时，有权查阅、复印 与产品相对应的记录、报告等资料。

5.6.1.2 质量计划中现场见证点（ W 点）的要求：购买方如果在卖方规定的时间和日期 没有到场，可执行此序工作，但事后购买方及业主代表有权查阅、复印与产品相对应的 记录、报告等资料。

5.6.1.3 质量计划中停工待检点（ H 点）的要求：购买方如果不在场，不得越过该点进 行下一步操作，除非购买方提前给出书面许可。

5.6.2 通知购买方参加有关现场见证点（ W 点）和停工待检点（ H 点）的程序按如下 要求执行。

# 5.6.2.1 公司内见证检查通知

公司各责任部门应提前 10 个工作日填写“质量计划见证点通知单”，并将“质量 计划见证点通知单”发送给核电工程部，由核电工程部向购买方发出预通知，提前五个 工作日发出确认通知。

其中，理化性能试验设为 H 或 W 点的见证序，需由设计部填写“质量计划见证点 通知单”（见附件 6 ），并按本程序 5.6.2.1 条执行，如材料进厂后不需进行理化性能检 验，则由质量检验部填写“质量计划见证点通知单”，并按本程序 5.6.2.1 条执行。

# 5.6.2.2 国外见证通知要求

对于国外采购产品的见证，供方应提前三个月通知采购部门。采购部门填写“质量 计划见证点通知单”书面通知核电工程部，由核电工程部向购买方发出预通知，提前十 五个工作日发出正式确认通知。在收到质量计划见证点通知单一周内，购买方应确认是 否出席见证，如出席见证应将见证人员名单报送核电工程部，由核电工程部通知采购部 门，以便采购部门协助见证人员办理入境签证手续。接到购买方出席见证的信息后，采 购部门需出具报告，请示主管副总经理批示公司内参与见证的部门及人员。

如购买方不参与见证，购买方需将放弃信息通知核电工程部，由核电工程部传递至 采购部门，采购部门将购买方放弃见证的信息传递至供方，供方按质量计划要求执行， 并做好检查记录及报告，以便购买方后续见证时对已放弃的见证序进行文件审查，审查 后购买方在质量计划上签字，并在备注栏注明文件审查。

如出现不可抗力因素，见证时间应相应延长。
