# 4.2 锻造

凸轮轴轴段毛坯需采用落锤锻方式获得，其流线按锻件外形分布， 不允许出现扭曲或严重折断。其锻件的制造和质量要求应按CB778-86 《船用柴油机锻钢件技术条件》验收，锻造比大于4。

凸轮轴锻件内部组织不得有过热、过烧现象。

凸轮轴锻件内部组织不得有过热、过烧现象。 凸轮轴锻件表面不得有刻痕，损伤，裂纹，锻造折叠，非金属夹 杂物等诸如此类的缺陷。

表面不得有锻造或机加工造成的氧化皮痕迹、损伤、裂纹、锻造 褶皱和毛刺。不允许出现降低强度的缺口和凸起。对于未加工区域若 残留的深度大于1mm 的表面氧化皮痕迹，必须沿纵向进行大范围打磨 处理。

凸轮轴锻件不允许采用焊补方法或金属喷涂等方法修整，不允许 进行气割。

# 4.3 热处理

# 4. 3. 1 正火

4.3.1 正火 凸轮轴锻造成型后在热处理炉内重新加热到临界温度以上进行正 火处理。 4.3.2 调质 凸轮轴应进行调质处理，调质的回火温度不得低于550℃，凸轮轴 调质处理后应达到要求的机械性能。

# 4. 3. 2调质

凸轮轴应进行调质处理，调质的回火温度不得低于 550℃，凸轮轴调质处理后应达到要求的机械性能。

因为热处理原因机械性能不合格的凸轮轴，可以重新进行调质处 理，但凸轮轴重复淬火不得超过两次，允许多次回火。

# 4.4 机械性能和晶粒度

在同一熔炼炉号、同一热处理炉号的凸轮轴锻件带一件随炉试棒 (试棒材料与凸轮轴同一熔炼炉号,直径与锻件轴杆相同)，进行机械性 能检测，机械性能应达到表2 要求。取样后的试棒余料随同批锻件发 往甲方，供甲方复试。 4.4.1 硬度 凸轮轴应100%按照DIN EN ISO 6506-1 进行硬度检验，硬度应符 合270-330HBW，硬度试验位置按照图1 和图2。

# 4.5 凸轮轴锻件表面质量

4.5.1 凸轮轴锻件表面不得有裂纹，锻造折叠，非金属夹杂物等诸如此类的缺陷。

4.5.2 加工区域的表面缺陷需打磨至足以确定缺陷深度的范围，若深度不大于单边实际加工余量的一半，则可以不消除此缺陷，但应同时采用磁粉探伤进行验证。

4.5.3 打磨凹坑边缘必须均匀光滑，必须进行磁粉探伤证明缺陷已消除。
