# 前 言

本标准是为规范五代机整体叶盘用 GH4151合金棒材而制定的，参考北京钢研高纳科技股份有限公司企业标准，并协调相关单位后编制了本标准。

本标准由制造工程技术研究室起草。

本标准的主要起草人：张晓越、邢丕臣、王蕾雯、张鑫、谢兴飞、吕少敏。

本标准所代替标准历次版本发布情况：无。

本标准由通用技术研究室归口。

本标准由制造工程技术研究室负责解释。

# GH4151合金棒材规范

# 1 范围

本标准规定了GH4151合金棒材的要求、质量保证规定和交货准备等。

本标准适用于第五代军用涡扇发动机压气机叶盘用直径不大于300mm的GH4151合金锻制棒材。

# 2 规范性引用文件

下列文件对于本文件的应用是必不可少的。凡是注日期或版次的引用文件，仅注日期或版次的版本适用于本文件。凡是不注日期或版次的引用文件，其最新版本（包括所有的修改单）适用于本文件。

GB/T 223 （所有部分）钢铁及合金化学分析方法

GB/T 2039 金属材料 单轴拉伸蠕变及持久试验方法

GB/T 2101 型钢验收、包装、标志及质量证明书的一般规定

GB/T 4162 锻轧钢棒超声检测方法

# 3.3 交货状态

棒材以锻态、经车光或磨光后交货，表面粗糙度Ra≤3.2μm。

# 3.4 力学性能

3.4.1 试样的热处理制度如下：

固溶处理：1100℃~1180℃，保温2h~6h，空冷或控制冷却；

第一级时效处理：830℃~880℃，保温4h~10h，空冷；

第二级时效处理：730℃~780℃，保温8h~24h，空冷。

实际热处理制度应在质量证明书中注明。

# 3.5 低倍组织

<!-- page: 8 -->

3.5.1 在经酸浸的挤压棒材横向低倍试片上检验低倍组织，其低倍组织应均匀、无明显偏析，无目视可见的缩孔痕迹、空洞、裂纹、气泡和外来夹杂等缺陷。

3.5.2低倍试片的进一步显微组织检查。

# 3.5.2.1 白斑或浅腐蚀区的显微组织检查

3.5.2.1 白斑或浅腐蚀区的显微组织检查

在挤压棒材的低倍试样上检查白斑、浅腐蚀区等，检验用试样研磨、抛光按GB/T 13298进行。

# 3.5.2.2 暗腐蚀区的显微组织检查

暗腐蚀区检验用试样研磨、抛光按GB/T 13298进行。暗腐蚀区如被确认为含有Laves相的黑斑，涉及棒材被拒收。如果棒材上发现含有Laves相的黑斑，由生产该棒材同炉铸锭生产的其他产品同样报废。其他情况，双方协商解决。

# 3.6 高倍组织

# 3.6.1 晶粒度

在经3.4.1热处理的棒材试样上检查晶粒组织，平均晶粒度应为ASTM 8级或更细。

# 3.6.2 显微组织

在经3.4.1热处理的棒材试样上检查显微组织，按GB/T 14999.4进行条带晶粒组织评级、一次碳化物评级，积累典型图片。

# 3.7 超声检测

棒材超声波探伤参照GB/T 4162执行，满足AA级验收要求。

# 3.8 尺寸、外形及允许偏差

棒材的尺寸和允许偏差应符合GB/T 908要求，或由供需双方共同确定，但必须经用户批准。

# 3.9 外观质量

棒材表面不允许有裂纹、结疤和龟裂等；表面局部缺陷应予打磨清除，打磨宽深比应不小于6，打磨深度不应超出棒材负偏差范围，从公称尺寸算起在该尺寸正公差之半范围内的个别细小的划痕、压痕、麻点可不予清理。

# 4.1 检验分类

本标准规定的检验为质量一致性检验。

# 4.2.3 判定与复验规则

4.2.3.1化学成分分析结果不合格时，该批棒材判为不合格。

4.2.3.2力学性能某项检验结果不合格时，允许从原棒材上切取双倍数量的试样对不合格项目进行复验，复验结果即使只有一个试样不合格，该批棒材判为不合格。若能确认不合格是由于热处理的原因，允许将试样按本规范规定的热处理制度进行重复热处理后，重新进行本规范规定的全部力学性能检验，若仍不合格，该批棒材判为不合格。重复热处理只允许进行一次，补充时效不计为重复热处理。并在质量证明文件中注明两次热处理的制度和相应试验结果。重复试验合格的棒材，第一次试验结果必须同时填入质量证明文件。

4.2.3.3低倍组织检验结果不合格时，该批棒材判为不合格。若对低倍组织检验结果存在异议时，应以该区域高倍组织的检验结果为准。

4.2.3.4 高倍组织检验不合格时，该批棒材判为不合格。

4.2.3.5 超声波检验不合格时，该支棒材判为不合格。

4.2.3.6 外观质量检验不合格时，该支棒材判为不合格。

4.2.3.7 尺寸、外形检验不合格时，该支棒材判为不合格。

# 4.3 检验方法

# 4.3.1 化学成分分析

化学成分分析按 GB/T 223（所有部分）进行。化学分析取样按 GB/T 20066进行。

# 4.3.2 室温拉伸试验

<!-- page: 10 -->

室温拉伸试验按 GB/T 228.1 进行。

# 4.3.3 高温拉伸试验

高温拉伸试验按 GB/T 228.2 进行。

# 4.3.4 高温持久试验

高温持久试验按 GB/T 2039 进行。

# 4.3.5 低倍组织检验

低倍组织检验按 GB/T 14999.2 进行。

# 4.3.6 晶粒度检验

晶粒度检验按 GB/T 6394 进行。

# 4.3.7 显微组织检验

显微组织检验按 GB/T 14999.4 进行。

# 4.3.8 超声波检验

超声波检验按 GB/T 4162进行。

# 4.3.9 尺寸、外形检验

尺寸、外形检验采用通用的测量工具进行。

# 4.3.10 外观质量检验

外观质量采用目视检验。

# 5 包装、运输和贮存

# 5.1 包装和标志

棒材的包装和标志按 GB/T 2101进行，每根棒材在断面或一头应有永久性的如下标志内容：

a）合金牌号；

b）熔炼炉号；

c）锭节号；

d）规格；

e）承制厂的检验标记；

f）其他。

# 5.2 运输

棒材运输按 GB/T 2101 的规定。

<!-- page: 11 -->

# 5.3 贮存

棒材贮存按 GB/T 2101 的规定。

# 5.4 质量证明书

每批棒材应附有供方质量检验部门签发的质量证明书，其上注明：

a）供方名称；

b）需方名称；

c）订货合同号、本标准号；

d）合金牌号、冶炼方法；

e）熔炼炉号、锭节号；

f）交货状态、热处理制度；

g）规格、数量、重量；

h）本标准或合同、协议所规定的各项检验结果（如进行复验，应包括两次检验结果）；

i）质量监督部门印记。

5.5 除本标准规定的要求外，包装、标志和质量证明书的其它要求均按 GB/T 2101的规定。

# 6 说明事项

# 6.1 预定用途

本标准规定的 GH4151合金锻制棒材预定用于叶盘等零件。

# 6.2 订购文件应明确的内容

合同或订单中应注明下列内容：

a) 本标准的名称和编号；

b) 合金牌号；

c) 冶炼方法；

d) 交货状态；

e）规格、数量；

f) 定尺长度；

g) 其他技术要求。
