本标准规定了需方设计的各产品用优质碳素结构钢、锰钢及合金结构钢锻件的技术、验收标准、标识和质量保证书。

# 6. 技术要求

# 6.1 冶炼和浇注

6.1.1 锻件用钢应采用电炉冶炼。经需方同意，也可采用保证质量的其他冶炼方法。

2

<!-- page: 7 -->

6.1.2 针对特殊冶炼方法（如电渣重熔等），需方应在锻件订货图样或订货协议中特殊说明，如不说明按照6.1.1中条款执行。

6.1.3 钢水应在浇注前或浇注过程中进行真空处理，可采用真空碳脱氧工艺去除氢气等有害气体。

# 6.2 锻造

6.2.1 锻件用钢应采用镇静钢。

6.2.2 锻造用钢锭的两端应有足够的切除量，保证锻件中不致有缩孔和有害偏析等缺陷。

6.2.3 采用的锻造工艺必须使锻件整体组织均匀，流线合理。锻件的轴线应与钢锭的中心线大致重合。

6.2.4 锻件应严格按照工艺规范进行加热和锻造，尽可能使锻件制成锻件图所给定的形状和尺寸，不得有损害成品零件机械性能的过大或过小余量。

# 6.2.5 锻造比

锻件的心部区域应有足够的塑性变形量。锻造比应符合下列规定：

（1）用钢锭锻造的锻件，其主体部分未经镦粗时不得小于3；经镦粗时不得小于2.5；对于法兰及其它凸出部分不得小于1.5。

（2）用钢坯锻造的锻件，其主体部分未经镦粗时不得小于1.5；对于法兰及其它凸出部分不得小于1.3。

（3）对圆盘状锻件，应用镦粗法锻造。如果坯料经过锻造比不小于1.5的初锻，则圆盘任何部分厚度不得大于坯料长度的1/2；如果坯料直接切于钢锭或经过锻造比小于1.5的初锻，则圆盘任何部分厚度不得大于坯料长度的1/3。

（4）对环状锻件（如齿圈等）的扩孔锻造比或空心锻件的拔长锻造比不得小于2。

6.2.6 锻件不得有过烧现象，保证组织均匀，不允许存在裂纹、白点、缩孔等缺陷。

6.2.7 锻件应在具有足够能量的设备上进行，保证整个截面锻透。

# 6.3 机械加工

锻件在超声波探伤前对锻件的外表面进行粗加工。

# 6.5 力学性能

6.5.1 供方应备有足够数量的试样毛坯，为锻件的试验、复验所用。

# 6.5.1.1 当成品性能热处理在供方处完成时：

6.5.1.1 当成品性能热处理在供方处完成时：

各项数据齐全合格、证书和同批锻件有锻件号，并将供方用剩试样毛坯（保证二套试样）交付需方，以备复查用。

如果同批锻件已经船检验收，则须有船检签发的合格证，锻件上应有船检等印记。

6.5.1.2 当成品性能热处理在需方处完成时：

供方作锻后力学性能测定，且合格，锻件交付时，应同时提交用剩的一半或一半以上的试样毛坯，保证2~3套试样。

6.5.2 碳钢、碳锰钢锻件经正火+回火（或淬火+回火）的力学性能应符合附录A中表A3规定。

6.5.3 渗碳合金钢锻件的淬火+回火后的力学性能应符合附录A中表A4的规定。

6.5.4 调质合金钢锻件的淬火+高温回火后的力学性能应符合附录A中表A5和A6的规定。

试样毛坯调质后，其抗拉强度等级Rm指标应根据规定的锻件直径及零件的钢材种类，按附录A中表A6查取，其对应的屈服强度、伸长率、断面收缩率等指标，则根据所查得的抗拉强度等级再按附录A中表A5中查取。

6.5.5 经正火+回火状态交货的渗碳合金钢锻件，应切取试样毛坯按7.2.2.3节进行试样毛坯热处理后，做力学性能试验。

若采用钢种超出本标准附表中规定的范围，力学性能按 GB/T 17107标准执行。

# 6.5.6 硬度检验

6.5.6.1 当硬度作为验收条件时，硬度检测试验在零件本体上进行。具体要求如下：

（1）对于圆盘和圆环锻件，应在端面至少测定2处，两处相隔180°；如果锻件外径大于2000mm，硬度测定应不得少于4处，并四处相隔90°；如果锻件外径大于2000mm、且厚度大于500mm，硬度测定应在两端面各不少于4处，并四相隔90°。

（2）对于轴类锻件，长度小于 500mm，应测一处；长度 500～1000mm、最大直径小于 500mm，应在距两端约四分之一处至少测定2处，并错位180°；长度大于1000mm、最大直径大于500mm，则应在轴两端和中部、以及最大直径外圆周表面上至少各测定3处以上，并大致均匀分布。

6.5.6.2 订货协议规定以正火+回火状态交货的渗碳钢锻件，其硬度值应在160～200HB范围内，但18Cr2Ni4WA锻件正火+回火硬度需单独标识，硬度值应在197～320HB范围内。

6.5.6.3订货协议规定以调质状态交货的调质钢，硬度值应符合订货图或协议要求。同一零件上表面硬度差值应不超过40HB。

# 6.6 无损探伤

# 6.6.1 一般要求

锻件不得有裂纹、白点、缩孔、拆叠、过度偏析及超过允许的夹杂和疏松。

# 6. 6. 2 磁粉探伤

6.6.2.1锻件精加工后，由需方对要求检验的部位表面进行磁粉检验，供方应保证检验结果符合以下要求：

（1）轮齿精加工后对齿面进行磁粉检验，齿面不得有任何显示表面缺陷和表皮下缺陷的磁痕。

（2）轴类锻件的轴颈部位（包括承受推力的轴向推力面）精加工后进行磁粉检验，不允许有大于 1.5mm 的任何缺陷显示。在 $ 2 5 \mathrm{c m}^{2} $面积上不允许有超过 5 个 0.5~1.5mm 的缺陷显示（磨削加工产生的表面缺陷由需方负责）。

（3）同一条母线上两个缺陷之间小于其较大缺陷长度5倍时，按一条连续缺陷处理。

6.6.2.2 磁粉检验后应充分退磁处理，退磁后磁粉检验表面的最大磁场强度不超过 $ 1 0 0 0 / 2 \pi $ A/m（空气中相应磁感强度为 $ 2 \times1 0^{-4} \mathrm{T} $）。

# 6.6.3 超声波探伤

超声波检验在锻件粗加工后进行，必要时由供需双方联合检验，验收标准如下：

（1）当量直径 $ \phi 2 \mathrm{mm} $以下的单个分散缺陷信号不计，但杂波高度应低于当量直径 $ \phi 2 \mathrm{mm} $幅度的 50%（单个分散的缺陷定义为：相邻两缺陷之间距离大于其中较大缺陷直径的10倍以上的缺陷）。

（2）不允许当量直径大于 $ \phi 3. 5 \mathrm{m m} $的任何缺陷存在。

（3）分散的当量直径 $ \phi 2\sim \phi 3. 5 \mathrm{mm} $的所有缺陷均应记录其轴向、径向和周向位置并报告给需方；其各部位允许的数量见表2。

（4）齿部区域不得有密集缺陷区。其余部位允许有3处当量直径小于 $ \phi 2 \mathrm{mm} $的密集区，但密集区在任何方向的尺寸不应大于25mm，并且任何两密集区间距离不应小于150mm。

（5）由缺陷引起底波衰减损失达3dB时应记录并报告给需方。

（6）不允许有游动信号。

# 6.8 锻件交货热处理状态

6.8.1 所有锻件都必须经过适当的热处理后交货。锻件订货图或订货协议中应明确锻件交货热处理状态。

(1) 碳钢、碳锰钢锻件交货状态：正火+回火（或淬火+回火）。

(2) 渗碳合金钢锻件交货状态：正火+回火。

(3)调质合金钢锻件交货状态：淬火+回火。

其中回火温度一般不应低于 550℃。

6.8.2 交货状态规定为调质处理的锻件，则应将锻件机加工到规定的尺寸（锻件订货图或订货协议规定）后进行调质处理。如调质后进行了校直，还应在校直后作消除应力处理。

6.8.3 交货状态要求为调质处理的锻件，应在锻件订货图中给出锻件调质硬度指标。

6.8.4 交货热处理状态后，不得再对锻件作热加工处理，如用火焰切割、碳弧气刨法在锻件上截下弃料等；不得损害锻件机械性能和加工性能。

6.9 尺寸和表面粗糙度检验

6.9.1 加工后锻件应符合订货图样规定。

6.9.2 锻件表面应光滑平整，不应有折叠、锻伤、裂纹、夹渣、缩孔和肉眼可见的疏松等缺陷。

6.9.3 锻件表面一般不允许补焊修整。如要补焊，船用锻件必须得到船级社的认可，其它锻件，应得到需方认可，并且焊补应在锻件交货状态热处理前进行。

# 8 质量控制与验收

# 8.1 通则

8.1.1 锻件需符合 CCS、API 等规范要求时，应按相应规范执行。

8.1.2 供方对锻件制造全过程应进行质量控制。订货协议有规定时，应向需方提供相应质量证明或接受需方监督。

8.1.3 交付的锻件，应由供方的质量检验部门（人员）逐件或逐批（小锻件）按本标准要求检验合格。

8.1.4 所有锻件都应进行表面质量及尺寸检验。

8.1.5 各类别的锻件按选定的试验项目测试并提供数据结果。

8.2 试验无效

下列情形，试验无效：

（1）试样毛坯和试样未按规定制备（含取样、制样及应进行的热处理等）。

（2）试验操作失误。

（3）拉伸试验的断口在标距外且试验结果不合格。

# 8.3 复试及验收

8.3.1 下列试验不合格时，允许复试：

（1）拉伸、冲击试验。

（2）硬度、晶粒度、气体含量。

8.3.2 拉伸试验复试

# 8.3.2 拉伸试验复试

<!-- page: 13 -->

拉伸试验结果不合格时，可从备用试样毛坯上取双倍数量的试样进行复试，复试结果均合格者，则可以验收。若复试结果仍有一个不合格，则不能验收。

# 8.3.3 冲击试验复试

冲击试验一组三个试样中，允许有一个值小于规定值，但不得小于规定平均值的 70%。当一组三个冲击试样所得结果不合格时，低于规定平均值的试样不超过两个，且其中低于规定平均值的 70%的试样不超过一个时，则允许再取一组三个冲击试样进行试验。前后六个试样的平均值如符合要求，而且在六个试验结果中，低于规定平均值的试样不超过二个，且其中低于规定平均值的 70%的试样不超过一个，则锻件可以验收。

8.3.4 复试应从原取样的试样毛坯上（如无试样毛坯，则应从原锻件上）并尽可能在原试样位置附近取样。

8.3.5 硬度、晶粒度试验不合格，允许对锻件重新热处理后复试。

8.3.6 当锻件的任一力学性能复试结果仍不合格时，可以进行重新热处理并重新取样试验，重新热处理的次数最多不超过两次，回火次数不限。
