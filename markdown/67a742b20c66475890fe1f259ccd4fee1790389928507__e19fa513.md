3.1.2 锻件用棒材应符合 Q/2S 4345 的要求，棒材应复验合格后方可投入使用。

# 3.4 交货状态

锻件以固溶态或固溶+时效态、粗加工后交货。交货状态应在锻件图样和质量证明书中注明。

# 3.5 热处理制度

固溶热处理制度：1100℃~1180℃，保温2h~6h，空冷或控制冷却；

第一级时效处理制度：830℃～880℃，保温4h～10h，空冷；

第二级时效处理制度：730℃～780℃，保温8h～24h，空冷。

实际热处理制度应在质量证明书中注明。

# 3.6.2 硬度

硬度不小于 399HB。

# 3.7 低倍组织

# 3.7.1 流线

流线应基本沿锻件的外形分布，且不应有穿流和严重涡流，可见流线应主要沿径向分布。

# 3.7.2 低倍组织

纵向低倍试样应无目视可见的缩孔痕迹、裂纹、分层、空洞、夹渣、夹杂、针孔、粗大疏松和偏析等冶金缺陷。

纵向低倍试样不允许有白斑和黑斑。

# 3.7.3 表面腐蚀

锻件粗加工后应逐件进行表面低倍腐蚀检验，应无目视可见的缩孔痕迹、裂纹、分层、空洞、夹渣、夹杂、针孔、粗大疏松和偏析等冶金缺陷，不允许有白斑和黑斑。

# 3.8.1 显微组织

碳化物、碳氮化物检验按GB/T 14999.4进行评级，积累典型图片。

# 3.8.2 晶粒度

平均晶粒度应为8级或更细，允许存在个别6级晶粒组织。

# 3.9 超声检验

锻件粗加工后应逐件采用水浸法进行超声检测，按HB/Z 34进行超声波检验，按HB/Z 34的AAA级验收。

# 3.10 尺寸和公差

锻件的形状、尺寸和公差应符合供需双方签订的图样的规定。

# 3.11 外观质量

锻件表面不允许有裂纹、折叠、结疤、夹杂等冶金缺陷，若这些缺陷存在，允许打磨清除，打磨处应圆滑过渡，并应保证打磨处留有不少于尺寸允许偏差二分之一的加工余量。

经粗车后的锻件不允许有黑皮、折叠、凹坑等缺陷，粗糙度应符合供需双方签订的锻件图纸的要求。

# 4.2.3 判定与复验规则

4.2.3.1化学成分分析结果不合格时，该批锻件判为不合格。

4.2.3.2力学性能检验结果不合格时，允许从同一检验件上切取双倍数量的试样对不合格项目进行重复试验；重复试验不合格时，允许进行重复热处理后重新提交验收，若仍不合格，该批锻件判为不合格。重复热处理不超过两次，并在质量证明文件中注明每次热处理的制度和相应的试验结果。重复热处理合格的锻件，第一次试验结果必须同时填入质量证明文件。

4.2.3.3 低倍组织检验不合格时，该批锻件不合格。低倍组织检验存在异议时，以高倍组织的检验结果为准。

4.2.3.4 表面低倍腐蚀不合格时，该件锻件不合格。

4.2.3.5 高倍组织检验不合格时，该批锻件不合格。

4.2.3.6 超声波检验不合格时，该锻件不合格。

4.2.3.7锻件形状、尺寸或外观质量不合格时，该锻件不合格。

# 6 说明事项

# 6.1 预定用途

本规范规定的 GH4151合金整体叶盘锻件预定用于航空发动机压气机盘零件。

# 6.2 分类

a) 根据受力情况、重要程度和工作条件等因素，锻件为Ⅰ类锻件。

b）锻件类别最终由需方确定，并在锻件图样或其他技术文件中标注。

合同或订单中应注明下列内容：

b) 合金牌号；

a) 本标准号；

d) 产品名称、图号或代号；

e）交货状态、数量；
