# 3.2.2 熔炼操作

合金应经过多次熔炼，最后一次熔炼应在真空下进行。首次熔炼可采用自 耗电极、非自耗电极、电子束或等离子束熔炼，不允许添加合金。

# 3.2.3 热处理

锻件应按下述规定热处理：高温测定应依据 AMS 2750 进行。

固熔热处理：当使用固熔热处理时，加热至 β 转变温度以下 50~150°F （ 28~83℃ ）范围内，在选择温度 ±25°F （ ±14℃ ）范围内依据材料截面厚度， 加热设备和使用工艺保持适当时间。以空冷速度或比空冷更快的速度冷却。

退火加热至 1800~4450°F （ 704~788℃ ）范围内，在选择温度 ±25°F （ ±14℃ ） 内保温不少于 1 小时后以一定速度冷却。

# $ \textcircled{3} $显微组织

主要是 α- β 区加工产生的组织，包括：转变的 β 基体上的等轴和 / 或拉长的 α 组织和在原 β 晶界不连续的网状 α 组织、不连续和扭曲晶界 α 和片状 α 组织。

在初始，晶界形成连续的 α 组织是不可接受的组织。

产品表面应无任何富氧层，诸如 α 层或其他表面污染层，测定方法采用放大 100 倍以上的全相检查。

# 3.2.5 质量

买方收到的产品其质量和状态须一致且良好，应无外来物质及有害于产品 使用的有害缺陷。

模锻件的晶体流向一般以锻件轮廓形成显示，晶体流向上下应有明显的不 封闭存在。

# 3.3.1 消除应力

半成品叶柄应进行真空消除应力，制度为： 550℃±10℃ ，保温 2h ，后采用 氩气冷却，可冷至适宜温度后空冷。保温时间根据全尺动叶钛合金叶柄的最大

# 3.3.2 腐蚀及目视检测

半成品叶柄 100% 进行腐蚀及目视检查，按照 MFS0450 进行腐蚀检查，叶 柄经腐蚀后，按 MFS0706 目视检查表面不允许有裂纹、折叠、夹杂、缩孔、明 显的清晰晶粒、烧伤和由成分偏析引起的暗条、白条等缺陷，乙方须出具每件 全尺动叶钛合金叶柄半成品图文形式满足 MFS0450 要求的腐蚀检验记录。
