总则：

1、甲方：成都飞机工业（集团）有限责任公司
乙方：无锡派克新材料科技股份有限公司

2、本协议作为 XB项目用锻件经济合同的正式附件，在 XB项目用锻件经济合同签定（盖章）后正式生效。

# 一、甲方的主要职责

1、甲方负责向乙方提供锻件生产所需的制造依据，并将生产期间技术状态变更的更改依据及时传递给乙方，如由于技术数据更改未及时通知乙方更改相应锻件图纸造成锻件报废由甲方承担。

2、甲方负责以书面《锻件协调更改信息传递单》（见附件模板）的形式传递技术状态变更信息。

3、甲方负责对乙方设计的锻件数模（3D）进行确认，并会签其锻件毛坯图（2D）。

4、甲方有权对乙方提供的锻件或粗加工件的外观质量、尺寸及公差、理化性能和超声波探伤进行入厂复验。

5、甲方有权全程参与乙方锻件生产过程控制与鉴定，以确保锻件满足工程设计的要求。

6、甲方应将锻件的理化性能复验结果、试加工结论，并结合乙方的试制鉴定报告，发出锻件固化工艺的综合结论，并及时以书面形式（模锻件试制鉴定书）传递给乙方。

7、甲方根据乙方生产情况，派出跟产人员负责协调处理乙方生产中出现的问

题、监督乙方对制造依据的执行情况，并负责解答甲方所提供文件的疑问。

8、对关键件/重要件的锻件，甲方及设计方有进入乙方进行现场记录和工作的权利，包括派出常驻或流动的质量验收代表。

# 二、乙方的主要职责

1、乙方所承接的锻件，生产应封闭在乙方厂内完成，不允许转第三方。

2、乙方应严格按GJB904“锻造工艺质量控制要求”进行锻件质量控制。

3、乙方负责所承接锻件的生产交付任务，严格按照甲方提供的生产依据、双方确认的锻件数模（3D）和会签的锻件毛坯图（2D）进行锻件的生产、检验（理化项目按双方会签的锻件毛坯图中的取样图进行）、交付，并对其生产的锻件质量全面负责。

4、会签的锻件图纸由乙方通过档案部门晒发（按照会签图中的分发单位要求一式四份）给甲方档案部门。

5、乙方负责贯彻执行甲方的《锻件协调更改信息传递单》，及时跟踪完善相关工艺、技术、生产质量控制文件资料，换版、会签锻件毛坯图。如乙方由于接收到甲方技术状态变更信息通知而未及时跟踪更改相应数模、图纸及相关资料造成锻件、模具报废，则由乙方负责。

6、乙方应对所用材料的供方进行质量评定，并按乙方的“合格供应商名录”实行原材料定点采购。

7、乙方应对关键件/重要件的生产工艺进行工艺评审（必要时通知甲方）后方可投产。

8、编制的工艺控制文件（PCD）和固化操作协议（FPA）文件提交甲方审签。乙方对已固化的锻件工艺若有重大更改时，应及时通知甲方及设计方，并在通过试制鉴定后，方可投产。

# 三、技术要求

# 1、原材料技术要求

1.1、GH4141锻件用原材料应符合技术条件GJB2456A-2021的要求。若所需规格超出GJB2456A-2021的，仍要求性能满足该技术要求，不能满足时，应通知甲方，同意后方可加工锻件。

1.2、原材料应按相应技术规范 100%进行超声波探伤检验（乙方可转抄原材料厂的探伤结论）。

# 2、锻件技术要求

# 2.1、锻件验收规范

GH4141锻件按ZZQB903-089的技术要求进行验收。

# 2.2、锻件的供应（交付）状态

GH4141锻件按C状态供应（退火处理加固溶处理加时效处理），具体状态应在锻件图纸中明确。

2.3、锻件的外形、尺寸及其公差应满足双方会签的锻件图纸要求。

2.4、锻件具体的取样检验项目及其试样切取位置、数量按甲、乙双方会签的锻件图中的理化取样图进行，并按相关标准进行验收。

# 2.5、超声波探伤

锻件需由乙方完成探伤后交付。

# 2.6、锻件组批

应由同一图号、同一母熔炼炉号、同一投产批号以及同一热处理炉批的锻件组成。

组批最小数量：原则上不得低于表1中的最小组批数，若有例外情况，乙方应报甲方采购部门批准后方可投产，否则甲方有权拒收该批锻件。交付批次数应满足：

交付批次<{（订货数量+解剖件数量）/最小组批数量}+1

# 2.7、锻件标记

按要求在指定位置打上（或墨印上，但字迹应清晰可见）锻件图号、熔炼炉号（母炉号和子炉号）、投产（生产）批号、热处理炉批号、材料牌号、锭节号（头部件增打“T”）和承制单位检印，并用油漆笔或采用钢印的方式注明锻件的流线（纤维）方向。

甲方理化用料由乙方切下并打上与锻件同样的标记后，随同批锻件一起发送甲方。

# 2.8、锻件质量证明书（合格证）

钢锻件质量证明书要求，至少应包含以下内容：

a)、锻件图号、锻件名称及类别、本技术协议编号、锻件规范；

b)、材料牌号、熔炼炉号、投产（生产）批号、锭节号、热处理炉批号；

c)、锻件数量、供应（交付）状态；

d)、热处理制度(包括锻件的预备热处理及理化试样的热处理)；

e)、化学成分（化学成分允许转抄乙方材料复验数据）；

f)、力学性能（室温拉伸性能、室温冲击性能、高温拉伸、高温持久）、硬度；

g)、低倍、晶粒度、纯洁度；

h)、锻件的尺寸检查结论；

i)、锻件的超声波探伤结论；

j)、甲方和乙方名称、生产日期。

k)、首批，或自上一批锻件生产结束之日起计算，超过1年未生产过的图号的锻件再次交付时，在合格证上注明“首批”。

3、若锻件外形尺寸出现偏差，乙方应及时以让步使用申请单的形式书面通知甲方，在甲方确认能够满足零件加工要求的书面反馈后，锻件方可交付给甲方，同时附上甲方已确认的让步使用申请单。

# 六、保密要求

1、乙方确保甲方提供资料、制造依据不得丢失、泄露，并按国家保密制度借阅和使用；

2、乙方确保锻件生产过程、工艺文件、记录、质量证明文件、不合格品审理单内容、实物、有关锻件生产信息不得泄露，不得告知任何第三方。
