# 支架42CrMo锻件工艺技术要求

# 一、材料要求

1. 支架原材料选用 42CrMo，化学成分检测应符合标准GB/T 3077-2015，具体如下：

# 二、锻造步骤及工艺要求

1. 用可溯源的棒料下料：首先确认是合格原材料供应商提供的棒料，再复验原材料，然后投料（切割），切割后的材料高径比须小于2.5，以防镦粗后折叠。

2. 加热：将棒料放入燃气炉有效加热区中加热，零件温度需要达到 1150±10℃，以提高材料的可塑性和减小变形抗力，利于锻造成形。每半年提供炉温均匀性测试报告。

3. 自由锻预成型：把棒料镦粗后完全去除氧化皮，多次锻打以确保表面质量：按支架零件要求确定成形原料的放置方式进行预锻。

4. 模锻成型：将预热锻打后的锻件放入锻模机中，通过上、下模具和锻造设备的压力，将锻件挤压成所需形状的支架。支架成型温度必须终锻温度大于 860℃（测温点为零件的最边缘位置）。

5. 切边、校正：按照技术图纸要求进行整形切边，以进一步修正锻件的尺寸和形状。

# 三、锻后清理与热处理要求

1. 锻件在不影响后续加工的条件下，缺陷仅限打磨方法去除，去除深度必须小于余量的 60% ，确保对称的几何尺寸有相对的切削量，表面脱碳层深度<0.55mm。

2. 正火处理：将锻件冷却至室温后，再进行正火处理，保温时间的确定取决于零件的最大有效截面，最少每 25mm/30min，改善锻件机械性能。

3. 调质处理：将锻件冷却至室温后，再进行调质处理，淬火池须配有底部搅拌，不接受静态水池，调质后锻件性能须达到下列第四项检测要求。

4. 表面喷丸：锻件经调质冷却后，对其表面进行喷丸处理，达到氧化皮的完全去除，以提高表面质量。喷丸后，锻件表面没有肉眼可见的裂纹、锻伤、结疤、夹层、凹坑、气孔、折叠等缺陷。

5. 正火、调质处理工序后，做机械力学性能检测与金相组织检测。每批次抽取1件锻件双方各半作理化检测。
