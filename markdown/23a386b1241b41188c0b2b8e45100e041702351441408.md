# 涡轴-10发动机无锡派克承制的GH4169合金锻件技术协议

# 1 说明

鉴于涡轴-10发动机前外安装边等5种GH4169合金锻件(见表1)现有供应商交货质量不稳定，周期长，无法满足型号生产进度需求。为满足型号研制和生产需要，经研究决定该5种GH4169合金锻件增加流水。根据招标编号为TC220Y0F9/4的中标通知书，无锡派克新材料科技股份有限公司为中标单位。

经中国航发南方工业有限公司（提出单位，以下简称需方）与无锡派克新材料科技股份有限公司（承制单位，以下简称供方）协调和沟通，就供方生产的涡轴-10发动机前外安装边等5种GH4169合金锻件，双方达成本技术协议。

# 3 双方责任

3.1 中国航发南方工业有限公司（需方）

3.1.1 提供零件图1份，毛坯图1份、技术条件1份；

3.1.2 负责毛坯图的设计；

3.1.3 对锻件进行复验和加工；

3.1.4 超差品的处理权在需方。

3.2 无锡派克新材料科技股份有限公司（供方）

<!-- page: 4 -->

第2页

3.2.1 负责必要的模具设计和制造；

3.2.2 会签毛坯图；

3.2.3 提供复验用的（化学成份、力学性能、金相等相关检测所需）试料；

3.2.8 因供方质量问题造成的不合格品，供方应按需方要求及时补足交货数量。

3.2.9 供方应针对质量问题及时整改，反馈整改情况，必要时接收需方的质量监督审核。

# 4 主要性能指标及参数

# 4.1 原材料

GH4169合金原材料应符合HB6702的要求。原材料经复验合格后方可投产。

# 4.2 锻件

# 4.2.1 锻造工艺

表1所列锻件应采用环轧或自由锻工艺试制和生产。

# 4.2.2 交付状态

表1所列锻件以固溶处理并经粗车后交付，热处理制度为： $ 9 5 0^{\circ} \mathrm{C} \sim 9 8 0^{\circ} \mathrm{C} $ ，在选定某一温度 $ \pm 1 0^{\circ} \mathrm{C} $范围内，保温不少于1h，空冷或油冷；HB≤275（试样时效后硬度和性能合格时，锻件固溶后硬度允许报实测）。

注：加热温度为金属实际达到的温度，保温时间为锻件最大截面热透后开始计算的时间。实际固溶处理加热温度和冷却方式应在质量证明书注明。

# 4.3 检验

4.3.1 化学成分、力学性能、硬度、目视检验、低倍、高倍组织等检验结果应符合 Q/16GJX0-594 的规定。

第3页

4. 3. 2锻件的形状、尺寸公差、表面质量等应符合毛坯图的要求。

# 4.4 其它

本协议未涉及的其他技术要求均按 Q/16GJX0-594执行。

# 5 质量控制与保证

# 5.1 质量控制

5.1.1 Q/2BG1.080408《外部供方技术质量管理要求》是本技术协议引用文件，供方须遵照执行（需方供应部门提供）。

5.1.2 原材料须从需方合格供应商目录中选择，当从其他制造商购买原材料时，供方应向需方质量部门提交例外采购审批表和相关文件，经需方批准后方可使用。

5.1.3 制造工艺（工艺过程、工艺参数、设备参数等）应符合相关技术标准和文件的规定，工艺方法应确保能生产出合格的锻件。

5.1.4 供方在试制或改变锻件工艺时应按有关的规定进行鉴定、定型，然后方可投入批生产。

5.1.5 锻件工艺过程的生产条件应按GJB 904A进行准备和控制。

5.1.6 当供方生产工艺有重大改变时，应预先征得需方技术主管部门的同意，并根据需要进行全面性能和工艺试验，其冶金质量不能低于改变前的质量水平；必要时，需方可查看供方的制造生产工艺和本标准所要求的各项试验，但应予以保密。

5.1.7 试制阶段锻件图号按表2进行管理，待锻件通过需方有关评审鉴定后方可按表1中正式图号进行管理。

# 5.2 特殊过程确认

# 5.2.1特殊过程审核批准

锻造、热处理等特殊过程需获得需方的审核批准。供方应向需方提出批准申请，并配合通过需方的特殊过程审批。供方特殊过程原则上不允许外委第三方，因自身不具备能力等原因确需外委某项特殊过程时，须向需方供应商管理部门提交次级供应商审批表及相关资料，经需方书面批准后方可外委。

# 5.2.2特殊过程确认

供方需对特殊过程建立特殊过程确认程序，确认程序包含人、机、料、法、环、测等方面的确认及再确认的要求。特殊过程确认应在首件鉴定前完成，特殊过程确认资料由供方收集并保存。

# 5.3.3 检验结果判定

<!-- page: 7 -->

第5页

5.3.3.1化学成分结果不合格时，允许对不合格元素取双倍试样进行重复分析，重复分析的数据应连同第一次分析结果填入质量保证书中，如果重复分析的结果不合格，则判定不合格。

5.3.3.2力学性能第一次试验不合格时，应在同一试验件上对不合格项目取双倍数量的试样进行重复试验；若重复试验仍不合格，允许在技术协议允许的温度范围内重复热处理后重新按表3试验项目提交验收，重复热处理允许一次，重复试验结果合格的锻件数据与第一次试验结果应同时填入质量保证书。

5.3.3.3 锻件的形状、尺寸、外观质量不合格时，单件不合格。

5.3.3.4 已检验合格的锻件，在随后的加工、检验过程中发现有超出本技术条件的冶金缺陷时，锻件仍属不合格。

# 5.3.4 质量异议

需方接到供方的锻件后，应及时按技术文件规定进行复验，复验中发现不符合本协议要求时，应及时向供方反映，供方接到需方质量异议后，应及时与需方协商处理。

# 5.3.5 仲裁试验

当供需双方对某项试验结果有分歧时，应由供需双方同意的仲裁单位进行仲裁试验。

# 6 交货准备

# 6.1 标志、包装及运输

6.1.1 每个锻件应打上毛坯图规定的所有标记。

6.1.2 锻件应包装，以防在装卸、运输和贮存过程中损伤。

# 6.2 质量证明书

每批锻件应附有质量检验部门签发的质量证明书，质量证明书上应注明：供方名称、零件图号或代号、零件名称、材料牌号、熔炼炉号、原材料冶炼方式及产地、投产批号、热处理炉批号、数量、出厂日期、本协议号及本协议规定的检验结果等内容，质量证明书上应盖有供方技术监督部门印记。
