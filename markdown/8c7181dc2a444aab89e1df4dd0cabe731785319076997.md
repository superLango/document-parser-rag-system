# 8防护及包装、运输和贮存

8.1.1 包装材料应清洁、干燥，与产品直接接触的包装材料不得对产品造成腐蚀或其他不良影响。

8.1.2 包装材料应牢固，以避免在储存和运输过程中破损。

8.1.3 单件重量≥15kg的锻件在进行包装时，应设置吊装装置或预留吊装空间，方便需方拆除包装后使用吊车或叉车等工具转运锻件。

8.1.4 每种锻件应单独进行包装（有超声波检验、表面腐蚀检验要求的关重件宜单件包装，避免运输过程中发生磕碰），不允许不同种类的锻件混装在同一包装中。锻件的包装上应有包装标签，标签内容应包括零件图号、零件名称、零件数量、批次号、封存期及承制单位等信息。

8.1.5 包装的质量应确保产品在运输过程中免受磕碰损伤。若因供方包装、防护、发运不当导致产品出现磕碰伤、锈蚀等问题，以需方入厂验收结果为准，相关损失由供方承担。

8.1.6 多余物控制按 2B.QM.801《供应商手册》执行。

9.1.1 供方应按照《供应商首件鉴定》（HFP5014）或《首件鉴定》（GJB908）建立首件(批)鉴定的程序，通过全面的检验和试验，以验证规定的生产条件能持续地制造出符合设计要求的产品；

9.1.2 首件(批)鉴定适用于试制产品、在列装定型前试生产中首次生产的产品、生产过程发生重大变更、顾客在合同（协议）中要求时；

9.1.3 经首件(批)鉴定批准后，不得随意进行工艺变更。

9.1.4 供方应按照需方发布或传递的采购产品清单或材料合格产品目录进行原材料采购。

# 9.2 技术状态管理要求

9.2.1 供方应按照《供应商技术状态管理》（HFP5016）开展技术状态管理工作，包括产品涉及的技术状态文件传递、贯彻、闭环等管理活动。

9.2.2 供方应及时、准确贯彻技术状态文件，对于改变技术状态的技术文件，供方应按具体技术文件和其内部的质量管理体系文件要求对相关执行文件和产品实物进行贯彻落实。并按照《供应商技术状态管理》（HFP5016）中技术状态信息贯彻反馈表进行反馈。

9.2.3 供方应建立技术状态管理台账，基本信息应填写完整，贯彻落实情况描述详实、清楚，并具有唯一性、可追溯性。

9.2.4 供方现场使用的技术文件必须是现行有效版本，做到正确、完整、协调、统一、清晰，文实相符。

# 9.3 生产过程控制要求

# 9.3.1 变更管理

# 9.3.1.1 设计变更

供方应评估图纸、标准、技术协议等设计变更对产品工艺的影响。如对主导工艺产生重大影响，应重新开展首批鉴定。

# 9.3.1.2 工艺变更

9.3.1.2.1 供方应按照《供应商生产过程变更控制》（HFW5149）对生产过程控制基准要素清单，在变更前向需方提交《供应商生产过程变更通知单》及变更分析报告（包含相关分析、论证、验证、风险评估情况等），并按照需方要求视情开展重新鉴定。

9.3.1.2.2 通过首批鉴定后，若发生工艺变更，且未按照要求完成变更管理前，产品不得装机。

9.3.1.2.3 锻件用原材料供应商的变更属于重大变更，需重新开展锻件的首批鉴定，以验证原材料的变更对产品是否存在影响，提交设计单位进行确认。

# 9.3.2 产品稳定性控制及持续改进

<!-- page: 13 -->

9.3.2.1 供方应制定关键过程参数（如锻造等关键过程工艺参数）偏离判定原则，在PCD或主导工艺卡中明确对应的工艺规程或程序文件，提交采购方审定；对生产过程中出现的偏离，及时研判并将判定结论传递需方。

9.3.2.2 供方应全面应用质量工具箱，完善内部质量管理文件，利用 PFMEA、8D 等方法，识别过程风险，制定应对措施。必须执行情形包括但不限于质量问题、设备异常、产品波动、批次报废等。

9.3.2.3 针对盘、轴、叶片等关重件，供应商应按照以下原则识别关键过程，形成SPC方法及控制文件。

a）供方应根据采购方下发的技术文件及关键件、重要件特性表识别产品生产过程中的关键过程；

b）除a）条确定的关键过程之外，供方应结合自身研制水平，对加工难度大、质量不稳定、易造成重大经济损失的加工过程进行过程能力分析和研究，确定关键过程。

9.3.2.4 供方应结合锻件工艺流程，对识别的关键参数进行实时测量及监控，并开展SPC控制。关键过程参数应满足 Cpk≥1.33。对于 Cpk 不满足要求的产品特性，供应商开展根本原因分析，采用 PFMEA 或控制计划等质量工具制定改进与验证措施。对于出现的异常，应触发工艺偏离预警，立即分析制定改进措施并形成报告。

9.3.2.5 供方应升级或增加智能化检验检测设备、手段，实现检验检测数据的自动化数据采集、分析和预警，有效防范设备异常波动及人工操作失误造成的问题发生。

# 9.4 风险管理

供方应开展生产全过程风险识别和分级管理，对照高温合金锻铸件制造过程风险清单进行识别和管控，并将识别出的高风险项及处置措施及时向采购方报备。

# 9.5 检验检测控制要求

# 9.5.1 原材料入厂复验

供方应对采购的原料、原材料建立入厂复验制度并编制内部入厂检验技术文件，复验后形成验收记录。所有原料、原材料复验送检前需对材料的标识、交付状态、热处理、数量、规格及质量证明文件进行检查确认。

# 9.5.2 过程检验

<!-- page: 14 -->

第11页

在锻件成型、热处理等工艺过程中，需对关键过程参数（如温度、时间、压力、电流等）、产品尺寸、表面状态等进行检测、记录，对过程数据进行分析并查找问题，针对发现的问题及时改进和处置，确保过程管控到位。

# 9.5.3过程实时监测

9.5.3.1 针对识别出的关键生产过程、关键过程，采取录像、传感信号等进行实时监测，对过程数据进行分析并查找问题，针对发现的问题及时改进和处置，确保过程管控到位。

9.5.3.2 升级或增加传感器（如温度、位移、压力、电流电压等）、视觉监控（如工业相机、视频等）相关装置/设施，提高生产过程实时监测能力。

9.5.3.3 升级实时监测系统，通过系统智能化分析、反馈和调整，实现对工艺过程控制参数的实时控制，保证工艺一致性。

# 9.5.4 出厂检验

供方应按图纸、技术协议、相关技术标准等规定的全部检验项目对锻件进行检验，对验收合格或不合格审理结论为同意使用的产品，出具《入库合格证》。供应商按合同和（或）技术文件完成交付产品的出厂检验，确保其过程质量和最终质量符合内部体系和中国航发供应商管理要求，经检查确认后开具产品质量合格证。

# 9.5.5 试验料及试样管理

9.5.5.1 试样的取样位置、尺寸、加工方式等应根据图纸、技术协议、相关技术标准等确定并进行取样。

9.5.5.2每个测试试样应具有唯一标识，试样标识应存在于取样、制样、检测和留样保存等各个环节，并可追溯到最终文件。

9.5.5.3 测试完的试样和剩余试料（如剩余试环、解剖件）应按要求妥善保存，到期后可按供方内部管理要求进行处理。若需方无要求测试试样应至少保存6个月。
