# 1 目的和适用范围

本文件规定了符合锻件标准**-0505-2004的GH4169 合金锻造涡扇-10 系列发动机盘前封严挡板和盘 后封严挡板锻件试验批评价与认可、试制批评价与批准的试验要求。

本文件与** 4149-2016 及封严挡板GH4169 合金锻件其他批准要求一起使用。

# 2 通用要求

2.1 供方应对设计单位的材料批准试验要求、材料标准和其生产过程控制标准进行评估，并将评估结果 以书面形式报设计单位，任何偏离的事项应事先经设计单位和需方批准。

2.2 供方根据材料批准试验要求、材料标准、主导工艺控制要求及其他生产过程控制标准等确定工艺方 案，编制生产试验批或首批材料的制造方法数据卡（或制造工艺规程、工艺文件）及主导工艺控制卡， 并报设计单位和需方进行工艺确认。

2.3 在试验批或首批试制过程中，其制造方法数据卡（或制造工艺规程或文件）及主导工艺控制卡如需 更改，按供方内部控制程序进行，并应作好详细的原始记录，以便向设计单位和需方在试验批认可时提 供原始依据。

2.4 试验批评价所用的产品应按经初步工艺确认的工艺方案及文件生产，且必须是初次热处理的产品， 评价所用的详细取样方案图、尺寸范围和验收标准应经过设计单位和需方的同意。试验批评价完成后应 按** 4149-2016 规定编制正式评价与认可报告，并提交设计单位和需方进行试验批锻件评价与认可，给 出可否接收试验批锻件及进行后续试制批锻件生产的结论。

2.5 试制批应按试验批认可的工艺进行生产，按锻件批准试验要求进行试制批产品的测试分析，还应对 生产过程指定的关键特性进行监测和记录。生产3～5 个试制批次，并完成本文件规定的工作后，按** 4149-2016 规定编制正式评价与批准报告，提交设计单位和需方进行试制批锻件评价与批准。

2.6 在粗加工阶段或者供货状态下进行残余应力测量。在粗加工状态锻件取样之前，需要设计单位确认 是否需要在所选的锻件上进行残余应力测量。残余应力测量位置另有文件说明。

2.7 试验批锻件冶金和力学性能评价均按本文的第3 和第4 部分的相关规定执行。试制批锻件冶金和力 学性能评价由供需双方协商执行。

# 3 冶金要求

# 3.1 化学成分分析

化学分析按**-0505-2004 要求进行化学成份分析要求进行取样和分析。

# 3.2 低倍检查要求

在锻件上沿直径方向取两个完整纵向(径轴向平面)切片，对截面和全表面进行腐蚀。按照 **-0102-2004 要求进行腐蚀和低倍组织评估，记录腐蚀剂，采用目视或10 倍放大镜进行低倍组织检验。 截面低倍组织应均匀，不允许有裂纹、孔洞、折叠、夹杂等缺陷。

# 5 报告要求

提交的报告应包含5.1 到5.6 要求的信息。

# 5.1 零件信息

零件毛坯号、原材料供应商、熔炼批次号、原材料合格证、评估目的。

# 5.2 制造方法

评估锻件使用的制造方法（工艺方案、工艺规程等）、生产原始记录、主导工艺控制卡。

# 5.3 冶金评估

低倍组织图片，每个位置的高倍组织图片。

# 5.4 化学成分

化学成分结果。

# 5.5 力学性能

力学性能试验结果。

# 5.6 结论

是否符合本文件要求的综合评价。如果在首件评估过程中发现有不满足标准而报废，或因超声波和 任何其他原因报废部分材料时，应提供书面的细节说明。
