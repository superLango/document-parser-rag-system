# 3 质量保证要求

3.1 乙方必须建立完整的质量管理体系并有效运行，取得第三方认证证书。

3.2零部件在制造中产生的不合格品应及时通知甲方，对其中严重影响产品性能和功能的不合格品，应及时向甲方提交不合格品报告和处理方案，经甲方审查认可后方能实施处理方案。不合格品处理完成后，乙方负责向甲方提供完整的不合格品处理文件（包括报告及支持性材料），经甲方审查不合格品并认可后，才能转入下道工序。甲方的这种审查和认可不能减轻或转移乙方的责任。

3.3 甲方有权对供方进行质量保证/质量控制活动（包括产品检查、监督验收和体系审核等活动）。这些质量保证/质量控制活动应事先由甲方通知乙方，但这些活动并不减轻乙方的合同义务和法律责任。

3.4 乙方进行零部件的制造、检验人员，应取得相应证书和资质。

3.5乙方应按照GJB904A《锻造工艺质量控制要求》、GJB509B《热处理工艺质量控制》对锻造、热处理进行过程确认，形成过程确认报告以备查，并将过程确认报告复印件提供给甲方一份，当人、机、料、法、环、测发生变化时，应重新进行过程确认。

3.6乙方设计和生产的产品必须符合船规以及行业标准的要求。有船检要求的必须取得船级社认证证书。

# 4. 制造过程要求

# 4.1 图纸

4.1.1乙方负责按照甲方提供的图纸、技术文件进行毛坯图纸设计，工艺编制、锻造等。

4.1.2 当甲方设计图纸、技术条件更改时，甲方采购部门负责及时进行信息传递。

4.1.3 甲方每次订货时，应确保给乙方提供的图纸及技术条件现行有效。

4.1.4乙方毛坯图纸需经甲方机械加工、热处理会签。乙方提供甲方会签后的毛坯图纸一

式两份。

4.1.5 毛坯图中示明批次号及制造厂标识位置。

# 4.2 原材料

4.2.1 连杆锻件原材料供货商的认可及原材料质量应满足图纸及 Q10.09431-2202 和 S0T0000DX0030 技术文件要求，图纸及技术文件见附件清单。

4.2.2 乙方核验原材料合格后方可投入生产。

# 4.3 锻造

4.3.1 连杆应采用模锻，锻件需在足够能量的设备上进行充分锻造，锻造要求需满足 Q10.029431-2202 相关要求。

4. 3. 2严格锻造、热处理工艺过程控制，确保按过程确认结果执行。

4.3.3 不允许存在过热过烧组织，晶粒度应不小于 GB/T6394-2002 中的 5级

4.3.4 连杆表面不允许有裂纹，折叠，非金属夹杂等类似杂物，也不允许有影响材料强度的缺口和扭曲变形等。

4.3.5 连杆锻件表面缺陷可通过打磨来消除，不允许用其它方法（如焊接、金属喷涂等）消除缺陷；表面缺陷的修整应符合技术文件的规定，打磨必须再次进行喷丸处理。

4.3.6 调质处理之后，所有的表面都须进行喷丸处理。

4.3.7后续加工中发现的毛坯质量问题由乙方负责。

4. 3. 8锻件经过程确认，首批检验合格后，乙方应该固化工艺并可进行批量生产。

# 4.4 热处理

# 4.4.1 组批原则及试样构成

连杆锻件按材料炉罐号、同锻造规范、同热处理炉号组批；当有船检要求时，需要的样件组数及机械性能等要求须满足相关船级社规定，具体船级社见合同。

4.4.2 模锻后应进行预备热处理，最终热处理方式为淬火+回火，其回火温度不得低于 550℃。

# 4.4.3 本体硬度

最终热处理后 100%进行硬度检验，连杆盖双面两点，连杆双面四点，打硬度位置如图所示，每点测3次，取平均值记录，各测点结果均应符合规定要求。

# 4.5 性能检验

首件（批）生产时，每热处理炉任意抽取杆身和杆盖各1个进行力学性能试验（一拉三冲），取样位置见技术文件Q10.09431-2202中示意图7所示，连杆锻件的力学性能应符合图纸规定；批量生产时，力学性能应根据Q10.09431-2202中3.2.2.4执行。理化件的锻件余料打印批次号，做好标识，随锻件一同交付甲方，用于甲方复验力学性能用。

# 4.6矫直

如果发现连杆毛坯扭曲、弯曲变形，则应进行校直处理，校直后为消除残余应力，应进行去应力处理。去应力处理不应对材料强度有负面影响。

# 4.7 超声波探伤检验

超声波检验按技术文件 Q10.09431-2202 中 3.2.2.6 执行（100%检验）。

# 4.8 磁粉探伤检验

磁粉探伤检验按技术文件 Q10.09431-2202 中 3.2.1.2执行（100%检验）。

# 4.9 连杆锻件表面质量

连杆锻件的表面质量应满足 Q10.09431-2202 技术文件要求。

4.9.1 连杆锻件表面非加工区域的氧化皮凹坑极限值按 Q10.09431-2202 要求（实例照片见附图）。凹坑的边缘必须修圆，且圆角半径不小于 10mm。修磨后须要进行喷丸处理和磁粉探伤检验，以确保该区域无缺陷。

# 4.9.2 加工区域

对于加工区域，打磨至足以确定缺陷深度的范围。若缺陷深度在加工余量范围内，则可不必消除此缺陷。同时采用磁粉探伤试验进行验证。

3.9.3乙方应保留缺陷修复的过程记录（包括缺陷的初始状态、最终修复状态等），以备查，必要时并将缺陷修复的过程记录随质量证明文件一起交予甲方。

# 5 验收

5.1 锻件的几何形状、尺寸应符合会签的毛坯图纸。

5.2 原材料及锻件的检验按照图纸、技术协议及质量要求，乙方保留完整的检验记录。

5.3 锻件须经有关船级社的认可，具体见合同要求。

# 6 关、重特性要求

连杆锻件为“关键件”，乙方要在连杆锻件相应工艺封面中增加“关键件”标识。在标有关键特性（如G1、G2等字样）的相应工序卡上增加“关键工序”标识。编制作业指导书，作业指导书中应明确对于关键重要特性是如何保证以及如何测量。关键重要特性必须100%检验。

# 7 标识

连杆毛坯打印位置见图纸，内容按技术文件 Q10.09431-2202 中 7.1 执行。

# 8 首件样品鉴定

8.1 在产品首次投产之前按质量保证要求第5条提供特殊过程确认报告并进行首件鉴定。

8.2 首件鉴定应邀请甲方参加。鉴定时需提供特殊过程确认表（见附表2）、首件样品和首件生产原始记录表（见附表3）、首件检验报告（见附表4）、首件试制过程报告（见附表5）、首件鉴定报告（见附表6）、首件鉴定组签到表（见附表7）。

8.3 首件鉴定通过后，方能投入批量生产。工艺更改和工序（工艺、设备的替换）更改必须经甲方同意。

8.4 乙方应向甲方提供2~3个锻件，以便于甲方进行产品成品最终检验验证；在甲方产品成品最终验证合格后通知乙方，乙方才可进行批生产。

# 9 入厂复验

9.1 供货范围检查：按照本协议第2项“供货范围”中的内容检查锻件表面质量、形状尺寸、硬度及理化试样检验（化学成分、机械性能、组织晶粒度等）等和质量证明文件资料的完整性。

# 10 防护及包装运输

10.1 产品包装箱应设醒目且可靠的标识，其内容至少应包含制造厂名称及厂址、产品名称、SXD零件编号、合同号、数量、毛重、装箱日期、收货单位及地址、起吊位置及“不许倒置、小心轻放”标志等基本信息。

10.2 为了防止毛坯在运输、存储期间变形、锈蚀，毛坯须防护得当。

# 11 全环保要求

11.1 乙方保证向甲方提供产品的生产制造过程符合《中华人民共和国安全生产法》、《中华人民共和国环境保护法》等安全环保法律法规的要求。
