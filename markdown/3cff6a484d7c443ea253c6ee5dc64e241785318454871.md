TA15合金延伸机匣采用环轧工艺制备锻件毛坯。根据发动机研制要求，TA15合金延伸机匣锻件及其原材料发生材料状态（生产流水、主导工艺等）更改时，需开展冶金质量评估。本文提出了TA15合金延伸机匣锻件的冶金质量批准测试要求，供锻件供应商执行并用于锻件首件鉴定。当不同承制单位向同一锻件供应商订货且锻件制备工艺相同时，允许共用本文要求的补充测试数据。

# 1 基本要求

a) 除非设计单位另有规定，否则必须按本文规定完成所有的测试项目；

b) 延伸机匣锻件应按 Q/S10-0537-2004《TA15 钛合金环形锻件》及设计图的要求进行退火并超声波探伤合格后，方可用于锻件解剖和取样测试；

c) 用于解剖、性能测试的延伸机匣锻件，应先按 Q/S10-0537-2004 规定的测试项目检验合格，再按本文第 3 章进行补充测试；

d) 锻件供应商应按本文规定的取样位置进行取样，并对取样位置和每个试样执行唯一标识；

e) 锻件供应商应选取首批试制锻件中相当于铸锭头部的1件锻件进行解剖，本文规定的所有测试项目原则上须在同一件锻件解剖件上完成；

f) 必要时，锻件供应商应向设计单位提供冶金检查的试样或解剖件的剩余部分，用于后续特定项目的补充测试；

g) 锻件供应商在完成本文规定的所有测试项目后，应向设计单位提供完整、详细的正式报告（含锻件毛坯状态、合格证、理化检测数据、金相组织图片等）。

# 2. 锻件标准规定测试项目及要求

首批试制锻件应按Q/S10-0537-2004进行所有规定检验项目测试，若测试结果不满足 Q/S10-0537-2004规定，应终止该批锻件的后续补充项目测试（不允许重复热处理后再进行测试)，锻件供应商应组织查明不合格原因，采取改进措施，重新研制锻件并进行首件鉴定；若测试结果均合格，则按第3章要求在锻件解剖件上进行补充项目测试。锻件补充测试项目与 Q/S10-0537-2004规定检验项目及取样位置相同的，允许共用测试数据。首件鉴定用解剖件按 Q/S10-0537-2004规定检验合格的数据，可作为同批次锻件的解剖件理化数据并用于锻件交付。

# 3 锻件补充测试项目及要求

# 3.1 低倍组织

锻件低倍组织取样位置如图1所示，在锻件解剖件上沿周向位置1、位置2、位置3分别取1片全截面低倍试片，按Q/S10-0537-2004进行低倍组织检验及验收。

# 3.2 高倍组织

锻件高倍组织取样位置（允许在低倍试片上取高倍组织试样）如图1、图2所示，将截面划分为10个区域，在位置1和位置2截面上按序号1~10各取10个高倍组织试样（推荐试样尺寸为10mm×10mm），检测径向、轴向（相邻两表面）的高倍组织，按Q/S10-0537-2004讲符

锻件硬度取样位置（允许在高倍组织试样上检测硬度）如图1、图2所示，在位置1和位置2截面上按序号1、3、6、8、10各取5个硬度试样，按Q/S10-0537-2004进行硬度检验及验收。
