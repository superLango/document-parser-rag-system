# 4. 技术要求

# 4.1 原材料

锻件采用电炉冶炼+电渣重熔工艺冶炼。

钢锭头尾应有足够切除量，以确保锻件无缩孔及严重偏析等缺陷。

锻件采用自由锻开坯+环轧工艺成形，锻件主截面部分的锻造比不小于5。

# 4.2 交货状态

锻件以正火+回火热处理态交货，正火允许加速冷却，供货表面应无氧化皮。

实际回火温度应≥705℃。

# 4.4.4 硬度要求

交货热处理态锻件的硬度不超过 190HBW。

# 4.4.5 模拟焊后热处理态性能

1）对交货热处理态锻件取样进行模拟焊后热处理，模拟焊后热处理态锻件力学性能满足 4.4.1、4.4.2、4.4.3、4.4.4 的要求。

2) 试料的实际模拟焊后热处理保温温度应控制在 675~705℃的范围内。模拟焊后热处理装/出炉温度不大于 400℃，400℃以上升温与冷却速度不应超过 55℃/h，保温期间温度偏差不超过±10℃。

3) 模拟焊后热处理过程（入炉温度、热处理保温温度、保温时间、加热和冷却速度）应记录并列入材料质量证明文件。

4) 管板筒节锻件模拟焊后热处理保温时间为20小时。

# 4.4.6 持久性能

应对锻件的持久强度进行性能评定，实测锻件在 530℃下 3000h的平均断裂应力不小于142MPa，实测10000h平均断裂应力不小于124MPa，并绘制应力-寿命曲线，试验点不少于8个应力值。

# 4.4.7 蠕变性能

对管板筒节锻件的蠕变性能进行评定，蠕变试验方案需提交采购方与设计方审查与认可。

蠕变试验需验证材料满足 ASME BPVC III-5 分卷 HBB-T-1800-D 等时应力应变曲线。

试验条件：温度为510℃；总应变为1%；至少选取5个应力水平（包含10000h对应的应力水平），每个应力水平布置2~3根平行试样。

<!-- page: 9 -->

# 4.4.8 疲劳性能

锻件在 530℃进行高温疲劳试验，性能应符合 ASME BPVC.III.1.NH 分卷中图 NH-T-1420-1D 设计疲劳曲线的要求，循环次数与应变幅由设计单位提供。

暂采用以下验收方案开展疲劳试验。

从锻件上取样进行高温疲劳试验，并应用 fatigue-strain-vs.-life 数据（ε-N）采用 Langer 等式法（表述式： $ \varepsilon\mathrm{a}=A_{1}(\mathrm{N})^{-\mathrm{n}1}+A_{2} $ ）对疲劳数据进行拟合；试验环境：大气环境；试验温度 530℃，三角波加载，R=-1，应变速率 $ 4\times10^{-3}\mathrm{mm/mm/s} $ ，在单一应变幅下控制试样循环至破坏（出现断裂或明显裂纹，或应力幅下降 25%）；包含一个循环周次不小于 $ 10^{6} $ 次的试样。

实测疲劳曲线按应力除安全系数 K1或寿命除安全系数 K2（取两个值中较保守的一个），获得验证疲劳曲线。

目标指标：安全系数 K1=2，K2=20时，验证疲劳曲线不低于 ASME BPVC III-5分卷中图 HBB-T-1420-1D设计疲劳曲线。

从交货热处理态锻件上切取低倍试片，低倍组织致密，不应有目视可见的白点、裂纹、一般偏析、折叠、孔洞等冶金缺陷，低倍组织缺陷等级报实测值。

# 4.8 尺寸、外形及允许偏差

锻件的形状、尺寸和公差应符合锻件图样的要求，锻件图样上在保证锻件尺寸公差要求的前提下，应注明尺寸公差和机械加工余量。

# 4.9 表面质量

锻件表面不得有裂纹、夹层、折叠、夹渣及其它影响使用性能的缺陷，并满足无损探伤对表面质量的要求。

表面质量检验和无损检测发现的表面缺陷，可用磨削方法清除，打磨区域应圆滑过渡。缺陷清除后，应采用当初发现该缺陷的方法重新对该区域以及邻近区域进行检验，以保证缺陷被完全清除。打磨后的锻件尺寸应符合订货文件或图纸的规定。

打磨缺陷使用的磨具不能污染锻件。

不允许进行补焊。

# 5 试验方法及验收规则

# 5.1 组批规则

每个锻件为一批。

# 5.2 取样

# 5.2.1 试验数量

每批锻件做两组试验，一组为模拟焊后热处理态，一组为性能态，取样位置互成 180°，取样方案需报设计单位认可。

每组力学性能试验包括：

<!-- page: 13 -->

a）室温拉伸试验，2个试样；

b）高温拉伸试验（每个试验温度），1个试样；

c）夏比V型缺口冲击试验，3个试样；

d）硬度试验，1个试样；

e) 落锤试验（含8~10个）。

对每个制造商按照相同的制造工艺制造的锻件进行一组持久强度试验、蠕变试验和疲劳试验。在进行持久强度、蠕变试验、疲劳试验之前，试验方案需提交设计单位认可。

# 5.2.2 取样位置

试料取自最终热处理后的锻件的加长部位，试料应标出主要加工方向。试料应具有足够的尺寸，以便截取有关试验和复验用的试样。试样的取样位置应符合ASME NB 2220 和NB 2320 中关于锻件的相关规定。

拉伸试验、Cv冲击试样、持久、蠕变、疲劳试样取环向试样，落锤试样无方向要求。

# 5.4 复验和判定规则

5.4.1 化学分析不合格时，不允许复验。若可证明是试样污染或其它非材料本身因素，导致的化学分析存在偏差时，可重新取样试验。

5.4.2 如果拉伸性能不合格，可按 ASME SA-788M 第10节的规定进行重新试验。如果Cv冲击试验结果不合格，可按 ASME NB-2350规定对不符合项进行复检。如果硬度试验结果不合格，可取双倍试样进行复试。若复检仍不合格，生产厂可对该批材料进行重新热处理（如果锻件在后续制造过程需进行焊后热处理，则力学试验用试料还需进行模拟焊后热处理）。重新热处理后必须进行除化学成分及非金属夹杂外所有性能检验。重复热处理次数不允许超过2次。未经设计方和采购方认可，不允许进行重新热处理。

5.4.3 低倍检验、晶粒度、非金属夹杂物不合格时，不允许重复检验。

# 6 见证件

# 6.1 焊接见证件

供货方按合同要求提供焊接见证件试料，焊接见证件试料的制造、取样、试验及验收应按照相关技术条件的规定执行，并应提供这些材料的质量证明文件。

<!-- page: 15 -->

焊接见证件母材按下列顺序优先选取：

取自制造该设备所用的材料；

取自制造该设备所有的相同技术条件、相同炉批号、相同热处理状态的材料。

焊接见证件母材为锻件时，应取自锻件延长部分，并标出见证件母材的锻造方向，并与对应产品焊缝两边的母材锻件锻造方向一致。若使用单独的锻件，必须得到设计方与采购方的认可，单独的锻件应满足下列要求条件：

取自产品焊缝锻件同炉号或相邻具有相同要求部件的锻件，具有相同的热处理制度和相似的锻造比；

对单独锻焊接见证件需补充半厚度处交货态及模拟态横向室温拉伸及高温拉伸。验收按表2执行。

# 6.2 母材见证件

母材见证件应取自验收试验结果合格的母材的剩余部分，这些见证件的截取必须在与验收试验相同的条件下获取试样。

管板筒节母材见证件取自本体延长段的任意一端。

母材见证件应具有足够的尺寸，应保证至少能切取一套与验收试验所需试样数量相同的试样，试验项目（不要求进行模拟焊后热处理状态的试验）、试验条件（试样尺寸、试样取样、取样位置、取样数量、试验标准）、验收指标都与母材技术条件相同。

母材见证件取切取试样的标记、取向、尺寸及相对见证件的位置都应做记录。

母材见证件的切取、解剖和试样的试验应在业主代表见证下完成。

母材见证件一套用于验收试验，另一套用作备用提交给业主。

试验用的剩余试料和经试验后的试样应由业主（中核霞浦核电有限公司）保管，从锻件验收之日起至设备交货前。

采购方应根据本技术条件对锻件进行验收。

验收（包括入厂验收）方式应按采购方和生产厂达成的协议进行，并作为订货合同的一部分。

采购方按协议进行入厂验收，如入厂验收结果不符合本技术条件时，可以拒收，并由采购方以书面形式立即通报给生产厂。被拒收的锻件按不合格处理。
