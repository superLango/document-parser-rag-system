# 3 要求

# 3.1 交货状态

采购规格为Φ450mm，直径公差为±10mm，交货状态为退火、车光锻棒。

# 3.2冶炼工艺

采用 EAF+LF+VD 或 EAF+LF+VD/RH+ESR 方式熔炼。注意控制气体含量。

# 3.3化学成分

化学成分（熔炼成分）应符合表1的要求。

# 3.4 探伤要求

棒材超声波探伤须满足标准 AMS STD 2154 Class A级标准（平底孔Φ2.0mm级别）。

# 3.5 力学性能要求

每炉号棒材在头尾上进行力学性能测试，力学性能试样在 R/2处取，方向为弦向。

测试项目：取样进行淬火和回火，淬火温度自行调节，回火温度最小620℃，热处理后进行硬度、室温拉伸、-60℃冲击、FATT符合下表2规定。

# 3.6 低倍组织要求

低倍无夹杂、裂纹、过热等有害特征，要求锻棒无超出标准规定的冶金缺陷。

表面腐蚀后，无雀斑、白点、孔洞等冶金缺陷。

酸浸低倍按GB/T1979组织级别应符合下表3的规定。
