# 0Cr15Ni5Cu2Ti不锈钢棒材规范

# 1 范围

本文件规定了航空发动机用0Cr15Ni5Cu2Ti不锈钢棒材的要求、质量保证规定和交货准备等。

本文件适用于航空发动机用直径不大于160mm的0Cr15Ni5Cu2Ti不锈钢热轧或锻制的棒材（以下简称棒材）。

# 3 要求

# 3.1 原材料

棒材制备用原料和坯料应符合相关标准或专用技术文件的规定，经检验合格后方可投产使用。

# 3.2 制造方法

3.2.1 棒材应采用真空感应熔炼+真空电弧重熔工艺生产。

3.2.2 棒材应采用热轧或锻制方法制成。

# 3.3 交货状态

3.3.1 棒材以退火状态交货，交货状态硬度不大于360HBW，推荐的退火热处理制度为：650℃±10℃，保温时间不小于3h，缓冷。

3.3.2 棒材表面粗糙度Ra应不大于3.2μm或满足超声检验要求。

# 3.4 化学成分

# 3.5 力学性能

# 3.5.1 通则

3.5.1.1 从交货状态的棒材上沿纵向切取试样，试样直径宜为25mm。

3.5.1.2 试样经热处理后进行室温拉伸和冲击性能检测，其热处理制度如下：

a）制度Ⅰ：950℃±10℃，空冷；

b）制度Ⅱ： $ 9 5 0^{\circ} \mathrm{C} \sim1 0 0 0^{\circ} \mathrm{C} $ ， $ 3 0 \mathrm{m i n} \sim1 \mathrm{h} $ ，空冷； $ 6 5 0^{\circ} \mathrm{C} \pm1 0^{\circ} \mathrm{C} $ ， $ 1 \mathrm{h} \sim3 \mathrm{h} $ ，空冷； $ 9 5 0^{\circ} \mathrm{C} \pm1 0^{\circ} \mathrm{C} $ ， $ 3 0 \mathrm{m i n} \sim $ 1h，空冷；（-70℃），2h空冷； $ 4 2 5^{\circ} \mathrm{C} \sim4 5 0^{\circ} \mathrm{C} $ ，1h～3h，空冷。

3.5.1.3 试样优先选用制度Ⅰ进行热处理，当按制度Ⅰ处理检测的结果不合格时，应按制度Ⅱ进行处理，仲裁按制度Ⅱ进行处理。

# 3.6 热顶锻

3.6.1 热顶锻用棒材应作热顶锻试验，热顶锻后试样高度为原试样高度的1/3，试样上不得有裂口和裂纹。

3. 6. 2 热顶锻温度由供需双方协商确定。

# 3.9 超声检验

棒材应进行纵波检测，直径不大于70mm的棒材检验结果应符合GB/T 4162-2008中的AA级，直径大于70mm棒材检验结果应符合GB/T 4162-2008中的A级。

# 3.10 尺寸和外形

热轧棒材应符合GB/T 702的规定，锻制棒材应符合GB/T 908的规定。

# 3.11 外观质量

棒材表面上不允许有肉眼可见的裂纹，折叠，结疤，龟裂和夹渣。棒材表面上的局部缺陷应清除，其允许清理深度不超过尺寸公差之半。

# 3.12 产品标识

3.12.1 棒材应打上明显的产品标识，应包含：

a) 材料牌号；

b) 棒材批号、锭节号；

c) 熔炼炉号；

d) 棒材规格。

3.12.2 棒材应按头尾管理，在相当于钢锭头部和尾部棒材的端面上应有清晰的标记。

# 4 质量保证规定

# 4.1 检验分类

本文件规定的检验为质量一致性检验。

# 4.2 组批规则

棒材应成批提交验收，每批应由同一材料牌号、同一熔炼子炉号、同一规格、同一加工方法、同一交货状态、同一热处理炉批的棒材组成。

# 4.4 判定与复验规则

4.4.1 化学成分检验不合格时，应取双倍试样，其中一份试样应在原棒材上取样，即使有一个试样不合格，该批棒材判为不合格。

4.4.2 拉伸性能、冲击性能、检验不合格时，应重取双倍数量的试样对不合格项目进行重复试验。其试样的一半应取自该不合格项目原取样的棒材，另一半取自同批的其他棒材，重复试验如有一个检验不合格，该批棒材判为不合格。

4.4.3 非金属夹杂物检验不合格时，该批棒材判为不合格。

4.4.4 热顶锻检验不合格时，该批棒材判为不合格。

4.4.5 低倍组织检验不合格时，该批棒材判为不合格。

4.4.6 超声检测不合格时，该支棒材判为不合格。

4.4.7 尺寸和外形及外观质量检验不合格时，该支棒材判为不合格。

4.4.8 产品标识检验不合格时，允许重新进行标识。

# 6 说明事项

# 6.1 预定用途

本文件规定的0Cr15Ni5Cu2Ti不锈钢棒材预定用于制造航空发动机主油路喷口、喷嘴壳体、推力拉杆接头等零件。

# 6.2 订购文件应明确的内容

合同或订单中应注明下列内容：

a） 本文件号；

b）合金牌号；

c）冶炼方法；

d) 交货状态；

e）规格、重量和数量；

f）棒材用途（是否用于热顶锻）；

g） 其他要求。
