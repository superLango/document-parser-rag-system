# 4.2 锻造开坯

UNS N06617 板材采用自由锻开坯 + 轧板成形的方法进行制造。原材料两端存 在偏析、夹杂、缩孔等问题，为保证去除此类缺陷原材料的头尾应有充分的切除 量。同时锻造与轧板时应留有足够的变形量，变形要均匀，保证充分消除内部缺 陷并细化晶粒，使其具有良好的超声波穿透性。

锻造开坯的过程如下：

a ）原材料头部切除率≥ 3% ，尾部切除率≥ 5% ；

c ）始锻温度≥ 1000 ℃（炉温偶）；

# 5.2 试验

# 5.2.1 化学分析

钢厂应从每个重熔合金锭上取样进行熔炼分析。

每批板材应进行成品分析：对交付件，成品分析试样应取自板材的延长端。

熔炼分析及成品分析按照 ASTM E1019 、 ASTM E1473 、 ASTM E2465 、 ASTM E3047 、 GB/T223.82 、 GB/T20127.2 或其他标准中引用的方法执行，结果满足表 4-1 要求，并在质量证明书中提供成品分析的报告。

# 5.2.2 力学性能

交货态和交货态 + 模拟稳定化热处理态的 617 合金板材应分别在室温和 700 ℃进行拉伸试验，拉伸试验应分别按照 ASTM E8/E8M 和 ASTM E21 进行， 拉伸性能应满足表 5-1 的要求。

# 5.2.3 金相检查

# 5.2.3.1 非金属夹杂物

每批次成品板材应分别按照 ASTM E45 中的 A 法和 ASTM E112 进行非金属 夹杂物和晶粒度检验，并在质量证明文件中提供晶粒度和非金属夹杂物评级金相

<!-- page: 13 -->

照片。金相试验试样取样位置同拉伸试样，并满足以下要求 :

（ 1 ）粗系和细系 A 、 B 、 C 和 D 类非金属夹杂物均应小于等于 1.5 级；

（ 2 ）对钛 - 碳氮化物参照 B 级、 D 级非金属夹杂物进行评级，等级要求如下 :B 级细系≤ 3.0 级，粗系≤ 3.0 级； D 级细系≤ 4.0 级，粗系≤ 3.0 级。

# 5.2.3.2 晶粒度

板材应按照 ASTM E112 进行晶粒度检验，晶粒度级别控制在 2~6 级，级差 小于 2.5 级。

# 5.2.4 复试与重新热处理

拉伸试验不合格时，可从被检板材原取样部位附近再取 2 个试样进行复试， 当复试结果都合格时，则该批产品的相应检验项目为合格。化学成分不合格时， 允许采用化学分析方法对不合格元素进行一次复试。

非金属夹杂物和晶粒度不合格时，不允许进行复试。

当拉伸试验不合格时 , 允许对该批板材重新热处理 , 但重新热处理次数不应超 过一次。

重新热处理后应按本文件的规定重新进行除化学成分和非金属夹杂物检验 外的所有检验和试验。

# 7 无损检测

# 7.1 表面检测——表面缺陷

最终交货的板材表面应光洁，不允许有裂纹、发纹、折叠、轧折、结疤、离 层及其它对使用有害缺陷。

# 7.2 内部检测——超声检验

板材应按 ASME NB-2530 的规定进行超声波直射法检测，验收标准满足 ASME NB-2532 的规定。

# 7.3 尺寸和外形检查

交货板材的尺寸和外形应符合订货合同的要求。

# 8 缺陷的清除与修整

如果板材表面发现不可验收的缺陷 , 可以采用打磨的方法清除。磨具应为仅含 碳化硅、氧化铝或金刚石磨料的磨具，该磨具应是未使用过的或此前仅在镍基合 金上使用过。打磨过程应避免局部过热，打磨区应与邻近表面平滑过渡。缺陷清 除后的尺寸应符合交货尺的规定。打磨区域还应按 ASME NB-2546 进行渗透检测。

不允许对板材进行任何焊补。

# 9 标记、清洁、包装和运输

板材的标志、清洁、包装和运输应符合订货合同的相关规定。

板材的验收应按本文件的规定执行。板材应进行标识，应至少包括以下内容 :

●制造单位名称 ;

11

<!-- page: 15 -->

●合金牌号、炉号 ( 真空自耗重熔锭 ) 或批号；

●文件编号；

●规格和出厂日期。

在板材的制造、加工和运输过程中，应避免接触到可能对材料性能和完整性 产生不利影响的物质，如硫、铅、锌、铜、铝、镉、锡、砷、汞、锑、铋、卤素 及其它低熔点金属和它们的合金及化合物。此外，由于含氯材料老化产生的酸性 氯化物是潜在的危险，因此需合理选用胶带、磁性墨水、标记物、耦合剂、渗透 剂及涂料等来予以避免。

板材表面应无锈斑、油污及其它污染物。

# 10 材料质量证明文件

板材交货时，板材制造厂应提交质量证明文件，其内容至少应包括 :

- 化学成分 ( 熔炼分析和成品分析 ) 分析报告 ;

- 热处理报告 ( 包括重新热处理，若有 );

- 力学性能试验报告 ( 包括复试，若有 );

- 金相检验报告 ;

- 表面质量检查报告 ;

- 超声检测报告 ;

- 渗透检测报告 ( 若有 );

- 尺寸和外形检查报告。

以上报告应至少包括 :

- 制造厂名称或代号 ;

- 检验机构名称 ( 如适用 )
