# 1. 范围

本技术条件规定了天红核科技研发中心项目堆芯反射层结构一重水箱（以下简称重水箱）和堆芯支承结构等设备用直径不小于10mm的6061铝合金棒材无损检测必须满足的技术要求。

本技术条件可作为采购方在订货和验收时要求无损检测的依据，也作为制造方编写无损检测规程的依据。

本技术条件规定了超声检测的方法和质量验收标准。

# 2 引用的标准和文件

下列法规、标准和文件的有关条款，通过本文件的引用而成为本文件的条款。未注明版本号的，其最新版适用于本文件。

# 3 总体要求

# 3.1 检测人员资格

无损检测人员资格应符合 HAF602的规定，或符合采购方认可的相关行业无损检测人员资格管理规定。取得不同无损检测方法各资格等级的人员，应从事与该方法和该资格等级相应的无损检测工作，并承担相应的技术责任。

# 3.2 检测规程

制造厂、装配厂或安装单位都应制定书面的检测规程。检测规程应当满足本技术条件的要求，并征得采购方的书面认可后才能实施。

检测规程应对使用的设备、检测工艺以及检测参数作具体的描述，检测人员应按照检测规程进行检测。

# 4 超声检测

# 4.1 检测规程

检测规程应至少包括以下内容：

(1) 被检材料类型和几何形状，包括厚度、尺寸和产品形式；

(2) 参考文件；

(3) 检测时机及表面状态；

(4) 超声仪器的型号，探头的类型、频率及尺寸；

(5) 耦合剂名称、型号；

<!-- page: 6 -->

(6) 检测技术（直射波、斜射波、接触法和/或水漫法等）；

(7) 检测表面、检测方向和检测范围；

(8) 声波在工件中传播的角度和波型；

(9) 专用探头、楔块，衬垫或鞍座（使用时）；

(10) 标准试块和/或对比试块；

(11) 灵敏度校准方法的详细描述；

(12) 扫查方向和范围；

(13) 要记录的数据以及记录方法；

(14) 检测后的表面清洁；

(15) 验收标准；

(16) 检测人员资格；

(17) 检测报告的格式和说明。

# 4.2 检测时机

除其他设计文件中有规定外，产品最终检验应在包装出厂前、最终热处理后进行，产品如再次进行热处理或可塑性变形需进行重新检验。被检产品如需要机械加工成工件时，应在精加工前完成超声波检验。

# 4.3 工件准备

检验前应检查被检工件表面状况是否满足检验要求，被检工件检验面应清洁、光滑、平直，无影响检验的划伤和斑痕，对不符合检验要求的表面应进行表面处理。被检工件的温度应控制在 22℃±15℃范围内。

被检工件的检验表面粗糙度(Ra)应不大于 3.2μm，被检工件表面车削应采用圆头刀具。

被检工件进行超声波检验时，噪声显示信号幅度比检验要求检出最小缺陷显示信号幅度至少低6dB。

采用水浸法自动检验的棒材应平直，每米弯曲度应不大于 2mm，全长曲度不应超过 5mm。

# 4.4 检测设备

# 4.4.1 检测仪器

应使用 A 型脉冲反射式超声波探伤仪，仪器的使用性能及校验要求应符合标准GB/T 6519 第7.3节要求。

# 4.4.2探头

根据被检产品的几何形状、厚度、表面状况及要检出缺陷当量的最小尺寸和种类、表面分辨力等选择合适的探头。

探头频率应在2MHz~15MHz范围内选择，如需要选用其他频率，需征得采购方同意。

纵波单晶直探头的压电晶片直径(或矩型长边)一般应在 6mm~25mm 之间，对缺

<!-- page: 7 -->

陷进行评定时，应选压电品片直径(或短型长边)不大于 20 mm 的平探头。

纵波双晶组合探头，根据被检样品厚度选择晶片尺寸和楔块倾斜角度(或焦距)。检验灵敏度应满足超声检测验收要求，并有最小10 dB的检验灵敏度余量。

聚焦探头的压电晶片尺寸及透镜曲率半径应根据被检产品形状及尺寸确定。

# 4.4.3 耦合剂

水浸法使用的耦合剂应采用无气泡、无杂质、清洁的室温水。

接触法使用的耦合剂应透声性好。耦合剂粘度及表面润湿性应根据被检产品表面粗糙度选择，应保证声能很好地传入被检产品中。

灵敏度调试、产品检验、缺陷评定时应使用相同的耦合剂。

# 4.4.4 对比试块

# 4.4.4.1 对比试块材料

对比试块材料与被检样品的材质、透声性、声速、声阻抗应相似。

一般情况下铝合金对比试块应由 7075-T6、2024(7A09 或 2A12 淬火)人工时效材料制作。这几种材料制作的对比试块可适用于大多数变形铝合金产品的检验。如果没有上述合金的材料，应从被检产品中或与被检产品合金状态、规格、形状相同的材料中截取试块制作对比试块。

对比试块材料的内部组织纯净度应利用水浸法，垂直人射超声纵波技术，根据检验需求，在检验要求规定的工作频率下进行对比试块材料检验，不应有任何高于噪声信号幅度的回波显示，且任何部位由材料引起的底波反射幅度变化均不应大于 3 dB。当对比试块用料是在被检产品中选取，试块用料超声波检验时，应达到检验要求等级更严一级的质量要求。

对比试块声束入射面表面粗糙度应与被检产品相同或相近，有影响时，应加以修正补偿。

# 4.5 检测方法

可采用自动或手工的接触式或水浸式的检验方法；对直径小于 40mm的棒材宜采用水浸法进行检验。

# 4.5.1 扫查方式

检测一般采用直射波从棒材的外表面作径向扫查。圆形截面的棒材须对整个圆周外表面进行检查；非圆形截面的棒材须尽可能通过每一对平行边在两个垂直方向上进行检查。

# 4.5.2 扫查速度

手工检验时的扫查速度应不大于 254 mm/s。

自动检验时，当重复频率满足扫查速度要求时，可提高扫查速度。

# 4.5.3 扫查间距

一般情况下，扫查间距不应大于所选用的对比试块中最小有效波束宽度的二分之一。有效波束宽度的测量应符合标准GB/T 6519第9.2.4节规定。

# 4.5.4 灵敏度调节

利用对比试块上的与验收级别相一致的参考反射体绘制DAC曲线，将最低响应的参考反射体波高调节至显示屏满刻度的 80%，以此作为基准灵敏度。

水浸法检测时，液层调节及探头固定等补充要求按GB/T 6519第9.2.2节规定执行。

# 4.5.5 检测系统校准和校验

检测灵敏度校准时的配置和耦合状况应与实际检测工况一致。

在以下情况下需要对检测系统进行校验：

(1) 每次检测工作开始和结束时；

(2) 检验过程中，检验参数发生变化或检验仪参数旋扭发生变动时；

(3) 连续操作最长2小时；

(4) 检验过程中，如更换仪器、探头、探头导线、耦合剂等；

(5) 手工检测更换操作人员时；

(6) 任何时间检测人员对检测系统的有效性存在怀疑时。

校验时，若发现灵敏度降低超过2dB，则要重新按规定进行校准，并对上一次校验以来所检测的所有工件重新进行检测；若灵敏度增加超过2dB，则要重新按规定进行校准，并对所有记录信号重新进行检测，并根据重新检测结果修改记录或重新记录。

校验时，参考反射体的显示深度与实际深度偏差应符合表4-2的要求。如不符合，则应对距离范围进行校正，并在检测记录上注明这种校正。上次有效校验以来所有记录的信号应重新检测，并在数据表上修改记录的数值。

# 4.6 缺陷记录及验收标准

# 4.6.1 缺陷记录

(1) 裂纹等危险性缺陷；

(2) 所有达到或超过0.8mm当量直径平底孔的缺陷信号；

(3) 排除结构及耦合影响，第一次底波降低到正常被检产品的第一次底波的 50%或更低。

缺陷的评定应符合 GB/T 6519 第 9.2.6 节规定。

# 4.6.2验收标准

(1) 裂纹等危害性缺陷，不验收；

(2) 排除结构及耦合影响，第一次底波降低到正常被检产品的第一次底波的 50%或更低，不验收；

(3) 棒材超声检测按GB/T 6519规定的AA等级验收，允许的缺陷当量具体见表4-3。

# 4.7 超声检测报告

检测报告应至少包括以下各项：

(1) 制造厂商的名称或代号；

(2) 被检工件的名称、产品规格、合金牌号、状态、批号、熔次号、产品编号；

(3) 检测规程及版本、验收标准；

(4) 检测时机；

(6) 所使用的仪器型号及编号；

(5) 表面状态；

(7) 所使用的探头型号，尺寸，频率；

(8) 耦合剂类型；

(9) 检测方法，包括检测灵敏度的标定（所使用参考试块的编号），扫查方向、范围以及被检产品的外形图；

(10) 检测结果，包括所有应予记录的缺陷信号幅度、深度、尺寸以及沿轴向、径向和周向的分布情况；

(11) 检测日期；

(12) 检测人员、审核人员签名及其资格。

# 5 缺陷处理后的检测

缺陷处理后的区域应按照相关技术文件的要求重新进行检测，以确认缺陷已消除或降低到合格的范围内。
