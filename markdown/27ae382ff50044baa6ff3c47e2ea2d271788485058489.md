3 技术要求

3.1 原材料

3.1.1 供应商

锻件用原材料生产单位：抚钢、宝钢、江苏隆达、西部超导。

# 3.1.2 冶炼方法

3.1.2 冶炼方法

合金应采用真空感应熔炼加电渣重熔冶炼方式生产，所采用的冶炼方

<!-- page: 3 -->

法应在合同和质量证明书中注明。

# 3.1.3 其他

锻件用原材料其他要求应符合Q/S10-0311-2004规定，检验合格后方可投产。

# 3.2 锻件

# 3.2.1 理化件选取和分配

首批锻件在相当于铸锭头部的锻件上设置加高试验环（15mm）作为理化件，试验环与同批锻件经过相同的热处理后切下，供货方在1/2试验环上完成出厂检验后，另1/2试验环打上相应标志随同批锻件发往订货方进行入厂理化检验；后续批锻件每批带1件与锻件同炉且状态相同的冲孔底片供入厂检验用。

每个锻件带不小于半件冲孔底片（底片尺寸不小于 $ 1 3 0 \times3 0 $），随锻件发往车间用于电加工试件，冲孔底片与锻件相同标刻要求。

# 3.2.2 首批锻件

# 3.2.2.1 理化检验项目

按Q/S10-0518-2017要求在试验环上进行化学成分、硬度、室温拉伸、低倍组织和晶粒度的检验。

高低倍组织图片应归档并随质量证明书提供给订货方。

# 3.2.3 锻件硬度

锻件逐件在上、下端面进行本体硬度检验，硬度检验位置为圆周方向间隔 90°均布的4点（共8点），硬度值 HB≤290。

硬度应在质量证明书中逐件、逐点注明，交付状态锻件表面不应带有硬度痕迹。

# 3.2.4 超声波探伤

锻件应逐件按照 Q/S10-0104-2004 进行超声波检测，探头频率 5MHz，按 A 级验收。

# 3.2.5 其他

锻件其他要求应符合 Q/S10-0518-2017 及锻件图纸。

# 4. 锻件的控制与管理要求

4.1 供货方在锻件试制前应进行工艺方案评审；试制批锻件出、入厂检验及加工合格后，由订货方组织进行锻件质量评审。

4.2 锻件生产主导工艺应按 AETF324A 要求进行确认、认可和批准，并形成主导工艺控制卡，批准后主导工艺不能随意更改，其更改须按 AETF324A 要求履行相应程序。主导工艺的规定按照 AETF324A 中的定义及相关管理文件（如主导工艺控制卡）。

4.3 订货方对质量证明书内容进行确认。

4.4 锻件的工艺准备要求、特殊过程确认、关键过程、首件鉴定、对外协作、不合格品处理、现场跟产、产品验收等本协议未明确的具体规定按 YnG5-W0421《某型号项目供应商管理办法》的要求执行。不合格品管理按 S25.JT.Z0034《某型号发动机不合格品管理规定》的要求执行。质量信息管理按 S25.JT.Z0035《某型号发动机质量信息管理规定》的要求执行。工程验证机阶段的质量管理按 S25.JT.Z0037《某型发动机（工程验证机阶段）质量保证大纲》的要求执行。供应商质量管理按 SS002《供应商质量
