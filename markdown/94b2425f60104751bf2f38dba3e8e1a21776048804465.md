# 1. 范围

本技术条件规定了国和一号 （ CAP1400 ） 山东莱阳核电项目5、6号机组堆内 构件用奥氏体不锈钢锻件无损检测必须满足的技术条件。本技术条件主要适用于 核安全级设备和管道用奥氏体不锈钢锻件和镍基合金锻件的无损检测。

本技术条件可作为采购方在订货和验收时要求无损检测的依据，也作为制造 方编写无损检测规程的依据。

本技术条件规定了超声检测、液体渗透检测的方法和质量验收标准。

# 2. 引用文件和标准

下列标准和文件的有关条款，通过本技术条件的引用而成为本技术条 件的条款。未注明日期的标准，其最新版本适用于本技术文件。

 GPR-NDE-V7-001 无损检测一般要求

 GPR-NDE-V7-013 奥氏体不锈钢锻件无损检验技术条件

 ASME BPVC 第III卷（ 2021 版）核设施部件建造规则

 ASME BPVC 第V卷（ 2021 版）无损检测

 JB/T 6064 无损检测 渗透试块通用规范

 生态环境部令第6号 民用核安全设备无损检验人员资格管理规定

 国核安函[2019]102号 《关于民用核安全设备特种工艺人员资格管理有关事项的通知》

# 3. 总体要求

# 3.1 人员资格

所有无损检验都必须由持有与其从事的检验方法相应的有效资格证书的检验 人员执行。

 对于原材料的采购：

1 属于国家核安全监管部门监管范围的原材料，其供应商从事无损检验 的人员必须按中华人民共和国生态环境部令第6号的规定，取得Ⅱ级 或Ⅱ级以上资格证书，并在有效期内；

2 不属于国家核安全监管部门监管范围的原材料，其供应商从事无损检 验的人员可以按相关规定获取TSG Z8001（特种设备）、或SNT-TC-1A （ASME）、或EN ISO 9712（EN/ICNDT证）、或GB/T 9445/ EN ISO 9712（中国无损检测学会）等国家或行业认可的质量保证体系的II级 或II级以上资格证书，并在有效期内。

# 3.2 检测规程

制造厂、装配厂或安装单位都应制定书面的检测规程。检测规程应当满足本 技术条件的要求，并征得采购方的书面认可后才能实施。

检测规程应对使用的设备、检测工艺以及检测参数作具体描述，检测人员应 按照检测规程执行检测。

# 4. 超声检测

# 4.1 检测规程

检测规程应至少包括以下内容：

a ) 被检材料类型和几何形状，包括厚度、尺寸和产品形式；

b) 参考文件；

c) 检测时机及表面状态；

d) 超声仪器的型号，探头的类型、频率及尺寸；

e) 耦合剂名称、型号；

f) 检测技术(直射波、斜射波、接触法和/或液浸法等)；

# 4.2 表面要求

被检锻件的表面粗糙度应不大于6.3 µ m，表面不应存在可能干扰检测实施或检 测结果解释的松散氧化皮、油漆或污物等。

# 4.3 检测时机

除其他设计文件中有规定外，超声检测一般应在最终热处理之后，精加工之 前进行。

# 4.4 检测设备

# 4 . 4. 1 检测仪器

应使用A型脉冲反射式超声波探伤仪，仪器能覆盖的工作频率范围至少应为 0.5 ~5MHz 。

检测设备性能除应符合ASME BPVC 第V卷第5章T-561的要求，另补充要求如 下：

仪器的示波屏高度方向的线性（即垂直线性）误差在示波屏满幅度80 % 范围内 不超过满屏 ±5% ；仪器的水平线性误差不超过1 % 。

每台仪器在下述情况需要进行上述校验：

 仪器验收时；

 修理后；

 在每次持续使用周期的开始或每隔3个月（两者取短者）。

# 4 . 4.2 探头

探头可以采用单晶片或双晶片。为保证探头与曲面工件获得满意的耦合效果 ，探头前可加楔块。

# 4.4 .3 耦合剂

应采用具有良好润湿性能的耦合剂，且应按下列要求控制耦合剂中的污染物：

— 镍基合金上使用的耦合剂含硫量不应大于250ppm;

检测系统校准和检测时应采用同样的耦合剂。

# 4.4.4 参考试块

# 4.4.4.1 参考试块的材料

参考试块的材料可以是：

 被检部件的延长段；

 材料牌号和热处理状态与被检部件相同的余料；

 声学特性与被检部将相近的材料。

# 4.4.4 .2 参考试块表面曲率

选择参考试块时，其表面曲率应满足以下要求：

a ) 对于直径等于或小于 500mm的锻件，应使用曲面参考试块。任何单一曲率 的曲面试块可用于表面曲率在试块直径0.9 ~ 1.5倍范围内的锻件检验；

b) 对于直径大于500mm但小于2000mm的锻件，可使用曲面参考试块或平面参 考试块。曲面参考试块的使用要求同 a ), 使用平面参考试块时则需要进行增益校 正；

c) 对于直径大于或等于2000mm的锻件，可使用曲面参考试块或平面参考试块 ，使用平面参考试块时不需进行增益校正；

# 4.4.4 .3 参考试块表面要求

参考试块的表面粗糙度应与被检部件相当，但不能优于被检件，否则应进行 表面补偿。

# 4.4.4 . 4 参考试块晶粒度要求

参考试块上用声穿透法测得的晶粒大小应与被检锻件类似。对于晶粒大小和

# 4.4.4 . 5 参考反射体

直射波检测用的参考试块为具有一系列不同声程的平底孔试块，平底孔直径 如下：

a) 对于厚度小于等于75mm的锻件，参考试块上的平底孔直径为3mm。

d) 对于厚度大于300mm，小于等于600mm，参考试块上的平底孔直径为13mm。

斜射波检测用参考试块应带有内外表面参考切槽，切槽形状为60 º ~70 º V型槽或 宽深比小于2的矩形槽（在锻件上的位置应不致产生相互干扰），槽的长度最大为 30mm，深度为锻件厚度的3%。

# 4.4.5 检测系统校准和校验

检测灵敏度校准时的配置和耦合状况应与实际检测工况一致。

在以下情况下需要对检测系统进行校验：

 每次检测工作开始和结束时；

 连续操作最大4小时；

 更换操作人员时；

 任何时间检测人员对检测系统的有效性存在怀疑时。

校验时，距离范围上任一点在扫描线上的偏差大于距离范围读数的10％或全 扫描线的5%（取大者），则应对距离范围进行校正，并在检测记录上注明这种校正 。上次有效校验以来所有记录的信号应重新检测，并在数据表上修改记录的数值

校验时，若发现灵敏度降低超过20％或2dB，则要重新按规定进行校准，并对 上次校验以来所检测的所有工件重新进行检测：若灵敏度增加超过20％或2dB，则 要重新按规定进行校准，并对所有记录信号重新进行检测，并根据重新检测结果 修改记录或重新记录。

# 4.5 检测技术

# 4.5 .1 检测方法

锻件的超声检测方法可以是接触法或液浸法。采用接触法检测时，校验试块 和被检面的温度差不得超过14 ℃ 。采用水浸法检测时，校验时的耦合剂与检验时 的耦合剂温度差不得超过14 ℃ 。

# 4.5 .2 扫查方法

直射波应能保证扫查到锻件的整个体积。如条件允许，锻件的所有部分均应 从两个相互垂直的方向采用直射波进行扫查。

直射波检测时，从相对两面检测的范围至少应有10%的重叠。

所有外内径比小于2 的环形或空心锻件除了进行直射波检测外还应采用斜射 波进行正反两个方向的周向扫查。所有轴向不能采用直射波检测的锻件都应该补 充采用斜射波进行正反两个方向的轴向扫查。

锻棒钻孔成管状产品后应按照《DFWH-LYS-SP0514 无缝钢管无损检测技术条 件》的要求进行检测。

# 4.5.3 扫查速度

探头扫查速度应不大于 150mm/s 。

为了保证整个锻件体积都能被检测到，探头的相邻两次扫查路径至少应有15% 的覆盖率。

# 4.5 . 4 检测灵敏度

同一个锻件采用厚度较小尺寸检测灵敏度作为整个锻件的检测灵敏度。

直射波检测时，利用试块上不同深度的平底孔制作DAC曲线，DAC曲线上至少 应有3点，DAC曲线即为基准灵敏度。

斜射波检测时，利用参考试块上的内外表面切槽制作DAC曲线，以此作为基准 灵敏度。从内壁或外壁进行全跨距检测；若因锻件结构原因不能进行全跨距检测 时，则应从内壁和外壁进行半跨距检测。

所有DAC曲线第一点之前的范围用水平直线延伸，最后一点之后的范围用该点 得切线延伸，直至覆盖整个检测范围。

扫查灵敏度应不低于记录灵敏度。

# 4.6 缺陷记录及验收准则

# 4.6 .1 缺陷记录

a) 直射波检测时，所有达到或超过50%基准灵敏度的缺陷信号。

b) 斜射波检测时，所有达到或超过50%基准灵敏度的缺陷信号。

c) 直射波检测时，排除结构和耦合因素的影响，伴随底波完全消失的缺陷信 号，当底波反射降低到原标定满屏高度5%时，就认为底波完全消失。

d) 在排除结构和耦合因素的影响下对于底波完全消失而没有缺陷信号时，应 以更低频率探头扫查该区域，如果出现一样的情况，则应在报告中标明该区域为 未检测区。

e) 当探头在锻件表面上移动25mm或更多时，在屏幕上向左或向右移动明显与 正常噪声信号不同的信号。

# f) 裂纹等危险性缺陷。

f) 裂纹等危险性缺陷。

检测时，如从锻件一个检测面发现记录性缺陷时，如条件允许，需从相对的 另一个检测面进行检测，并以较严重的结果作为最终评定依据。

应记录缺陷的位置、幅度和长度等参数。

缺陷长度的测量方法为 -6dB 法。

# 4.6 .2 验收准则

a) 不允许存在危险性缺陷，如裂纹等；

b) 直射波检测时，不允许存在反射波幅达到或超过100%基准灵敏度的缺陷信 号；

c) 直射波检测时，不允许出现伴随底面反射波完全消失情况的缺陷信号；

d) 斜射波检测时，任何回波幅度等于或大于参考切槽回波幅度的缺陷都不予 验收；

# 4.7 超声检测报告

检测报告应至少包括以下各项：

a) 制造厂商的名称或代号；

b) 被检工件的图号、名称、编号和材料牌号；

c) 检测规程及版本；

d) 检测时机；

e) 表面状态；

f) 所使用的仪器型号及编号；

g) 所使用的探头型号，尺寸、频率；

h) 耦合剂的类型；

i) 检测方法，包括检测灵敏度的标定（所使用的参考试块的编号），扫查方 向，范围以及被检锻件的外形图；

j) 检测结果，包括所有应予以记录的缺陷信号幅度、深度、尺寸以及沿轴向 、径向和周向的分布情况；

k) 检测日期；

l) 检测人员签名及其资格。

# 5. 液体渗透检测

# 5.1 检测规程

检测规程至少包括以下内容：

a) 被检工件的材料、形状或尺寸及检测范围；

b) 引用标准或技术条件；

c) 检测时机及表面状态；

d) 所使用的渗透材料型号及生产厂；

e) 检测前的预清洗和干燥的方法；

f) 表面准备（表面粗糙度和清洗技术，包括清洗溶液的类型）

g) 检测过程的详细描述；

h) 检测操作方式（渗透剂施敷方式，去除多余表面渗透剂方法，干燥方法， 施加显像剂方法等）；

i) 检测步骤间的时间要求（表面准备后的最短干燥时间，渗透剂滞留的时间 范围，渗透剂去除后的最长干燥时间，去除多余渗透剂后到施加显像剂的最 长间隔时间，缺陷判断的时间范围）；

j) 表面温度超出标准温度范围时的检测工艺鉴定要求；

k) 最小光照强度的要求；

l) 缺陷显示的记录以及记录方式；

m) 验收标准；

n) 检测人员资格；

o) 检测后的清理；

p) 缺陷处理后的检测；

q) 检测报告的内容及格式。

# 5.2 表面要求

检测前，检测人员应对被检表面作外观检查，被检表面及相邻至少 25mm 范围 的区域不应有任何污垢、油脂、纤维屑、锈皮、焊渣、焊接飞溅物、油或其他有 碍检测的物质。

被检表面的粗糙度 Ra 不应超过 6.3μm 。

# 5 .3 检测时机和检测范围

除其他设计文件中有规定外，液体渗透检测应在交货状态下进行。

检测范围应符合上游相关技术文件的规定，检测区域应包括100%外表面和可 达到的内表面。

# 5 .4 检测设备和材料

# 5.4.1 渗透材料

渗透材料指检测过程中所使用到的所有渗透剂、溶剂或清洗剂、显像剂。不 允许将不同种类或不同制造厂生产的渗透材料相互混用。

除其他设计文件中有规定外，对用于镍基合金、奥氏体不锈钢、双相不锈钢 以及钛材料，一定量渗透检测剂蒸发后，残渣中的有害元素氟、氯的总含量的重 量比不得超过0.1%，硫的含量的重量比不得超过0.1%，其他有害元素含量限值应 按照相关技术文件的要求执行。每批渗透材料应有有害元素的分析报告，分析报 告中应包括渗透材料生产厂、产品型号及批号、分析方法及结果，这些分析报告 应妥善保存。

所使用的渗透材料应在保质期内，必须有供应商提供的合格证。

对用于预清洗或者过程中所使用的水，有害元素含量应符合上述的要求。

# 5.4.2 对比试块

检测温度在5 ℃~52℃ 之间时，使用 JB/T 6064 规定的三点式 B 型试块校验渗透 检测剂系统灵敏度及操作工艺正确性。

检测温度超过5 ℃~52℃ 范围时，应使用 JB/T 6064 规定的 A 型试块对检测工艺 进行鉴定。

# 5.4.3 辅助工具

应使用干净不脱毛的白纸或布，必要时可使用2~10倍放大镜。

# 5.5 设备校准

# 5.5.1 照度计

照度计应每年校验一次或当照度计有要求时随时校准。

# 5.5.2 温度计

测量被检区表面的温度计应每年校验一次或当有要求时随时校准。

# 5.6 检测技术要求

# 5.6.1 渗透检测方法

采用溶剂去除型着色法。

# 5.6.2 检测灵敏度

每班开始工作时以及更换渗透材料（包括不同牌号、批次等）应将 B 型对比试 块放在受检区域一起进行渗透操作，试块上所有 3 个辐射状裂纹应清晰可辨，否则 应停止操作，查明原因后重新检测。

# 5.6.3 检测温度

渗透剂和被检工件表面的温度在整个检测过程应保持在5 ℃~52℃ 范围内。对 于超出该温度范围的检测，应采用 A 型对比试块对该方法做鉴定，以证明能达到同 样的检测结果后方可采用。

# 5.7 渗透检测方法

# 5.7.1 预清洗

所有要检验的工件或工件的有关部位 , 均必须在施加渗透剂之前进行清洗和干 燥。局部检验时，准备工作范围应从检验部位四周向外扩展 25mm 。

# 5.7.2 预清洗后的干燥

在预清洗之后，被检表面的干燥应采用常规蒸发；可用不脱毛的布擦拭、采 用吸水纸吸干、吹以热风或冷风来完成，应确保完全干燥。

干燥的最小时间间隔，应能保证在施加渗透剂之前使溶剂全部蒸发掉。

# 5.7.3 施加渗透剂

施加渗透剂可采取浸渍、刷涂或喷涂的方法。渗透剂在渗透过程中，工件表 面应始终保持润湿状态。如果渗透剂一旦变干，则应从预清洗开始重新进行渗透 检测。

在10 ℃≤ T ≤ 52 ℃ (T为工件表面温度)的条件下，渗透时间应至少10分钟。在 5 ℃≤ T<10 ℃ (T为工件表面温度)的条件下，渗透时间应至少20分钟。在任何检测温 度下，渗透剂的最长滞留时间不得超过 2 小时。

# 5.7.4 多余渗透剂的去除

渗透结束后，多余渗透剂应使用清洁、不起毛的布或纸来擦除，再用蘸少量 清洗剂的布或纸轻擦，但禁止用清洗剂直接冲洗工件表面。使用的清洗剂必须是 由液体渗透剂制造商推荐的渗透剂中的一种。

多余渗透剂去除后，工件应在常温下自然蒸发干燥。

干燥时间应根据干燥类型和工件尺寸、特性、形状及数量等因素确定，干燥 时间不应超过30分钟。

# 5 . 7 .5 显像

当多余渗透剂被去除后，经干燥应立即进行显像，显像剂使用湿式显像剂， 采用喷洒的方法均匀施加到整个被检表面。湿显像剂一干，显像时间即开始。

# 5.7.6 观察

缺陷显示痕迹应在施加显像剂后的10至 60 分钟内观察，并作出最终判断。被 检表面光照度应不低于 1076lx 。

# 5.8.1 缺陷的评定

# 5.8 缺陷评定及验收标准

a) 显示痕迹包括相关显示（即缺陷显示）和非相关显示，非相关显示不作为 合格与否的评定依据。

b) 凡超过5.8.2节规定的任何显示痕迹，必须用相同方法复验，必要时可采 用其他无损检测方法，以确定是否存在真正的缺陷。复检前可先进行表面修磨， 凡是掩盖缺陷显示的非相关显示，以及大面积渗透着色区，则为不合格。

c) 相关显示包括线性显示和圆形显示。线性显示是指长度大于宽度三倍的显 示。圆形显示是指圆形的或长度小于等于宽度的三倍的椭圆形显示。

# 5.8.2 验收标准

除其他设计文件和图纸有规定外，应按下述要求验收：

a) 凡主要尺寸大于 1. 5 mm 的相关显示均应记录。

b) 不允许存在下列相关显示：

 任何裂纹等危险性缺陷；

 凡长度大于下列规定的线性显示：

—当材料厚度小于16mm时，长度大于1.5mm的线性显示；

—当材料厚度为16mm到50mm时，长度大于3mm的线性显示；

—当材料厚度大于或等于50mm时，长度大于5mm的线性显示。

 凡尺寸大于下列规定的圆形显示：

—当材料厚度小于16mm时，尺寸大于3mm的圆形显示；

—当材料厚度大于或等于16mm时，尺寸大于5mm的圆形显示。

 在一条直线上有四个或四个以上，且边缘间距不大于1.5mm的相关显示；

 在相关显示最密集部位的任意一个面积为4000mm 2 （长径不大于150mm）的矩 形区域内，有十个或十个以上的相关显示。
