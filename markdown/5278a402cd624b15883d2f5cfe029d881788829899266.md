# 原材料订货技术协议

# 1 内容与适用范围

本协议规定了 ASTM A240/A240M S30403(304L)材质原材料的技术要求和质量要求。

# 2 引用标准

ASTM A240/A240M

ASTMA751

# 2 要求

# 2.1 制造过程

钢锭应使用电炉（+AOD）+VAR的方法冶炼。

# 2.5内部质量

供方应该保证，原材料经过扩氢、锻造、轧板成型、空气烘烤后，板材的内部质量的质量满足要求。

# 2.6 低倍组织

在交货状态下的棒材横向酸浸低倍试样上，不应由目视可见的缩孔痕迹、裂纹、针孔和夹杂等冶金缺陷。

# 2.7尺寸规格

规格尺寸详见合同。为保证质量，应清除缩孔和过分的偏析，的头尾应有充分的切除量（尾部切除率≥5%，头部切除率≥8%）。

# 2.8表面质量

原材料表面应光洁，不允许有裂纹、发纹、折叠、气孔、结疤、夹渣、离层及其它对使用有害缺陷。详见 PK-PC-JSTZD-019 Rev.A 《关于钢锭表面质量检验要求的管理规定》。

有本体取样要求的原材料，需要对取样部位进行打磨处理，并应满足原材料表面质量要求的管理规定。

# 2.9 其他要求

供方需提供头尾复验用料，保证可取出1个30*30*30的成分样，1个25*25*60气体样，1个15*15*15的夹杂物样。

对原材料的其他要求，由供需双方协商确定。

# 3 交付

# 3.1质量证明书

原材料应附有符合本协议要求和合同中规定的质量证明书，并注明：供方名称、需方名称（全称）、合同号、材料牌号、熔炼炉号、重量、头/尾化学成分、熔炼方式、锭节号（如有）等。

请注意，质保书上的签名应为手签版。

# 3.2 材料标识

原材料需印记齐全，具有可追溯性，原材料本体标识应包含合金牌号、重量、熔炼炉号、锭节号（如有）。

# 3.3包装

应采用合理的包装方式，确保在吊装及运输过程中安全可靠。

# 4 入场复验

原材料回厂后，需对以下分项进行100%检查：外形尺寸、化学成分、外观质量、非金属夹杂物。
