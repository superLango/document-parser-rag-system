# 工艺工作内部通知单

核电技术室 字2017-001号

事由：关于材料申请单中外购物项的相关书写要求及释义

所有外购物项在材料申请单的“材料名称”栏填写“外购”，在“特殊要求”栏按如下要求注明：

1、“特殊要求”栏填写“外购成品”时，指按设计图或国家/行业等相关标准，向供方采购成品物项；

2、“特殊要求”栏填写“外购锻件”时，指按锻件采购图（无锻件采购图时，按附表1），向供方采购毛坯锻件；当工艺对锻件余量有特殊要求时（如水压余量等），应备注明确；

3、“特殊要求”栏填写“外购铸件”时，指按铸件采购图，向供方采购半成品铸件；当工艺对铸件余量有特殊要求时，应备注明确；

4. 铸件机加后表面易产生缺陷（原材料原因），且返修困难，为尽可能避免此类 NCR，铸件类零件应优选外购成品，但铸件类零件需要与其它零件焊接时，应根据实际情况确定；

5、在工艺零件清单、材汇的“备注”栏应注明外购物项的实际情况，如：外购成品、外购锻件、外购铸件。

以上要求自本通知单发布之日起开始执行！

编制：韩志红审核：程州2017.8.25批准：

抄送：核电部、质保部、材研所、物管部、101车间、201车间、106车间、104车间
