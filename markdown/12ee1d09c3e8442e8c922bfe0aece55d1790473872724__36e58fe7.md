# 铝合金锻件低倍组织补充技术要求

# 1 范围

木标准规定了型号用铝合金锻件低倍组织检查的补充技术要求、检验方法、判定原则。

本标准适用于GBn223和GJB2351两项标准中可热处理强化类铝合金自由锻件及模锻件（统称锻件）的采购与验收，其他标准铝锻件可参照执行。

下列文件中的条款通过本要求的引用而成为本要求的条款。凡是注日期的引用文件，其随后所有的修改单（不包含勘误的内容）或修订版均不适用本要求，然而，鼓励讨论本要求的各方研究是否可使用这些文件的最新版本。凡是不注日期的引用文件，其最新版本适用于本要求。

# 3 技术要求

# 3.1 低倍组织

3.1.1 锻件低倍组织中不允许存在残留铸造组织。

3.1.2 锻件低倍晶粒度应不大于4级。晶粒度大于4级时，在粗晶区取有效力学性能试样（试样标距在粗晶区内且满足取样方向要求）进行拉伸试验，试验结果满足锻件技术标准要求时判合格，对于不能做力学性能的进行硬度试验（视面积进行1~3点检测，取平均值），试验结果满足锻件技术标准要求时判合格。

3.1.3 全截面低倍组织检查中，位于锻件加工余量区域内的粗晶区，可不参与合格判定，锻件加工余量区域需与需求方确认。

# 4 检验方法

3.1.4 对于未经热处理强化以锻造状态（R/H112/T1等）交货的毛坯锻件，应对低倍组织试样热处理后按本标准要求进行检验，除有特别指明外，试样热处理制度参照GJB 1694A的规定执行。

4.1 锻件的低倍组织每批抽检1件，图样、技术文件或双方合同另有规定的按相应规定执行。

4.2 锻件的低倍组织检验方法按GB/T 3246.2执行。

# 5 判定原则

本标准规定的检测项目有不合格时，判批不合格。

# 6 其他

其他技术要求按锻件技术标准执行。
