# 总则：

1、甲方：成都飞机工业（集团）有限责任公司

乙方：无锡派克新材料科技股份有限公司

2、本协议作为枭龙飞机锻件经济合同的正式附件，在枭龙飞机锻件经济合同签定（盖章）后正式生效。

# 一、甲方、设计方的主要职责

1、甲方负责向乙方提供锻件生产所需的零件数模，并将生产期间技术状态变更的更改依据及时传递给乙方，如由于零件数模更改未及时通知乙方更改相应数模和图纸造成锻件、模具报废由甲方承担。

2、甲方负责以书面《锻件协调更改信息传递单》（见附件模板）的形式传递技术状态变更信息。

3、甲方负责对乙方设计的锻件数模（3D）进行确认，并会签其锻件毛坯图（2D）。

4、甲方有权对乙方提供的锻件或粗加工件的外观质量、尺寸及公差、理化性能和超声波探伤进行入厂复验。

5、甲方、设计方有权全程参与乙方锻件试制过程控制与鉴定，以确保锻件满足工程设计的要求。

6、甲方应将锻件的理化性能复验结果、试加工结论，并结合乙方的试制鉴定报告，发出锻件固化工艺的综合结论，并及时以书面形式（模锻件试制鉴定书）传递给乙方。

7、甲方、设计方根据乙方生产情况，派出跟产人员负责协调处理乙方生产中出现的问题、监督乙方对制造依据的执行情况，并负责解答甲方、设计

1、乙方所承接的锻件，生产应封闭在乙方厂内完成，不允许转第三方。

2、乙方随交付的锻件提供的该批次锻件合格证应包括本协议规定的合格证的所有内容。

3、包装、发运要求：

按采购合同的要求执行。

4、乙方应严格按 GJB904A《锻造工艺质量控制要求》进行锻件质量控制；乙方应严格按 HB5402-1997《锻件试制定型规范》对每项锻件进行试制鉴定，试制鉴定报告需提交甲方、设计方会签。

5、乙方负责所承接锻件的生产交付任务，严格按照甲方提供的生产依据、双方确认的锻件数模（3D）和会签（甲方、设计方）的锻件毛坯图（2D）进行锻件的生产、检验（理化项目按会签的锻件毛坯图中的取样图进行）、交付，并对其生产锻件的质量全面负责。

6、会签的锻件毛坯图由乙方通过档案部门晒发（一式五份）给甲方档案部门，也可提供正式签发的锻件毛坯图电子版给甲方档案部门。

7. 乙方负责贯彻执行甲方的《锻件协调更改信息传递单》，及时跟踪完善相关工艺、技术、生产质量控制文件资料，换版、会签锻件毛坯图。如乙方由于接收到甲方技术状态变更信息通知而未及时跟踪更改相应数模、图纸

# 三、技术要求

# 1、原材料技术要求

# 1.1 钢锻件用原材料技术要求

1）原材料棒材45A、30CrMnSiA、30CrMnSiNi2A应符合技术规范 GJB1951-94《航空用优质结构钢棒规范》；附件表1中45钢采用45A钢代替。棒材应逐支进行超声波探伤检测，且应符合GB/T4162中A级要求。棒材应为无发纹电渣钢棒。

2）原材料棒材2Cr13、1Cr18Ni9Ti、1Cr17Ni2（选用1175±100Mpa专用料）应符合技术规范GJB2294-95《航空用不锈钢及耐热钢棒规范》。棒材应逐支进行超声波探伤检测，且应符合GB/T4162中A级要求。专用料需定点在“东北特殊钢集团有限责任公司抚顺特殊钢股份有限公司”采购。棒材应为无发纹电渣钢棒。

3）原材料棒材Cr16Ni6应符合技术条件C1J15-90《Cr16Ni6中温不锈钢技术条件》，且为无发纹钢。棒材应逐支进行超声波探伤检测，且应符合GB/T4162中B级要求。

4）原材料棒材OCr12Mn5Ni4Mo3Al（69111）应符合技术条件BTXG233-2004 《OCr12Mn5Ni4Mo3AL 不锈钢棒技术条件》或 YS-X-9022《OCr12Mn5Ni4Mo3Al 不锈钢棒技术条件》，且为无发纹钢。棒材应逐支进行超声波探伤检测，且应符合GB/T4162中A级要求。

# 1.2 铝锻件用原材料技术要求

原材料棒材 LF2、LD5应符合技术规范 GJB2054-94《航空航天用铝合金棒材规范》；棒材应逐支进行超声波探伤检测，且应符合 GJB3538 中A级要求。

# 1.3 钛锻件用原材料技术要求

原材料棒材 TC4应符合技术规范 GJB1538-92（≤Φ150mm）《航空结构件用钛合金棒材规范》；棒材应逐支按 GJB1538-92的要求进行超声波探伤检测，合格棒材用于锻件生产。

# 2、锻件技术要求

# 2.1 钢锻件技术要求

材料为45、2Cr13、1Cr18Ni9Ti、1Cr17Ni2、30CrMnSiA、30CrMnSiNi2A的钢锻件按HB5024-89《航空用钢锻件》标准进行制造与验收，45A钢锻件按HB5024-89《航空用钢锻件》标准中45钢锻件进行制造与验收。

材料为 Cr16Ni6 的钢锻件按技术规范 Q/CACPS2020403TY005《Cr16Ni6 航空用钢锻件验收规范》进行制造与验收。

材料为 OCr12Mn5Ni4Mo3Al（69111）的钢锻件按技术规范 ZZQB903-015 《0Cr12Mn5Ni4Mo3Al 不锈钢锻件技术规范》进行制造与验收。
