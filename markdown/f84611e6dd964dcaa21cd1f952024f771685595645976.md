# 3 技术要求

# 3.1.1 供应商

锻件用原材料生产单位应为宝钛、西部超导、湖南金天。供货方应严格贯彻410JX（通用）-D-001中1.2.2条对锻件用原材料合格供应商的年限控制要求。

<!-- page: 3 -->

# 3.1.2 冶炼方法

用于制造棒材的铸锭应采用真空自耗电弧炉熔炼，熔炼次数为3次。

# 3.1.3 其他

锻件用原材料其他要求应符合410JX（通用）-D-S10-0351，原材料经复验合格后方可投产。

# 3.2 锻件

# 3.2.1 理化件选取和分配

理化件的选取应位于或相当于铸锭头部的锻件，理化件应与同批锻件经过相同的热处理。理化检测在本体加高件上进行。供方在1/2理化件上进行理化检验，另1/2打上相应标志随同批锻件发往需方复验用。

每件锻件带一直径不小于150mm，厚度不小于30mm的冲孔底片，与锻件同标记后随件发往订货方，用于定氢等试样加工。

# 3.2.2 常规检验项目

按410JX（通用）-D-S10-0537要求在加高件上进行化学成分、室温拉伸、室温冲击、高温拉伸、高温持久、硬度（图1中2#）、低倍组织、高倍组织（图1中2#）检验。

# 3.2.3 增加检验项目

按照图1增加1#和3#位置所示的硬度和高倍组织检测，按照410JX（通用）-D-S10-0537验收。

# 3.3 锻件本体硬度检验

锻件逐件在上下端面进行本体硬度检验，硬度检验位置为圆周方向间隔 90°均布的4点共8点，硬度值应符合HB（d）=3.3~3.8mm的要求。记录不同位置的实际硬度值并逐点在质量证明单中注明。交付的锻件表面应不带有硬度测试痕迹。

# 3.4 超声波检验

锻件应逐件进行超声波检验，按410JX（通用）-D-S10-0105的A级验收。

# 3.5 其他

锻件的其他要求应符合410JX（通用）-D-S10-0537及锻件图纸的要求。

# 4. 锻件的控制与管理要求

4.1 供货方在锻件试制前应进行工艺方案评审，试制批锻件出、入厂检验及加工合格后，由订货方组织进行锻件质量评审。

4.2 锻件生产主导工艺应按 EP0608A01 要求进行确认、认可和批准，并形成主导工艺控制卡，批准后主导工艺不能随意更改，其更改须按 EP0608A01 要求履行相应程序。主导工艺的规定按照 EP0608A01 中的定义及相关管理文件（如主导工艺控制卡）。供货方应参照 S15.JT.2894 进行锻件评估。

4.3 锻件用原材料管控，锻件的质量评审要求，锻件工艺、检验和质量控制，文件管理，质量证明、记录与可追溯性和能力与资质要求，不合格品处理，包装与运输，保密要求应符合 410JX（通用）-D-001中相应内容。
