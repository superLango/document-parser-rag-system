# 4.2 锻造

锻件采用自由锻成形方法进行制造。锻造时应保证足够的变形量，变形要均匀，以达到均 匀组织细化晶粒的目的，使其具有良好的超声波穿透性。

具体操作按 PK-JS-55-2020 《核锻件锻造作业指导书》及锻造工艺执行。主要锻造变形要 求如下：

锻造设备： 1250T/2000T/3600T/7000T 。

钢锭头部切除率 ≥12% ，尾部切除率 ≥3% ；

锻造温度范围： 850~1250℃ ；

保证足够锻比，总锻比 ≥3 ；

锻后缓冷；

锻件在钢锭中的位置及钢锭信息如下；

# 4.4.2 性能热处理

# 5 试验方法及验收准则

# 5.1 组批原则

一批由同一熔炼炉号，经过相同制造工艺，同炉热处理 ( 如果采用间歇炉必须是同炉次热 处理 ) ，且尺寸相近的棒材 ( 最大棒材直径与最小棒材直径比值小于等于 1.1 ，最大棒材截面积 与最小棒材截面积比值小于等于 1.25 组成）。

# 5.2 取样及检验项目

每根棒材应按照 RCC-M MC1000 的规定进行硬度测量后，在每批中取 4%( 至少为 2 根 ) 的棒材进行试验，其中 2% 为该批中硬度最高的棒材，另外 2% 为该批中硬度最低的棒材。在 每根取样的棒材上分别截取 1 个室温拉伸试样、 1 个 150°C 拉伸试样 ( 适用时 ) 、 1 个 300°C 拉 伸试样 ( 适用时 ) 、 1 组 (3 个 ) 冲击试样和 1 个硬度试样 ( 螺母用棒材 ) 。

试料应具有足够尺寸，以便截取全部的试验和复验所需用的试样。

试样上与试验有关的部分距棒材端部的距离不小于棒材热处理直径。试样轴线应与棒材轴 线平行，试样轴线的位置要求如下 :

——当 d≤25mm ，试样轴线位于棒材的轴线处 ;

——当 25mm<d≤50mm 时，试样轴线距棒材热处理表面 12.5mm;

——当 d>50mm 时，试样轴线位于距棒材轴线 1/4d 处。

注： d 为热处理直径。

# 5.3.3 复试与重新热处理

棒材力学性能试验不合格时，应按照 RCC-M M5150 第 4.4 节的规定进行重新热处理，重 新热处理的次数不得超过 2 次。重新热处理后应进行除化学成分以外的全部试验。

# 6 精加工

按采购图和采购合同约定的尺寸、公差对锻件进行精加工。最终机加工后的锻件进行无损 检测。

锻件在精加工完成后，应按采购图和采购合同约定的尺寸及公差进行检验。锻件的尺寸、 公差和表面粗糙度应满足采购图纸及合同规定。

# 7 无损检测

# 7.1 尺寸检验

最终交货的锻件应进行尺寸检查，尺寸检测和验收应按照 RCC-M M5150 第 8 章的规定执 行。

# 7.2 目视检验

最终交货的锻件表面应光洁，不允许有裂纹、发纹、折叠、夹渣及其它对使用有害缺陷， 合金的检测及验收应按照 RCC-M M5150 第 5.1 节的规定执行。

# 7.3 渗透检验

最终成品尺寸的锻件表面应进行 100% 渗透检测，渗透检测和验收应按 RCC-M M5150 第 5.2 节的规定执行。

# 7.4 超声波检验

锻件应按 RCC-M M5150 第 6 章的规定进行 100% 超声检测，验收标准满足 RCC-M M5150 第 6 章的规定。

# 8 缺陷的清除和修理

在棒材上，缺陷清除应按照 RCC-M M5150 第 7 章的规定进行。

棒材不允许进行焊接修补

# 9 标记

应至少标记以下内容 :

供方名称或标志 ;

熔炼炉号、批号 ;

材料牌号；

采规中标识号信息。

# 10 清洁、运输

# 10.1 清洁

棒材表面应保持清洁、无污物和金属屑，无需涂油防护，允许存在轻微浮锈。在运输和搬 运过程中对棒材应进行充分、有效的保护，防止发生磕碰和变形。

包装前零件的表面应保持干燥、无污物和金属屑。

# 10.2 运输

包装箱应足够牢固，避免在运输过程中损坏或者散架，必要时箱体外表面用钢板加固。如 包装箱内有间隙，应采用不吸湿或吸湿性小的材料填满以避免零件在运输和装卸时相互之间发 生磕碰、损伤。

运输过程中，包装箱应采取覆盖塑料布等有效的防雨防潮措施，并避免覆盖物发生变质和 脱落等现象导致零件浸水、锈蚀。
