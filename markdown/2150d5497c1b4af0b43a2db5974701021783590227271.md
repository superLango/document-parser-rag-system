# 1 目的

为方便在徐圩华龙一号机组汽轮机设备过程中对产品质量进行监督和跟踪，以确保产品质 量，特制定本程序。

# 2 范围

本程序适用于《江苏徐圩核能供热厂一期工程（华龙一号）汽轮发电机组（ TG 包）汽轮 机设备供货合同》（工作令号 143023 、 143024 ）范围内的设备或零部件质量计划的编制与管理。

# 3 术语和定义

本程序采用 HTC/QM 《质量手册》、 HTC/PQAP-143023/143024-2023 《江苏徐圩核能供热 厂一期工程（华龙一号）汽轮发电机组（ TG 包）汽轮机设备质量保证大纲》的术语和定义， 并增加下述定义：

# 3.1 质量计划

产品进行制造、检查、试验和验证的一种计划性文件。公司内通常指零部件制造过程中的 重要工艺过程及工序的检查内容要求的文件。

# 3.2 见证

指对文件、记录、实体、过程等实物、活动进行观察、审查、记录、确认等监督检查的活 动。

# 3.3 见证人员

指经授权或资格认定具有在质量计划质量控制点签字权的，且对设备或零部件质量控制点 进行见证工作的相关人员。

# 3.4 质量控制点

为保证工序处于受控状态，在一定时间和条件下，在物项制造过程中需要重点控制的质量 特性、关键部件或薄弱环节，包括记录审查点（ R ）、现场见证点（ W ）、停工待检点（ H ）。

# 3.5 记录审查点（ R ）

由见证人员对设备或零部件的有关文件、记录或报告等进行见证而预先设定的质量控制 点。

# 3.6 现场见证点（ W ）

由见证人员对设备或零部件的过程、工序、节点或结果进行现场见证而预先设定的质量控 制点。

# 4 职责

# 4.1 质量管理部

a ）负责编制本项目质量计划控制程序，并对质量计划程序执行过程进行监督考核；

b ）负责质量计划清单的汇总工作，并将最终批准的质量计划清单上传至 OA 系统核电质 量信息平台上发布实施；

c ）负责质量计划模板的编制、修订与发布，确保模板符合项目质量体系管理要求；负责 将质量计划模板上传至 OA 核电质量信息平台。

# 4.2 核电工程部

a ）作为外部接口管理部门，负责与顾客 / 营运单位协调、传递质量计划工作相关信息及资 料；

b ）负责将质量计划见证点通知单编号并传递给顾客 / 营运单位，并对监造过程进行协调处

# 4.3 设计部门

a ）负责按职责分工要求，编制采购质量计划清单；

b ）负责按职责对供方编制的质量计划进行审核会签；负责对会签质量计划中工序设置的 完整性、技术要求的符合性、工序描述的规范性进行审核；负责根据实际需求提出专业意见； 负责对供方质量计划更改意见的落实进行确认。

# 4.4 采购部门

4.4 采购部门 a ）负责向供方传递公司、顾客 / 营运单位的有关质量保证要求，责成供方编制设备或零部 件质量计划；负责对供方质量计划更改意见的落实进行确认；负责将各核电项目质量计划模板 向供方有效传递；负责对供方提交的质量计划进行审核，审核内容包括质量计划模板使用的正 确性、质量计划中基础信息填写的准确性，审核通过后方可提交至相关部门进行会签工作；

b ）负责将采购设备或零部件质量计划传递到工艺部门 / 设计部门、质量检验部会签；

c ）负责国内、外供方见证点通知及见证手续办理工作，并协调供方组织见证工作；

d) 负责将最终批准的质量计划上传到 OA 系统核电质量信息平台上，负责对核电质量信 息平台上的质量计划版本进行维护。

# 5.2.1 质量计划的编制原则

# 5.2.1.1 质量计划的编制原则

a ）依据合同、 HTC/XW QMSP 01 《江苏徐圩核能供热厂一期工程（华龙一号）汽轮发电 机组（ TG 包）汽轮机设备质保分级控制程序》的要求，对质保等级为 QR1 、 QR2 、 QR3 级的 设备或零部件（包括原材料）的制造、检查、试验等活动需编制质量计划并提交顾客 / 营运单 位审查。

b ）外部不符合项处理需要修理且工艺过程复杂的质保等级 QR2 级及以上设备或零部件；

c ）同一图号的多个零件或不同图号的相同质量计划工序可编制一份质量计划，若不同图 号的多个零件个别不同的质量计划工序进行明确注明后也可编制一份质量计划；

d ）质量计划中仅某外协序，在工艺部编制的质量计划中，此序适用文件及标准一栏只填 图号，防止标准不适用于外协。

# 5.2.1.2 质量控制点的设置原则

a ）质量控制点的设置应根据零部件质保等级，考虑工序对质量影响的重要性，结合供方 的技术和管理能力及业绩稳定性，将制造活动中对质量要求高、难度大、活动输出不能由后续 的监视或测量加以验证、或一旦出现质量问题处理困难的一些工序设置为质量控制点；

b ）质量控制点级别从高到低依次为 H 点、 W 点、 R 点。

1 ）公司内生产的设备或零部件质量计划，公司选点级别不应低于顾客 / 营运单位选点级别， 如低于，按顾客 / 营运单位选点级别执行。如顾客 / 营运单位选取了公司未选取的控制点，则公 司应按照顾客 / 营运单位选取的控制点进行补充选点；

2 ）采购的设备或零部件质量计划，供方选点级别不应低于公司和顾客 / 营运单位选点级别， 如低于，按公司和顾客 / 营运单位选点级别执行。如供方未选取公司和顾客 / 营运单位选取的控 制点，则供方应按照公司和顾客 / 营运单位选取的控制点进行补充选点。

3 ）对于先决条件检查、质量计划关闭（验收）、隐蔽工序、质量标准高、技术难度大、对 安全和正常使用有重要影响的工序及关键试验，可设置为 H 点；

4 ）对于质量标准高、技术难度大的工序，在执行过程中需要到现场进行过程见证的工序，

b ）质量计划多次升版，有版本未执行的情况，如 A 版质量计划正在执行，其间升为 B 版， B 版还未执行，升为 C 版。此时按 5.2.2.6 a) 要求执行，按版本顺序进行填写，未执行的版本 也要按要求进行说明，并将全部版本保留。

# 5.2.3 质量计划审批与提交

# 5.2.3.1 公司内生产零部件质量计划审批与提交

工艺部门应在设备或零部件制造活动开始前 2-3 个月编制完成质量计划（可按三级计划要 求）并提交质量检验部选择见证点（ 2 个工作日内完成），质量计划由工艺部门主管领导批准。 编制部门将审批后的质量计划通过 OA 系统中“核电质量计划报批流程”传递给核电工程部。 核电工程部提交顾客 / 营运单位审查，审查批准后方可执行。若在特殊情况下无法在规定时间 提供质量计划时，核电工程部必须尽早通知顾客 / 营运单位，并需取得顾客 / 营运单位对新的提 交日期的认可。

a ）质量计划扫描应清晰，不能有歪斜、签字模糊、比例不合适（放大或缩小）的情况；

b ）如质量计划发生变更，应包含变更单。

# 5.2.3.4 质量计划制 / 修订要求

a ）会签部门在收质量计划会签工作流程到达后，原则上应在 3 个工作日内完成会签工作 或提出修改意见，质量计划编制部门，在质量计划完成会签后，应在 2 个工作日内提交核电工 程部；供方编制质量计划，在供方提交公司采购部门后，采购部门应在 5 个工作日内完成签批 和会签工作；

b ）质量计划编制部门在接收到顾客 / 营运单位审核意见后，工艺部门编制的质量计划应在 3 个工作日内完成质量计划的修订工作并发起流程。采购部门应在 5 个工作日内完成质量计划 的修订工作并发起流程。

c ）质量计划修订后，编制部门及各会签部门要做好审核工作，严禁出现漏改，版本错误 等问题；

d ）各节点流转时间控制在 2 个工作日内，特殊情况需进行说明；

e ）生产部、核电工程部对编制、修订执行不及时影响进度或引起用户不满的问题进行考 核，质量管理部对质量计划执行过程中的管理问题进行考核，质量检验部对未按见证要求和提 交质量证明文件进行考核；

f ）质量管理部应对质量计划模板进行规范管理，负责根据实际需要或业主要求及时修订 更新质量计划模板并发布实施，并在质量计划模板中适当备注填写说明；

g ）采购部门、质量检验部、工艺部门、设计部门应严格按照本程序的工作职责要求开展 质量计划的会签、审核工作。

# 5.2.4 质量计划的变更

# 5.2.4.1 变更原因

如下原因可能会造成质量计划的变更，但不限于：

a ）质量计划编制依据文件内容的变更；

b ）根据制造质量趋势和经验反馈需要的变更；

c ）技术澄清和技术的变更；

d ）公司质量计划的修订可能影响顾客 / 营运单位见证点的变化，如：制造工序和工艺有重 大的调整，可能对质量有一定的影响，导致顾客 / 营运单位见证点的变化；

e ）没有前后逻辑关系且对质量没有影响的工序调整、依据文件版本更新、个别文字错误 等；

10

<!-- page: 11 -->

f ）由于不符合项返工、修理等活动需要增补质量计划的变更。

# 5.2.4.2 质量计划的升版变更

# a）质量计划升版前确认

质量计划升版前，编制部门需联系生产部门确认产品生产状态，确认质量计划升版对生产 制造有影响的，由编制部门将升版信息传递至生产部门，生产部门暂停相关生产制造工作。待 升版后的质量计划得到正式批复后方可启动生产制造工作。

# b ）质量计划的升版

由于 5.2.4.1 前四种原因公司原则上对质量计划进行升版，升版质量计划的审批流程同原 质量计划。当质量计划升版后，需要对正在实施的质量计划进行更替，新版质量计划生效之日 前完成的部分工作，对应的质量计划及其记录作为历史信息不变；正在进行和后续实施的工作 按升版后的质量计划实施。公司应对行老版本质量计划的变更内容和页面进行清晰标注以确保 二者的有效衔接。

# c ）质量计划升版后的传递和通知

编制部门或采购部门将升版后的质量计划发送至核电工程部，核电工程部传递至顾客 / 营运单位审批，顾客 / 营运单位审批同意后，核电工程部将顾客 / 营运单位回函传递至质量计划 的编制部门或采购部门和质量检验部本项目质保工程师。编制部门或采购部门负责将新版质量 计划上传至 OA 核电质量信息平台，同时通知使用部门及时进行变更。

# 5.2.4.3 质量计划的划改变更

由于 5.2.4.1 前三种原因引起的局部变更，也可通过《质量计划变更申请单》（见附件 2 ） 的方式进行变更，质量计划变更的审批流程同原质量计划。《质量计划变更申请单》经审查批 准后，应将变更的内容在质量计划中直接划改，在划改处签署修改人姓名和修改日期，并在“备 注栏”中标注划改原因和《质量计划变更申请单》批准函的编号。

对于质量计划中存在 5.2.4.1 原因（ 5 ）的，需填写《质量计划变更申请单》，按照内部控 制要求完成审批，无需顾客 / 营运单位审批，但需经监造人员审查签字确认。监造人员签字确 认后，可将变更的内容在质量计划中直接划改，在划改处签署修改人姓名和修改日期，并在“备 注栏”中标注申请单编号。

# 5.2.4.4 补充编制

由于不符合项的处理导致修理、返工需要增补相应的跟踪质量计划，如修理和返工的工序 是原制造工序的重复，则各方见证点的设置原则上同原质量计划，补充编制的质量计划提交顾 客 / 营运单位备案即可；如修理和返工的工序与原制造工序不同，则补充编制的质量计划需经 顾客 / 营运单位批准，审批流程同原质量计划。

5.2.4.5 执行版质量计划各方签字栏留有足够的填写区间，在设备制造工序流转过程中确保质 量计划的完成并有效，避免出现各种原因造成的质量计划填写或识别困难。

# 5.2.5 质量计划的关闭

5.2.6.2 公司内制造的设备或零部件的质量计划随工序流转，最后一序关闭后由质量检验部回 收，归入产品质量档案。

# 5.3 质量计划的实施

# 5.3.1 总体要求

a ）对于顾客 / 营运单位选择的 W 、 H 点，公司及供方不得在未通知顾客 / 营运单位的情况 下擅自从事制造活动；

b ）公司及供方应首先确保人员、材料、设备、环境满足要求，且相关人员资质证书、工 艺技术文件等在现场可得的情况下，经顾客 / 营运单位见证合格后，方能开始 W 、 H 点工序的 操作；

c ）各质量计划使用部门应对质量计划在本部门的管理建立管理要求，并设置专人对质量 计划进行统一管理，严禁出现丢失，破损情况；

d ）当质量计划跨部门（供方）传递时，交接部门均应建立交接记录并签字确认；

e ）被业主批准的，且正在执行过程中的各版本质量计划均应全部保留，并将关闭后的质 量计划由质量检验部存档；

f ）质量计划未经顾客 / 营运单位认可前不能进行相关的生产制造活动；

g ）质量计划中仅某外协序，在公司内执行到该序后，由协作部将质量计划传递至供方， 并做好与上序分厂和供方的交接工作（避免损毁、丢失），在质量计划协作序完成并在质量计 划中签字后，由协作部将质量计划传递至公司，并做好下序分厂和供方的交接工作。

5.3.2.5 如果公司或供方在没有通知顾客 / 营运单位的情况下，自行完成了需要顾客 / 营运单位 见证的“ W ”点或“ H ”点的相关活动，顾客 / 营运单位有要求重新进行相应工序的权利。如果 无法重新安排相应工序，由责任部门组织各有关部门召开专题会议，分析并确认质量是否受控， 当确认为受控则由责任部门形成报告给出 H/W 点取消或转为 R 点的变更建议并提供支持性材 料，报核电工程部，核电工程部报顾客 / 营运单位监造人员，监造人员根据审核结果可发起放 弃或降点流程回函。发生越点情况的责任部门应进行分析和整改，按公司有关规定对其考核。

# 5.3.2.6 R 点的见证实施

对于哈汽公司、顾客 / 营运单位设置的 R 点可通过函件审查和现场审查的方式实施见证， 具体要求如下：

公司内生产单位在工序完成后，应在工序完成 1 个工作日内向质量检验部、顾客 / 营运单 位提交相关记录和报告，并按工序时间顺序组织在质量计划签字栏上完成签字；

供方制造的产品，须在下一次 W/H 点见证报检前，完成前序 R 点相关记录的整理工作， 可提前或在进行下一个 W/H 点报验时，将前序 R 点文件一同传递至哈汽采购部门，采购部门 通过 OA 系统进行 W/H 点报验时，将前序 R 点文件一同传递至质量检验部及核电工程部，质 量检验部根据 W/H 点派员情况，安排实施 R 点见证人员，在 W/H 点见证实施前应完成前序所 有 R 点见证并在质量计划签字栏上完成签字。

5.3.3.1 质量计划所涉及的首序部门负责从核电质量信息平台下载质量计划并打印。质量计划 使用时需与零部件一一对应，即一份质量计划对应相应的设备或零部件。

5.3.3.2 两件及以上的同一零部件，如螺栓、罩螺母、管板等成批生产件，在加工过程中如需 分件跨车间 / 分厂转序时，上序生产部门应将执行中的质量计划复印件随件（每件对应一份质 量计划）一同转入下序生产部门。

5.3.3.3 批量生产的零部件，首序部门需在质量计划的图样代号后面用括号注上总数的几分之 几，并在硬件（设备或零部件）图样代号后作相同标注，即：分母表示该零件的总件数，分子 表示该零件的第几件。例如：中间管板共 10 件，图样代号为： N469.15.003 ，其第 1 件即为 N469.15.003 （ 1/10 ），以此类推。

5.3.3.4 封闭在本部门的“质量计划”，应随工序运转，需检查员和顾客 / 营运单位检查的控制 点，应经相关人员签字确认，责任部门将关闭后的“质量计划”与相关记录一并提交给质量检 验部检查员。

5.3.3.5 跨部门的“质量计划”，应随“工序完工转送单”一起转至下序部门，需检查员和顾 客 / 营运单位检查的控制点，应经相关人员签字确认，责任部门将关闭后的“质量计划”与相 关记录一并提交检查员。

# 5.4 备品备件和增补设备质量计划的管理

# 5.4.1 备品备件

对于主合同中所列的备品备件，如由原制造方（公司、供方）生产制造，使用原质量计划 中对应的相关部件章节，并附备品备件清单；如更换制造方，则需要重新编制质量计划，提交 顾客 / 营运单位进行审批，并附备品备件清单。备品备件的质保等级应与该零部件本身的质保 等级保持一致。

# 5.4.2 增补设备

增补设备，如果按照原工艺增订的，应按照原来已批准的质量计划执行，并在该质量计划 名称后标注 “ 增补 ” 字样；如果工艺过程有变，应重新编制质量计划提交顾客 / 营运单位进行审 批。

# 5.4.3 增补的运行备件

对于增补的运行备品备件，其质量计划编制和审批、质量控制点的设置及见证直至质量计 划关闭的要满足原备品备件质量控制的要求。
