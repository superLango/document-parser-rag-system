# 1 总则

1.1 为加强东方电气（武汉）核设备有限公司（以下简称公司）采购管理，规范 采购业务，提高采购质量，降低运营成本，根据《中华人民共和国招标投标法》 （以下简称招标投标法）、《中华人民共和国招标投标法实施条例》（以下简称 实施条例）、《工程建设项目施工招标投标办法》（2013 年3 月11 日国家发展 改革委、工业和信息化部、财政部、住房城乡建设部、交通运输部、铁道部、水 利部、广电总局、民航局令第23 号修订）和《机电产品国际招标投标实施办法》 （商务部令2014 年第1 号）等有关法律法规和集团公司管理要求，结合实际， 制定本制度。

1.2 本制度编写的依据文件：

1.2.1 集团公司《采购管理规定》（DEC-0304-3）。

1.2.2 集团公司《招标采购管理办法》（DEC-0306-3）。

1.2.3 公司《“三重一大”及重要事项决策管理办法》（DFWH-0101-2）。

1.3 本制度适用于公司物项及服务采购管理工作。

1.4 采购管理遵循以下原则：

1.4.1 公开、公平、公正、诚实守信原则。

1.4.2 保证质量、效益优先原则。

1.4.3 管办分离、招采分离、评定分离原则。

1.4.4 统一采购流程、统一采购平台、统一招标管理、统一供应商管理原则。

1.4.5 强化集团内各单位间的协同，同等条件优先选用集团内部单位原则。

1.4.6 精益化、协同化、国际化、智慧化、绿色化原则。

1.5 本制度由采购部编制并负责解释，经公司总经理办公会批准后发布，自2025 年12 月16 日起生效施行，原《采购管理制度》（DFWH-1201-3）同时废止。

# 2 定义

2.1 本制度规定的物项及服务采购是指公司生产、经营、科研等活动所需货物、 工程及服务（以下合称物资）的采购。

# 2.2 采购项目

公司生产、经营、科研等活动所需物项、工程和服务的统称，按照与产品的

相关性分为产品类物项和服务、非产品类物项和服务两大类。非产品类物项和服 务包括生产类物项、固定资产/无形资产、综合类物项、综合类服务。

# 2.2.1 产品类物项和服务

包括产品用原材料、焊接填充材料、产品外委外协、检验试验和计量检测服 务、运输服务。

# 2.2.2 生产类物项

不成为产品一部分的用于生产制造的物项，包括工装、工具、备件、辅料、 劳保用品、危险化学品等物项。

# 2.2.3 固定资产/无形资产

该类物项按照公司《固定资产管理办法》、《无形资产管理办法》执行。

# 2.2.4 综合类物项

除产品类物项、生产类物项和固定资产/无形资产以外的物项。

# 2.2.5 综合类服务

除产品类服务以外，公司向外单位寻求协助或服务支持的服务。

# 2.3 采购方式：

包括招标类采购和非招标类采购两类。其中，招标类采购包括：公开招标采 购和邀请招标采购；非招标类采购包括：战略合作谈判采购、竞争谈判采购、询 比采购、竞价采购、电商采购、集团内部采购、单一来源采购。

# 2.3.1 公开招标采购

公开招标采购是指招标人以招标公告的方式征集3 个及以上不特定的法人或 者其他组织参与投标，按照招标文件约定的标准确定中标供应商，并与之签订采 购合同的采购方式。

招标投标法、实施条例和《机电产品国际招标投标实施办法》（商务部令2014 年第1 号）、《工程建设项目施工招标投标办法》(2013 年修订)、《必须招标的 工程项目规定》（中华人民共和国国家发展和改革委员会令第16 号）、《必须 招标的基础设施和公用事业项目范围规定》（发改法规规〔2018〕843 号）等法 律法规规定的依法必须进行招标的项目，应当公开招标。其中，法律法规明确可 以进行邀请招标或可以不进行招标的除外；

对非依法必须进行招标的项目，单次采购物资预算金额达到限额的采购项目， 且采购需求明确、采购时间允许及采购成本合理时采购责任部门可选择公开招标。

# 2.3.2 邀请招标采购

邀请招标采购是指招标人以投标邀请书的方式邀请3 个及以上合格供应商参 与投标，按照招标文件约定的标准确定中标供应商，并与之签订采购合同的采购 方式。

依法必须进行招标的项目有下列情形之一的，可选择邀请招标：

（1）技术复杂、有特殊要求或者受自然环境限制，只有少量潜在投标人可供选 择；

（2）采用公开招标方式的费用占项目合同金额的比例过大。

非依法必须进行招标的项目，单次采购物资预算金额达到限额，具备招标条 件但不宜采用公开招标的，采购责任部门可选择邀请招标。

# 2.3.3 战略合作谈判采购

战略合作谈判采购是指采购人基于生产经营、战略发展需要和市场供应趋势， 对维护供应链安全稳定所必需物资，以谈判邀请书的方式邀请2 个及以上合格供 应商进行一轮或多轮谈判，经评审确定成交供应商，并与之签订长期（一年及以 上）框架协议或合同，建立相对稳定的战略采供关系的采购方式。

具备下列情形之一的可选择战略合作谈判采购：

（1）供需双方通过联合研发、共担风险模式形成的原创性产品或服务的采购；

（2）企业瓶颈物资、特定重要零部件、对公司产品质量和生产经营产生重大影 响的，需要长期稳定供应并和特定供应商协商建立长期战略合作关系的采购。

# 2.3.4 竞争谈判采购

竞争谈判采购是指采购人以谈判邀请书的方式邀请2 个及以上合格供应商进 行一轮或多轮谈判后，经评审确定成交供应商，并与之签订采购合同的采购方式。 具备下列情形之一的可选择竞争谈判采购：

（1）采购物资因技术复杂或性质特殊，采购人不能准确提出采购需求，需与供 应商谈判后研究确定的；

（2）采购需求明确，但有多种实施方案可供选择，采购人需通过与供应商谈判 确定实施方案的；

<!-- page: 5 -->

（3）市场供应资源缺乏，合格供应商只有2 家的；

（4）询比采购项目，仅2 家报价的或经评审后有效供应商仅有2 家的；

（5）因企业生产经营需要，需与供应商进行价格谈判的；

（6）采用其他采购方式均不适合保护国家基本安全的。

# 2.3.5 询比采购

询比采购是指采购人以询比邀请书的方式邀请3 个及以上合格供应商报价， 由供应商一次报出不得更改的价格后，经评审确定成交供应商，并与之签订采购 合同的采购方式。

同时具备以下三种情形的可选择询比采购：

（1）采购人能够清晰、准确、完整地提出采购需求；

（2）采购物资的技术和质量标准化程度较高；

（3）市场资源较丰富、竞争充分，合格供应商不少于3 家。

# 2.3.6 竞价采购

竞价采购是指采购人以竞价邀请书的方式邀请3 个及以上合格供应商在规定 时间内多轮次公开竞争报价，按照最终报价最低确定成交供应商，并与之签订采 购合同的采购方式。

同时具备以下四种情形的可选择竞价采购：

（1）采购人能够清晰、准确、完整地提出采购需求；

（2）采购物资的技术和质量标准化程度较高；

（3）采购物资以价格竞争为主；

（4）市场资源较丰富、竞争充分，合格供应商不少于3 家。

# 2.3.7 电商采购

电商采购是指采购人在集团公司电子商城或指定的第三方电商平台中，通过 比较、遴选、协商等选定采购物资的采购方式。

具备下列情形之一的可选择电商采购：

（1）商品价格在集团公司电子商城公开，已经形成竞争性市场价格的；

（2）国资委组织中央企业在指定的第三方电商平台实施联合采购的。

# 2.3.8 集团内部采购

<!-- page: 6 -->

集团内部采购是指采购人以谈判邀请书的方式邀请1 个或多个集团公司所属 企业（指合并财务报表企业，下同）进行报价，经评审确定成交供应商，并与之 签订采购合同的采购方式。原则上，集团公司和集团公司所属企业参股30%及以 上的子企业可直接纳入集团内部采购对象范围，集团公司和集团公司所属企业参 股但未达到30%的，经公司总经理办公会审批同意后，可纳入集团内部采购对象 范围。

集团内部采购可不进行供应商评审，不受金额限制，其中采购集团公司所属 企业的首台套、首批次、首版次物资时应优先选用集团内部采购。

# 2.3.9 单一来源采购

单一来源采购是指采购人以谈判邀请书的方式邀请唯一合格供应商进行一 轮或多轮谈判后，经评审确定成交供应商，并与之签订采购合同的采购方式。

具备下列情形之一的可选择单一来源采购：

（1）涉及国家秘密、国家安全或企业重大商业秘密，不适宜竞争性采购的；

（2）因抢险救灾、事故抢修等不可预见的特殊情况需要紧急采购的；

（3）需采用不可替代的专利或者专有技术的；

（4）需向原供应商采购，否则将影响施工或者功能配套要求的；

（5）市场供应资源缺乏，合格供应商有且仅有1 家的；

（6）为保障重点战略物资稳定供应，需签订长期协议定向采购的；

（7）联合投标、联合研发、国产化替代项目不适宜采用其他采购方式的；

（8）行业垄断和政府指定采购项目；

（9）满足科技创新项目开发所需的技术合作、实验用材料（不含固定资产）采 购的；

（10）用户合同中明确了唯一供应商的；

（11）工业母机、工业软件、关键材料、核心零部件等符合首台套、首批次、首 版次应用要求的；

（12）国家有关部门文件明确的其他情形。

2.4 集采平台：集团公司采购管理平台，简称SRM。

# 4 工作程序

# 4.1 供应商寻源及管理

4.1.1 征集供应商应按照广泛寻源的原则，采购责任部门和技术、质量等相关部 门均可开展供应商寻源有关工作。根据公司供应商资源结构、采购特征、公司产 品特征，提前、广泛开展供应商寻源工作。采购责任部门负责在集中采购管理平 台首页发布供应商公开寻源公告，并负责提出潜在合格供应商准入申请。

4.1.2 公司对供应商实施评审准入及合格供应商动态管理，并做好分级分类管理。 质量安全环保部组织对供应商提供物项/服务质量、价格、交货及时性等进行评 价，根据评价结果对供应商进行合理选择和调整，及时淘汰不合格供应商。

4.1.3 要严格控制代理商和经销商数量，按照“能清尽清”原则对原厂商为国内 制造商的经销商和代理商（不含集团公司所属企业）进行清退，并应直接向原厂 商（即制造商，下同）采购。对于原厂商不参与的采购项目，应邀请原厂商指定 的代理商或经销商参与，投标或响应报价时应附原厂商对供应、交货、服务等事 项的承诺函。

# 4.9 供应商违约索赔

供应商未按合同履约，须按合同约定或双方达成的协议对供应商进行索赔； 若造成质量损失的，按照《质量损失统计管理办法》或双方合同约定执行索赔。

# 4.10 支付与结算

4.10.1 按照采购合同条款具备付款条件后，采购责任部门按照公司《资金支付 管理办法》的规定办理支付申请。财务部对采购执行部门提交的付款申请及相关 资料进行审核，具备付款条件后支付款项，并反馈支付信息（包含支付金额、支 付方式）。

4.10.2 在付款过程中，采购及财务经办人员应严格审查采购发票的真实性、合 法性和有效性。发现虚假发票的，应查明原因，及时报告处理。发票作为重要凭 证应严格进行管理，避免出现发票丢失和作废的事件。

4.10.3 采购执行部门应做好采购付款的过程控制和跟踪管理，发现异常情况的， 应当拒绝付款，避免出现资金损失和信用受损。

4.10.4 采购责任部门应做好预付账款和定金的管理。涉及大额或长期的预付款 项，应当定期进行追踪核查，综合分析预付账款的期限、占用款项的合理性、不 可收回风险等情况，发现有疑问的预付款项，应当及时采取措施。

# 5 采购管理要求

# 5.1 组织实施部门

5.1.1 招标类采购项目由招标中心统筹管理和组织实施，确需委托第三方招标代 理机构实施的项目，报招标中心同意后由采购责任部门委托第三方招标代理机构 实施。

5.1.2 战略合作谈判采购、单次采购物资预算金额达到限额的询比采购和竞争谈 判采购，由招标中心组织实施；竞价采购、集团内部采购、电商采购、单一来源 采购、单次采购物资预算金额未达到限额的询比采购和竞争谈判采购，由采购责 任部门自行组织实施。

# 5.2 定标/成交审批

5.2.1 采购责任部门负责按制度规定权限组织完成定标/成交审批，审批过程中 发现评标/评审的分值汇总计算错误、客观评审因素评分不一致、评分超出评分 标准范围、评分项遗漏等影响评标/评审结论的，应书面说明情况，由该项目原 组织实施单位（招标中心或采购责任部门）核实后组织原评标组/评审组进行复 评，并在评标/评审报告中如实记录复评原因及复评情况。

5.2.2 定标/成交审批过程中，原则上应当确定评标/评审报告中推荐的第一候选 人为中标人/成交人。若排名第一的候选人放弃、因不可抗力不能履行合同、不 按要求提交履约保证金，或者被查实存在影响中标/成交结果的违法行为等情形 时，可经公司分管业务和分管采购的两名公司领导审批同意或者经总经理办公会 审批同意后选定后一家候选人，也可以流标/终止。

5.2.3 非招标类采购项目，若成交结果与评审结果不一致时，采购责任部门应对 调整的原因予以书面说明。如果未按照评审报告中推荐的候选人排名顺序确定成 交人的，采购责任部门应书面说明调整的原因和合理性，经公司分管业务和分管 采购的两名公司领导审批同意或者经总经理办公会审批同意后确认成交人，其中 由招标中心组织实施的项目还需经招标中心审核同意后确认成交人。

5.2.4 定标/成交审批委员会按定标/成交审批权限表（详见附件七）进行定标/ 成交审批，定标/成交审批委员会议事规则详见附件八，

5.2.5 加强定标/成交审批过程的合规与风险管控，对未确定评标组/评审组推荐 的第一候选人为中标人/成交人的，要从严审批，其中由招标中心组织实施的项 目，采购责任部门还需将定标/成交审批的调整情况、候选人的责任等书面报招 标中心。

5.2.6 原则上定标/成交审批时间不得超过30 天，超过30 天未完成定标/成交审 批的项目，需说明原因，并报分管相应采购责任部门的公司领导审批。

# 5.3 框架协议采购管理

5.3.1 加强采购计划的统筹管理，将一定时期（季度、半年、年度等）的物资需 求进行分类和整合，大力实施框架协议采购，合理减少采购频次，降低采购管理 成本。

5.3.2 框架协议采购应选择公开招标采购、邀请招标采购、询比采购、竞争谈判 采购、战略合作谈判采购和集团内部采购6 种采购方式之一实施。

5.3.3 框架协议采购应明确框架协议执行期限和上限金额，协议到期或达到上限 金额时框架协议应终止，各单位应结合实际情况制定框架协议管控要求。

# 5.4 集中采购管理

对于集中采购授权单位按照集团公司一级集采目录实施的集中采购项目，按 照所签订的集中采购框架协议或合同严格执行。未包含在集中采购框架协议或合 同中的物资，由各采购责任部门自行采购。

# 5.5 采购管理平台

东方电气采购管理平台是集团公司实施采购业务的唯一平台，除例外采购外 的其他所有采购业务均需在采购管理平台上按规定流程完成。

# 5.6 业主指定采购

- 17 -

<!-- page: 18 -->

5.6.1 在投标阶段时，产业发展部或技术部应将我方合格供应商名单尽可能纳入 投标文件，原则上不能少于3 家。

5.6.2 在销售合同谈判阶段，产业发展部不得接受配套件唯一供应商，若有特殊 情况，应报本单位公司级领导审批。若在签约后合同中存在唯一供应商的情况， 产业发展部合同移交给执行部门时应提交书面说明。

5.6.3 对在项目执行阶段业主提出的指定采购；业主指定供应商时，应提供带有 业主项目公司主要负责人签字并加盖公司级签章的文件、函、传真等材料证件。

# 5.7 采购原则

5.7.1 坚持集中采购原则。对同一张采购需求的同类采购项目，不允许采购责任 部门采用“分拆”的办法规避招标采购。

5.7.2 坚持供应商准入原则。只有经过评审合格的供应商，才具备与我公司签订 采购项目合同的资格。采购责任部门须按公平公正和竞争原则，充分应用供应商 评价结果，择优确定供应商；在供应商选择上，能选择直接供应商的须选用直接 供应商，减少中间供应商选用；采购责任部门应持续做好供应商寻源、开发工作， 减少单一来源采购。

5.7.3 坚持阳光采购原则，减少采购中间环节。

5.7.4 坚持应邀尽邀的原则。邀请招标采购、竞争谈判采购、询比采购和竞价采 购应对同级别合格供应商应邀尽邀。若未实现应邀尽邀，采购员应在采购策划时 说明理由。

# 5.8 采购需求的管理

5.8.1 加强计划管控。采购需求部门对需求的合理性负责，采购需求提出前，须 核实库存和在途物资情况，以避免短时间内重复采购，降低物资积压；需求部门 对造成的非正常库存负直接责任。

5.8.2 采购需求应进行分类管理，不同类别的采购物项须分别提交采购需求。

# 5.9 采购策划的管理

为达到高效保障生产，且经济、可靠的采购目的，采购责任部门对拟采购物 项/服务开展深入的市场调研和分析，做好采购策划。

# 5.10 例外采购的管理

- 18 -

<!-- page: 19 -->

对于因特殊原因不能在采购管理平台实施的涉密、应急、零星等采购或不能 在采购管理平台实施的向国外供应商直接采购，可实施例外采购。

# 5.10.1 涉密物项的采购

因采购对象、渠道、用途等涉及国家秘密，需要在采购过程中控制国家秘密 的知悉范围，经保密管理部门确认后，可按需选择邀请招标采购、询比采购、竞 争谈判采购和单一来源采购方式之一进行采购。

# 5.10.2 应急采购

（1）对于采用“应急采购”流程的，需求部门应根据实际需求情况，填写《应 急采购审批表》（详见附件九），写明应急采购原因，经部门领导、部门分管领 导、财务部门领导及采购责任部门分管领导审批后，提交采购责任部门执行。

（2）采购需求部门根据实际采购情况提交采购需求，质量安全环保部将相应供 应商补充纳入本项目合格供方名单范围内，采购责任部门在SRM 系统中补充完善 询价/定价手续，验收部门、采购需求部门配合完成采购物项的入库、出库等手 续。

# 5.10.3 零星采购

零星采购适用于生产制造部，零星采购部门应通过强化计划的前瞻性，尽可 能避免零星采购。对于确因生产突发状况，需零星采购以满足生产进度需求的情 况，可在本部门相应零星采购额度范围内自行采购，凭票报销。相应的管理要求 如下：

（1）生产制造部可自行实施的零星采购，范围为单项物项价值量小于3000 元的 设备备品备件等设备维修类物项（不包括固定资产和无形资产），为满足生产进 度所需的机物料物项。

（2）设备维修类物项经生产制造部公司分管领导审批后可实施零星采购；机物 料物项根据实际情况一事一议，经生产制造部公司分管领导审批后可实施零星采 购。

（3）零星采购内控要求。零星采购部门应建立零星采购管理台账，规范本部门 零星采购业务流程，零星采购频次要求。

（4）零星采购的价格审批按《价格管理办法》执行。

（5）零星采购额度为每月不超过1 万元整。

5.10.4 除涉密采购外的例外采购，例外采购按如下要求补录至采购管理平台。

（1）采购计划补录：例外采购应在采购管理平台中创建采购计划，通过采购管 理平台采购补录模块进入，创建采购计划，录入采购计划信息，并提交审批。

# 6 其他要求

6.1 要严格执行国家相关法律法规，严格对依法必须进行招标的项目进行判断和 审查，杜绝出现依法必须进行招标的项目不招标、依法应当公开招标的项目不公 开招标和将依法必须进行招标的项目化整为零，或者假借保密工程、抢险救灾等 特殊工程的名义规避招标等情况。

6.2 选用战略合作谈判采购与单一来源采购方式的，按照从严管控的原则进行审 批。单一来源采购和集团内部采购需建立台账清单，定期报集团供应链管理部备 案。

6.3 对于原创技术策源地企业、创新联合体、启航企业等产生的创新产品和服务， 工业和信息化部等部门相关名录所列首台（套）装备、首批次材料、首版次软件， 以及《中央企业科技创新成果推荐目录》成果，各单位在兼顾经济性情况下可采 用战略合作谈判采购、竞争谈判采购、单一来源采购和集团内部采购方式实施。 首台（套）装备、首批次材料、首版次软件参与采购活动时，仅需提交相关证明 材料，即可视同满足市场占有率、使用业绩等要求。

6.4 确需联合投标的，原则上应通过竞争方式确定联合投标方，特殊情况应明确 审批流程。

6.5 加强采购计划集成，强化对短期内频繁采购同类物资、拆分计划多次采购等 造成采购综合成本增加、规避提交招标中心等行为的监督和考核。

6.6 要加强对采购物资的价格分析测算，做好预价工作，提升采购成本管控能力 和水平。

6.7 鼓励将标准工业品、低值易耗品、通用服务项目等通过电子商城进行电商采 购；电子商城应通过竞争性方式依法合规确定铺货供应商，约定商品上下架、价

格调整、风险分担、支付结算等交易规则；电子商城应具备比质比价功能。

6.8 要积极推进绿色供应链建设，建立健全绿色采购制度，明确绿色采购要求， 同等情况下可优先采购供应商开发的绿色低碳产品和服务。

6.9 要大力支持中小企业参与采购活动，不得违法限定供应商所在地、所有制形 式、组织形式、注册资本、股权结构、经营年限等，或者设定其他不合理的条件 排斥、限制中小企业参与采购活动。同时要积极落实政策性采购要求，鼓励在同 等条件下优先采购脱贫地区、革命老区、民族地区和边疆地区产品。

6.10 供应商管理相关要求按公司《供应商管理办法》执行。

# 6.11 保密要求

采购人员、招标人员和评标专家以及其他参与人员不得在采购过程中向供应 商透露采购方式、标底等信息。保守国家秘密、保守公司商业秘密（包括供应商 信息、进货渠道、进价策略等信息）、维护公司利益。对违规的，将严格按照公 司规定追责问责；对违法的，依法移交司法机构处理。

# 6.12 廉洁协议管理要求

采购责任部门按公司管理要求与供应商签订《廉洁协议》。

# 6.13 限额以下采购管理要求

采用限额以下采购方式的，原则上在集采平台上的挂网时间应在3 天及以上， 生产急需、安全整改等项次，在所邀请供应商全部完成报价后，可提前开启报价。

# 6.14 供应商询价管理要求

原则上只允许在两种情况下向供应商询价，一是竞争谈判采购（限额以下）、 询比采购（限额以下）、竞价采购、集团内部采购、单一来源采购开标时，由采 购人员向该采购项目的所有供应商提出二次报价要求；二是在招标动作结束后， 由采购人员根据预中标价格和财务预价评判是否需要供应商二次报价，二次报价 原则上只允许和评标排名第1 的供应商洽谈，若评标排名靠后的供应商报价低于 评标排名第1 的供应商，也可以进行洽谈，供应商的再次报价不能超过之前报价。

# 6.15 寻源/询价管理要求

为进一步提升采购质效，要求采购责任部门结合实际充分使用“全国企业采 购交易寻源询价系统”，从严采购预价管控，强化采购成本管控，拓展供方寻源

# 6.16 刀具的重复性采购要求

刀具的重复性采购，由生产制造部按照附件四提出采购需求，采购需求提出 时需要技术部会签。

# 6.17 监督检查

纪律检查部应对采购活动进行监督，对违法违规等行为进行调查，并提出处 理建议交由公司纪委、党委处理。

# 7 罚则

7.1 采购人员不履行职责，不正确执行该制度规定给公司造成负面影响，或对采 购工作弄虚作假、徇私舞弊的，按照《员工行为守则管理办法》处理。

7.2 部门领导不履行职责，不正确执行公司采购管理制度相关规定，给公司造成 负面影响、损失或在采购工作中弄虚作假、徇私舞弊的，按照《中层领导人员管 理办法》处理。

7.3 对情节严重，泄露公司重要机密，严重侵害公司利益者，公司将解除劳动 合同；涉嫌犯罪的,依法移送司法机关处理。

# 4 议事程序

# 4.1 会议审议

4.1.1 采购责任部门领导根据采购实施情况，结合审议事项组织召开定标/成交审 批会议。

4.1.2 会议议程由采购责任部门介绍项目情况、评标及评审结果、推荐的中标/成 交候选人等，委员会成员对相关情况进行提问和讨论。

4.1.3 委员会成员根据项目情况分别发表意见，会议主持人最后发表意见，如委员 会对议题结论存在一定意见分歧，则以会议主持人意见为最终结论；如意见分歧较 大，则暂缓做出结论，待研究成熟后再议。全体参会委员应在定标/成交审批表上 签署意见。

# 4.2 签字审批

4.2.1 采购责任部门发起审批流程，同时提交定标/成交签批资料，签批资料至少 包括：项目情况、评标及评审结果、推荐的中标/成交候选人。

4.2.2 委员会参与成员分别按照流程签署定标/成交审批意见，会议主持人最后签 署意见，如委员会对议题结论存在一定意见分歧，则以会议主持人意见为最终结论； 如意见分歧较大，则暂缓做出结论，待研究成熟后再议。

4.3 采购责任部门根据审批意见确定中标/成交供应商，并按采购管理有关规定与 供应商签订合同。
