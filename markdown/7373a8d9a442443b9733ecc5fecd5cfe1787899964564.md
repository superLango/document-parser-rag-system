# 一、 目的

本规范旨在为紧凑型聚变能实验装置（ BEST ）的屏蔽结构提供材料性能数据支撑 与技术依据。其采用奥氏体高硼钢作为中子屏蔽材料。针对 BEST 工况特性制定本规 范，确保材料满足：核聚变装置的射线屏蔽要求；安全可靠性要求；长寿命服役的疲 劳耐受性和辐照环境下的性能稳定性。

# 二、 适用范围

适用于 BEST 项目包层中所使用的奥氏体高硼钢锻件及板材。

# 四、 制造工艺

为了满足本规范中对结构和夹杂物含量的要求，钢的冶炼工艺应采用真空感应炉 熔炼（ VIM ）加真空电渣重熔（ ESR ）或真空感应熔炼（ VIM ）加真空自耗重熔（ VAR ）。 供应商应提供详细的工艺工程文件，包括但不限于熔炼工艺、热处理工艺、检测方法 等。

考虑装置安全性和高硼钢材料的制造难度，材料制造商须已有完成 3 吨级及以上 高硼钢制备、锻件制造、加工的验证经验，并提供材料性能 CNAS 资质第三方检测报 告包括密度、热膨胀系数、杨氏模量、泊松比、导热系数、定压比热、力学拉伸性能 和疲劳性能等数据，锻件力学和焊接性能满足 7.1 要求。全流程制造和性能分析需由 甲方见证认可。

# 5.2 铁素体含量和磁导率

# 5.2.1 铁素体含量评估

采用 RCC-MR 2007 规范的改性 Schaeffler 图（图 RMC 1341.2, Section 3 ）进行 预测；铁素体含量 ≤ 0.5% （以金相法 EN ISO 643 为仲裁依据）。

# 5.2.2 磁导率测试

产品在固溶热处理后，在室温下测量其相对磁导率，测量值应≤ 1.03 。测试应 按照 ASTM A342 进行。

* 允许使用磁导率仪（如 Foerster 、 Ferromaster 等），但设备的类型、商标和相 关性 ( 该材料、厚度、形状等 ) 应由供应商提供。材料证书应提供其校准证书的类型、 商标和副本。

# 六、 制作与加工要求

# 6.1 制作方案

供应商应在生产启动前提交经采购方批准的制造计划，包含：

⚫ 熔炼工艺的确定；

⚫ 铸造或锻造零件的图纸、热处理、无损检测和交货的轮廓图；

⚫ 中间热处理和最终热处理对机械性能的条件；

⚫ 验收试验样品在零件上的位置；

⚫ 样品上试验样品的位置的尺寸图。

各种热处理、抽样和无损检测操作应按时间顺序进行。

经甲方批准后方可生产。

# 6.2 交货条件

材料经机加工并进行应力消除处理后交付。

# 6.2.1 固溶处理

固溶热处理应包括：将材料加热至 1050 ℃ ~ 1200 ℃ 范围内的指定温度，保温保 持，随后进行水淬，并提供完整的热处理温度 - 时间曲线记录及报告文件。

# 6.2.2 表面条件

表面应经机加工，确保交付状态下金属表面无油污或油脂残留，且粗糙度 Ra 平 均值≤ 6.3 μ m （依据 EN ISO 4288 规范）。

# 7.2 取样和测试

# 7.2.1 试样制备

试样应在完成锻造并进行固溶热处理后进行取样。锻件试样应从以下部分进行切 割：

⚫ 锻件本身；

⚫ 或从与零件整体连接的延伸部分或多余材料中。

样品应适当标记。测试样品的大小应足以提供足够的测试样品供所有测试和复试 使用。

测试样品应按以下方式切割 : 使其轴线与主要锻造方向垂直，且轴线与最近处理表 面（表面）之间的距离为：

⚫ 厚度＞ 40 mm 时： 20 mm ；

⚫ 厚度≤ 40 mm 时：厚度 /2 ；

试样测试相关区域与其他处理表面之间的距离不得小于：

⚫ 如果厚度大于 40 mm ，则为 40 mm ；

⚫ 如果厚度小于 40 mm ，则为该厚度。

如果零件的形状不允许这样做，应尽可能获得上述给定值。试验样品应具有圆形 横截面。其正常直径应为 10mm 。对于小于 20mm 厚的锻件，圆柱形试验样品可由 具有矩形横截面的样品代替。

焊接试样取样：在硼钢锻件上切割 10~20mm 厚板与同壁厚 316LN 不锈钢板焊接， 取焊缝试样测试。

# 7.2.2 力学性能测试

室温测试按 EN ISO 6892-1:2016 （ GB/T 228.1-2021 、 GB/T 229-2020 ）执行，高温 测试按 EN ISO 6892-2:2018 执行，必须测定：

<!-- page: 9 -->

⚫ R p0.2 （ 0.2% 屈服强度， MPa ）；

⚫ R m （抗拉强度， MPa ）；

⚫ A （断后伸长率， % ）；

⚫ 冲击值。

# 7.2.3 批次定义

批次由同炉钢锭 + 相同锻造工艺 + 同一热处理炉次的锻件组成，且满足几何相似性。 一个批次应包括直径 d 、厚度 e 和横截面 S 等，并按照以下定义：

普通锻件：单件重量≤ 1000kg 时允许组批，但批次总重严禁超过 3000kg 。

屏蔽块本体锻件：无论重量或尺寸均须单独组批，禁止与其他部件混合。

# 7.3 再处理

因力学性能不达标被拒的锻件，仅允许进行一次再处理。再处理必须严格按 6.2.1 固溶热处理规范执行（ 1050-1200 ℃保温 + 水冷），并在试验报告中完整记录：

⚫ 再处理温度 - 时间曲线（含升 / 降温速率）；

⚫ 再处理前后力学性能对比表。

禁止条款：

⚫ 再处理后性能仍不合格者永久报废；

⚫ 非固溶热处理（如退火、正火）不得作为再处理手段。

# 八、 表面检查

所有加工阶段均须执行表面完整性全检。零件表面应确保：无氧化皮、污渍、撕 裂和任何危害性缺陷。交货时需提交最终检查报告。

# 8.1 渗透检测规范

每个锻件 100% 按 EN 10228-2:2021 执行液体渗透检测，所有真空接触表面必须 使用采购方书面批准的渗透剂。

# 九、 体积检查

所有产品必须执行 100% 体积超声波检测，严格按 EN 10228-4:2023 执行，验收标 准根据厚度动态调整。对于结构应用中使用的锻件，采用质量等级 3 。当零件的轮廓

<!-- page: 10 -->

允许进行测试性能时，应进行此项检测。应按以下优先顺序进行：首先进行机械加工 后的检测，其次进行热处理后的检测。

应对粗加工后的毛坯锻件的整个体积进行超声波检测。按照标准 EN 10228-4 第 12.4 节的规定，应进行 100% 的扫描覆盖。考虑的范围和验收标准应依据检测零件的 厚度而定，并应符合标准 EN 10228-4 中正常探伤的规定。

# 十、 去除不可接受区域

锻造厂允许通过研磨消除表面缺陷，但必须确保研磨后零件仍满足设计尺寸公差 要求。研磨作业完成后，须立即按本规范“表面检查”章节规定的标准执行液体渗透 检验。

严禁采用任何形式的焊接修复工艺处理缺陷。

# 十一、 尺寸检测

尺寸应按照图纸的要求进行检查。主要尺寸应记录并保存。测量值应在图纸上给 出的公差范围内。

# 十二、 标记

供应商应规定所使用的识别和标记方法，并在技术制造计划中进行描述。标记应 通过压印或采购方指定的其他可接受的方式进行。

标记至少应包括 :

⚫ 制造商名称或标志

⚫ 材料等级

⚫ 与质量记录相关的牌号或唯一识别号

⚫ 熔炼炉号

提供对生产控制所需信息的清晰参考标记或代码是可接受的。随零件提供的样品 应按照采购订单的规定进行标记。

# 十五、 验收

供应商必须在交货前向采购方提供材料测试报告及认证文件，所有材料及其认证 均需符合本规范要求。不符合本规范的材料禁止验收。供应商应提供质量证书，证明 材料的生产制造、取样、测试及检验全过程均遵循材料规范要求，且经验证符合全部 技术条款。

# 十六、 文件和证书

供应商须额外提供符合现行有效国际 / 国家标准（如 ISO 17025 或 EN 10204 3.1 ） 的检验证书。证书须包含本规范要求的所有测试报告（含原始测试及符合本规范要求 值 / 标准的重新测试结果），并补充以下信息：

⚫ 材料名称及标识标记；

⚫ 熔炼炉号与零件追踪编号；

⚫ 供应商认证标识；

⚫ 采购订单合同号；

⚫ 如适用：偏差许可申请、不符合项报告（ NCR ）、不合格品处理记录、批准 的控制计划副本

所有数据必须采用国际单位制（ SI 单位），文件须以不可编辑的 PDF 格式提交。

# 十七、 质量控制要求

所有供应商必须持有采购方书面认可的质量保证计划，或具备现行有效的 ISO 9001 认证质量体系。供应现成材料时，可豁免专项质量计划及制造检验计划（ MIP ）。 若需补充测试，须由认可的第三方实验室执行。所有目视与无损检测必须由符合 ISO 9712 持证人员操作。
