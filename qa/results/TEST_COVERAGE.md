# P0 阶段测试覆盖率统计表

统计口径：覆盖率 = 实际通过用例数 / 计划用例数；单模块通过率必须 ≥95%。
模块全覆盖判定 = 该模块在五层中至少覆盖 3 个层，且所有用例通过。

## 覆盖率结论

- 计划用例数：130（pytest 105 + Playwright E2E 20 + 迁移脚本 5）
- 实际通过：130（100%）
- 失败/阻塞：0
- 模块全覆盖：9/9（100%）
- **结论：覆盖率 100% ≥ 95%，P0 测试完成，可进入下一阶段。**
