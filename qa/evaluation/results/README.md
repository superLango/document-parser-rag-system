## 完整性说明

- 每份 JSON 为当次 extraction_results 完整返回（含 categories/summary/timing/error/version），可直接复核；
- validation 与 full_flow 的 metrics 文件为脚本计算值（综合分 = 0.35×填充率 + 0.25×完整率 + 0.25×可用率 + 0.15×脚本命中率）；
- full_flow/gjb_strict.json 为阈值 0.9 的全剔除演示，gjb_loose.json 为 41 类别全参与结果（含 metrics）；
- 各运行检索配置：GJB 调优/引擎对比/验证使用 strict(0.035) 召回（full_flow strict 演示用阈值 0.9 全剔除）；
- LLM 输出存在随机性，同配置多次运行指标会有小幅波动。
