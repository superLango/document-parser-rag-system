## 6. 风险与应对

| 风险 | 应对 |
|---|---|
| 领域专家时间不可控 | 先完成 A/B 副本与 diff 工具，专家只处理争议项；争议项清单按表/字段排序 |
| 非记录表型抽取范围大 | 先做 inspection（数量最多），再做 classification/clause；共用表-条款定位 |
| 收紧 condition 导致 F1 下降 | 先补 facet 抽取，再收紧；每次收紧跑回归，回退阈值 0.01 |
| 困难表修复引入回归 | 单表修复 + 表级回归用例；只对目标表启用新规则 |
| Qwen 输出波动 | 固定 prompt/版本、温度；保存每次 mapping 结果；失败回退规则 |
| 标注口径变化 | 冻结 `goldset/v0`；新增口径放 `goldset/v1`，不混用 |
