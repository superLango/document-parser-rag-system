## 5. 调用契约

### 5.1 GLM-OCR

端点：

```text
POST http://192.168.1.35:9977/v1/chat/completions
```

请求体：

```json
{
  "model": "GLM-OCR",
  "messages": [
    {
      "role": "user",
      "content": [
        {"type": "image_url", "image_url": {"url": "data:image/png;base64,<...>"}},
        {"type": "text", "text": "请将图片中的表格完整识别并转换为 HTML <table> 格式输出，保留所有行列内容，不要输出解释。"}
      ]
    }
  ],
  "max_tokens": 4096,
  "temperature": 0
}
```

响应：

```text
choices[0].message.content
```

块类型与 prompt（与 hansonDoc_RAG 一致）：

| 块类型 | prompt |
|---|---|
| `title` | 完整识别标题文字，直接输出 |
| `text` | 识别正文，保留段落/换行，输出 Markdown |
| `table` | 转 HTML `<table>`，保留行列 |
| `formula` | 转 LaTeX |
| `image_caption` | 识别图注 |
| `table_caption` | 识别表注 |
| `footnote` | 识别脚注 |
| `aside_text` | 识别旁注 |

图片预处理：

- RGB；
- 最长边 >2048 时等比缩到 2048；
- 最短边不小于 32；
- PNG base64 data URL；
- 超时 120s，重试 2 次；
- 并发：页 4 × 块 8。

### 5.2 Qwen3.5-9B

端点：

```text
POST http://192.168.1.35:9989/v1/chat/completions
```

请求体（抽取建议）：

```json
{
  "model": "Qwen3.5-9B",
  "messages": [
    {"role": "system", "content": "你是金属材料标准抽取器，只输出 JSON。"},
    {"role": "user", "content": "<表头/行数据/schema>"}
  ],
  "temperature": 0,
  "max_tokens": 4096,
  "response_format": {"type": "json_object"},
  "chat_template_kwargs": {"enable_thinking": false}
}
```

关键点：

- Qwen3.5 **默认 thinking**，会输出 `<think>...</think>`；抽取必须显式 `enable_thinking=false`；
- 先用 `response_format=json_object`；严格 guided JSON（schema 约束）在 M2 用 vLLM `structured_outputs` 验证后启用；
- 文本抽取可加 `--language-model-only`，跳过视觉编码器；
- 不要让 9B 与 RAG 35B 同时跑。

## 7. 资源预算

| 服务 | `gpu-memory-utilization` | 估算 | 说明 |
|---|---|---|---|
| NIII 现有 | — | 11GB | 不可停 |
| GLM-OCR | 0.16 | ~19GB | 页级 OCR |
| Qwen3.5-9B | 0.25 | ~30GB | 32K 上下文 |
| Layout | — | ~1–2GB | 进程内 |
| 总计 | 0.41 + 现有 | ~61GB | 119GB 内安全 |

规则：

- 启动前 `nvidia-smi` + `free -h`；
- 35B 运行时不要启 9B；
- OOM 先降 `--max-model-len` / `--gpu-memory-utilization` / `--max-num-seqs`；
- 每个服务记录 GPU 秒数与成本。

## 8. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `FileNotFoundError: 'ninja'` | flashinfer JIT 找不到 ninja | 启动前 `export PATH=/home/grainuser/hansonDoc_RAG_deploy/venv/bin:$PATH` |
| `:9977 occupied` | 旧进程未退/端口冲突 | `ss -ltnp`、`pgrep -af vllm`，按端口停 |
| `GLM-OCR stopped` 但 pid 文件存在 | 进程已死，pid 陈旧 | 删除 pid 文件后重启 |
| 模型加载后 SIGINT | 手动/脚本停止 | 查 `logs/vllm_*.log` |
| Qwen 输出带 `<think>` | 未关 thinking | 请求加 `chat_template_kwargs.enable_thinking=false` |
| Qwen OOM | 上下文/并发过大 | 降 `max-model-len`、`max-num-seqs`、utilization |
| layout hash mismatch | 权重被替换 | 核对 SHA256 或 `verify_hash=False`（仅调试） |
| GLM 返回空内容 | 图片过大/裁剪过小/prompt 不匹配 | 检查 2048 上限、bbox、prompt |
| 端口从笔记本不可达 | 防火墙/绑定地址 | 服务用 `--host 0.0.0.0`；检查防火墙 |
