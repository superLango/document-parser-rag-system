## 0. 本版改了什么

v1.0 已经给出 M0–M5 和任务清单。v2.0 不改变总体技术路线，只做四件事：

1. **按当前真实进度重新基线**：M0 已完成 Schema v0、20 份清单、3 份迷你标注、mock 端到端与评测脚本；剩余项单独列为 M0 收口。
2. **把每个里程碑拆成子里程碑**：M1-S1…M1-S8、M1.5.x、M1.7.x 等，每个子里程碑有独立入口、交付、退出条件。
3. **任务级细化**：每个任务增加输入、交付物、验收证据、依赖、Owner 和优先级，可直接导入项目管理工具。
4. **增加阶段门、失败分支、止损线**：明确“不达标时怎么办”，避免带病进入下一阶段。

> 编号说明：为避免与里程碑 M1.5、M1.7 冲突，M1 的子阶段统一记为 M1-S1…M1-S8；M1.5、M1.7 仍表示引用图谱与全文档覆盖两个独立里程碑。
> 阶段细节文档：`stages/README.md`（M0–M5 每个里程碑一份执行级文档）。
> 模型运行手册：`stages/09-模型服务与调用手册.md`（188.75 的 GLM-OCR、Qwen3.5-9B、PP-DocLayoutV3 启动与调用）。

不变的三条红线：

- 没有证据的值不发布；
- 不可复现的路径不进生产；
- 不能证明覆盖就不算完成。

## 15. 数据与评测治理

### 15.1 黄金集版本

- v0：20 份清单 + 3 份 mini（当前）；
- v1：20 份完整标注（M1-S7）；
- v2：生产失败案例回流（M4 起）；
- 任何版本变更必须记录变更原因、标注人、复核人。

### 15.2 标注质量

- 双人独立标注；
- 争议仲裁；
- 值一致 ≥98%，比较符/单位 ≥99%，条款 ≥95%；
- 未达门槛不得用于阶段门。

### 15.3 指标定义

| 指标 | 定义 | 目标 |
|---|---|---|
| Field Accuracy | 严格匹配（值 + comparator + unit） | M1 简单表≥85%，扫描≥75%；M2≥95% |
| Value Accuracy | 只看值，分母为已抽字段 | 用于区分归一化/漏抽 |
| Record F1 | `(grade/level, condition)` 匹配 | ≥95% |
| Header Mapping | 列角色/属性/单位 | ≥98% |
| Coverage Rate | 必填字段有证据或明确状态 | ≥95% |
| Clause F1 | 方法/方向/位置/数量/温度/判定 | ≥90% |
| Link Accuracy | 表-条款链接 | ≥95% |
| Orphan Rate | 无牌号/条件行占比 | <1% |
| Hallucination | 无证据值/发布值 | <1% |
| STP | 无人工修改直接发布 | ≥80% |

### 15.4 回归

- 每次 prompt/recipe/model 变更跑黄金集；
- 输出新增错误/修复错误/覆盖变化；
- 核心字段下降 >1pp 阻止合并；
- 生产失败案例自动进入回归集。

## 17. 风险、止损线与升级路径

| 风险 | 触发信号 | 影响 | 应对 | 阶段门 |
|---|---|---|---|---|
| OCR 质量差 | 低文本页、乱码、表线丢失 | 全链错 | 页质量分、裁剪重 OCR、人工 | G1 |
| 表格结构复杂 | 多层表头、跨页、转置 | 列错位 | TableGrid、金样例、困难表清单 | G1/G1.5 |

| 微调过拟合 | 留出集下降 | 隐性错误 | 教师蒸馏、扰动、按文档切分 | G2 |
| 配方过拟合 | 同族换文档即崩 | 隐性错误 | 聚类代表、影子、签名约束 | G2.5 |

| GPU 不足 | 队列积压 | SLA 不达标 | 池隔离、配额、扩容 | G3/G5 |
| 范围蔓延 | 全条款/全表格 | 交付失控 | schema 必填字段为准 | 每次门 |

## 附录 D · 指标公式

```text
Field Precision = 严格正确字段 / 已发布字段
Field Recall    = 严格正确字段 / 金标字段
Field F1        = 2PR / (P + R)

Value Accuracy  = 值正确字段 / 已抽出字段
Evidence Rate   = 有有效证据的值 / 已发布值
Hallucination   = 无证据值 / 已发布值

Record F1       = 2 * RecordP * RecordR / (RecordP + RecordR)
Coverage Rate   = (found + not_applicable) / required
Clause F1       = 2 * ClauseP * ClauseR / (ClauseP + ClauseR)
Orphan Rate     = 无牌号/条件行 / 总行数
STP             = 无人工修改直接发布文档 / 总文档
```
