## 3. 失败分类与处置

### A. 牌号口径（已修评测侧，管线修复待部署）

- `iso-5832-3-2021`：pred 牌号全部为 `~`，金标为 `Ti-6Al-4V`；文档标题是中文“钛-6铝-4钒合金”。已在 `_document_grade_hint` 增加中/英文 Ti-6Al-4V 识别（单测通过），**待发布 parser 后该文档可从 0 恢复**。
- `asme-sb575-2023`：pred 为 `Alloy N06035`，金标为 `N06035`。`gold_eval.canon_grade` 已剥离 `Alloy` 前缀并按 UNS 提取，F1 从 0 → 0.176；剩余差距是提取量不足（29 vs 176）。
- `astm-b708-25`：pred 为描述式牌号（`90%tantalum-10%tungsten(R05255)`）。评测侧已提取括号内 UNS，F1 0 → 0.035；仍有 197 条 `~` 记录，需要按表头/文档补牌号。

### B. 漏表/漏行（版面与 OCR 侧，最大缺口）

- `asme-sb265-2025`：金标 1108 项，仅 34 项；大量化学成分/拉伸/弯曲表未进入记录。
- `astm-b338-17`、`asme-sb338-2021`、`astm-b348-13`：缺约 50 条室温拉伸 + 每种元素 28~39 行，疑似续表/跨页表未合并。
- `astm-b861-14/24`、`astm-b862-23`：precision 高（0.99–1.0）但 recall 仅 0.29，说明已抽到的都对，剩余表格没抽到。

### C. 条件与静默值

- `gbt-5231-2022` 静默 54.8%、`gbt-14976-2025` 45.6%、`ams-5663p` 47.5%、`astm-f136-26` 46.4%：值存在但键/条件不一致，主要来自厚度块、纵向/横向、跨页重复行。
- 全量条件一致率 0.3310，W3 列级条件/单位元数据已实现，待部署后验证。

### D. 金标特殊口径

- `gbt-5231-2022` 缺 `Cu+所列元素总和` 292 条（金标合成字段）、`其他元素` 56~82 条（各 ASTM/ASME）；需要配方/评测映射明确“其他元素/总和”的产出规则。
