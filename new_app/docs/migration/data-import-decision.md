## 3. 决策

**本轮不导入旧文档、运行记录、产物与反馈。**

- 仅导入业务词典（已完成，2203 条）。
- 旧系统与旧数据只读保留，作为效果对比基线；不删除、不迁移。
- 新系统上线后数据重新生成。

**未达标差异清单（不导入的理由）**

1. **字段口径差异**：旧 KV2 vs 新 KU2、旧 HB vs 新 HBW、旧 ReH vs 新 RP0.2；部分为命名差异，部分为配方绑定差异。
2. **行键污染**：备注/长句被识别为牌号（如“该牌号仅适用于2，3级棒材”），导致字段键漂移。
3. **大表覆盖不足**：部分标准（如 GBT33084）旧 812 字段、新 238 字段，多牌号/多表覆盖不完整。
4. **配方覆盖缺口**：部分文档新系统 0 共同字段（如 gbt1591 样本），路由/配方未覆盖 KV2、CEV、Pcm 等字段。
5. **静默错误**：共同字段中 9.13% 数值不一致，超过 5% 门槛。

## 4. 若后续确认导入（当前不执行）

仅当完成以下修复并复测达标后，重新评估导入范围：

| 修复项 | 验收 |
|---|---|
| 字段别名映射（KV2/KU2、HB/HBW、ReH/RP0.2） | 对比脚本中语义别名归一；F1 提升 |
| 行键校验（长度/句子/备注过滤） | 不再出现长句牌号 |
| 大表与多牌号覆盖 | GBT33084 类样本 F1 ≥ 0.8 |
| 配方覆盖（CEV/Pcm/KV2 等） | 样本 0 共同字段数降为 0 |
| 静默错误 | ≤ 5% |

导入范围建议（如届时需要）：仅导入复测达标的文档类型；运行/产物/反馈仍不导入，避免带入旧问题。
