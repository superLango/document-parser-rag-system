# 文档处理

HansonDOC RAG 支持多种文档格式的 OCR 识别、版面分析与结构化处理。

## 支持的格式

| 格式 | 扩展名 | 处理方式 |
|------|--------|---------|
| PDF | `.pdf` | PP-DocLayoutV3 版面分析 + 全并行 OCR |
| 图片 | `.png` `.jpg` `.jpeg` `.tiff` | 直接 OCR 识别 |
| 文本 | `.txt` `.md` | 直接读取，跳过 OCR |

## 解析流程

文档解析采用异步任务模式（arq worker），完整流程：

1. **下载**：从 MinIO 拉取原始文件（走 KB 专属 bucket）
2. **OCR 识别**（进度 20%-50%）：GLM-OCR 混合模式，PP-DocLayoutV3 版面分析 + 全并行 OCR
3. **文本清洗**（进度 55%）：按配置级别清洗空段落、冗余标记、乱码字符
4. **结构化抽取**（进度 60%）：若指定 Schema，执行字段抽取
5. **术语标准化**（进度 80%）：按 KB 术语库替换同义术语
6. **保存结果**（进度 90%）：解析文本、版面数据、结构化数据入库
7. **完成**（进度 100%）：任务通知发送给文档所有者

## 任务监控

在「任务」标签可查看所有解析任务的状态、进度与错误信息。任务失败时可点击「重试」重新解析。

## 文件预览

文档列表支持预览：

- **PDF**：内置 PDF 查看器，支持翻页
- **图片**：显示原图 + OCR 识别框叠加
- **文本**：Markdown 渲染

## 全文搜索

在「搜索」标签可跨文档搜索关键词，结果高亮显示匹配片段，支持按文档过滤。

## 通知

文档解析完成或失败时，顶栏铃铛会收到通知提醒，点击通知可跳转到对应任务。
