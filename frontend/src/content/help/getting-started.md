# 快速开始

欢迎使用 HansonDOC RAG。本指南将引导你在 5 分钟内完成从登录到首次问答的完整流程。

## 1. 登录系统

在登录页输入用户名与密码。若连续 5 次输入错误密码，账户将被锁定 30 分钟。如需重置密码，请联系管理员。

## 2. 创建知识库

1. 点击侧边栏「知识库」进入列表页
2. 点击「新建知识库」
3. 选择领域模板（材料检测 / 医疗器械 / 合同 / 通用问答），或选择「空白知识库」
4. 填写名称与描述，点击创建

每个知识库拥有独立的数据库隔离、向量库 Collection、对象存储 bucket 与图谱 space，确保数据物理隔离。

## 3. 上传文档

进入知识库后，切换到「文档」标签：

1. 点击「上传文档」，支持 PDF / 图片 / 文本格式
2. 文档自动进入解析队列，状态变为「处理中」
3. 解析完成后状态变为「已完成」，可点击查看解析结果

## 4. 结构化抽取

切换到「抽取」标签：

1. 选择已解析的文档
2. 选择抽取 Schema（字段模板）
3. 点击「开始抽取」，系统通过 SSE 流式返回字段抽取结果

## 5. 智能问答

切换到「问答」标签，输入问题即可获得基于知识库的 RAG 问答结果，回答附带引用来源与置信度评分。
