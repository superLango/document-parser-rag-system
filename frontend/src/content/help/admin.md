# 系统管理

系统管理功能仅超级管理员可见，包括用户管理、审计日志、资源清理与系统监控。

## 用户管理

在「用户管理」可：

- 查看所有用户列表
- 创建 / 停用 / 启用用户
- 重置用户密码
- 设置超级管理员权限
- 查看用户登录历史

密码策略：

- 最小长度 8 位
- 必须包含大小写字母与数字
- 不能与最近 5 次密码重复
- 连续 5 次登录失败锁定 30 分钟

## 审计日志

审计日志记录所有关键操作，支持：

- 按 action / 用户 / 知识库 / 资源类型 / 日期范围过滤
- 操作趋势图（按天）
- 操作类型分布图（Top 8）
- 按操作者统计 Top 10

审计日志保留天数由 `AUDIT_LOG_RETENTION_DAYS` 配置项控制。

## 资源清理

系统每日凌晨 3:00 自动执行清理任务：

| 清理项 | 说明 |
|--------|------|
| 过期任务 | 删除超过 30 天的 Task 记录 |
| 审计归档 | 归档超过保留期的审计日志 |
| 孤儿向量 | 清理无对应文档的向量 |
| 孤儿图谱 | 清理无对应文档的图谱节点 |
| 临时文件 | 清理 OCR 临时输出 |

管理员可在系统设置中手动执行清理（支持 dry-run 预览）。

## API 安全

系统已实施多层安全防护：

- **CORS**：动态配置允许的源
- **IP 白名单**：`/admin/*` 路径仅允许白名单 IP
- **分级限流**：认证 5/min、上传 10/min、AI 20/min、默认 60/min
- **登录锁定**：连续失败自动锁定
