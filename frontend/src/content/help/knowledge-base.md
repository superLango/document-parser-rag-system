# 知识库管理

知识库是 HansonDOC RAG 的核心隔离单元，每个知识库独立管理文档、配置、成员与资源。

## 创建知识库

新建知识库时需选择领域模板，系统会自动初始化：

- **PostgreSQL**：按 `kb_id` 行级安全策略（RLS）隔离
- **Milvus**：专属 Collection（doc_chunks + 五维向量）
- **MinIO**：独立 bucket（`kb-{kb_id}`）+ 独立 IAM 密钥
- **NebulaGraph**：专属 graph space
- **Redis**：键前缀隔离 + 独立 ACL 用户

## 领域模板

内置 4 个领域模板：

| 模板代码 | 名称 | 适用场景 |
|---------|------|---------|
| `material_testing` | 材料检测 | 航天航空检测标准，5 类别 3 正则 |
| `medical_device` | 医疗器械 | 医疗器械文档，4 类别 2 正则 |
| `contract` | 合同条款 | 合同分析，5 类别 3 正则 |
| `general_qa` | 通用问答 | 纯 RAG 问答，无结构化抽取 |

模板是纯数据配置，特殊业务逻辑由 Hook 承载。

## 配置中心

在「配置」标签可管理：

- **基础配置**：OCR 引擎、向量维度、抽取模型等
- **领域类别**：自定义文档分类规则
- **正则规则**：字段提取的正则表达式
- **字段模板**：抽取字段定义
- **Hook 脚本**：每 KB 独立的扩展脚本

## 成员管理

知识库采用显式成员制，必须加入成员才能访问。4 种角色：

| 角色 | 权限 |
|------|------|
| owner | 所有者，全部权限 + 删除知识库 |
| admin | 管理员，配置 + 成员管理 |
| editor | 编辑者，文档 + 抽取操作 |
| viewer | 查看者，只读访问 |

## 备份恢复

管理员可在配置中心创建知识库备份（ZIP），包含配置、文档元数据、抽取结果、术语、Schema。备份可下载到本地或在新知识库中恢复。
