# 中压二级过热器管板用SA336 F91锻件采购技术规范

# 1. 适用范围

本技术要求规定了中压二级过热器SA-336F91锻件的基础标准、技术要求、检测方法等要求。

本技术要求适用于中压二级过热器用管板锻件的订货和验收。

# 3. 基础标准

锻件的牌号为 SA-336 F91。锻件的一般要求应满足 SA-336/SA-336M 和 SA-788/SA-788M 的要求。当上述标准和本技术要求相抵触时，应以本技术要求为准。

# 4. 技术要求

4.1 制造

锻件应为镇静钢，经过电炉冶炼和真空脱气或其他相当的方法。钢锭的头、尾应切掉足够的料头，以保证把缩孔和过度偏析部分去除。

# 4.3 热处理

4.3.1 锻件应以正火（允许快速冷却）+回火状态交货，回火温度在 $ 7 3 0^{\circ} \mathrm{C} \sim 7 8 0^{\circ} \mathrm{C} $ 。具体热处理参数应在质量证明书中明确。

4.3.2 锻件试样应模拟热处理，热处理制度：锻件试样进炉后，随炉加热到 300℃，然后以 55℃/h的速度升温到 760℃±10℃，保温时间15小时，然后以 55℃/h的速度降温至 300℃后，出炉空冷。

# 4.4 力学及工艺性能

4.4.1 锻件应按 ASME SA370的规定进行力学性能试验，按 ASTM E21的规定进行高温拉伸试验，交货状态和模拟热处理后的力学性能都应符合表2的规定。

4.4.2 锻件应按 ASME SA370 的规定进行夏比 V 型缺口冲击试验，冲击试样按 GB/T 2975 制备。交货状态和模拟热处理后的冲击性能应符合表 3 的规定。

4.4.3 锻件应按 SA-788 S12 的要求在交货状态和模拟热处理后进行轴向拉伸试验。

# 4.5 金相观察

显微组织观察应在放大200倍的情况下进行，并拍摄金相照片。显微组织应为回火马氏体。

# 4.6 晶粒度

锻件的实际晶粒度应按ASTM E112进行评定，评定的结果应为5级或更细。

# 4.7 无损检测

4.7.1 交货状态锻件应进行超声波检测，检测方法应满足NB/T 47013.3-2023的要求，质量等级应满足NB/T47008-2017表4的要求。

4.7.1 交货状态锻件上下表面和圆周表面应按NB/T 47013.4-2015中I级的要求进行磁粉检测。

# 4.7 表面质量

在锻件制造的过程中，应非常仔细地检查锻件的所有表面。最终机加工后的锻件表面不允许有起鳞、裂纹、槽痕或其它有损于锻件使用的缺陷。表面质量不得影响无损检测。

# 4.8 焊补

锻件表面不允许焊补。

# 4.9 尺寸及允许偏差

锻件的尺寸及允许偏差应符合 SA-788/SA-788M 和订货图纸的规定。

# 4.10 复试及重新热处理

4.11.1 如果拉伸性能的试验结果不合格，可按 SA-788 第10.3节进行复试。

4.11.2 未经锻件采购方和设计方认可，不得进行重新热处理。

# 5. 试验

5.1 锻件应按件进行验收。

5.2 锻件的试验项目及验收标准如表 4 所示。

5.3 取样

# 5.3.1 试样的截取

试料应在交货状态的锻件上切取，每个取样部位试料应包含所有试样及可能的复试试样，然后进行模拟焊后热处理。试样应采用机加工方法切取，避免形成因热切割而导致的热影响区。应取切向试样。

试料应在距最大应力区域最近的热处理表面一倍距离深度（t）及距第二个表面至少二倍距离（2t）处进行取样，t应不小于20mm。

5.3.2每个取样位置应截取2套（交货态一套、模拟态一套）力学性能试样，每套试样包括2个室温拉伸试样、2个高温拉伸试样、1组（3个）冲击试样。2套试样位置间隔180°。

5.3.3 每组3个冲击试样应并排截取，试样缺口轴线垂直于锻件最近的热处理表面。

# 5.3.4 金相试样取样

金相检验的试样（金相观察、晶粒度）可取自破断的室温拉伸试样端部。

5.3.5 常规拉伸和冲击试样的纵轴应垂直于锻件的切向方向。

每个锻件还应取2个（交货态一个、模拟态一个）轴向拉伸试样。轴向拉伸试样应尽可能靠近颈部并在内缘或外缘截取，如有必要，可用小尺寸试样。试样的纵轴应平行于颈的长度方向。可参考SA-788附录中图S1。

# 6. 材料质量证明文件

在锻件交货的同时应提交材料质量证明文件，材料质量证明文件应至少包括如下内容：

1）合同号或订单号；

2）锻件名称和锻件编号；

3）锻件图；

4）材料牌号；

5）熔炼炉号和热处理炉号；

6）化学成分（熔炼分析和成品分析）分析报告；

7）热处理记录；

8）各项力学性能试验报告（包括复试，如果有）；

9）金相检验报告（晶粒度、显微组织照片等），质量证明文件正本应附有金相照片原件，副本允许用复印件；

10）表面质量和尺寸检验报告；

11）无损检测报告；

12）材料识别标记；

13）存档材料的资料信息（如要求）；

14）未曾焊补的声明。

# 7. 标记

锻件、试料、存档材料等应有清晰可见的标记。在无损锻件使用性能的前提下，交货的每个锻件应至少标记以下内容：

1）合同号或订单号；

2）熔炼炉号；

3）锻件图号、锻件编号；

4）材料牌号；

5）热处理炉号；

6）锻件制造厂名称或商标。

# 8. 清洁、包装和运输

成品锻件的表面应没有锈斑、灰尘及其它污染物。

锻件的清洁、包装和运输都应符合订货合同的相关规定。
