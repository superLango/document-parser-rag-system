# 1. 适用范围

本技术协议适用于 Equatorial Port Cell 11 部件（VQCIA）用 316L 奥氏体不锈钢锻件（方钢）及棒材。本协议以 RCC-MR 2007 中的产品采购规范 RM 3322为基础，并结合部件安装位置特性所产生的附加要求制定。这些锻件按 RCC-MR的分类规定，归属于设备2级（Class 2）。

制造商在开工前应提供如下技术类文件，以保证产品质量：

（1）锻件和棒材的制造大纲（MPS）

- 按时间先后顺序列出各种热处理、取样和无损操作过程；

- 冶炼工艺；

- 锻造工艺；

- 钢锭的重量和类型；

- 钢锭头尾切除率；

- 每一锻造火次的锻件尺寸简图和每火次的锻造比及总锻造比；

- 锻件（毛坯）图、性能热处理外形图；

- 中间热处理和最终性能热处理条件；

- 验收试验用试料在部件上的位置图；

- 试样在试料上的位置图；

- 热处理工艺；

- 理化检验要求；

- 无损检验；

- 尺寸检验；

- 清洁、包装及运输要求。

（2）锻件和棒材的加工与检验计划（MIP）

（3）无损操作规程

# 5. 热处理要求

锻件及棒材应在粗加工后、成品取样前进行固溶退火处理。

材料等级为：根据 ITER_D_7XW3EA-v1.1 规范的 316L。

固溶退火工艺应将锻件在 1050 $ ^{\circ} $ C至1150 $ ^{\circ} $ C（含温度公差）范围内保温，随后水冷。保温期间的正向温度偏差不得超过+15 $ ^{\circ} $ C。包括炉温公差在内的保温温度上限不得超过 1150 $ ^{\circ} $ C。整个热处理过程中的温度-时间曲线必须全程记录，并将记录数据纳入材料检验证书中。

# 6. 公差尺寸要求

# 6.1锻件

锻件在热处理前应进行粗加工。粗加工尺寸应尽可能接近最终交付尺寸。

锻件的最终交付尺寸应符合以下公差要求：宽度公差（0，+10 mm）；长度公差（0，+10 mm）；厚度按EN10029A级执行；平面度按EN10029S级执行；锻件重量公差为±5%；边缘拱曲度：实际锻造长度的0.2%；非方正度：实际锻件宽度的1%（G）；

# 6.2 棒材

所有部件均应根据 ITER_D 7XW3EA 规范。材料等级：依据 ITER

# 7. 取样要求

# 7.1.1 锻件取样

在完成固溶热处理后，应从锻件上取样。

取样应符合 ITER_D_7XW3EA-v1.1 的要求。根据零件几何形状允许的情况，样品的取向应满足以下要求：

- 试样轴线应与主锻件方向垂直；

- 当厚度＞40mm时，试样轴线与最近处理表面（表皮）之间的距离为≥ 20mm；

- 当厚度＜40mm时，在厚度中点处。

试样有效测试区域与其他任何处理表面之间的最小距离应为： $ \rightarrow $当厚度> 40mm时，为≥40mm； $ \rightarrow $当厚度≤40mm时，为厚度值的2倍。

若零件几何形状导致无法完全满足上述要求，则取样位置应尽可能接近规定数值。

# 7.1.2 锻件批次定义

组批规则：一个批次应由形状、截面和直径相近的零件组成，并应满足以下条件： $ \varphi\max /\varphi\min < 1.1 $ ； $ \mathrm{e}\max /\mathrm{e}\min < 1.1 $ ； $ \mathrm{S}\max /\mathrm{S}\min < 1.25。 $

特殊情况下上述尺寸限制不适用于厚度≤80mm、单件重量≤500kg的空心圆形零件。

通用要求：在任何情况下，同一批次中的所有零件必须：

来自同一炉号钢水；

经历相同的加工工艺流程；

来自同一炉次，或接受同一次热处理工艺。

批量限制：

- 单个批次的总重量应不超过 5000 kg；

- 交付状态下单件重量大于1000kg的零件，应单独作为一个批次；

# 8. 无损要求

# 8.1 UT检测

所有锻件和棒材均应进行超声体积检测（UT）。所有 UT 人员均须根据 ISO 9712标准获得资格并取得认证。结果的解释工作应由二级或三级人员执行。

# 8.1.1 检测程度及检测时机

该检测应在零件外形尺寸满足检测条件、能够保证检测效果时进行。检测的实施顺序优先级如下：

（1）最终机加工完成后；

（2）为满足力学性能要求而进行的热处理之后，无论之后是否还需进行机加工。

由于零件几何形状限制，若在热处理后无法进行检测的零件或零件局部，应在可行的最晚中间工序阶段进行检测。对于小型成形零件，可在半成品状态下进行检测。

# 8.1.2 检测程序

超声检测程序应符合 RCC-MR 2007 中的 RMC 2310 和 RMC 2320的规定，并适用 EN 10228-4 标准中规定的条件。探头的常规参数如下：

- 直探头检测：频率 2 MHz；

- 斜探头检测：频率1 MHz，折射角根据零件几何形状确定。

对于厚壁零件，如材料组织需要，可采用更低频率的探头。

零件的整个体积均应进行超声检测。应按照 EN 10228-4 标准 12.4 的规定实施 100% 扫查覆盖率。零件类型为 1、2、3 或 4 类。

# 8.1.3 显示评定

超声检测显示的评定应符合 RCC-MR 2007 中 RMC 2310 和 RMC 2320的要求。

直探头检测：所采用的检测范围及与零件厚度相关的验收准则，应符合 EN 10228-4 中针对直探头的规定。当厚度≥75 mm时，就底波衰减而言，可记录的

# 8.2 PT检测

# 所有锻件和棒材均应进行 100%的PT检测

在生产及加工的各个阶段，应彻底检查每件锻件的表面，以确认金属完整性。零件应无裂纹、疏松、飞边、撕裂、凹痕或其他有害缺陷。所有零件均需进行目视检查，随后按照制造商合格的液体渗透检测程序执行液体渗透检测（PT）。所有从事PT检测的人员必须具备资质并符合ISO 9712标准要求。结果的解释由二级或三级人员负责。若发现不合格的指示，应适用第9节的规定。

# 8.3 见证要求

取样前需提前3天通知甲方现场无损见证，如甲方无法到达，可经书面通知的形式以其他形式见证

# 9. 清除和不可接受区域

表面缺陷可通过打磨去除，但必须确保锻件和棒材在交付状态下的尺寸公差仍符合规定。打磨后，应按照制造商的合格液体渗透检测程序进行PT检测。验收标准须满足第8.2节的要求。在任何情况下均严禁采用焊接修复。

# 10. 重复热处理

因机械性能测试结果不符合要求而被拒收的批次，可采用固溶热处理方式进行再加工。再加工仅允许进行一次，且再加工属于重要防护活动（PIA），须相应记录。

制造商应在开始重复热处理操作前通知甲方。再加工热处理应按照本协议第5节的要求执行。再加工过程中所采用的工艺参数应记录在专门的再加工热处理报告中，并纳入材料制造档案。

再加工完成后，应严格按照本制造程序第4节和第7节的规定进行取样和检测。若再加工后仍不符合要求，则该批次应被最终拒收，并立即通知客户。

# 制造商名称及标识

凡能够清晰对应生产控制所需信息文件的标识或代码，均可被接受。随零件一同交付的试样应按采购订单的规定进行标识。

注：制造商在进行成品标识前，应提前告知甲方关于标识内容及相关信息，在甲方同意后方可标识。如甲方不认可，乙方需根据甲方提供的标识清单进行标识。

# 12. 文件及测试报告要求

供应商应根据EN10204:2004提供3.1型检验证书。只有当材料制造商拥有经欧盟内认可机构认证的适当质量保证体系，并持有针对该材料的特定批准时，3.1型检验证书才被接受。

制造商应在每一项单独试验完成后，并且最迟在零件交付前，编制以下报告：

- 熔炼分析和成品分析的化学成分结果（如适用），以及冶炼工艺方法；

- 金相显微检查记录，包括夹杂物评定和晶粒度测定结果；

- 力学性能试验结果；

- 无损检测结果；

- 尺寸检查记录；

热处理记录及曲线。

清洁、包装和运输的要求应符合合同规定，并特别考虑RF-6000的要求。
