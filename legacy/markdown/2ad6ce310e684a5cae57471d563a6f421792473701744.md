# 1. 范围

本技术协议规定了34CrNiMo6圆钢的尺寸、长度、外形、重量及允许偏差、技术要求、试验方法、检验规则、包装、标志和质量证明书等内容。

本技术协议适用于直径≤250mm的锻制或热轧圆钢。

# 3. 尺寸、外形、长度及允许偏差

原材料的尺寸、外形、重量及允许偏差应满足 GB/T 908(锻制圆钢)或 GB/T 702(热轧圆钢)中2组的有关规定。

# 4. 技术要求

4.1 冶炼方法

# 4.1 冶炼方法

采用电弧炉+炉外精炼+电渣重熔方法冶炼。

# 4.2 供货状态

原材料车光或磨光，以退火状态交货，布氏硬度≤241HB，锻造比≥4。

# 4.6低倍组织

钢材的横截面酸浸低倍组织试片上不允许有肉眼可见的缩孔残余、气泡、空洞、翻皮裂纹、白点、夹杂、点状偏析等缺陷。

横向酸浸低倍组织按GB/T1979标准进行评级，一般疏松≤2.0级，中心疏松≤2.0级，锭形偏析≤2.0级，一般点状偏析和边缘点状偏析不允许有。

# 4.7 晶粒度

钢材应检验奥氏体晶粒度，按GB/T 6394评级，其合格级别不小于5级。

# 4.8 超声波探伤

按GB/T4162逐支进行100%超声探伤检测，探伤精度等级不低于A级。

# 4.9表面质量

钢材表面不应有目视可见的裂纹、结疤、折叠及夹杂缺陷。如有上述缺陷必须清除，清除深度从钢棒实际尺寸算起不超过尺寸公差的一半，清除宽度不小于深度的5倍，同一

# 6. 入厂复验

# 6.1 组批规则

钢材应按批检查和验收，每批由同一牌号、同一炉号、同一加工方法、同一尺寸、同一交货状态、同一热处理炉次（或制度）的钢材组成。

# 6.2 检查与验收

原材料入厂复验按表4规定执行，但应尽量减少取样数量，不同实验项目可在同一试样上进行。

# 6.3 复验与判定规则

圆钢低倍不合格时，要重新取样复检，在不合格炉号的不同支数上取双倍数量试样，复检仍不合格时，则该炉不得交货。圆钢的复验与判定规则应符合GB/T 17505标准要求。
