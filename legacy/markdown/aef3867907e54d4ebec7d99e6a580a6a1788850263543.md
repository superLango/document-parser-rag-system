# 1 目的

规定东方电气（武汉）核设备有限公司上海院 CAP1000 和 CAP1400 堆内构件原材料、 外购件采购活动中，原材料、外购件供应方应遵守的质量保证及质量控制要求。

# 2 范围

# 5 对供应方的停工令管理

# 5.1 由购买方发出的停工令

当购买方发现供应方制造活动中出现但不限于下列情况时，购买方可以下达停工通知。

➢ 通知点管理不善，出现超越业主、顾客或其代表设定的 H 点制造的情况；

➢ 有特殊资格要求的活动由未获得相应资格的人员实施；

<!-- page: 5 -->

➢ 使用未经验证或已知有不可纠正缺陷的设备、材料；

➢ 擅自变更设计文件；

➢ 继续制造将导致重大返工或修理；

➢ 使用未经过批准的工艺文件和作业指导书；

➢ 制造过程中出现重大质量问题或重大质量风险；

➢ 对于重复出现的问题没有采取纠正措施或采取的纠正措施没有效果。

# 5.2 由购买方传递的停工令

国家核安全监管单位、业主、采购方下达的停工通知，由购买方传递至供应方。

供应方收到停工通知后，应立即停止相应产品制造，并将产品置于安全状态。未收到 复工通知前，不得开展任何相关工作。

# 7 变更与澄清

# 7.1 术语

设计和工艺变更（ DEN ）：购买方对供应方发出的对设计和工艺文件进行修改的通知。

技术变更申请（ TA ）：供应方向购买方发出的，为了适应供应方某种特殊的资源、设备 制造方法、某些特殊现场条件而对设计文件内容进行技术调整或修改的请求。

技术澄清要求（ CR ）：供应方向购买方发出的，对技术文件中未作规定或规定不清楚 的技术内容提出进一步说明和澄清的要求。

# 7.2 购买方向供应方下达的设计和工艺变更

购买方向供应方下达设计变更有两种形式：

<!-- page: 6 -->

➢ 升版采购技术规格书、图纸或其他设计文件

➢ 发出 “ 设计变更通知单 ”

供应方收到购买方的技术和工艺变更后，应立即组织评审：

➢ 评审结果为 “ 可实施 ” 时，应修改相应制造工艺文件，确保制造满足技术和工艺变更 后的要求；

➢ 评审结果为 “ 不可实施 ” 时，须在 3 个工作日内向购买方回复意见并说明原因和处 理建议，由购买方采购部组织进行协调，其结果有以下三种情况：

− 指令供应方实施设计和工艺变更

− 修订设计和工艺变更

− 撤销设计和工艺变更

# 7.3 供应方向购买方申请的技术变更

供应方填写 TA 单，通过通信渠道发送至购买方，购买方采购部接收、转发技术部并 予以跟踪。购买方技术部通过 “ 设计和工艺意见反馈单 ” 回答，由采购部发送供应方执行。

# 7.4 供应方向购买方提出的设计澄清

供应方填写 CR 单，通过通信渠道发送至购买方，购买方采购部接收、转发技术部并 予以跟踪。购买方技术部通过 “ 设计和工艺意见反馈单 ” 回答，由采购部发送供应方执行。

# 8 质量保证分级

# 8.1 质量保证分级的目的

为保证物项的设计和建造质量满足预期的功能要求和性能要求，同时达到合理控制质 量成本，以达到节省投资的目的，而对物项 / 服务确定质量保证等级。质量保证等级的高低， 首先要依据物项的安全等级或重要性，其次还要考虑物项的设计、制造、建造的经验以物 项的工艺成熟性、运动部件多寡、供货史、标准化程度等多种因素。

# 8.2 质量保证分级的原则

以物项的失灵或服务中的差错对安全和可利用率所造成的影响为依据，并按照物项和

<!-- page: 7 -->

服务对安全和可利用率的影响程度和重要程度来进行分级控制，原则上，安全等级高和重 要程度高的物项和服务，则质量保证等级高。

# 8.3 质量保证分级的确定

质量保证等级分为 QSA 、 QRA 和 QNA 三类，在 QSA 和 QRA 类中又各分三级，即 QSA1 、 QSA2 、 QSA3 和 QRA1 、 QRA2 、 QRA3 连同 QNA 共 7 级。

具体物项和服务的质量保证分级，由购买方通过合同或 “ 质量保证分级清单 ” 向供应方 下达。

# 9 质量保证体系要求

对制造不同质量保证分级物项的供应方质量保证体系有如下要求。

# 9.1 QSA1/2/3 级

➢ 质量管理体系应经过 ISO9001 体系认证，提供物项或服务已取得国家或行业资格 许可。

➢ 遵守 HAF003 及相应导则（国外供应方执行 IAEA-50-C-QA 或 ASME NCA 3800 ）。 制定和实施项目质保大纲。

➢ 合同执行期内接受每年至少一次的质保监查（国外供应方至少一次）。

➢ 接受源地监造。

➢ 编制完工文件。

# 9.2 QRA1/2/3 级

➢ 质量管理体系应经过 ISO9001 体系认证，提供物项或服务已取得国家或行业资格 许可。

➢ 遵守 HAF003 及相应导则（国外供应方执行 IAEA-50-C-QA 或 ASME NCA 3800 ）。 制定和实施项目质保大纲。

➢ 合同执行期内接受至少一次的质保监查（国外供应方必要时开展）。

➢ 接受源地监造。

➢ 编制完工文件。

# 9.3 QNA 级

➢ 质量管理体系应经过 ISO9001 体系认证，提供物项或服务已取得国家或行业资格 许可。

<!-- page: 8 -->

➢ 必要时开展质保监查。

➢ 接受源地监造。

➢ 编制完工文件。

# 11 文件的版本和状态

供应商需对文件的版本和状态进行定义并标识。

<!-- page: 9 -->

# 11.1 文件版本控制

文件版次使用大写英文字母顺序标识（ A 、 B 、 C ， …… ）表示这些文件的内容尚未固 化、未达到施工应用的要求。文件版次使用数字顺序标识（ 0 、 1 、 2 ， …… ）表示这些文件 属于施工应用文件。文件版次使用字母加数字顺序标识（ A0 、 A1 、 A2 ，……）表示这些文 件属于竣工文件，合同另有约定的执行合同要求。应在文件的“版次”栏或其他规定的地 方标识文件版次信息。

# 11.2 文件状态的定义及标识

文件状态规定了该文件内容的有效程度。通常文件采用下述三种文件状态：

a) PRE （ Preliminary ，试行文件）：这种文件的内容很可能还会变动，而且编制者认为 文件还未最后定稿。该状态可用于作业图的发布，以便客户审查、批准、招投标，这种文 件通常作为施工设计的预备性文件。

b) CFC （ Certified For Construction ，施工文件）：这种文件的内容已为编制者确认有效 并可实施。

c) CAE （ Certified As Executed ，竣工文件）：这种文件的内容完全符合竣工状态。

另外，对于部分仪控供应商产生的文件，可使用 DES （ Descriptive ，描述状态），这种 文件为描述状态，不作为施工执行依据性文件。

文件编制者应在文件的“状态栏”及其他规定的地方标识文件的状态信息。

# 11.3 文件版本和状态的联系

文件版本连同文件状态一起表示工程文件内容的有效性。字母版本标识与 PRE 状态同 时使用，数字版本标识与 CFC 状态同时使用，字母和数字的组合标识与 CAE 状态同时使 用，数字版本标识与 DES 状态同时使用。用法举例如下：

# 12 质量计划

# 12.1 质量计划的编制要求

➢ 所有零部件（含铸锻件、板材、管材、见证件）和设备的下列活动都应编制质量计划：

<!-- page: 10 -->

—制造、检查、试验、设备运输和装卸等活动；

—由于不符合项的处理导致的修理、返工等活动。

➢ 对于 RCC-M 、 ASME 等规范管辖范围内焊接材料的制造和 / 或复验，应编制质量计划。

➢ 对于分包的单一工序或部分工序，需编制单独的质量计划，或者可在原质量计划分包 工序所在的备注栏中文字说明分包情况（手写备注时应签署姓名及日期）。

➢ 针对购买方采购的成品标准件，供应方的制造活动可以不编制质量计划，但有特殊要 求的入厂复验或第三方检验等活动，需编制质量计划。

# 12.2 质量计划的内容

为证明核安全设备制造中所要达到的质量要求、所需进行的制造、检验及试验等活动 得到定义并执行，而制定的对制造中拟执行的制造、检验及试验等质量相关活动的列表， 即质量计划。

质量计划的内容应包括：

a) 封面 ( 包括项目名称 ( 包含机组号、设备名称 ) 、制造单位名称、质量计划名称及内外 部编号、文件编制、审核、批准、状态、版本、日期等 )

b) 引用合同 / 订单和设备技术规格书及版本号

c) 设备名称和编号、零部件名称和图号

d) 炉 / 批号、材质、规格、数量

e ）章节名称、章节号及版本

f ）安全等级、质保等级、抗震类别

g ）按操作流程逐一列出所有的工序

a) 工序序号

# 13 见证管理

检查点：指所制造物项相关方（供应方质量控制部门、购买方、采购方、业主等）及 国家核安全局在制造过程中设置的希望被通知并进行见证和检查的活动，检查点分为：停 工待检点（ H 点）、现场见证点（ W 点）及记录审查点（ R 点）。

# 13.1 停工待检点（ H 点）

H 点是制造过程中的一项关键工序，供应方应以书面形式提前 32 天 ( 国外 90 天 ) 发出 H 点检查见证通知单，并提前 8 天 ( 国外 14 天 ) 确认。

H 点见证为强制执行，没有采购方或购买方见证人员的出席或以书面通知放弃该 H 点 的监督，供应方不得进行该点及后续操作。在计划的时间见证人员未到达见证现场，供应 方再次发出通知，并把该点的操作往后推。 H 点放弃通知须纳入完工文件。

# 13.2 现场见证点（ W 点）

W 点是制造过程中的一项关键工序，供应方应以书面形式提前 32 天 ( 国外 90 天 ) 发出 W 点检查见证通知单，并提前 8 天 ( 国外 30 天 ) 确认。

在购买方未明确表示不出席 W 见证点的情况下，不得执行该工序及后续工序。在已经 发出正确的 W 点通知情况下，而采购方不能在指定的时间出席，工作可以在采购方缺席的 情况下继续进行而不用书面的放弃通知。采购方可以以口头、邮件或书面等形式放弃 W 点。

# 13.3 记录审查点（ R 点）

供应方在工序完成后及时将相关记录和资料 ( 包括制造技术文件、合格证明文件、检查 和试验结果记录等 ) 提交购买方。

购买方在确认质量记录达到规定要求后，在相应的质量计划签字，或以函件的形式予 以认可；如果认为设备制造文件或见证记录的内容不符合规定的要求，供应方对相应的文 件进行补充完善。

# 13.4 见证通知单

W 点、 H 点见证通知单内容至少应包括：

➢ 项目名称、机组号；

➢ 采购合同 / 订单号；

➢ 设备、零 / 部件名称或代码；

➢ 质量计划编号、版本及通知单；

➢ 操作类型（包括在质量计划中的顺序编号）；

➢ 执行地点；

➢ 操作日期和时间；

➢ 联系人及联系方式。

# 13.5 W 点和 H 点的放弃

a) 对于 H/W 点，如要放弃见证，购买方需编制书面放弃函，见证点放弃单格式见附 录。

b) 放弃的 W 点或 H 点，如有相应报告产生，可以转为 R 点进行控制，先决条件检 查、取样等无报告产生的工序除外。

c) 购买方明确 W 点和 H 点的放弃后，供应方可以独立执行，但供应方应在该 H 、 W 点工序完成后作为 R 点提供相关记录和资料 ( 包括制造技术文件、合格证明文件、 检查和试验结果记录等 ) 供购买方审查确认，先决条件检查、取样等无报告和记录 产生的工序除外。

d) 购买方决定放弃的 H 点见证，需以书面形式通知采购方。购买方明确 W 点和 H 点的放弃后，应通知供应方人员在质量计划中备注“ XX 单位放弃见证”字样和“书 面通知的函号或放弃审批单编号”。

b) 如因见证时间冲突，且难以重新安排见证，对于多次重复工作完成单一工序的见 证，可以采取抽查方式完成见证和控制点签字，此时应在见证记录及质量计划上

# 13.7 多次重复的相同工序见证

a) 数量较多的原材料、零件（如板材、管材、小锻件、管配件等），当使用同一质量 计划，质量计划复印多次，分批次进行重复工序时，每批次均应发生见证通知。每 批次见证点见证，均应满足程序要求并进行控制点签字。

b) 如因见证时间冲突，且难以重新安排见证，可以按批次数量抽查见证 W 点和 H 点。

c) 未抽查见证的质量计划相应工序，如有相应报告产生，可以转为 R 点进行控制， 先决条件检查、取样等无报告产生的工序除外，但不需要执行放弃审批。

d) 数量大、批次多、可通用互换的材料、零部件、组件、设备等进行连续性生产作业 时，可仅对首批次材料、零部件、组件、设备的开工检查、检测检验、功能试验、 出厂试验等工序选点见证，其他批次可选为 R 点或不选点。但应对制造过程进行 巡检，并按巡检内容填写质量监督记录（记录巡检数量、批次）。

# 13.8 持续时间很长工序的见证

持续时间很长的焊接、热处理、 PT 、 UT 、试验等工序，当选为 W 点时，可以不进行 整个操作过程旁站见证。但必须检查工序开始实施条件是否符合要求、监督重要操作参 数和步骤是否符合要求；当选为 H 点时，原则上应全过程见证。

# 13.9 签点日期

a) H 、 W 点见证时，各见证方应先完成质量计划前面 R 点的审查签点，有逻辑关系 的前序 R 点未签，不能执行后续 H 、 W 点工序及见证；无逻辑关系的前序 R 点， 如因报告未出或其它特殊情况，前序 R 点未签可以进行后续 H 、 W 点工序操作和 见证签点，签点时应在 H 、 W 点工序“备注栏”备注“ XX 序 R 点报告未提交审 查”，同时签名及备注日期，日期应为 H 、 W 点见证日期；在后续完成报告审查后， 见证人员应在质量计划对应 R 点栏及时完成签署姓名和日期，日期应为报告审查 完成日期； R 点签署日期不得早于厂家报告审批日期。

# 十大质量红线

# 一、严禁违反/无依据文件作业

释义：本条特指在作业过程中，违反经批准的施工方案/制造大纲、特殊措施和工作程序，或者无依据文件作业，如未按照程序和规程进行检验试验，补焊过程无依据文件。

# 二、严禁违反流程擅自处理质量缺陷

释义：本条特指在作业过程中产生质量缺陷后，有关人员未按规定的流程或未按批准的措施，擅自处理质量缺陷，如违规补焊，且补焊过程没有补焊工艺评定、补焊工艺规程等指导文件。

# 三、严禁质量文件造假

释义：本条特指编造、捏造设计、制造、建造、调试过程中产生的质量文件，或者在质量文件上伪造人员签名、日期，如试验数据造假、篡改原材料质量证明书、出具虚假的无损检验报告、伪造无损检验人员签名、伪造理化检验人员签名。

# 四、严禁人员无证上岗

释义：本条特指需要持证上岗的焊工、焊接操作工以及检查和试验人员，没有取得有效的证书或证书范围不覆盖，如焊工无证上岗、焊工项目资质不覆盖实际焊接活动、无证人员参与PT检验。

释义：本条特指在设计、制造、建造、调试过程中，将某一项活动/工序，违规分包给其他单位，如违规分包无损检验活动、违规分包关键工艺、违规分包设计和制造活动、违规分包冲击试验。

# 五、严禁违规分包

# 六、严禁使用不合格的材料、检查与试验设备

释义：本条特指材料未经验收或验收不合格；检查与试验设备未经标定或标定已过期，标定不符合要求；如使用复验不合格的材料、使用未经标定的检查与试验设备。

# 七、严禁越点作业

释义：本条特指未经验收、验收不合格、见证点（W点）未签字放行即进行下一道工序、停工待检点（H点）未签字放行即进行后续工作。

# 八、严禁未按规定进行技术交底

释义：本条特指在作业活动开始前或过程中，未按规定进行技术交底，如未按规定的时间进行技术交底、参加技术交底的人员不符合规定要求。

# 九、严禁漏报、谎报、瞒报质量事件

释义：本条特指在作业过程中，漏报、谎报和瞒报质量事件，如故意隐瞒质量事件不上报。

# 十、严禁先决条件未放行即开始作业

释义：本条特指某项作业活动开始前，未经先决条件检查放行即开始作业。
