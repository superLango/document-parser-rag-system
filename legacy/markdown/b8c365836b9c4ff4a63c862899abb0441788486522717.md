# 4.3 交付状态

# 4.3.1 热处理状态

锻件经以下状态之一供应，锻件的供应状态应在订购文件和质量证明书中注明：

a）A状态：锻态；

b）B状态：固溶态；

c）C状态：固溶+时效状态。

# 4.4 热处理制度

热处理制度应符合下列要求，其中加热温度为金属实际达到的温度，保温时间为锻件最大截面热透后开始计算的时间，实际固溶处理加热温度和冷却方式应在质量证明书中注明：

a）固溶：1140℃±10℃，保温1h，空冷；

b）时效：900℃±20℃，保温16h，空冷。

# 4.6 低倍组织

4. 6.1 从C状态的锻件或试验料上切取横向试样进行低倍组织检查。

4.6.2 锻件金属流线的方向应沿锻件受检截面的外形分布，模锻件的金属流线应基本符合锻件的结构外形，且不应有穿流和严重的涡流；自由锻件的金属流线不应有明显的切断。

4.6.3 低倍试片上不准许有肉眼可见的缩孔、孔洞、翻皮、裂纹、分层、夹渣、夹杂物和偏析等冶金缺陷。

# 4.7 高倍组织

4.7.1 从C状态的锻件或试验料上切取试样，按需检查合金的晶粒度及纯洁度，累积数据。

4.7.2 锻件不准许有过烧组织。

# 4.8 超声波探伤

除非设计有特殊要求，探伤按 HB 20159 A 级验收。

# 4.9 形状、尺寸

锻件的形状、尺寸及公差应符合设计图纸的要求。

# 4.10 外观质量

锻件表面不准许有裂纹、结疤、折叠。局部出现这些缺陷允许以倾斜打磨清除。打磨处应圆滑过渡，并保证锻件在该处留有不少于三分之一的名义加工余量，非加工表面上的缺陷清除宽度不小于深度的6倍。

# 4.11 产品标识

4. 11. 1 锻件应按锻件图纸标明的位置逐件打上如下标记：

a) 检验印记；

b) 材料牌号或代号；

c) 锻件件号或代号；

d) 熔炼炉号；

e) 锻件锭节号及头部件（按实际情况）。

4.11.2 大锻件应实行锭节号管理，小锻件应实行头部件管理，理化试样应在相当于钢锭头部的锻件上取样。

# 5.2.3 判定与复验规则

本文件判定原则是基于检测结果有效的前提下进行规定，如确定检测结果是由于试样尺寸、设备故障或试验程序有误等非材质原因导致，则检验结果应当判定为无效并更换试样，当次检验不计为重复试验。具体项目判定和复验规则如下：

a）化学成分分析不合格时，该批锻件判为不合格；

b）力学性能检验不合格时，允许在原受检的锻件或试验件上对不合格项目取双倍数量的试样进行重复试验，重复试验仍不合格时，该批锻件判为不合格。若能够确认力学性能不合格是由于热处理的原因，允许供方按本文件规定的热处理制度重复热处理后重新提交验收，重复热处理只允许进行1次；

c）低倍组织检验不合格时，该批锻件判为不合格；

d）高倍组织检验不合格时，该批锻件判为不合格；

e）超声波探伤不合格时，该件锻件判为不合格；

f）尺寸、外形或外观质量检验不合格时，该件锻件判为不合格；

g）产品标识不合格时，需要重新进行标识。

# 6 交货准备

# 6.1 包装

锻件包装方式由供需双方协商确定。

# 6.2 标志

每批锻件的包装均应带有标牌，其上注明：合金牌号、熔炼炉号、重量和数量等。

# 6.3 运输

锻件应在在防雨、防潮、防雪等条件下进行运输，并平稳装卸，防止磕碰、损伤等。

# 6.4 贮存

锻件应在清洁、干燥等环境下储存，按炉批整齐堆放，避免混批，并防止损伤和污染。

# 6.5 质量证明书

每验收批锻件均应附有质量检验部门签发的质量证明书，其上应注明：

a）供方名称；

b）需方名称；

c）合同号、本文件标准号；

d）锻件图号、名称、合金牌号、锻件类别、交货状态、交付日期；

e）熔炼炉号、锭节号、数量、锻造批号、热处理炉批号；

f）冶炼方法、原材料产地、相转变温度；

g）热处理制度及按本文件和协议、合同规定的各项检验结果（如复验，应包括两次检验结果）；

h）锻件高低倍组织图片；

# 7 说明事项

# 7.1 预定用途

本文件规定的GH4648合金锻件为镍基变形高温合金，预定用于航空发动机封严壳体、蜂窝座、篦齿封严环、安装边等零件。

# 7.2 分类

本文件规定的锻件按专用技术文件划分为Ⅱ、Ⅲ类锻件，锻件类别在锻件图样或其他文件中标注。

# 7.3 订货文件内容

合同或订单中应注明下列内容：

a） 本文件编号；

b）合金牌号；

c）锻件图号或代号、锻件名称、类别、数量、交货状态；

d）供需双方协商确定的其他要求。
