# 三、生产设备、工装及检测设备的控制

生产设备应建账管理，并进行维护、保养，检测计量设备应建立台账，并按期进行校准和检定。

# 四、技术要求及技术文件的控制

1、甲方向乙方提供有关的图纸/数模、设计更改单等技术资料，并对其有效性和准确性负责。

2、锻件加工所需要的材料由乙方购买，化学成分允许偏差应符合 GB/T222的规定，原材料入厂应逐件 100%进行超声波检查，按 A 级验收，乙方应妥善保存探伤原始记录。

3、原材料及锻件技术条件的要求见表2，外形尺寸公差按图纸要求控制。

# 五、制造过程控制

1、原材料冶炼工艺：按原材料技术条件。

2、锻件生产：按甲方提供的锻件图纸生产锻件及试件。

3、超声波检查：乙方锻件出厂时超声波检查面见光，按锻件图样要求逐件进行超声波检查。

4、理化试验：所有锻件出厂前，乙方需进行理化测试，向甲方提供2套理化照片和理化测试结论，并随合格证一起发出。

# 六、入厂检验、不合格品控制

1、若发现锻件有质量问题，由双方协商进行重复试验，重复试验可委托第三方进行。

2、锻件在机加过程中，若发现冶金质量问题而造成毛坯报废时，由乙方承担毛坯损失，其他事项由双方协商解决。

# 七、产品交付

1、锻件按锻件图样规定的内容进行标刻印记。

2、所有试料上均应标刻熔炼炉号、锻件图号和批次号，所有试料熔炼炉号、热处理状态应与相应锻件相同。

3、锻件交付时，乙方须提供超声波检查报告、理化照片和理化测试结论、合格证。

4、交付状态：超声波检查面见光。

5、锻件运输由乙方负责运输至甲方指定现场。

# 八、其它

1、图纸及文件资料的传递由双方资料管理部门进行。

2、乙方不得向任何第三方扩散甲方提供的产品图纸、技术文件、工艺文件等资料，不得向任何第三方扩散产品，未经甲方同意不得复制任何技术资料，由此造成的后果由乙方承担。合同执行完后，所有技术资料应如数交还甲方。
