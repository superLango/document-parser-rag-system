# 4.2 锻造

合金锭应经高温扩散退火处理并采用锻造开坯。为清除缩孔和过分的偏析， 合金锭的头尾应有充分的切除量 , 锻造时应留有足够的变形量，变形要均匀，以达 到均匀细化晶粒的目的，使其具有良好的超声波穿透性。应保证始锻温度≥ 1000 ℃，终锻温度≥ 800 ℃，锻件的总锻比应≥ 4 。

锻造过程参数如下：

a ）原材料头部切除率≥ 3% ，尾部切除率≥ 5%;

b ）锻造设备： 1250T/2000T/3600T/3150T 快锻机；

性能热处理为固溶热处理。

固溶热处理加热温度 1150-1200 ℃（实际温度按工艺规程），保温后采用水 冷或者其他快速冷却的方式。保温期间，每个锻件偏离热处理规定温度的最大允 许偏差为± 10 ℃。

# 5.2.3 金相检查

# 5.2.3.1 非金属夹杂物

每批次成品锻件应分别按照 ASTM E45 中的 A 法和 ASTM E112 进行非金属 夹杂物和晶粒度检验，并在质量证明文件中提供晶粒度和非金属夹杂物评级金相

照片。金相试验试样取样位置同拉伸试样，并满足以下要求 :

（ 1 ）粗系和细系 A 、 B 、 C 和 D 类非金属夹杂物均应小于等于 1.5 级；

# 5.2.3.2 晶粒度

锻件应按照 ASTM E112 进行晶粒度检验，晶粒度级别控制在 2~6 级，级差 小于 2.5 级。

# 5.2.4 复试与重新热处理

拉伸试验不合格时，可从被检锻件原取样部位附近再取 2 个试样进行复试， 当复试结果都合格时，则该批产品的相应检验项目为合格。

化学成分不合格时，允许采用化学分析方法对不合格元素进行一次复试。

非金属夹杂物和晶粒度不合格时，不允许进行复试。

当拉伸试验不合格时 , 允许对该批锻件重新热处理 , 但重新热处理次数不应超 过一次。

重新热处理后应按本文件的规定重新进行除化学成分和非金属夹杂物检验 外的所有检验和试验。

# 7 无损检测

# 7.1 表面检测——表面缺陷

最终交货的锻件表面应光洁，不允许有裂纹、发纹、折叠、夹渣及其它对使 用有害缺陷。

# 7.2 内部检测——超声检验

锻件应按 ASME NB-2542 的规定进行 100% 超声检测，验收标准满足 ASME NB-2540 的规定。

# 7.3 表面检测——液体渗透检验

最终成品尺寸的锻件表面应进行 100% 渗透检测，渗透检测和验收应按 ASME NB-2546 的规定执行。

# 7.4 尺寸和外形检查

锻件加工至规定尺寸后，应进行尺寸和外形检查，尺寸和外形检测结果应符 合规定，并形成记录和报告。

# 8 缺陷的清除与修整

如果锻件表面发现不可验收的缺陷 , 可以采用打磨的方法清除。磨具应为仅含 碳化硅、氧化铝或金刚石磨料的磨具，该磨具应是未使用过的或此前仅在镍基合 金上使用过。打磨过程应避免局部过热，打磨区应与邻近表面平滑过渡。缺陷清 除后的尺寸应符合交货尺寸的规定。打磨区域还应按 ASME NB-2546 进行渗透检 测。

不允许对锻件进行任何焊补。

# 9 标记、清洁、包装和运输

锻件的标志、清洁、包装和运输应符合订货合同的相关规定。

锻件的验收应按本文件的规定执行。锻件应进行标识，应至少包括以下内容 :

●制造单位名称 ;

●合金牌号、炉号 ( 真空自耗重熔锭 ) 或批号；

●文件编号；

●规格和出厂日期。

在锻件的制造、加工和运输过程中，应避免接触到可能对材料性能和完整性 产生不利影响的物质，如硫、铅、锌、铜、铝、镉、锡、砷、汞、锑、铋、卤素 及其它低熔点金属和它们的合金及化合物。此外，由于含氯材料老化产生的酸性 氯化物是潜在的危险，因此需合理选用胶带、磁性墨水、标记物、耦合剂、渗透

剂及涂料等来予以避免。

锻件表面应无锈斑、油污及其它污染物。

# 10 质量证明文件

锻件交货时，锻件制造厂应提交质量证明文件，其内容至少应包括：

- 化学成分（熔炼分析和成品分析）分析报告；

- 热处理报告（包括重新热处理，若有）；

- 力学性能试验报告（包括复试，若有）；

- 金相检验报告；

- 表面质量检查报告；

- 无损检测报告；

- 尺寸和外形检查报告。

以上报告应至少包括：

- 制造厂名称或代号；

- 订货合同号；

- 本文件号和材料牌号；

- 熔炼炉号、批号、尺寸和产品编号；

- 材料识别标记（若有）；

- 检验机构名称（如适用）；

- 各种试验和复试结果（若有），以及相应的规定值。
