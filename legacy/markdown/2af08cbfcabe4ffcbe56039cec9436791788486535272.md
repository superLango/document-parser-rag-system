# 0Cr15Ni5Cu2Ti钢锻件

# 1 范围

本文件规定了0Cr15Ni5Cu2Ti钢锻件的技术要求、锻件控制要求、交付要求等。

本文适用于航空发动机和燃气轮机用 0Cr15Ni5Cu2Ti 钢喷嘴壳体等锻件。

# 2 规范性引用文件

# 3 术语和定义

本文件没有需要界定的术语和定义。

# 4 要求

# 4.1 原材料

# 4.1.1 冶炼方法

合金采用真空感应熔炼+真空电弧重熔工艺生产，所采用的冶炼方法应在质量证明书中注明。

# 4.1.2 复验

锻件用 0Cr15Ni5Cu2Ti 合金棒材应符合 AETM309 要求，经复验合格后方可投产。

# 4.3 制造方法

锻件采用轧制、模锻或自由锻成形，对于尺寸或内径较小的环形锻件也可采用直接冲孔或马架扩孔方法成形。

# 4.4 交付状态

# 4.4.1 热处理状态

锻件经退火热处理状态供应，锻件的供应状态应在订购文件和质量证明书中注明。

# 4.4.2 表面状态

锻件经吹砂并酸洗后交货。

# 4.5 热处理制度

热处理制度应符合下列要求，其中加热温度为金属实际达到的温度，保温时间为锻件最大截面热透后开始计算的时间，实际固溶处理加热温度、冷却方式和保温时间应在质量证明书中注明：

a）退火处理：660℃±10℃，保温6h，空冷；

b）固溶处理：950℃±10℃，空冷。

# 4.6 力学性能

从已交货锻件上取样，试样选用固溶热处理。力学性能应满足表2。

# 4.7 低倍组织

锻件的断口和酸浸试片上呈现的低倍组织，不应有白斑、白点、缩孔、气泡、空洞、翻皮、分层、裂纹及肉眼可见的夹杂、点状偏析、银亮斑点、针孔、层状和石状断口。

# 4.8 断口

锻件的断口上，不应有过热缺陷。断口级别按 GJB 5040规定评定。

# 4.9 形状、尺寸

4.9.1 锻件的形状、尺寸及公差应符合锻件图样的规定。

4.9.2 锻件的机加余量、形状位置公差和尺寸公差应符合锻件图规定。

# 4.10 外观质量

4.10.1 锻件表面不应有过烧裂纹和影响材质的其它缺陷存在，发现后锻件应予以报废处理。

4.10.2 锻件加工表面上的裂纹、折叠、嵌入和成片的氧化皮应全部清除，其它缺陷可不清除，但均应保证锻件留有不少于三分之一的公称加工余量或机械加工工艺要求的附加加工余量。

4.10.3 锻件的非加工表面上可存在轻微的凹坑、缺肉、压伤和深度不超过单面负偏差值的划痕、折皱等分散缺陷；裂纹、异类夹杂物、折叠、氧化皮等缺陷应全部清除，且均应保证锻件的单面极限尺寸（孔、槽处则为单面最大极限尺寸）。

4.10.4 可用打磨的方法清除锻件表面上的缺陷，但打磨时缺陷清除处应圆滑转接，对非加工表面打磨时，其打磨宽度不应小于深度的6倍。

# 5 质量保证规定

# 5.1 质量控制

5.1.1 锻件在试制、转厂或改变主导工艺时应按AETF332的规定进行鉴定、定型，然后方可投入批生产。

5.1.2 锻件主导工艺过程的生产条件应按AETF517进行准备和控制。

# 5.2.3 判定与复验规则

本文件判定原则是基于检测结果有效的前提下进行规定，如确定检测结果是由于试样尺寸、设备故障或试验程序有误等非材质原因导致，则检验结果应当判定为无效并更换试样，当次检验不计为重复试验。具体项目判定和复验规则如下：

a）化学成分分析不合格时，该批锻件判为不合格；

b）力学性能检验不合格时，可在原受检的锻件或试验件上对不合格项目取双倍数量的试样进行重复试验，重复试验仍不合格时，该批锻件判为不合格。若能够确认力学性能不合格是由于热处理的原因，供方可按本文件规定的热处理制度重复热处理后重新提交验收，重复热处理只允许进行1次；

c）低倍组织检验不合格时，该批锻件判为不合格；

d）断口检验不合格时，该批锻件判为不合格；

e）形状、尺寸或外观质量检验不合格时，该件锻件判为不合格。

# 5.3 检验方法

# 5.3.1 化学成分分析

化学成分分析按GB/T 223（所有部分）进行，仲裁按GB/T 223（所有部分）进行。

# 5.3.2 室温拉伸试验

室温拉伸试验按GB/T 228.1进行。

# 5.3.3 室温冲击试验

室温冲击试验按GB/T 229进行。

# 5.3.4 低倍组织检验

低倍组织检验按GB/T 226进行。

# 5.3.5 断口检查

断口检验按GB 1814进行。

# 6 交货准备

# 6.1 标记

锻件应按图样标明的位置（或挂标签等）打上如下标记：

a）合金牌号（或代号）；

b）锻件图号（或代号）；

c）投产批号；

d）熔炼炉号（或代号）；

e）锭节号（按需）；

f） 其他标记。

# 6.2 包装、运输和贮存

6.2.1 锻件应装箱交货。

6.2.2 锻件的包装、运输和贮存方法应在合同中注明。

# 6.3 质量证明书

每批锻件应附有质量检验部门签发的质量证明书，其上注明：

a）供方名称；

b）需方名称；

c）合同号、本文件标准号；

d）锻件图号、名称、合金牌号、锻件类别、交货状态、交付日期；

e）熔炼炉号、锭节号、数量、锻造批号、热处理炉批号；

f）冶炼方法、原材料产地；

g）热处理制度及按本文件和协议、合同规定的各项检验结果（如复验，应包括两次检验结果）；

h）质量监督部门印记；

i）需方的其他要求。

# 7 说明事项

# 7.1 预定用途

本文件规定的锻件预定用于制造航空发动机及燃气轮机0Cr15Ni5Cu2Ti合金钢制喷嘴壳体锻件。

# 7.2 分类

本文件规定的锻件按AETF28划分为Ⅲ、Ⅳ类锻件，锻件类别在锻件图样或其他文件中标注。
