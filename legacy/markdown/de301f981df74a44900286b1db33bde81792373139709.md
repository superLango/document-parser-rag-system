# 核电汽轮机静叶用12Cr12Mo不锈钢棒及锻件采购规范1范围

# 1 范围

本标准规定了核电汽轮机叶片用钢棒和锻造毛坯的制造、检查和验收的要求。

本标准适用于采用电渣重熔进行冶炼，毛坯形式为热轧或锻造钢棒、圆钢、方钢或扁钢。横截面尺寸最大为250mm。

# A.1 技术要求

# A.1.1 制造方法

# A.1.1.1 冶炼工艺

钢锭应由电炉冶炼加电渣重熔或其他由购方认可的熔炼方法制造。A.1.1.2 切头

棒材需热轧或锻造制成，轧制比或锻造比不得小于 5:1。

严重视场的δ-Fe应不超过 5%，平均视场的δ-Fe应不超过 3%。

# A.1.5 宏观组织

钢棒横截面酸浸试片上不允许存在肉眼可见的缩孔、气泡、折叠、裂纹、裂缝、氧化皮、轧疤、疏松、硬点、脱碳、过度的非金属夹杂、偏析、白点和其他所有对材料使用有害的缺陷。表A.4注明了允许的宏观组织级别。

# A.2 表面质量

棒材表面不得有氧化皮、折叠、裂缝、裂纹、过多的非金属夹杂物和所有其它可能损害材料使用的缺陷。如果必要，对于轻微的表面裂缝允许在最终检查前进行局部打磨处理。这些打磨的深度不能超过棒材尺寸允许公差范围，宽度不能超过圆周的1/4。打磨后应进行磁粉探伤检查以确认无残留缺陷存在。不允许补焊消缺。

# 普通商密 不得复制

# A.7 质量异议

交货后出现明确是制造方责任的质量问题，制造方应对该质量问题进行处理，并且在两周内提出出现问题的原因和处理措施。

# A.8 包装、标识

钢棒应按订单号、尺寸规格和熔炼炉号隔离装运。每根钢棒的两端均应采用牢固的标识方法标识上熔炼炉号和材料牌号。应采取必要的措施，以避免在运输和装卸过程中遗失或损坏。每批应在外包装上采用永久性标识，注明订单号、数量、尺寸、熔炼炉号、重量、材料牌号和制造方名称或商标。棒料本体和质证书均应以7位编码作为材料牌号。

# A.9 文件

除非订单上另有说明，制造商在交付时，应提供一式三份检验证书。该证书需包含以下详细内容。

1) 订货方名称；

2) 供货方名称；

3) 合同号；

4) 熔炼炉号；

5) 零件名称、材料牌号及本规范编号；

6) 热处理记录；（温度、时间、冷却条件和去应力退火条件）

7) 数量及重量；

8) 交货状态和本体硬度试验结果（应提供所有单个数值）；

9) 材料技术规范要求其他所有试验报告项目；

10) 外观和尺寸检查报告。

# 第Ⅱ部分 毛坯技术要求

本规范第Ⅱ部分规定了由东方汽轮机有限公司或东方汽轮机有限公司批准的合格供方进行的叶片毛坯的性能热处理、试验和验收要求。

# B.1 性能热处理

为了达到规定的性能要求，叶片毛坯必须进行系列热处理工序。表B.1中所示为推荐热处理工艺。

*表 B.1 热处理工艺*

<table border="1"><tr><td colspan="3">热处理条件</td></tr><tr><td>淬火温度</td><td>990~1010℃</td><td>油冷</td></tr><tr><td>回火温度</td><td>≥700℃</td><td>空冷</td></tr></table>

# B.2 组批原则

一“批”的定义是由同一尺寸规格、同一熔炼炉号和同一热处理炉次（同一热处理炉次是指同一回火炉次）的叶片毛坯组成。每批叶片毛坯的最大数量是400片。

# B.3 化学成分检查

每批抽取1件毛坯取样，按照GB/T 223或其他适用的国家/国际标准要求进行化学成分分析，成品分析允许偏差应符合GB/T 222的规定，结果应符合表A.1规定。

# B.4 力学性能试验

力学性能试验应在所有热处理工序完成后进行，包括所有去应力处理。试料不得进行额外的热处理或压力加工。

# B.4.1 硬度试验

每批叶片均应 100%进行本体硬度试验，本体硬度试验结果应记录。试验方法应符合 GB/T231.1 或供方等效的国际标准，F/D2系数为 30（F单位为 kg）。

模锻叶片毛坯的布氏硬度试样应在叶根和叶顶进行。方钢叶片的硬度测试位置应在毛坯的适当位置进行。

# B.4.2 力学性能试样

力学性能试样取样比例为每批 2%件数，从最高和最低硬度值的叶片毛坯中各选取一半，但最少必须≥2件。

对于叶片毛坯，取样位置按照 DW804A2135执行。

# B.5 重新试验

# B.5.1 总则

如果因不当的试验程序或设备问题而导致试样未能符合表 B.2要求的，该试验结果应予以作废，应按 B4规定另外取样进行试验。

# B.5.2 拉伸试验

重新试验的试样应取双倍，其中一个应从取下原始试样的毛坯上取样。重新试验的力学性能试样应符合标准要求。如果重新试验失败的话，就说明该材料不满足规范的要求。

# B.5.3 V型缺口冲击试验

如果三个冲击值的平均数低于规范要求的规定值，或是有一个值低于规定值的 70%，就应另外进行2套（包括6个试样）V型缺口冲击试验。试验获得的单个数值必须满足表B.2所列出的规定值。

对经双倍取样进行性能试验的叶片毛坯，若试验结果仍不合格，则允许对其重新进行性能热处理。重新性能热处理的次数不应超过3次。

# B.10 包装，标识和证书

叶片毛坯（或锻造方钢）应采取必要的措施，以避免在运输和装卸过程中遗失或损坏。对于每一叶片毛坯均应以采用永久性辨识号进行标识（如钢印）。每批应在外包装上采用永久性标识，注明订单号、数量、尺寸、熔炼炉号、重量、材料牌号和制造方名称或商标。

除非订单上另有说明，应提供一式三份检验证书。该证书需包含以下详细内容。

a) 材料牌号

b) 合同号

c) 本规范编号

d) 熔炼炉号；

e）化学成分分析结果；

e) 热处理记录（温度、保温时间、冷却介质）

f) 硬度试验结果（应提供所有单个数值）

g）力学性能试验结果；

h）金相检验结果（含晶粒度、δ铁素体含量、夹杂物含量报告）；

i）无损检验结果

j) 尺寸及外观检查结果
