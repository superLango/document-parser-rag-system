# 2. 技术要求

# 2.1资料提供

2.1.1 甲方向乙方提供零件图纸或毛坯图纸，供乙方设计锻件图。并将生产期间技术状态变更的更改依据及时传递给乙方，如由于零件数模或零件图纸更改未及时通知乙方更改相应数模和图纸造成锻件、模具报废由甲方承担。

2.1.2 甲方应对乙方设计的锻件图进行会签，作为乙方锻件生产和验收的依据。锻件图纸经会签后生效，乙方向甲方提供会签后的锻件图一式四份。

第1页共5页

<!-- page: 4 -->

# 2.2原材料要求

# 2.2.1 原材料技术要求：

30CrMnSiNi2A锻件用原材料应符合标准GJB1951-1994要求；

TC18锻件用原材料应符合标准GJB2218A-2018要求；

A100锻件用原材料应符合标准ZZQB903-006要求。

2.2.2原材料按相应技术条件进行入厂复检，合格后方可投产。

# 2.3锻件技术要求

2.3.1 30CrMnSiNi2A锻件技术条件应符合GJB5040中I类锻件相关要求；

TC18锻件技术条件应符合YMS1508中Ⅰ类锻件相关要求；

A100锻件技术条件应符合ZZQB903-009中I类锻件相关要求。

2.3.2 锻件尺寸公差、加工余量等应符合供需双方会签的锻件图要求。

# 2.4 锻件的验收

2.4.1 锻件理化检测项目、取样位置及数量按双方会签的锻件图或取样图执行。

2.4.2 标识、尺寸：100%检查材料牌号、表面质量、尺寸、标识；

2.4.3 低倍：按理化取样图要求位置处切取低倍试样，检查低倍组织；

2.4.4 显微组织：按理化取样图要求位置处切取试样，检查显微组织；

2.4.5 力学性能：按理化取样图要求位置切取试样，检测力学性能；

2.4.6 超声波探伤：

30CrMnSiNi2A锻件无需粗加工及探伤。

TC18锻件除理化件外，锻件由乙方粗加工后，100%按GJB1580进行

超声波探伤，并按 YMS 1508 中 A 级进行验收；

A100锻件超声波探伤由乙方按双方会签的锻件图执行，甲方认可乙方的探伤结果。

2.4.7 化学成分：允许转抄原材料入厂复验报告（H含量除外）。

# 3. 锻件交付

3.1 乙方应对锻造及热处理工艺按 GJB 1269A-2008 进行工艺评审，需邀请甲方人员参加，工艺评审报告交于甲方。

3.2 乙方应对特殊过程（锻造）进行确认，要按 Q/AVIC GM 1434-2022《锻造特殊过程确认准则》进行特殊过程管理和确认，当人、机、料、法、环、测六要素发生变化时应及时进行再确认。乙方将确认报告发给甲方。

3.3 乙方交付的锻件，甲方在加工过程中发现确因锻件质量问题造成的报废，经乙方确认后，由乙方负责报废、更换。甲方保留向乙方索赔的权利。

3.4 若锻件外形尺寸出现偏差，乙方应及时书面通知甲方，在甲方确认能够满足零件加工要求书面反馈后，锻件方可交付，同时在合格证上注明偏差情况。

3.5 每验收批应由同一图号、同一熔炼炉号、同一投产批号、同一热处理炉批的锻件组成。

3.6 乙方提供锻件的同时应有质量保证证明书（合格证），合格证应至少包含以下内容：

（a）锻件图号、名称、本技术协议编号、合同号、材料规范；

（b）材料牌号、熔炼炉号、投产（生产）批号、热处理炉批号；

（c）锻件数量、供应（交付）状态；

（d）锻件热处理制度；

（e）各项分析检验结果；

（f）棒材超声波探伤结论、锻件超声波探伤结论；

(g) 甲方和乙方名称、生产日期。

# 4. 其它

4.1 甲乙双方互相提供的数模、图纸等技术资料双方需保密，未经对方许可，双方不得擅自扩散、转移和更改。

4.2 本协议一式四份，双方各两份，双方签字盖章后生效。

4.3 未尽事宜双方协商解决。

> 技术要求：
1. 尺寸按交点注，坡边倒角允许至C2；
2. 锻件类别：I类，铁MAS 1508生产和验收；
3. 100%在专用试样上取样检测，每般验收解制1件，在解剖件上进行理化（供需及方各单件）；
4. 理化检测项目及联样数量需理化联样图；
5. 供应状态：双缝火，组加工交件；室温力学标称km=1080-1280MPa；
6. （J）为标识位置，标刻内容：锻件图号，材料牌号，熔炼炉号，锭节号（头部部件标识“T”）；
7. 为热处理炉号，流线方向及印制；
8. 超声波探伤仪VAS 1508，A级验收沿厚度方向进行；
9. 超声波探伤，化学成分，硬度检测仅供方进行，需方认可供方结果；
10. 每验收批田一圆一号，固一熔炼炉号，固一生产周期制逾的、同一热处理炉批组成。
