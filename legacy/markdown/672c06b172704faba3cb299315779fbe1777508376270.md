# 4.2 锻造

锻件采用自由锻的方法进行制造。锻造时应留有足够的变形量，以达 到均匀细化晶粒的目的，使其具有良好的超声波穿透性。

锻造过程如下：

a ）原材料头部（冒口）切除率≥ 12% ，尾部（水口）切除率≥ 3% ；

b ）始锻温度≤ 1250 ℃；

c ）自由锻成型。保证足够锻比，要求总锻比 >5 ；

d ）终锻温度≥ 850 ℃；

e ）产品在钢锭中的大致位置见图 4-1 ，锻件变形过程见图 4-2 ；

f ）锻后空冷。

# 4.5.2 性能热处理

性能热处理应在预备热处理和粗加工后，及截取试料前进行

性能热处理工艺为淬火 + 回火热处理。

淬火：加热温度 850-925 ℃（实际温度按工艺规程）。淬火保温时间 每 2mm 厚度（直径）至少 1min ，浸水冷却；

回火：回火温度 635-665 ℃（实际温度按工艺规程）。回火保温时间 每 2mm 厚度（直径）至少 1min ，空气冷却。

根据实际情况增加加热保温台阶。 850-925 ℃与 635-665 ℃为实际热 处理温度范围，包括控温范围± 10 ℃的偏差。

根据锻件采购规范，当每炉产品为多件时，需按对应工艺进行热处理 （同炉产品按相同热处理工艺，同时出炉）。

# 7 成品加工

锻件应进行机加工，锻件的尺寸和表面粗糙度应符合订货合同的要求。

锻件交货前应按照订货图纸和合同的规定，对锻件的尺寸和外形进行 检查。

# 8 无损检测

# 8.1 表面缺陷检验

# （ 1 ）目视检查

按照 RCC-M MC 7100 规定执行，锻件必须完好无损，不得有发纹、 裂纹、切痕或其它有害的缺陷。

目视检查规程应在检验前提交采购方认可。

# （ 2 ）磁粉检查

# A 、检验方法

锻件的所有表面应按 RCC-M MC 5000 要求进行检验。

# B 、记录和验收标准

尺寸大于或等于 1mm 的任意缺陷显示应予以记录。

下列任意缺陷显示均为不合格：

a) 线性显示；

b) 尺寸大于 3mm 的非线性显示；

c) 边缘间距小于 3mm 的 3 个或 3 个以上排成一行的显示，或边缘 间距 3mm 到 6mm ，其分布长度大于 15mm 的显示。

<!-- page: 17 -->

若两个邻近缺陷显示的间距小于较小缺陷显示长度的两倍，则把这两 个显示看作一个显示。总的显示长度应为两个显示长度之和加上两个显示 的间距。

若磁粉检验不可行，按照 RCC-M MC 4000 规定进行液体渗透检验， 并按照 RCC-M M 2143 第 6 章要求验收。

磁粉检查规程应在检验前提交采购方认可。

# 8.2 锻件的内部缺陷检查

最终机加工后，对产品进行超声检测。

# A 、检验时机

在锻件最终机加工后进行检验。

# B 、检验方法

一般采用直径为 8mm ～ 15mm 、频率为 6MHz ～ 10MHz 的纵波直探 头和折射角为 45 °及 60 °、频率为 4MHz 的横波斜探头。

纵波直探头超声检验应在试块两个相互垂直的表面上进行全体积检 验，其交线为试块的最长尺寸。

45 °和 60 °横波斜探头超声检验应在试块两个相互垂直的表面上进 行全体积检验，其交线为试块的最长尺寸，至少进行两个相对方向的扫查。

a) 纵波直探头超声检验

不允许存在波幅超过Φ 2mm 平底孔当量的缺陷。

b) 45 °和 60 °横波斜探头超声检验
