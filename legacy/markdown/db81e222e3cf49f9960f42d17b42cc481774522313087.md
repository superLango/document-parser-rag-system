本文参照 HF.131624W3695 《新材料测试要求制定作业指导书》编制。

TC4 合金进气机匣壳体采用环轧工艺制备锻件毛坯。根据发动机研制要求， TC4 合金进 气机匣壳体锻件及其原材料发生材料状态 ( 生产流水、主导工艺等 ) 更改时，需开展冶金质 量评估。本文提出了 TC4 合金进气机匣壳体锻件的冶金质量批准测试要求，供锻件供应商执 行并用于锻件首件鉴定。当不同承制单位向同一锻件供应商订货且锻件制备工艺相同时，允 许共用本文要求的补充测试数据。

# 1 基本要求

a) 除非设计单位另有规定，否则必须按本文规定完成所有的测试项目；

b) 进气机匣壳体锻件应按 Q/S10-0533-2004 《 TC4 钛合金环形锻件》及设计图的要求进 行退火并超声波探伤合格后，方可用于锻件解剖和取样测试；

c) 用于解剖、性能测试的进气机匣壳体锻件，应先按 Q/S10-0533-2004 规定的测试项目 检验合格，再按本文第 3 章进行补充测试；

d) 锻件供应商应按本文规定的取样位置进行取样，并对取样位置和每个试样执行唯一标 识；

e) 锻件供应商应选取首批试制锻件中相当于铸锭头部的 1 件锻件进行解剖，本文规定的 所有测试项目原则上须在同一件锻件解剖件上完成；

f) 必要时，锻件供应商应向设计单位提供冶金检查的试样或解剖件的剩余部分，用于后 续特定项目的补充测试；

g) 锻件供应商在完成本文规定的所有测试项目后，应向设计单位提供完整、详细的正式 报告 ( 含锻件毛坯状态、合格证、理化检测数据、金相组织图片等 ) 。

# 2 锻件标准规定测试项目及要求

首批试制锻件应按 Q/S10-0533-2004 进行所有规定检验项目测试，若测试结果不满足 Q/S10-0533-2004 规定，应终止该批锻件的后续补充项目测试 ( 不允许重复热处理后再进行测 试 ) ，锻件供应商应组织查明不合格原因，采取改进措施，重新研制锻件并进行首件鉴定；若 测试结果均合格，则按第 3 章要求在锻件解剖件上进行补充项目测试。锻件补充测试项目与 Q/S10-0533-2004 规定检验项目及取样位置相同的，允许共用测试数据。首件鉴定用解剖件按 Q/S10-0533-2004 规定检验合格的数据，可作为同批次锻件的解剖件理化数据并用于锻件交 付。
