# 1. 总则

为保证所采购的物项满足采购技术规格书的要求，特制定本要求。

# 2. 范围

2.1 适用于防5、6机组拦污栅采购（标段一）（5号机组）拦污栅项目（以下简称：本项目）用奥氏体不锈钢锻件的采购控制。

2.2 本项目用奥氏体不锈钢锻件的采购质保等级为C1b级（物项质保等级为Q2级）。

# 3. 定义

3.1 质量计划：对制造、检查和试验等活动实施控制，列有制造和验收中应进行的所有工艺、程序、工作细则、试验和检查的流程图或工序列表，并设有相关方质量控制点等内容的文件。

3.2 质量控制点（见证点）：为确保各制造工序处于受控状态，在项目实施过程中，需要对重点控制的质量特性、关键部件或薄弱环节设置相应的控制点。质量控制点：包括停工待检点（H点）、现场见证点（W点）、报告或记录审查点（R点）。

> H点：停工待检点，指设备制造过程中的一项关键工序，在质量计划中预先设定，未经见证单位人员出席见证或书面通知放弃该H点的监督见证，不得进行该道工序及后续操作。买方确定H点的前5天以书面形式通知买方进行见证。

> W点：现场见证点，在质量计划中预先设定，如见证单位人员明确不出席或未在双方约定时间出席，可继续后续工作或工序。买方确定W点的前5天以书面形式通知买方进行见证。

> R点：报告或记录审查点，见证单位人员通过审查报告来进行监督的工作或工序。

3.3 买方：四川科新机电股份有限公司（单位缩写：SCKX）。

3.4 供方：为我公司提供物项的分供方。

3.5 需求方：中广核研究院有限公司（单位缩写：CNPRI）。

3.6 业主方：中广核工程有限公司（单位缩写：CNPEC）。

4. 引用文件

4.1 《核电厂质量保证安全规定》（HAF003）及其相关导则

# 5. 责任

5.1 买方质量保证部：负责对采购物项提出质保要求；负责组织对供方质保文件的审查和质量控制过程的监督。

5.2买方物资供应部：负责对采购物项供方进行评选：负责对采购物项进行进度跟踪：负责对采购物项有关信息的传递和工作协调。

5.3 供方：必须严格按照本合同要求提供各类质量保证文件，并严格执行，同时提供符合要求的物项。

# 6. 行动

6.1 本项目锻件供应商应为买方的合格供应商，买方物资供应部在物项采购时，必须在合格供方名录中选取具有相应能力、且须为持有民用核安全设备制造许可证的供方。

6.2 买方物资供应部负责建立与本项目合同相关各单位接口关系，明确接口人和通讯方式。按合同进度要求敦促供方按计划提交接口文件，在收到供方提交的接口文件后，及时分发至各相关部门处理，并及时将回复意见通过正式渠道向供方反馈，直至接口关闭。

# 6.3 质量控制要求

6.3.1 供方应编制实施本项目合同物项的质量保证大纲，建立项目组织机构、明确各项资源配备，有效开展各项质量活动。项目质量保证大纲应满足《中华人民共和国核安全法》、《核电厂质量保证安全规定》（HAF003）及其相关导则、《核动力厂质量保证大纲的格式和内容》、合同及其附件的要求，使覆盖所有重要的、与物项制造全过程相关的质保活动都得到有效的控制。在物项制造开工前，供方应按合同要求将项目质量保证分大纲以正式形式提交买方审查、认可。同时，还应为买方人员提供一切方便条件，以使其确信所供物项的符合性。

6.3.2 供方应严格按合同规定执行防造假要求并建立“防造假管理制度”，将防造假要求纳入到项目质保大纲中并严格履行防造假义务，且须采取有效措施防止出现造假现象（如冒签、违规代签、数据或资质造假等）。另，供方应根据本项目要求组织各相关人员系统学习防造假知识，且须按要求签署《防造假承诺书》（模版见附录一）以备查。同时，供方还应明确核安全文化要求，贯彻落实“两个零容忍”、“四个凡事”并建立经验反馈管理体系。

6.3.3 在物项制造过程中，严禁出现弄虚作假、违规操作等管理问题。如若出现类似情况，供方质量保证部门须在发现后5个工作日内采用书面形式报送买方，同时根据买方要求及时报送相关资料。

6.3.4 从事本项目物项无损检测的人员，应取得相应的有效资格证书并按本项目《奥氏体不锈钢锻件采购技术规格书》的要求执行相关无损检验活动。

# 6.4 过程控制要求

b）修改记录，内容包括：版本变化、修改原因、内容简述和修改日期等；

d）质量计划正文：包括供方名称/LOGO、质量计划名称及编号、版本、物项名称及材质、图号、采购质保等级、核安全等级（若有）、记录或报告编号栏、备注栏等信息。

# 6.6.2 不符合项的分类

制造阶段不符合项分为内部不符合项和外部不符合项，即：I类不符合项和E类不符合项，具体分类原则如下：

a) I类不符合项：指偏离了供方内部管理要求或技术要求（如管理程序、工艺文件、操作细则等），但未偏离法规和合同或其所涉标准规范的不符合项；对于标准允许的焊缝补焊返修、供方自行直接报废处理的不符合项可划分为I类不符合项，但涉及质量证明文件真实性存疑或规定的E类不符合项除外。

b) E类不符合项：指偏离了法规和合同或其所涉标准规范要求的不符合项，包括影响到设备的可靠性、可用性或所涉标准的不符合项。E类不符合项主要包括但不限于以下几个方面：

> 偏离采购合同（或订单）技术附件规定；

> 偏离采购合同（或订单）中规定、或买方已经认可的材料方面的要求；

> 偏离合同及其附件规定的已认可的审查类(R类)文件的要求；

> 偏离合同要求的制造工艺（如制造质量计划）。

c）根据处理方式不同，E类不符合项可分为E1和E2两种类型类，具体为：

1）E1类不符合项：可根据合同要求或所涉及法规、标准要求，或按照买方已经认可的处理程序，通过修复能予以纠正的E类不符合项。对于质量证明文件真实性存疑且无法提供证明材料的情况，应按下述6.6.3条及时开启E1类不符合项报告处理。
