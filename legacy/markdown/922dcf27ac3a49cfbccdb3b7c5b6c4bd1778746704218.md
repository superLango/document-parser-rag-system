# 1.5 供货范围

# 1.5.1 硬件供货范围

按本规格书及设备图册提供 H-TH4 热中子孔道设备一台及其附件，含孔道用氦 气气路控制柜一套（共用），风管配对法兰、紧固件及密封件一套，电控柜及气路控 制柜设备所需的电缆、线缆槽及安装附件等。

# 1.5.2 软件供货范围

供货文件参见本规格书第 6 节。

# 1.5.3 备品备件

备品备件至少需包含 10% 的紧固件及备用密封件，且单个规格型号不少于 2 件。

其它备品备件由采购方在合同中规定。

供货方提供的备品备件应附带有一份清单。清单至少应包括以下内容：备品备件 的编号、数量、名称、规格等内容。

# 1.5.4 供货时间及方法

由采购方在设备订货合同中确定。

所有材料应满足相应的要求，并符合相应的技术标准，具有质量合格证明。安全 级部件所用材料必须具有材料鉴定试验报告和供货方对该材料的复验报告。用于本设 备制造的全部焊接材料，都必须符合相关焊接材料技术条件的要求。

# 2.2.7 铅材料

H-TH4 热中子孔道旋转闸门由电机 - 减速器驱动蜗杆转动进而带动转盘转动，从 而实现孔道的启闭动作。

旋转闸门的前端与水池壳体之间设置有水池接管，接管埋在重混凝土内，以降低 中子通量，防止旋转闸门前端活化。在水池和重水箱之间设置有导向波纹管，导向波 纹管上设置有波纹管用于补偿水池壳和重水箱之间因温度变化造成的伸缩量。

转盘由碳钢、铅和铅硼聚乙烯做成的“夹心”结构，中间设置有转轴，装配在外 壳内，单个旋转闸门包含有五个转盘。

# 2.3.1 闸门的启闭

闸门的启闭由电动驱动组件进行驱动，电机驱动组件通过传动丝杆、蜗杆带动涡 轮旋转。蜗轮设置在旋转闸门的第一个转盘上，其后还设置有四个转盘，装配在外壳 内。当第一个转盘转动 60 °后，依次带动接续转盘空转 60 °后带动后续转盘转动， 最终带动第五个转盘转动 60 °，直至第一个转盘转动 300 °。每个转盘的方形孔洞在 环向位置间隔 60 °时孔道闸门完全关闭，满足屏蔽需求。当孔道需要开启时，电机 反向转动，依次带动转盘空转 60 °后带动后续转盘转动，直至第一个转盘转动 300 °， 各转盘方形孔对齐，孔道开启，允许一定强度的中子流通过。

旋转闸门的单次开启（或关闭）时间不大于 67.5s 。

# 2.3.2 电机驱动组件

电机驱动组件包含伺服电机、角度传感器、减速器、联轴器、键及与丝杆连接套 筒、保护罩壳及集油盘等，同时需配备手动盘车装置，以确保失电情况下可靠运行。

伺服电机上装置有旋转编码器，通过编码器进行启闭动作的控制，同时传动丝杠 上设置有限位螺母，丝杠转动过程中，丝杠转动时螺母上下运动，在启闭上下极限位 置有限位开关用于控制闸门的启闭极限位置。

减速电机在失电及电机故障的情况下，应可以手动操作设备，如通过手轮驱动电 机轴驱动丝杠、蜗杆进行转动。

驱动机构应在地震载荷下不解体并且各传动部件保持原位不变。

电机驱动组件由供货方进行细化设计、选型并提交图纸及计算说明书供审查认 可。

电机驱动组件需保证在地震载荷下不解体且能保证旋转闸门处于原位不变。

水平试验孔道方孔中心标高 1.510m 。

# 3.4.6 焊缝的返修

1) 对本设备的焊缝，同一位置只允许补焊 2 次，更多次数的返修需获得采购方 的批准，同时应将返修次数、部位和返修情况记录在册。

2) 当焊缝上发现有不允许的缺陷时，应采用机械法去除，斜度不大于 1 ： 4 。去 除缺陷后进行渗透检测，在确认缺陷已完全去除后方能进行补焊。补焊后应 作相应检查。

3) 焊缝返修的焊接工艺评定和焊接工艺规程应符合 3.4.1 的规定。

# 3.5 无损检验要求

承担设备安全级部件焊缝的无损检测人员的资格应满足 HAF602 的规定。

承担设备非安全级部件焊缝的无损检测人员的资格应满足关主管单位相关要求 的规定。

所有安全级部件的无损检验应按 ASME BPVC-V 、 ASME BPVC-III 的相关要求 进行检查。

全部安全级部件焊缝坡口应进行目视检查和液体渗透检验。

全部安全级部件焊缝应进行目视检查、 100% 液体渗透检验和射线检测。

所有 A 、 B 、 C 类焊缝和 D 类对接焊缝进行射线检测。其他焊缝如无法射线检测 的，可用逐层液体渗透检验替代。

所有非安全级部件焊缝应按 NB/T 47013.5 的要求进行 100% 液体渗透检测， II 级 为合格。

所有安全级部件应进行目视检查（包括母材和全部焊缝），必要时可采用 3~5 倍 放大镜进行检查，应无气孔、裂纹、划伤、氧化等缺陷。

# 3.6 有损检测要求

NA 。

# 3.7 耐腐蚀性能要求

1) 奥氏体不锈钢应以固溶处理状态交货。

2) 所有奥氏体不锈钢应按 GB/T 4334 中 E 法进行晶间腐蚀试验。

3) 为避免水平孔道铝合金与不锈钢材料的直接接触，提高材料耐腐蚀性及耐磨 性，在不锈钢表面镀铬，具体的基材预处理要求、镀覆工艺以及消除氢脆影 响的后处理方法等均可参照 AMS 2460B 中 Class 2 执行，并依据标准提供的 测试方法对镀层进行检测，最终保证镀层厚度、附着力、硬度等均满足要求 即可。

# 3.10 试验

出厂前应完成出厂试验。出厂试验应在采购方见证的情况下实施完成。

设备进行厂内试验、出厂试验和现场试验时，产生的试验报告应予以提交。

供货方应按照规范书和相关标准的规定编制试验大纲和程序，试验大纲和程序应 经过采购方的批准和认可。

# 3.10.1 水压试验

1) 水压试验按 ASME BPVC-III NC-6100 和 NC-6200 的规定执行和验收，试验 压力为 0.125MPa ，保压时间为 30 分钟。

2) 水压试验用水应满足 THG-D01-A01-602 中 B 级水的要求。

3) 水压试验中必须使用两个量程相同的压力表，压力表应满足 NC-6400 的要 求，指示型压力表的刻度范围不小于试验压力的 1.5 倍，但不大于试验压力 的 3 倍。

4) H-TH4 热中子孔道套筒应整体进行外压试验，并在试验中配备工装保护波纹 管段免受试验损伤。

# 3.10.2 气密试验

旋转闸门段应进行气密试验，充气压力为 0.0115MPa ，保压 30 分钟，无明显压 降为合格。

# 3.10.3 启闭功能试验

设备出厂前应进行孔道启闭功能试验，试验次数不小于 20 次。设备试验应满足 本文件对设备功能和性能的所有要求。

# 3.11 波纹管要求

波纹管的制造、焊接、检测、试验要求详见 THG-D01-BR01-D15-002 。

# 4 清洁、包装、贮存、运输要求

# 4.1 清洁要求

设备水压试验之前应进行清洁检查，所有的内部构件在组装进设备之前应先进行 检查，内部构件装配后要检查所有的可视表面保证无湿蒸汽、油脂、研磨粉、喷砂研 磨剂或其它物质。检查后应立即安装密封件以密封设备准备水压试验，维持其清洁度。

在运输密封前，设备应干燥并检查清洁度。内表面应使用干净的软布擦拭使其无 污染物。检测之后，立即进行设备的密封并保持清洁度。

<!-- page: 19 -->

用于最终清洁的水质和清洁度应满足 THG-D01-A01-602 的要求。

铝窗的清洁应按照 THG-D01-D01-001 中 B 级要求执行， H-TH4 热中子孔道套筒 清洁要求应按照 ASME NQA-1 第 2.1 节 B 级标准执行，其余部件按照 C 及标准执行。

# 4.2 防腐涂层要求

产品非转动碳钢件表面需涂漆，涂漆参照 THG-D01-A01-501 相关要求进行。

# 4.3 包装要求

1) 铝窗按照 THG-D01-D01-001 要求执行， H-TH4 热中子孔道套筒按 ASME NQA-1 第 2.1 节 B 级标准执行，其余部件按照 C 及标准执行。

2) 设备出厂前，供货方应根据设备的结构特点和运输要求，做分箱包装设计， 并避免因包装不妥而造成运输中受损，包装设计和制造应征得采购方的认可。

3) 包装前，应完成本设备的清理与清点工作。

4) 包装箱应具备防震措施，确保吊装和运输过程中设备保持平稳。包装箱还应 具有防止运输变形或碰伤设备表面而影响设备的功能。各零部件在包装箱内 必须固定可靠，防止发生变形或损坏。

5) 包装箱外应标有产品的名称、编号、箱号、重量、外形尺寸、吊装位置、正 方箭头、收货单位和发货单位等常规标记。

# 4.4 吊装、运输和贮存

1) 铝窗按照 THG-D01-D01-001 要求执行， H-TH4 热中子孔道套筒按 ASME NQA-1 第 2.1 节 B 级标准执行，其余部件按照 C 及标准执行。

2) 在吊装时，必须小心轻放，采取有效措施，防止结构变形和碰伤部件表面， 设备不应倒放或承压过重物体，要按包装箱吊装位置标记进行操作，防止跌 落损坏。

3) 在运输过程中，包装箱禁止无遮盖运输，必须用绳子捆扎好包装箱，不能晃 动，尽量避免有过大冲击。

4) 设备在制造厂及出厂后运至现场安装前应妥善保管，必须储存在室内安全、 干燥、清洁的区域，防止积灰。

5) 从设备出厂后至现场安装前应妥善保管，产品的包装箱禁止无遮盖运输和露 天存放，并应采取措施防止包装箱受潮损坏。
