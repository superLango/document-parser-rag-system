# TA15 钛合金环形锻件

# 1 范围

本标准规定了 TA15 钛合金环形锻件的要求、质量保证规定和交货准备。

本标准适用于涡扇 -10 系列发动机用 TA15 钛合金环形锻件。

# 3.3 交货状态

3.3.1 锻件最终应在( α ＋ β )两相区轧制。锻件以轧制 、 退火状态交货。

3.3.2 热处理制度为：退火： 700 ℃～ 850 ℃（在选定温度下的温度波动应不超过± 10 ℃），保温 1h ～ 4h ， 空冷。

# 3.4 力学性能

# 3.5 低倍组织

3.5.1 在锻件的低倍试样上不应有缩孔、裂纹、气孔、偏析、金属和非金属夹杂及其他冶金缺陷。

3.5.2 低倍晶粒度按图 1 ( 10 级评级图)评定， 1 ～ 6 级晶粒度为合格；当出现 7 级情况时，以高倍组织和 力学性能为准。低倍组织允许有纤维状组织和拉长晶粒组织；允许个别区域的纤维状组织和拉长晶粒组织 不超过受检总面积的 30% 。

# 3.6 高倍组织

高倍组织按图 2 ( 9 级评级图) 进行评定，符合 1 ～ 5 级图片要求为合格。

# 3.7 β 转变温度

供方应实测并提供每批锻件的 β 转变温度（可转抄原材料检测数据）。

# 3.8 超声波检验

锻件应逐件进行超声波检验，按 Q/S10 － 0105 － 2004 的 A 级验收。异形件在中间坯上进行超声波检验， 应按 Q/S10 － 0105 － 2004 的 B 级验收。

3.9 形状、尺寸

锻件的形状、尺寸和公差应符合供需双方签定的图样的规定。

# 3.10 外观质量

3.10.1 锻件表面不允许有夹杂等影响材质的冶金缺陷，发现后锻件予以报废。

3.10.2 锻件加工表面上的裂纹、氧化皮等缺陷必须清除，压伤、压坑等局部缺陷，如其深度不超过机加 工余量的三分之二，则允许不清除。在所有清除和允许不清除缺陷的部位，均须保证锻件留有不小于三分 之一的名义加工余量。有要求时，还应保证锻件留有后续加工过程中所需的工艺余量。

3.10.3 缺陷的清除处应圆滑转接，清除宽深比不应小于 10 。

# 4 质量保证规定

# 4.1 质量控制

4.1.1 锻件在试制、转厂或改变主导工艺时应按 HB 5402 的规定进行鉴定、定型，然后方可投入批生产。

4.1.2 锻件主导工艺过程的生产条件应按 GJB 904B 进行准备和控制。锻件实行锭节号管理。

4.1.3 当供方生产工艺有重大改变时 , 应预先征得需方技术主管部门的同意，并根据需要进行全面性能和 工艺试验，其冶金质量不应低于定型批质量水平；必要时，需方可查看供方的制造生产工艺和本标准所要 求的各项试验，但应予保密。

4.1.4 已检验合格的锻件，在随后的加工、检验(如超声波)过程中发现有超出本标准的冶金缺陷时，锻 件仍属不合格。

4.1.5 如果一个环形件供制造几个零件用时，允许将不能保证加工成零件的部分报废，并作好标记，同 时在质量证明书中予以注明。

# 4.2 质量一致性检验

# 4.2.1 组批规则

锻件应按批提交验收，每验收批应由同一图号、同一熔炼炉号、同一投产批、同一热处理炉批的锻件 组成。

4.2.2.2 锻件的取样部位按锻件图或专用技术文件的规定。

# 4.2.3 判定与复验规则

4.2.2.3 Ⅱ类锻件每批取一个锻件或试样环进行理化检验，供方在半个试验件上进行理化测试，另半件 打上相应标志随同批锻件发往需方供复验用。

4.2.3.1 当化学成分分析结果不合格时，则该批判为不合格。

4.2.3.2 力学性能检验不合格时，允许在同一试验件上切取双倍数量的试样进行不合格项目的重复试验； 重复试验不合格时，允许重复热处理后重新提交验收，若仍不合格，该批锻件判为不合格。重复热处理只 允许进行一次。

4.2.3.3 锻件的超声波检验、形状、尺寸、外观质量不合格时，该件不合格。

4.2.3.4 高倍组织、低倍组织检验不合格时，则该批判为不合格。

室温拉伸试验按 GB/T 228.1 进行。

# 4.3.3 室温冲击试验

室温冲击试验按 GB/T 229 进行。

# 4.3.4 高温拉伸试验

高温拉伸试验按 GB/T 228.2 进行。

# 4.3.5 高温持久试验

高温持久试验按 GB/T 2039 进行。

# 4.3.6 布氏硬度试验

布氏硬度试验按 GB/T 231.1 进行。

# 4.3.7 低倍组织检验

低倍组织检验按 GB/T 5168 进行。

# 4.3.9 β 转变温度检验

β 转变温度检验按 GB/T 23605 进行。

# 5 交货准备

# 5.1 标志、包装、运输和贮存

锻件的标志、包装、运输和贮存按 GB/T 8180 的规定进行。

锻件应按图样标明的位置逐件打上如下标记：

a ) 供方质量监督部门的印记；

b ) 合金牌号(或代号)；

c ) 锻件图号(或代号)；

d ) 锻件批号(或代号)；

e ) 熔炼炉号(或代号)；

f ) 按锭节号管理时应标明锭节号；

g ) 其他标记。

# 5.2 质量证明书

每批锻件应附有质量证明书，其上注明：

a ) 供方名称；

b ) 需方名称；

c ) 合同号；

d ) 本标准编号；

e ) 产品图号和代号、名称、合金牌号、类别、交货状态、热处理制度；

f ) 熔炼炉号、数量、投产批号、热处理炉批号；

g ) 冶炼方法及原材料产地；

h ) 按本标准和合同协议所规定的各项检验结果(如重复试验还应包括两次检验结果)；

i ) 技术监督部门印记；

j ) 包装日期。
