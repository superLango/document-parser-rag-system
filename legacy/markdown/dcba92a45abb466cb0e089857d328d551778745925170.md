# 1 适用范围

1 适用范围 1.1 本规定适用于东方锅炉的核电中间商，以及材料和零部件供方的中间 商。

1.2 本规定适用于公司核电物项（既包括核岛物项，也包括常规岛物项； 既包括核质保级物项，也包括非核质保级物项；既包括配套件、零部件和材 料，也包括辅料、工装、工具和计量器具，下同）。

1.3 本规定既适用于上述物项，也适用于相关质量资料【既包括纳入完工 报告 / 质量证明资料的资料（譬如合格证、检查和试验报告、第三方检测报告 等），也包括不纳入完工报告的支持性质量资料（譬如培训资料、质量体系证 书等）。】

1.4 当东方锅炉与材料 / 零部件供方建立直接接口，物项和质量资料由材 料 / 零部件供方直接交接给东方锅炉，中间商不参与交接活动时，不适用于本 规定。

# 2 术语和定义

2 术语和定义 2.1 物项，在本规定中指东方锅炉采购的用于核电的配套件、零部件、材 料、辅料、工装、工具和计量器具。

2.2 中间商，指在东方锅炉与供方 / 顾客之间参与物项交易业务，促使采 购行为发生和实现的组织或个人。

2.2.1 东方锅炉与材料 / 零部件供方或者顾客之间承担的包装、仓储和运输 的供方，需要满足本规定。

2.3 造假，在本规定中指中间商、分供方及其有关员工，故意违反法规、 技术标准和东方锅炉采购要求，或故意提供不准确和不完整的信息和记录。

2.4 物项标识，在本规定中指物项或其包装上的标识。

2.5 质量资料，包括直接质量证明资料和间接质量证明资料：

2.5 质量资料，包括直接质量证明资料和间接质量证明资料： （ 1 ）直接质量证明资料，包括质量证明书、完工报告、合格证、第三方 检测报告、作业过程记录、理化试验报告、无损检验报告、缺陷处理记录、 尺寸检查报告等；

（ 2 ）间接质量证明资料，包括签名、印章、见证巡检记录、检定校准记 录、设备鉴定维保记录、资格与培训记录、供方评价资料、资质证书、体系 证书、授权证书、代理证书、业绩证明等。

# 3 防造假原则

3.1 中间商按照本规定对其提供物项和质量资料的真实性承担责任。东方锅炉防造假核查不转移或减轻中间商承担的防造假和防造假核查责任。

3.2 禁止中间商伪造或者冒用认证标志等质量标志。

3.3 禁止中间商伪造物项的产地，伪造或冒用他人的厂名、厂址、商标、 印章，提供回收或翻新物项等。

3.4 禁止在销售物项中掺杂、参假，以假充真，以次充好。

3.5 物项应经检验合格，不得以不合格物项冒充合格物项。

# 4 实物防造假

4.1 中间商不得从事仓储、包装和运输以外可能影响物项质量的活动。

4.2 中间商不得切割、更改或修复物项，禁止中间商在物项上实施焊接。

4.3 除了辅料中间商外，中间商不得委托第三方对物项进行检测。

4.4 物项标识必须真实，中间商不得去除或修改物项标识，并采取措施确 保这些标识清晰完整。需要重新包装时，中间商必须确保新包装上的物项标 识与原包装的物项标识一致。

4.5 中间商应核实物项的标识以及与采购要求的一致性。实物核查工作流 程如下：

<!-- image: page 5 -->

（1）物项标识是否被修改过？紧固件标识（头标）是否符合规范？

（2）物项与分供方许可/经营范围是否一致？

（3）物项的状态、颜色、尺寸、数量等与采购要求和质量资料是否一致？

（4）焊缝和表面是否存在异常斑点显示？

5.2 中间商须建立并执行质量资料管理制度和进货检查制度。

5.2.1 中间商收到物项后应协调分供方及时提供质量资料。

5.2.2 中间商必须验明物项标识及其质量资料。

5.2.3 中间商应将其验明认可的质量资料妥善保存并与物项一一对应。通 过扫描或复印后保存时，扫描文本分辨率不得低于 300dpi ，且不得歪斜。

5.2.4 缺少质量资料的物项，不得提供给东方锅炉。中间商不得采取“张 冠李戴”的方式提供质量资料。中间商应能证明物项与其资料对应关系。

（3）观察是否存在同一页面多个相同印章、不同页面印章方向相同情况。

# 第五步：认证证书核查。

第五步：认证证书核查。 中间商应对中间商及其分供方的体系证书、业绩证明、资质证书、营业 执照、代理证书、销售授权许可进行防造假核查并作出防造假核查标识。

（ 1 ）若这些资料为复印件时，中间商应索取原件、原件照片或原件扫描 件开展比对核查。

（ 2 ）对于体系证书和资质证书，中间商应通过“全国认证认可信息公共 服务平台”查询确认。

# 第六步：异常处理。

第六步：异常处理。 中间商核查发现异常时，应组织核实并排除风险，不能确认真伪或不能 排除风险时，应反馈东方锅炉组织处理。

# 6 采购要求修改或澄清

6 采购要求修改或澄清 6.1 当中间商认为东方锅炉采购要求存在不足、遗漏、前后矛盾、含糊不 清或对其意义或正确性有质疑时，可书面向东方锅炉提出修改或澄清要求。 严禁更改原始质量资料予以满足。

6.2 当东方锅炉及东方锅炉的顾客审查发现问题需要澄清或修改质量资 料时，中间商必须传递给质量资料提供方澄清或修改。中间商不得自行澄清 或更改。中间商协调资料提供方澄清或修改存在困难时，应反馈东方锅炉组 织处理。

6.3 当特殊要求导致中间商无法获得满足要求的物项时，中间商应反馈东 方锅炉组织处理。严禁中间商自行作出技术判断，将其它物项视为满足要求 的物项提供给东方锅炉。

# 7 签署防造假

# 东方锅炉防造假政策声明

核安全设备制造过程中，必须坚持对违规操作零容忍和对弄虚作假零容 忍。公司确定了 “ 违规指挥、违规作业、违规处置、违规放行、隐瞒不报和弄 虚作假 ” 六条质量红线，并建立了防造假机制。

各类文件中应努力减少可能导致造假的诱因，原则上不提出超出实际需 要或与实际情况脱节的管理和技术要求。同时通过合同约束和激励考核，实 现 “ 不敢造假 ” 的震慑作用；通过风险管理和过程管控，实现 “ 不能造假 ” 的屏 障作用；通过警示教育和经验反馈，实现 “ 不想造假 ” 的引导作用。从而预防、 识别、阻断、打击造假，遏制造假行为，确保规范、有效地开展防造假工作。

为此，郑重声明如下：

一种态度：始终秉持核安全高于一切的态度，提升核电从业人员质量和 诚信意识，任何决定和行为都应确保核安全。

两个担当：做好制造责任担当和采购监督责任担当。切实履行策划、准 备、制造、检查、试验、纠偏和记录的符合性责任，同时做好对供方准入、 选择、审查、监造、验收、监查的过程监督责任。

三层防护：织密人防、技防和制防三层屏障。人防就是要强化人员防造 假主动意识和提升防造假核查技能；技防就是要充分利用信息化技术、精益 管理手段等，做好防造假；制防就是通过修订、宣贯、监督和反馈，不断完 善细化各项规定。

四项机制：不断完善培训机制，加强经验反馈并做好警示教育；强化风 险管理机制，开展风险识别并做好风险管控；细化防造假核查机制，明确核 查责任并规范核查流程；明确激励考核机制，落实防造假责任并调动防造假 积极性。
