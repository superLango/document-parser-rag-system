# ASTM A182 F6NM 原材料订货技术协议

# 1 适用范围

本协议适用于派克公司所采购的 ASTM A182 F6NM 钢锭，规定 了 ASTM A182 F6NM 钢锭的技术要求和质量要求等。

# 2 引用标准

ASME SA-182 高温用锻制或轧制合金钢和不锈钢称 管道法兰、锻制管配件、阀门和零件

ASTM E45 钢中非金属夹杂物含量的测定

# 3 要求

# 3.1 冶炼要求

采用 EAF+AOD/VOD ，或其他满足要求的，等效的、更优的方 法冶炼。

# 3.2 化学成分要求

# 3.4 内部质量要求

供方应该保证，原材料锻造成锻件后的质量满足下列检验要求：

锻件探伤要求按照 EN 10228-3 等级 4 进行验收。

# 3.5 尺寸规格要求

规格尺寸见合同。为清除缩孔和过分的偏析，头尾应有充分的切 除量。

# 3.6 表面质量要求

原材料表面不得有肉眼可见的裂纹、结疤、折叠、夹杂物以及影

<!-- page: 4 -->

响钢锭使用的其它有害缺陷存在。详见 PK-PC-JSTZD-019 Rev.A 《关 于钢锭表面质量检验要求的管理规定》。

表面应光洁，不允许有裂纹、发纹、折叠、气孔、结疤、夹渣、 离层及其它对使用有害缺陷。有本体取样要求的原材料，需要对取样 部位进行打磨处理，并应满足原材料表面质量要求的管理规定。

# 3.8 其他要求

需提供头尾复验用料，保证可取出 1 个 30*30*30 成分、 1 个 25*25*25 气体、 1 个 15*15*15 夹杂。

当对原材料有其他要求时，由供需双方协商确定。

# 4 交付

# 4.1 质量证明书

原材料应附有符合本协议要求和合同中规定的质量证明书，并注 明：供方名称、需方名称、合同号、材料牌号、熔炼炉号、重量、头 部 / 尾部化学成分、熔炼方式。

质保书中需按照 EN 10204 3.1 要求提供合格证。在合格证中增加 如下内容：“ This certificate is written according to EN 10204 3.1 本合 格证的编制按照 EN 10204 3.1 ” .

# 4.2 材料标识

原材料需印记齐全，具有可追溯性，原材料本体标识应包含合金 牌号、重量、熔炼炉号、锭节号（如有）。

# 4.3 包装

<!-- page: 5 -->

应采用合理的包装方式，防止在运输过程中产生磕碰等质量事 故。

# 5 入厂复检

原材料回厂后，需对以下分项进行 100% 检查：外形尺寸、化学 成分、外观质量、非金属夹杂物。
