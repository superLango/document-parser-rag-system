# 4. 检验类别

4.1 本标准规定了对用黑色金属、有色金属和合金制的模锻件、锻件、铸件、优质轧材、板材、带材、线材、管材、型材制造的零件，经过最终热处理和化学热处理后的检查组别。本标准没有规定焊接结构的检查组别。检查组别由设计部门确定，或设计部门会同有关部门确定，在图样的技术要求中指明，并应符合行业标准的技术要求。

4.2 本标准对进行过热处理（淬火、淬火与回火、淬火与时效、退火、正火）的零件确立了6个检查组别，对进行过化学热处理的零件（渗碳、氮碳共渗、渗氮）确立了2个检查组别。

4.3 根据经热处理零件试验种类的内容不同，检查组别应符合表1的规定。

4.4 零件几何形状不允许测量硬度，或测量硬度后的修磨会导致超差的零件，归入第4检查组，这时硬度检查在检验样件上进行。样件的厚度，通常应相当于零件的最大厚度。

4.5 对于2、2a、3、4和5检查组别的零件，允许最终热处理在毛坯上（对一个或几个零件的）进行。毛坯的检查按图样或行业标准规定的检查组别进行。然后，用这些毛坯制造的零件，如不进行某种能导致原来由最终热处理确定下来的性能变化的热加工，则不需要检查。

4.6 如半成品（模锻件、锻件、铸件）按图样的要求经过了热处理，并且按它们的供货技术文件经过了检查，用它们制造的零件，以后没再经过热加工（去应力热处理除外），按试验类型的内容已作过不少于对零件规定的内容，则按本标准的检查不进行，或者只对半成品没有进行的那些内容和试验类型进行检查。

4.7 对1、2和2a检查组别的零件，当规定按试验类型的被检特性——硬度和力学性能（强度极限、伸长率、收缩率、屈服极限、冲击韧性）时，设计者应该从它们中确定哪些是对于给定的材料、热处理和零件运行条件起决定作用的。

4.8 经化学热处理的零件，按试验类型的内容，不同检查组别应符合表2的规定。

4.9 对于不需检查力学性能和芯部硬度的零件，在图样和行业标准内指明一个规定检查表面层质量的检查组别。

4.10 对需要在化学热处理前或以后检查力学性能或芯部硬度的零件，在图样和行业标准内指出两个检查组：第一组检查力学性能或芯部硬度按表1；第二组检查硬度、金相组织和表面层深度按表2。

4.11 力学性能和硬度的检查，按行业内现行的试验技术文件进行。硬度的检查按图样和行业标准中指出的方法进行。在必要时指明测量硬度的部位。当没指明时，硬度在任意部位测量。图面硬度标注按附录A的规定进行。
