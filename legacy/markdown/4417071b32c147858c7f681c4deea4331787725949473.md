# 1 、 2 、 3 级设备用奥氏体不锈钢钢板及冲压件技术条件

# 1. 范围

本文件规定了华龙一号改进型核电机组 1 、 2 、 3 级设备用 06Cr19Ni10 、 022Cr19Ni10 、 026Cr19Ni10N 、 06Cr17Ni12Mo2 、 022Cr17Ni12Mo2 、 026Cr18Ni12Mo2N 、 06Cr18Ni11Ti 奥氏体不锈钢板的制造、化学成分、力学性能和验收等要求。

本文件适用于华龙一号改进型核电机组 1 、 2 、 3 级设备用厚度不超过 120mm 的奥氏体 不锈钢板。

# 3. 订货要求

3.1 需方应在订货合同上注明本文件号、牌号、钢板等级、供货状态和数量等。

3.2 需方应在订货合同中明确以下技术要求：

—— 是否考虑钢的耐腐蚀性能；

—— 钢板是否需进行焊接；

—— 钢板是否与反应堆一回路流体接触；

—— 钢板的交货状态；

—— 钢板是否进行高温拉伸试验；

—— 钢板在使用条件下是否存在层状撕裂危险；

—— 其他要求。

# 4. 制造

# 4.1 制造大纲

制造厂应在生产之前编制一份制造大纲，并对制造过程的各个关键工序，如轧制、热 处理、取样和无损检测等编制文件进行控制，对钢板生产的全过程进行质量控制。

对于 1 、 2 级设备的钢板，应制定包括下列内容的制造大纲：

a) 钢的冶炼方式；

b) 钢锭或连铸坯的质量和类型；

c) 钢锭头、尾的切除百分比，连铸坯的头、尾切除量；

d) 主要热加工工序；

e) 钢板处于钢锭中的位置，特别是相应于钢锭轴线的最终轧制方向；

f) 主要轧制方向；

g) 冷轧钢板的主要冷加工操作特征；

h) 中间热处理和最终固溶处理的条件；

i) 性能检验用试料的位置图及试样在试料中的位置图；

j) 无损检测规程；

k) 应按时间先后次序列出各个操作过程的流程图。

对于 3 级设备钢板，可由钢板制造厂与订货方商定相关的制造大纲，但应至少包括 a) 、 f) 、 h) 和 i) 。

# 4.2 冶炼

不锈钢应采用电炉冶炼并经适当的精炼工艺，亦可采用其他相当或更好的工艺冶炼。

# 4.3 交货状态

钢板应在 1050 ℃ ~1150 ℃进行固溶处理。保温期间，每一钢板偏离热处理规定温度的 最大允许偏差为 ±10 ℃。钢板以热处理状态交货，分下列两种情况：

# a) 厚度 ≤3mm 的冷轧钢板

钢板冷轧后应经固溶处理＋酸洗＋钝化处理后交货。当有要求时也可以固溶处理＋酸 洗＋钝化＋加工硬化处理后交货。带钢和条钢可以盘卷交货。

b) 厚度＞ 3mm 的冷轧和热轧钢板

钢板轧制后经固溶处理＋酸洗＋钝化处理后交货。

当订货合同中有规定时，钢板也可以轧制状态交货。

材料制造厂应对热处理的实际工艺过程进行记录。

# 4.4 尺寸、外形及允许公差

钢板的尺寸和外形应满足订货合同所规定的要求。允许偏差除合同中另有规定外，应 符合 GB/T 4237 或 GB/T 3280 的规定，厚度允许偏差按 GB/T 709-2019 中的 B 类执行。

# 6.2 取样规定

# 6.2.1 试样截取

在交货状态的钢板上截取试料，随即作适当标记并标明最终轧制方向。

中国核电工程有限公司 在交货状态的钢板上截取试料，随即作适当标记并标明最终轧制方向。

<!-- page: 9 -->

试料应有足够的尺寸，以便截取全部试样和可能进行复试所需的试样。

当订货合同中规定钢板以轧制状态交货时，应按 4.3 的规定，在经模拟固溶处理的试 料上取样进行力学性能试验。

试样应在钢板中心线和钢板边缘之间的二分之一部位截取，试样距钢板端部的距离不 得小于钢板的厚度。

# 6.2.2 批的定义

每批钢板应由相同熔炼炉号、相同制造过程，同炉热处理或在连续式炉中经受相同条 件的连续操作不超过 8h 的同一次热处理且相同公称厚度的钢板组成；以轧制状态交货的 钢板，按原轧制张进行检查和验收。

# 6.2.3 试样数量

在交货状态的钢板上截取试料，随即做适当标记并标明主加工方向。

对于采用钢锭生产的钢板：如果每批钢板质量不大于 3000kg ，则在紧邻钢锭头部的 钢板端部截取一块试料；如果每批钢板质量大于 3000kg ，则在紧邻钢锭头部、尾部的钢 板端部各截取一块试料。

对于采用连铸坯生产的钢板：如果每批钢板质量不大于 3000kg ，则任取一张钢板在 其一端截取块试料；如果每批钢板质量大于 3000 kg ，则任取两张钢板各截取一块试料， 当只有一张钢板时，在该钢板的两端各截取一块试料。试料应有足够的尺寸，以便截取全 部试样和可能进行复试所需的试样。

# 6.2.4 试样位置

拉伸试样的纵轴应垂直于钢板的最终轧制方向。试样的纵轴位置如下所述：

a) 当钢板公称厚度不大于 10mm 时，试样厚度等于钢板厚度（采用矩形试样）；

b) 当钢板公称厚度不大于 30mm 时，试样的纵轴位于厚度的中心处；

c) 当钢板公称厚度大于 30mm 时，试样的纵轴位于厚度的四分之一处。

冲击试样的纵轴应位于钢板厚度的中心处，缺口轴线应垂直于钢板轧制表面，三个冲 击试样应在邻近部位截取。

# 6.2.5 试样的形状

拉伸试样应采用 GB/T 228.1—2021 中规定的 R4 试样；当钢板公称厚度不大于 20 mm 时， 可采用 GB/T 228.1—2021 中规定的矩形横截面比例试样。冲击试样应采用 GB/T 229—2020 中规定的标准尺寸夏比 V 型缺口试样。

室温拉伸试验按 GB/T 228.1 的规定进行。

# 6.3 试验方法

高温拉伸试验按 GB/T 228.2 的规定执行，试验时，从开始至试样达到屈服，应力速率 应不大于 80MPa/min 。

冲击试验方法按 GB/T 229—2020 的规定执行。

# 7. 晶间腐蚀试验

在交货状态的钢板上，按 6.2.1 和 NB/T 20004-2014 中第 18 章中方法一的要求截取和加 工试样，进行晶间腐蚀试验。除 06Cr19Ni10 和 06Cr17Ni12Mo2 外，其他牌号的试样在试验 前应进行敏化处理，敏化处理制度和晶间腐蚀试验按 NB/T 20004-2014 中第 18 章中方法一 的规定进行。如果晶间腐蚀试验的试样具有清脆的金属声，并在弯曲后无裂纹或开裂现象， 则该试验结果为合格。如果有疑问，则用金相法进一步判定。

当订货合同中规定钢板以轧制状态交货并有晶间腐蚀要求时，应按 4.3 的规定，在经 模拟固溶处理及相应的敏化处理后进行晶间腐蚀试验，但此检验不能替代附录 B 中冲压件 的晶间腐蚀试验。

如果晶间腐蚀试验不合格，则整批钢板报废，不允许进行复试和重新热处理。

# 8. 金相检验

# 8.1 试样

应在 6.2.3 所述的试料上取样进行金相检验。

# 8.2 晶粒度

按 GB/T 6394 的规定检查奥氏体晶粒度，检验面应按照 GB/T 13298 的规定执行，应为 3 级或更细。

# 8.3 非金属夹杂物

在每批钢板上取一个试样，按 GB/T 10561—2023 中的 A 法检查非金属夹杂物，检验面 应按照 GB/T 13298 的规定执行，采用 GB/T 10561—2023 附录 A 中 ISO 评级图进行评定，检 验结果应符合下列要求：

——A 类：粗系、细系分别小于或等于 1.5 级；

——B 类：粗系、细系分别小于或等于 1.5 级；

——C 类：粗系、细系分别小于或等于 1.5 级；

——D 类：粗系、细系分别小于或等于 1.5 级；

<!-- page: 11 -->

——DS 类：小于或等于 1.5 级。

# 9. 复试和重新热处理

如果某项拉伸性能的试验结果不符合表 2 的要求，可从不合格试样取样的邻近部位取 双倍试样对不合格项目进行复试，如复试结果均合格，则该批钢板的拉伸试验结果合格， 否则，该批钢板为不合格。

如果冲击性能不符合表 2 的要求，则应在不合格试样的邻近部位再截取三个试样进行 试验。如果下列条件都满足，钢板的冲击试验为合格：

a) 六个试样的平均值不小于规定的平均值；

b) 六个试样中吸收能量小于规定的平均值的试样不超过两个；

c) 六个试样中最多有一个试样的吸收能量小于规定的平均值的 70% 。

对力学性能不合格的钢板，可重新进行固溶处理，再按本文件的要求（化学成分和非 金属夹杂物检验除外）重新取样进行试验和检验。

重新固溶处理只允许进行一次。

# 10. 无损检测

# 10.1 目视检测

钢板需进行表面目视检测，检测按 NB/T 20003.7-2010 进行。

钢板表面应平坦、光洁整齐且无波浪状弯曲。不允许有毛刺、结疤、裂缝、气泡、刮 痕、夹杂及缩孔痕迹等缺陷存在。

# 10.2 渗透检测

钢板切割到交货尺寸后，周边不得有开裂或分层。如有疑问，应进行渗透检测，检测 方法按 NB/T 20003.4-2010 执行。

对于钢板侧边的渗透检测的验收准则为：

# a) 对 1 、 2 级钢板

—— 钢板公称厚度 ≤40mm 时，允许呈现长度 ≤8mm 的线性显示；

—— 钢板公称厚度＞ 40mm 时，允许呈现长度 ≤10mm 的线性显示。

当合同中明确钢板在使用条件下可能存在层状撕裂危险时，则只允许存在下述的显示：

—— 钢板公称厚度 ≤40mm 时，在缺陷显示最密集的 1m 范围内显示总长度＜ 30mm ；

—— 钢板公称厚度＞ 40mm 时，在缺陷显示最密集的 1m 范围内显示总长度＜ 40mm 。

<!-- page: 12 -->

当两个显示之间的距离小于较小显示长度的两倍时，应被视为一个显示。其长度等于 两个显示长度之和加上两个显示之间的距离。

# b) 对 3 级钢板

—— 钢板公称厚度 ≤40mm 时，允许呈现长度 ≤12mm 的缺陷显示；

—— 钢板公称厚度＞ 40mm 时，允许呈现长度 ≤15mm 的缺陷显示。

如果不符合上述要求，钢板应予剔出。如果钢板在以后的机加工过程中发现开裂或分 层现象，钢板应予剔出。

如果缺陷显示属于孤立的、局部的（经斜射法超声检测），通过磨削清除后尺寸符合 验收要求的情况下，该钢板可以验收。

# 10.3 超声检测

对公称厚度不小于 12mm 的 1 级钢板和公称厚度不小于 30mm 的 2 级钢板，应在固溶处理 后逐张进行超声检测，检查方法及验收标准按 NB/T 20003.2-2010 的规定执行。

# 11. 缺陷的清除

可以采用打磨法清除表面缺陷。打磨后钢板表面光滑过渡，厚度公差在允许范围之内。

钢板打磨后应按 NB/T 20003.4-2010 的规定进行渗透检测，凡尺寸 ≥1mm 的显示应予 记录，不能出现线性显示或尺寸＞ 2mm 的圆形显示。

不允许进行焊补。

# 12. 尺寸和外形检查

按图纸或订货合同的规定进行尺寸和外形检查，所测数值应在规定的公差范围内。

# 13. 清洁、包装、运输和标志

钢板表面应清洁无污物。包装应能保证钢板在贮存、运输过程中不被碰伤、弄脏、弄 湿，并且不允许与低熔点元素 S 、 Pb 、 Zn 等接触，防止与碳钢相接触。为避免应力腐蚀破 损，应避免钢板被卤素和卤素化合物所污染，如清洁剂、标志剂、包装物及贴封带等。

钢板包装、标志的其他要求均按 GB/T 247 的有关规定执行。

# 附录 B 1 、 2 、 3 级设备用不锈钢冲压件的补充要求

本附录给出了按本文件采购的钢板，经冲压成形的不锈钢冲压件的补充要求。

# B.1 订货要求

B.1.1 需方应在订货合同上注明本文件号、钢号、冲压件等级和数量等。

B.1.2 需方应提供订货图样、尺寸允许偏差。

# B.2 制造

# B.2.1 制造大纲

对于 1 、 2 级不锈钢冲压件，制造厂在开始制造前应制订包括以下内容的制造大纲：

a) 冲压件在钢板上的位置，钢锭轴线和终轧方向应在冲压件上和试料上作出标记；

b) 成形工艺；

c) 验收用试料在冲压件上的位置；

d) 试料上截取试样的位置图；

e) 按时间先后次序列出热处理、成形、机加工 ( 如需要 ) 、热处理、取样和无损检测的 流程图。

# B.2.2 交货状态 — 热处理

成形后的冲压件应在 1050 ℃～ 1150 ℃进行固溶处理，保温期间，每一冲压件偏离热处 理规定温度的最大允许偏差为 ±10 ℃。冲压件应以热处理 + 酸洗 + 钝化状态交货。

# B.3 基体材料

钢板可在不经热处理状态交货，但应在经模拟热处理的试料上取样进行力学性能试验。

# B.4 晶间腐蚀试验

交货状态的冲压件应进行晶间腐蚀试验，晶间腐蚀试样取自经固溶处理后的冲压件或 从 B.5.1 中规定的试板上截取并进行敏化处理，每批冲压件做一次试验。如果晶间腐蚀试 验不合格，则整批冲压件报废，不允许进行复试和重新热处理。

# B.5 力学性能

冲压件的力学性能规定值同钢板的规定。

# B.5.1 取样

试料取自冲压件加长部分，并与冲压件经受相同的热处理。如果上述要求不能实现， 试料可以在冲压前从基体钢板上截取，该试料要与冲压件经受相同的加热过程，并在固溶 处理前与冲压件焊在一起。

试料应作适当标志，特别是应指明终轧方向。

中国核电工程有限公司 试料应作适当标志，特别是应指明终轧方向。

<!-- page: 16 -->

试料应具有足够的尺寸，以便能截取所有试验和可能做复试所需的试样。

试料应取自制造冲压件的钢板，并使保证取样位置在钢板边缘与轴线之间的中间部位， 或尽可能靠近这个部位。

试样距离试料边缘的距离至少等于钢板的厚度，也可用与试料等厚隔热板焊接在试料 上保护其边缘。

拉伸试样和冲击试样的纵轴应垂直于最终轧制方向。

拉伸试样的纵向轴线应位于：

— 冲压件或钢板试料厚度 ≤30mm 时，拉伸试验试样的纵轴线位于厚度的 1/2 处（冲压 件厚度小于 10mm 时，试样应尽可能厚，且应为矩形截面）；

— 冲压件或钢板试料厚度＞ 30mm 时，在厚度的 1/4 处。

冲击试样的纵轴线应位于 1/2 厚度处。

冲击试样缺口底线应垂直于轧制表面。

试料在冲压件上的位置示意图和试样在试料中的位置尺寸图应列入制造大纲中。

# B.5.2 试样数量

对于 1 、 2 、 3 级设备压制件：

—— 每批质量等于或小于 3000kg ，在制取冲压件的钢板头部做 1 组试验；

—— 每批质量大于 3000kg ，在制取冲压件的钢板头尾部各做 1 组试验。

当设备规格书或其他相关合同文件对高温拉伸试验有规定时，应进行高温拉伸试验。

对 1 级设备的冲压件，高温拉伸试验试样应取自相当于钢锭的尾部的钢板。

# B.5.3 试验

冲压件按批进行检查和验收。每批的冲压件应来自同一原轧制张钢板或同批钢板，经 过相同的制造工艺、同一热处理炉号或在连续式炉中经受相同条件同一次热处理。每批仅 限于四个尺寸相近的冲压件，其最大厚度和最小厚度之比小于等于 1.1 ，且变形量相近（最 大变形量与最小变形量相差不超过 10% ）。

冲压件的其它试验要求同钢板。
