# 1 总则

1.1 本技术协议适用于 6061 锻环的订货和验收。

1.2 乙方的生产依据为甲方提供的技术文件以及本技术协议。

1.3 生产过程中凡涉及技术文件及技术协议要求的技术问题由甲方进行处理。

1.4.甲方按提供的技术文件、图纸及技术协议进行产品验收。

1.5 甲方有权对乙方的生产过程进行监控检查。

1.6 乙方未经甲方同意，不得将甲方提供的图纸、技术文件及技术协议提供给第三方。

1.7 乙方未经甲方同意，不得将零件加工委托给第三方。

1.8 甲方应按 Q/CZ.G28.79《特殊过程管理流程》要求开展特殊过程确认工作；按 Q/CZ.G25.25 《首件鉴定流程》要求完成首件鉴定质量报告的编写并完成首件鉴定工作。

1.9 为便于产品质量的追溯，乙方生产过程的质量原始记录（如组织性能报告单、工艺卡、超声波探伤记录等）、存档试样需进行妥善保管，保管期不少于15年，满15年后若要销毁，需征得甲方同意。

1.10 工艺方案由乙方确定，并经过评审后方可执行。生产过程中重大工艺更改（坯料选择、影响锻件组织与性能的锻造及热处理工艺等），应提请甲方评审会签。甲方必要时，可派代表到乙方抽查主导工艺，以确定是否满足技术文件要求。

1.11 乙方应树立质量第一的思想，严格按军工产品质量管理有关法规的要求，实施有效质量管理，并对生产全过程实施有效控制。

1.12 乙方从事产品生产的操作、检验、试验人员应具有相应资质，取得相应上岗资格。

1.13 甲方应对涉及乙方产品的加工工艺保密；乙方应对甲方的产品技术文件、配套情况等保密。

# 2.5 低倍组织

2.5.1 低倍组织的取样方向为垂直于纵向的全截面。

2.5.2 低倍组织不允许有裂纹、气孔、化合物偏析和非金属夹杂物等缺陷，低倍组织中的氧化膜缺陷应符合 GJB2351 的规定。

2.5.3 低倍组织应是均匀的变形组织。

2.5.4 试样表面允许有粗晶，条件是粗晶区力学性能应合格。

2.6 断口组织：断口组织不允许有非金属夹杂物，断口组织中的氧化膜缺陷按 GJB2351规定。

2.7 显微组织：锻环的显微组织不允许有过烧。

# 2.8超声波检验

2.8.1 超声波探伤应在锻环热处理完成后进行。

2.8.2 锻环应进行 100%超声波探伤，按 GJB2351 采用接触法，1类锻环采用 A 级探伤，探伤方向按图 4 规定规定。

2.9 外观质量：锻环的表面缺陷应予清除，清除缺陷的部位应保证留有二分之一的名义加工余量。

# 2.10 试验方法

# 2.10.1化学成分分析方法

锻环的化学成分分析取样按 GB/T 17432规定，化学成分分析方法可采用 GB/T6987或 GB/T7999，仲裁分析方法应符合 GB/T6987的规定，原材料化学成分应符合 GB/T3190。

# 2.10.2 外形尺寸测量方法

锻环的外形尺寸测量方法按 GJB2351规定执行。

# 2.10.3力学性能试验方法

1) 锻环的室温拉伸力学性能试样，纵向采用 $ \Phi10 $的圆试样；高向和横向采用 $ \Phi5 $的圆试样且符合GB/T16865的规定。取样方向、位置应与图4相一致。其试验方法应符合GB/T228的规定。

2) 金属常温冲击韧性试验方法按 GB/T229规定。纵向和高向采用 $ 5 5 \times1 0 \times1 0 $协议试样，冲击速度 $ 5. 5 \pm0. 5 \mathrm{m / s} $，冲击能量 50J；横向采用 $ 4 0 \times5 \times5 $试样，冲击速度 $ 5. 5 \pm0. 5 \mathrm{m / s} $，冲击能量 15J。

3) 金属布民硬度试验方法按 GB/T231规定。

# 2.10.4氢含量检验方法

锻环的氢含量检验方法应符合 GB/T20975.30 的规定。

# 2.10.5低倍组织和断口检组织验方法

锻环的低倍组织和断口组织检验方法应符合 GB/T3246.2 的规定。

# 2.10.6 显微组织检验方法

锻环的显微组织检验方法应符合 GB/T3246.1规定。

# 2.10.7超声波检验方法

锻环的超声波检验方向按图4规定，检验方法按GB/T6519进行。

# 2.10.8 外观质量的检验

锻环的外观质量检验按 GJB2351规定执行。

# 2.11 检验规则

# 2.11.1 检验和验收

1）锻环应由乙方进行检验，保证产品质量符合本协议的规定，并填写质量证明书。

2）甲方应对收到的产品按本协议的规定进行复验。复验结果与本协议及订货合同的规定不符时，向乙方提出，由双方协商解决。如需仲裁，仲裁取样应由双方共同进行。

# 2.11.2组批

锻环应成批提交验收，每批应由同一合金牌号、熔次、状态、规格、热处理炉次或连续热处理炉次组成。

# 2.11.3 检验项目

每批产品出厂前应进行化学成分、外形尺寸及偏差、力学性能、氢含量、低倍组织、显

# 2.12 检验结果的判定

2.12.1化学成分不合格时，判该熔次不合格。

2.12.2 外形尺寸不台格时，判该件不合格。

2.12.3室温拉伸力学性能不台格时，应从原试样的相邻部位另取双倍数量的试样进行复验，复验合格时判批(或淬火炉)合格。若复验结果仍有不合格者时，判批(或淬火炉)不合格，但允许供方进行重新热处理后重新取样检验。重新热处理次数不得多于2次。

2.12.4 氢含量检验不台格时，判该熔次不合格

2.12.5 低倍组织和断口组织不合格时，判批不合格。

2.12.6 显微组织不合格时，判该炉次不合格。

2.12.7超声波检验不合格时，判该件不合格。

2.12.8 外观质量不合格时，判该件产品不合格。允许清除缺陷部分重新检验。合格者交货。

# 3 技术状态的控制

3.1 甲方向乙方提供锻件生产技术文件，并对所提供资料的正确性、完整性及有效性负责。

3.2 甲乙双方应按资料清单进行交接并办理手续。

3.3乙方在加工过程中使用的图样和技术文件应受控并有效。当甲方对技术状态要求变更或协调时，甲方选择以下三种方式之一通知乙方，乙方根据变更内容对实物状态进行核实和落实，并于1天内书面反馈给甲方，由甲方明确处理意见。

三种方式如下：

a、协商修改技术协议；

b、增加工艺状态表；

c、以“技术状态协调单”形式传递书面通知乙方。

3.4 乙方在产品生产过程中，若发现甲方提供的技术文件有不协调或不清楚的情况，应以书面形式向甲方提出。甲方应及时给予书面答复，并作为产品验收的依据。

3.5 乙方完成产品加工后，甲方按文件清单全部收回技术文件。

# 5 产品验收

5.1 乙方锻环生产完工，按要求完成检验、试验合格后，编制锻环首件鉴定质量报告和首件锻环生产质量报告，报告编制完成后，通知甲方及军代室进行下厂预验收，验收通过后召开首件鉴定和首件质量评审会，评审通过后方可交付。产品批次生产完工后，由乙方编写锻环批次生产质量报告并组织批次产品质量评审会。

5.2 产品交付甲方后，甲方还应按要求开展入厂复验，在入厂复验中发现的质量问题，甲方有权拒收。

5.3 甲方在入厂复验和生产过程中发现的锻件本身的质量问题由乙方负责分析原因，制定纠正和纠正措施。

5.4 乙方开具的质量证明文件，应字迹清楚、签署完整。合格证内容包括产品名称、数量、产品编号、材料牌号、材料状态、锻件热处理状态和炉批号。

5.5 产品交付时，乙方应将检测、试验报告复印件和多媒体记录提供甲方。

# 6 质量管理

6.1 乙方应按照甲方提供的图样、技术文件、质量技术协议编制工艺指导文件。

6.2 出现重大质量问题时，乙方应及时通报甲方，甲方有权对乙方的生产工艺、质量控制情况进行审查。

6.3 乙方生产所用的计量器具、设备等，必须进行定期检查、鉴定和校验，并注明有效期。不合格的计量器具、设备不得使用。

6.4 乙方应配备专职检验人员，独立实施检验职能。

6.5 需要时，乙方应配合甲方完成各项质量复查工作。

6.6乙方对在生产中出现的重大质量问题应及时通知甲方，及时查找原因制定纠正措施，并根据甲方要求完成技术分析或归零工作，甲方视情况组织有关人员进行评审。
