# 1 目的

本规程规定了东方电气集团东方锅炉股份有限公司（以下简称 “ 东方锅炉 ” ） 核电采购物项的质量保证要求，确保供方提供的物项满足法规和采购要求。

# 2 范围

本规程适用于东方锅炉核电采购物项供方。根据采购质保等级不同，明确 了不同物项供方质量保证的相关要求。

本程序根据下列文件制订：

# 4 术语

物项：在本规程中指东方锅炉采购的用于核电的材料和零部件。

材料：包括锻件、铸件、钢管、焊材、圆钢、钢板、型钢、油漆等。

零部件：包括辅助设备、配套件、半成品、非标紧固件、标准件、铭牌等。

采购质保等级：为了规范物项采购阶段质保要求，东方锅炉根据设备零件质保等级（如QA1、QA2、QA3、QNC）确定的采购质保分级要求，包括A1、A21、A22、A31和A32共5个等级。

顾客：接受由东方锅炉提供的核安全设备的单位。

供方：按照东方锅炉要求提供物项或服务的个人或单位。

顾客：接受由东方锅炉提供的核安全设备的单位。 供方：按照东方锅炉要求提供物项或服务的个人或单位。 分供方：按照供方要求提供物项或服务的个人或单位。 中间商：指在东方锅炉与供方 / 顾客之间参与物项交易业务，促使采购行为 发生和实现的组织或个人。

中间商：指在东方锅炉与供方/顾客之间参与物项交易业务，促使采购行为发生和实现的组织或个人。

材料评定组织：供方的一种形式，在顾客和东方锅炉监督下，供方通过检 查和试验证明该材料满足东方锅炉采购要求。

造假：在本规定中指供方、分供方及其有关员工，故意违反法规、技术标 准和东方锅炉采购要求，或故意提供不准确和不完整的信息和记录。

二次转包：区别于原材料采购和工序外委的分包活动，指供方将东方锅炉 采购合同物项整体转让给其他单位，或将合同肢解以分包的名义将合同各部分 转让给其他单位，在这种情况下供方实际并未履行合同主体义务。

# 6.11 质量记录

# 6.11.1 质量记录基本要求

6.11.1 质量记录基本要求 质量记录必须字迹清楚，内容完整，并与所对应的物项一致，尤其材料检 查和试验报告应可追溯到材料标识（如炉号、批号等）。质量记录须用合适的 材料制成（譬如使用碳素墨水钢笔和签字笔进行数据记录和签名）。质量记录 只有在注明日期并经授权人员签字、盖章或经过其它鉴定后方能生效。

质量记录需要更改时，为避免原记录在更改之后难以辨认，被更改的内容

<!-- page: 10 -->

应用单线划去，并由供方授权人员签署姓名和日期。质量记录的更改不允许采 取涂改或刮改的方式进行处理。

针对本规程和采购技术规程要求的质量记录，供方负责记录贮存环境的管 理，确保满足防潮、防火、防蛀等要求，并且记录的贮存方式应防止其变质和 便于存取。射线胶片贮存须满足核技术规范要求。

# 6.11.2 完工文件要求

# 6.11.2.1 完工文件记录签署要求

6.11.2.1 完工文件记录签署要求 ①签名要求 ——签署本人姓名（严禁签署其他人员姓名）； ——严禁在可编辑文本上直接粘贴无效电子签名（电子办公系统产生的带 日期的签名视为有效电子签名，必要时书面说明）；

# $ \textcircled{1} $签名要求

一一严禁在可编辑文本上直接粘贴无效电子签名（电子办公系统产生的带日期的签名视为有效电子签名，必要时书面说明）；

# $ \textcircled{2} $日期要求

②日期要求 ——操作完成后，操作者、检查和试验人员应确认各项操作要求均已满足， 并在流转卡或质量计划上签署姓名和当天日期；

——H/W 点签点日期为实际见证日期，R 点签点日期为实际审核日期；

—— H/W 点签点日期为实际见证日期， R 点签点日期为实际审核日期； ——分批或重复执行时，按实际执行日期分批或重复签署，且分批或重新 出具报告；

一一检查/试验日期、报告编制、审核和批准日期须为相应活动实际日期；

# $ \textcircled{3} $划改要求

一一不得刮改、涂改记录，划改时应单杠划去原数据，在附近空白处填写更改后的数据，并签署更改人的姓名和日期。

# 6.11.2.2完工文件自我核查要求

6.11.2.2 完工文件自我核查要求 供方在提交完工文件前，应自我核查、确认是否存在如下现象，如存在， 应组织整改后再提交东方锅炉。

# $ \textcircled{1} $真实性核查

一一冒签字的现象（表现为同一人签名字迹不同）；

一一不规范使用电子签名的现象（如 PS 或粘贴他人签名）；

一一记录刮改、涂改的现象；

一一数据雷同的现象；

一一执行或签字日期与逻辑顺序有悖且无合理说明的现象；

——其他影响质量记录真实性的现象；

# $ \textcircled{2} $规范性核查

一一跟踪质量计划填写不完整的现象（如记录/报告编号未填写、工序出现的NCR编号未填写、表头设置的栏目如质保等级未填写等）；

一一报告留有空白栏，未用单杠划去的现象；

一一页面不清晰、不完整的现象；

——报告留有空白栏，未用单杠划去的现象； ——页面不清晰、不完整的现象； ——物项数量、物项标识在完工文件多处出现，不完全一致的现象； —— NDE 报告中人员资质与要求不符的现象； ——其他不规范的现象。

——NDE报告中人员资质与要求不符的现象；

——其他不规范的现象。
