# 1 范围

1.1 本规程适用于海阳辛安核电项目 1#2# 机组蒸汽发生器给水接管、人孔座、水平支承连接板和套 筒支承板用 18MND5 锻件的采购和验收。

1.2 采购的给水接管、人孔座、水平支承连接板和套筒支承板锻件应满足本规程和第 2 章引用标准 的要求。

1.3 本规程中如存在任何与引用标准相矛盾的地方，供方应向买方提交澄清后方可开始制造。

1.4 除非在本规程中另有说明，采购合同中附加要求或补充协议也适用。

# 3 质量保证

质量保证应满足采购合同质保附件的要求。

# 4 制造

# 4.1 制造技术大纲

制造前供方应编制制造技术大纲，制造技术大纲应符合 RCC-M M2119 第 3.1 节的要求，并经买 方、设计方审查后方可实施。

用于化学成分分析的试样取样阶段和取样位置应在锻件制造技术大纲中说明。

# 4.2 冶炼

钢应在电炉中冶炼，真空脱气，加铝镇静，并控制铝夹杂物以细化晶粒。

# 4.3 锻造

为消除缩孔和主要偏析，钢锭应保证充分的头尾切除率。

钢锭重量和头、尾切除百分比应记录并放入完工文件中。

按照 RCC-M M380 计算的总锻造比应大于 3 ，各部位锻造变形应尽可能均匀。

# 4.4 机加工

# 4.4.1 性能热处理前

性能热处理前，锻件粗加工外形尺寸应尽可能加工到接近交货外形尺寸。锻件粗加工外形尺寸 应在制造大纲中进行详细规定。

# 4.4.2 性能热处理后

性能热处理后，最终超声波检测前，锻件应加工至交货外形。

# 7 取样

# 7.1 产品取样要求

应使热处理轮廓尽量接近产品轮廓。

锻件经性能热处理后再截取试料，试料截取应符合 RCC-M M2119 第 4.2 节规定。水平支承连接 板和套筒支承板锻件还应满足补充要求： X 试料应从代表钢锭头部的位置截取， Y 试料应从代表钢 锭尾部的位置截取。

在截取的试料上，取一部分试料加工成试样，进行本规程表 4 、表 5 和表 6 规定的试验。另一 部分试料应按本规程第 4.5 节的规定进行模拟焊后热处理后，加工成试样进行本规程表 4 、表 5 和表 6 规定力学性能试验以及非金属夹杂物检验、晶粒度检验。

RT NDT 测试和韧脆转变曲线上平台冲击功测试的试样制备应满足 RCC-M M2119 附录 1 的要求， 其余试验的试样制备满足 RCC-M M2119 第 4.2 节的规定。水平支承连接板和套筒支承板锻件还应满 足补充要求：水平支承连接板试样的截取应使试样中与试验有关的部分距任一热处理表面大于或等 于 40mm ，距其他热处理表面大于或等于 60mm ；其中套筒支承板（厚度薄）试样轴线位于二分之一 厚度处，试样有用部分距离其他热处理表面至少一倍厚度。

# 9 母材见证件和焊接见证件

# 9.1 母材见证件

母材见证件应取自性能试验合格的验收试料的余料。母材见证件以性能热处理态交货，尺寸应 满足采购合同的规定。

母材见证件的标识、取向、尺寸、与验收试料的相对位置应在制造大纲中详细规定，并在实际 制造过程中详细记录，该记录应放入产品完工报告中。

# 9.2 焊接见证件

焊接见证件应按以下规定之一选取：

(1) 优先取自相应产品的延长部分；

(2) 取自于产品同炉号的钢锭，与产品相同制造工艺和相同的热处理 ( 相同的保温温度和保温时 间 ) 。

焊接见证件的试验与检验应满足本规程的要求。

# 10 缺陷清除

缺陷部位的清除应按照 RCC-M M2119 第 8 章的要求进行。

打磨缺陷后对零件表面进行磁粉检验，试验方法按照 RCC-M MC5000 要求，验收标准如下：

1) 尺寸大于或等于 1mm 的任一缺陷应予以记录。

2) 以下情况缺陷锻件应予拒收：

- 线性显示；

- 尺寸超过 2mm 的圆形显示；

- 边缘间距小于 3mm 的 3 个或 3 个以上排成行的显示，或边缘间距 3mm 到 6mm ，其分布 长度大于 15mm 的显示。

若两个临近缺陷显示的间距小于较小缺陷显示长度的两倍，则把这两个显示看作一个显示。总

若缺陷位于磁粉不可达区域，可用液体渗透检验代替，试验方法按照 RCC-M MC4000 要求，验 收标准如下：

1) 尺寸大于或等于 1mm 的任一缺陷应予以记录。

2) 以下情况缺陷锻件应予拒收：

- 线性显示；

- 尺寸超过 2mm 的圆形显示；

- 边缘间距小于 3mm 的 3 个或 3 个以上排成行的显示；

# 11 标记

# 11.1 一般要求

应使用既不污染材料也不产生明显加工硬化和缺口效应的方法做标记。

标记应打在零件承载最小的区域，尤其要避开应力集中区、特别是形状突变区。

标记不应影响对无损检验结果的判定。

标记应清晰可见，无损锻件的使用性能。

标记位置满足采购合同和图纸要求，应打在锻件的明显部位。

# 11.2 人员要求

标记操作人员应经过专门的标记技术和方法培训，具备标记操作及起草相应技术文件和报告的 能力。

标记检查应由具有目视检查资格的人员承担。

11.3 应按 RCC-M B1300 的规定对锻件进行标记，同时应满足图纸中要求的标识方法。

标记应使用最小半径为 0.8mm 的低应力冲头在采购图中要求的位置进行标记，除图纸中要求的 标识内容外，应至少包括以下内容：

- 锻件制造厂名称或识别标志；

- 18MND5 ；

- 炉号；

- 锻件编号；

- 水口端和冒口端标识；

- 方位角（如适用）；

<!-- page: 14 -->

- 零件标识 ( 零件图号或标识号 ) ；

- 设备号（ XA1#2# ）。

对于零件标识和设备号除采用冲头打印方式外，应使用油漆再标识一次。

母材见证件和焊接见证件的标记与产品相同，同时母材见证件还应标记母材见证件编号；母材 见证件的方向（ B 侧 /T 侧）。

11.4 制造中锻件的临时标识和转移应满足以下要求：

1 ） 除非特殊情况，制造过程中，材料上原有的全部标记均应进行转移标记；

2 ） 锻件加工为若干个零件时，应增加可表示零件在原锻件中位置的标记，必要时（如环形锻 件切割为弧形板时）应增加方位角标记。

# 12 清洁、包装和运输

交货地点在采购合同中规定。

供方应在发运之前，提交清洁、包装和运输方案给买方审核。

锻件表面无需涂油防护，允许存在轻微浮锈。

# 13 供方应提供的资料

# 13.1 供方应提供给买方确认的文件：

- 制造技术大纲 ( 制造前 ) ；

- 无损检验规程 ( 使用前 ) ；

- 清洁、包装和运输规程 ( 使用前 ) 。

# 13.2 完工文件

完工报告应符合 RCC-M M2119 第 12 章的规定。完工报告应至少包括：

- 熔炼分析和成品分析报告；

- 氢元素含量报告（预备热处理后）

- 锻造记录；

- 热处理记录报告 ( 包括全部热处理记录 ) ；

- 力学性能试验报告；

- 金相检验报告 ( 包括晶粒度和非金属夹杂物 ) ；

- 无损检验报告；

- 尺寸检验报告；

- 母材见证件设置情况 ( 母材见证件的标识、取向和位置 ) ；

<!-- page: 15 -->

- 标识检查报告 ( 包括标识内容、位置和方法 ) ；

- 未曾补焊的声明；

- 澄清和变更及回复 ( 如果有 ) ；

- 不符合项报告 ( 如果有 ) ；

- 已完成的质量计划。

上述报告内容均应包括：

——炉号、批号和部件编号；

——供货商的识别和联系方式；

——采购订单号；

——检验机构的名称（如果有）；

——各种试验的结果，以及相应的要求值。

# 14 验收

按本规程的要求对质量证明文件进行审核，并对锻件外包装进行检查。若外包装破损，则应对 锻件进行表面质量检查。
