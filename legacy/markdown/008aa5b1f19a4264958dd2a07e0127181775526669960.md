# 5 对供应方的停工令管理

# 5.1 由东方武核发出的停工令

当东方武核发现供应方制造活动中出现但不限于下列情况时，东方武核可以下达停工 通知。

 通知点管理不善，出现超越顾客设定的 H 点制造的情况；

 有特殊资格要求的活动由未获得相应资格的人员实施；

 使用未经验证或已知有不可纠正缺陷的设备、材料；

 擅自变更设计文件；

 继续制造将导致重大返工或修理；

 使用未经过批准的工艺文件和作业指导书；

 制造过程中出现重大质量问题或重大质量风险；

 对于重复出现的问题没有采取纠正措施或采取的纠正措施没有效果。

# 5.2 由东方武核传递的停工令

国家核安全监管部门、顾客下达的停工通知，由东方武核传递至供应方。

供应方收到停工通知后，应立即停止相应产品制造，并将产品置于安全状态。未收到 复工通知前，不得开展任何相关工作。

# 7 变更与澄清

# 7.1 术语

设计和工艺变更（ DEN ）：东方武核对供应方发出的对设计和工艺文件进行修改的通 知。

技术变更申请（ TA ）：供应方向东方武核发出的，为了适应供应方某种特殊的资源、 设备制造方法、某些特殊现场条件而对设计文件内容进行技术调整或修改的请求。

技术澄清要求（ CR ）：供应方向东方武核发出的，对技术文件中未作规定或规定不清 楚的技术内容提出进一步说明和澄清的要求。

# 7.2 东方武核向供应方下达的设计和工艺变更

东方武核向供应方下达设计变更有两种形式：

 升版采购技术规格书、图纸或其他设计文件

 发出 “ 设计变更通知单 ”

供应方收到东方武核的技术和工艺变更后，应立即组织评审：

 评审结果为 “ 可实施 ” 时，应修改相应制造工艺文件，确保制造满足技术和工艺变更 后的要求；

 评审结果为 “ 不可实施 ” 时，须在 3 个工作日内向东方武核回复意见并说明原因和处 理建议，由东方武核采购部组织进行协调，其结果有以下三种情况：

 指令供应方实施设计和工艺变更

 修订设计和工艺变更

 撤销设计和工艺变更

# 7.3 供应方向东方武核申请的技术变更

供应方填写 TA 单，通过通信渠道发送至东方武核，东方武核采购部接收、转发技术 部并予以跟踪。东方武核技术部通过 “ 设计和工艺意见反馈单 ” 回答，由采购部发送供应方 执行。

# 7.4 供应方向东方武核提出的设计澄清

供应方填写 CR 单，通过通信渠道发送至东方武核，东方武核采购部接收、转发技术 部并予以跟踪。东方武核技术部通过 “ 设计和工艺意见反馈单 ” 回答，由采购部发送供应方 执行。

# 8 质量保证分级

# 8.1 质量保证分级的目的

为保证物项的设计和建造质量满足预期的功能要求和性能要求，同时达到合理控制质 量成本，以达到节省投资的目的，而对物项 / 服务确定质量保证等级。质量保证等级的高低， 首先要依据物项的安全等级或重要性，其次还要考虑物项的设计、制造、建造的经验以物 项的工艺成熟性、运动部件多寡、供货史、标准化程度等多种因素。

# 8.2 质量保证分级的原则

以物项的失灵或服务中的差错对安全和可利用率所造成的影响为依据，并按照物项和 服务对安全和可利用率的影响程度和重要程度来进行分级控制，原则上，安全等级高和重 要程度高的物项和服务，则质量保证等级高。

# 8.3 质量保证分级的确定

质量保证等级分为 QSA 、 QRA 和 QNA 三类，在 QSA 和 QRA 类中又各分三级，即 QSA1 、 QSA2 、 QSA3 和 QRA1 、 QRA2 、 QRA3 连同 QNA 共 7 级。

具体物项和服务的质量保证分级，由东方武核通过合同或 “ 质量保证分级清单 ” 向供应 方下达。

# 11 文件的版本和状态

供应商需对文件的版本和状态进行定义并标识。

# 11.1 文件版本控制

文件版次使用大写英文字母顺序标识（ A 、 B 、 C ， …… ）表示这些文件的内容尚未固 化、未达到施工应用的要求。文件版次使用数字顺序标识（ 0 、 1 、 2 ， …… ）表示这些文 件属于施工应用文件。文件版次使用字母加数字顺序标识（ A0 、 A1 、 A2 ，……）表示这 些文件属于竣工文件，合同另有约定的执行合同要求。应在文件的“版次”栏或其他规定 的地方标识文件版次信息。

# 11.2 文件状态的定义及标识

文件状态规定了该文件内容的有效程度。通常文件采用下述三种文件状态：

a) PRE （ Preliminary ，试行文件）：这种文件的内容很可能还会变动，而且编制者认为 文件还未最后定稿。该状态可用于作业图的发布，以便客户审查、批准、招投标，这种文 件通常作为施工设计的预备性文件。

b) CFC （ Certified For Construction ，施工文件）：这种文件的内容已为编制者确认有效 并可实施。

c) CAE （ Certified As Executed ，竣工文件）：这种文件的内容完全符合竣工状态。

另外，对于部分仪控供应商产生的文件，可使用 DES （ Descriptive ，描述状态），这种 文件为描述状态，不作为施工执行依据性文件。

文件编制者应在文件的“状态栏”及其他规定的地方标识文件的状态信息。

# 11.3 文件版本和状态的联系

文件版本连同文件状态一起表示工程文件内容的有效性。字母版本标识与 PRE 状态同 时使用，数字版本标识与 CFC 状态同时使用，字母和数字的组合标识与 CAE 状态同时使 用，数字版本标识与 DES 状态同时使用。用法举例如下：

# 12.1 质量计划的编制要求

 所有（含铸锻件、板材、管材、见证件等）和设备的下列活动都应编制质量计划：

—制造、检查、试验、设备运输和装卸等活动；

—由于不符合项的处理导致的修理、返工等活动。

 对于 ASME 规范管辖范围内焊接材料的制造和 / 或复验，应编制质量计划。

# 12.2 质量计划的内容

为证明核安全设备制造中所要达到的质量要求、所需进行的制造、检验及试验等活动 得到定义并执行，而制定的对制造中拟执行的制造、检验及试验等质量相关活动的列表， 即质量计划。

质量计划的内容应包括：

# 质量计划的内容应包括：

a) 封面 ( 包括项目名称 ( 包含机组号、设备名称 ) 、制造单位名称、质量计划名称及内外 部编号、文件编制、审核、批准、状态、版本、日期等 )

b) 引用合同 / 订单和设备技术规格书及版本号

c) 设备名称和编号、零部件名称和图号

d) 炉 / 批号、材质、规格、数量

b) 工序工作内容 ( 包括检查和试验内容 )

# 12.3 质量计划的审查

供应方编制的零部件（含铸锻件、板材、管材、见证件）和设备质量计划，由东方武 核审查后报顾客审查确认。

ASME 规范管辖范围内焊接材料的制造和 / 或复验的质量计划，由东方武核审查后报顾 客审查确认。

由于不符合项的处理导致的修理、返工等活动，需要编制相应的跟踪质量计划，供应 方审查后报顾客审查确认。

500 号令监管目录范围内的物项的质量计划，由供应方编制，东方武核审查，顾客审 查确认。对于民用核安全设备持证单位，由供应方提交国家核安全监管部门备案。具体遵 循国家 500 号令要求。

# 12.4 质量计划检查点设置

制造厂应根据制造工艺，在产品制造前预先制定质量计划，并对质量控制点作出专门 规定，包括应由东方武核见证的 H 、 W 、 R 点，至少包括下述内容：

a) 原材料的无损检测和性能试验；

b) 焊缝 ( 包括硬质合金堆焊层 ) 的无损检测和试验；

c) 热处理；

d) 特殊工艺或关键工序。

# 13 见证管理

检查点：指所制造物项相关方（供应方质量控制部门、东方武核、顾客等）及国家核 安全局在制造过程中设置的希望被通知并进行见证和检查的活动，检查点分为：停工待检

<!-- page: 13 -->

点（ H 点）、现场见证点（ W 点）及记录审查点（ R 点）。

# 13.1 停工待检点（ H 点）

H 点是制造过程中的一项关键工序，供应方应以书面形式提前 32 天 ( 国外 90 天 ) 发出 H 点检查见证通知单，并提前 8 天 ( 国外 14 天 ) 确认。

H 点见证为强制执行，没有顾客或东方武核见证人员的出席或以书面通知放弃该 H 点 的监督，供应方不得进行该点及后续操作。在计划的时间见证人员未到达见证现场，供应 方再次发出通知，并把该点的操作往后推。 H 点放弃通知须纳入完工文件。

# 13.2 现场见证点（ W 点）

W 点是制造过程中的一项关键工序，供应方应以书面形式提前 32 天 ( 国外 90 天 ) 发出 W 点检查见证通知单，并提前 8 天 ( 国外 14 天 ) 确认。

在东方武核未明确表示不出席 W 见证点的情况下，不得执行该工序及后续工序。在已 经发出正确的 W 点通知情况下，而顾客不能在指定的时间出席，工作可以在顾客缺席的情 况下继续进行而不用书面的放弃通知。顾客可以以口头、邮件或书面等形式放弃 W 点。

# 13.3 记录审查点（ R 点）

供应方在工序完成后及时将相关记录和资料 ( 包括制造技术文件、合格证明文件、检查 和试验结果记录等 ) 提交东方武核。

东方武核在确认质量记录达到规定要求后，在相应的质量计划签字，或以函件的形式 予以认可；如果认为设备制造文件或见证记录的内容不符合规定的要求，供应方对相应的 文件进行补充完善。

# 13.4 见证通知单

W 点、 H 点见证通知单内容至少应包括：

 项目名称、机组号；

 采购合同 / 订单号；

 设备、零 / 部件名称或代码；

 质量计划编号、版本及通知单；

 操作类型（包括在质量计划中的顺序编号）；

 执行地点；

 操作日期和时间；

<!-- page: 14 -->

 联系人及联系方式。

见证通知单的格式可按照附录。

# 13.5 W 点和 H 点的放弃

a) 对于 H/W 点，如要放弃见证，东方武核需编制书面放弃函，见证点放弃单格式见 附录。

b) 放弃的 W 点或 H 点，如有相应报告产生，可以转为 R 点进行控制，先决条件检 查、取样等无报告产生的工序除外。

c) 东方武核明确 W 点和 H 点的放弃后，供应方可以独立执行，但供应方应在该 H 、 W 点工序完成后作为 R 点提供相关记录和资料 ( 包括制造技术文件、合格证明文件、 检查和试验结果记录等 ) 供东方武核审查确认，先决条件检查、取样等无报告和记 录产生的工序除外。

d) 东方武核决定放弃的 H 点见证，需以书面形式通知顾客。东方武核明确 W 点和 H 点的放弃后，应通知供应方人员在质量计划中备注“ XX 单位放弃见证”字样和“书 面通知的函号或放弃审批单编号”。

# 13.6 签点日期

a) H 、 W 点见证时，各见证方应先完成质量计划前面 R 点的审查签点，有逻辑关系 的前序 R 点未签，不能执行后续 H 、 W 点工序及见证；无逻辑关系的前序 R 点， 如因报告未出或其它特殊情况，前序 R 点未签可以进行后续 H 、 W 点工序操作和 见证签点，签点时应在 H 、 W 点工序“备注栏”备注“ XX 序 R 点报告未提交审 查”，同时签名及备注日期，日期应为 H 、 W 点见证日期；在后续完成报告审查后， 见证人员应在质量计划对应 R 点栏及时完成签署姓名和日期，日期应为报告审查 完成日期； R 点签署日期不得早于厂家报告审批日期。

b) 完成 H 、 W 点见证并核实相应报告（如有）合格后，在质量计划相应栏签字放行， 原则上，见证点签署日期应为工序执行完成日期。见证点的签点移植时，也应移 植其原始日期。

c) 对 W 、 H 点，供应方见证人员签署的日期应满足不早于工序完成日期（可以是起 止日期）； R 点签署日期应满足不早于报告批准日期；有前后逻辑顺序的工序，前 序签署的日期不晚于后序签署的日期；所有工序签署的日期不得晚于质量计划关

<!-- page: 15 -->

闭日期。

# 13.7 R 点的函审

对于 R 点的签点释放，如果审查不在现场进行，可以通过函件认可形式替代相应质量 计划中的签署。

对于有报告产生的工序，供应方原则上应在该工序完成后的三个工作日之内出具报告。

# 13.8 报告的出具

13.9 对持续时间较长的工序，东方武核质量监督员和顾客监造代表（如有）在该工序 最终完成后，在质量计划上签字确认。

13.10 对于通过多次重复工作完成的工序，应通过多次通知及检查完成，其每一次工作 都应进行记录，在所有工作完成并符合要求后才可以完成该工序的控制点签字。

13.11 对于操作中发生质量问题或见证检查不满意，则问题处理完毕后，质量监督员和 顾客监造代表（如有）认可后方可在质量计划上签字确认。

# 13.12 不符合项

若在工序执行过程中发生不符合项，应将不符合项编号标注在相应工序的“备注”栏 中，原则上相应的 H/W/R 点需要待不符合项报告关闭后方可签署放行（签署日期为执行见 证的日期）；如果产生的 NCR 不能关闭，但不影响本工序其它工作和后续相应工作，可以 在 NCR 工序“备注”栏中备注说明相应情况或注明按已审查通过的 NCR 报告中的限制条 件执行，然后签署放行。通过 NCR 清单跟踪、关闭 NCR 。

见证质量计划关闭或完工报告审查时，存在 NCR 需交付现场验证关闭或在后续工序 进行验证关闭等情况，可以进行有条件签署放行，此时质量计划“备注”栏中备注说明按 已审查通过的 NCR 报告中的限制条件执行，然后签署放行。通过 NCR 清单跟踪、关闭 NCR 。

# 14 不符合项的管理

供应商应制定不符合项控制程序，对各类别的不符合项识别、标识、隔离、评价及处 理的职责、流程及审批权限做出规定，以防止不符合要求的物项被误用、误装或进入下一 道工序。

任何其它文件、记录，如纠正措施要求 (CAR) 、质量观察报告 (OBR) 、会议纪要、设 计变更、技术澄清等，均不能替代不符合项报告 (NCR) 对不符合物项的处理。

<!-- page: 16 -->

NCR 的开启应尽量做到一事一议，针对批量物项不符合的情况，除非在同机组、同 物项类别、同偏差类型及建议处置方案等要素都相同时可放在同一份 NCR 中，否则应针 对上述各不同要素分别开启 NCR 。

# 14.1 不符合项的分类

按照与采购文件要求的符合性，将不符合项分为内部不符合项和外部不符合项：

# 1 ）内部不符合项

未违反东方武核的采购文件或认可的技术文件的要求，仅违反供方内部标准规定要求 的不符合项；或建议处理方式为报废且未进入现场的供方所供物项。

# 2 ）外部不符合项

除供应方内部不符合项以外的所有不符合项。

# 14.2 不符合项的审批权限

对于内部不符合项，由供应方按照内部授权进行审批。

内部不符合项发生后，立即通知东方武核驻厂监督人员 ( 如有 ) ，没有驻厂监督人员的， 3 个工作日内提交东方武核备案。

对于外部不符合项，由供应方提出推荐处置意见，提交东方武核审批，得到书面审批 意见后，方可开展进一步工作。

外部不符合项发生后，立即通知东方武核驻厂监督人员 ( 如有 ) ，没有驻厂监督人员的， 2 个工作日内提交东方武核审批。

# 14.3 不符合项的上报分工

对于民用核安全设备制造许可证持证单位，由供应方按照国核安发【 2016 】 84 号《民 用核安全设备制造阶段不符合项监督管理要求（试行）》上报较大不符合项及重大不符合 项。

对于非民用核安全设备制造许可持证单位，由东方武核按照国核安发【 2016 】 84 号 《民用核安全设备制造阶段不符合项监督管理要求（试行）》要求上报较大不符合项及重 大不符合项。

# 14.4 外部不符合项的验证关闭

当外部不符合项处理完成后：

1 ）对于返工、返修类需提交东方武核验证关闭的 NCR ，应将记录不符合项处置过程

<!-- page: 17 -->

的文件、记录（包括产生实体处置的历史版本）整理后，一起提交东方武核验证；供方关 闭 NCR 后，应将完整关闭的 NCR 提交东方武核备案。

2 ）对于照用类东方武核同意关闭的 NCR ，应将完整关闭的 NCR 提交东方武核备案。

# 15 分包

QSA 级物项未经事先约定或东方武核书面审查认可，供应方不得将下料、机加工外的 任何工序分包。

供应方应建立质量保证程序，根据拟分包物项或服务的质保等级、重要性、复杂程度、 成熟性等，通过拟分包的分供应方质量管理能力、技术能力、商务能力、以往业绩等进行 评价，形成评价报告。

# 17 进入的权利

# 17.1 东方武核、顾客

在正常的工作日，东方武核、顾客代表有权利进入供应方及其下游的各个供应方的制 造场地、办公室进行相关监督、检查或监查活动，范围包括设计、制造、检查及试验、采 购、管理及记录查阅等。供应方应向他们提供必要的信息及协助使其顺利完成活动。买方 的源地见证活动不减轻供应方确保其产品质量合格的责任。

# 17.2 国家核安全监管部门

供应方应提供服务便利，使国家核安全监管部门人员能顺利开展其在供应方场所的相 关监督检查活动。

# 18 防造假

为杜绝设备制造过程中质量造假行为，保证核电产业链的良性发展，原材料、外购件 供应方需建立质量诚信与防范造假的有效措施和奖惩机制，明确防造假管理要求，提出具 体管控目标与措施，确定基本的核查原则与奖惩机制。

原材料、外购件供应方应识别和确认设备制造活动过程中的造假风险，开展防造假警 示教育，制定针对性的防造假管控措施。供应方应将防造假要求向其分供方传递。

供应方必须严格遵守严禁“弄虚作假、违规操作”要求，并将该要求向分供应方逐级 传递。对于制造过程中出现的弄虚作假、违规操作等问题，供应方须在发现后 1 个工作日 内采用书面方式报东方武核。

<!-- page: 19 -->

具体需实施的防造假要求详见附件 4 。

# 19 经验反馈

供应方应建立经验反馈机制，以便将适用的经验教训和良好实践反馈并应用于项目设 备设计、制造、运输等活动，从而达到预防相同或类似问题的发生和持续改进的目的。

在合同的供货范围内，出现下列情况（包括但不限于），供应方应开展经验反馈活动：

a) 发生质量事件或质量事故；

b) 设计失误或缺陷造成设备制造难以进行，从而造成工期延误或增加投资；

c) 重复发生率较高的质量问题或不符合项；

d) 违反十大质量红线（详见附录 6 ）；

e) 顾客进行经验反馈的异常事项或问题；

f) 供应方认为应进行经验反馈的其他异常情况。

# 附录 4 ：

# 供应商防造假管理具体要求

本要求依据东方电气（武汉）核设备有限公司《防造假管理》（DFWH-QA-MH-1401）制 定，适用于为公司提供物项的采购供方、提供工序外包等服务的外包供方（以下统称“供 方”），供方需严格遵照本要求开展防造假相关工作，确保供货及服务过程的真实性、合规 性。

# 一、建立防造假管理机制

1. 采购/外包供方需按公司要求，建立完善自身防造假管理机制，明确防造假工作职责、 流程和管控措施；

2. 采购/外包供方需将防造假管理要求传递至自身下游各级分包方，确保全供货/服务链 条落实防造假管控。

# 二、实体质量及管理行为防造假基本要求

# （一）严禁各类实体质量造假行为

1. 不得擅自更改、伪造与产品质量有直接关系的证明报告，包括但不限于水质报告、设 备精度鉴定报告、试验/检查报告、焊接评定及焊接质量报告、质量证明书等制造完工报 告。

2. 不得向公司提供冒牌产品，或未经公司及顾客同意的贴牌产品。

3. 不得存在产品以次充好、厂家混料/换料等影响产品实体质量的造假行为。

# （二）严禁各类管理造假行为

1. 不得出现冒名顶替签名、印章造假、数据填报造假、事后补填记录等行为。

2. 未出席相关见证点的，不得签署对应报告或记录。

3. 不得伪造供方评价、培训、监督评估等记录，不得虚报质量相关资源和配置。

4. 特种作业人员不得无证上岗，不得违反“三按”作业要求开展生产操作。

5. 不得使用无效、超期的设备、工具、量具进行作业；不得违规处理质量问题，不合格 品未经公司许可不得入库、转序。

6. 发现质量问题后，不得隐瞒不报、不如实报告或不按规定流程报告。

# 三、质量证明文件及检测报告相关防造假工作

# （一）原材料质量证明文件真伪及合规性管控

<!-- page: 25 -->

1. 向公司提交的原材料、外购件质量证明文件需100%保证真实、合规，文件格式统一、 印章清晰可追溯，试验项目完整、结果符合标准及合同要求。

2. 严禁对质量证明文件进行遮挡修改后复印、涂改数据等行为，原则上质量证明文件不 允许涂改，确需修改的需按规范流程执行。

3. 若为经销商/代理商供货，需配合公司完成原材料质量证明文件的真伪核查，确保文件 可追溯、信息真实。

# （二）第三方检测报告真伪及合规性管控

1. 供方自身委托第三方检测机构出具的检测报告，需由供方完成100%真伪核查；向公司 提交的所有第三方检测报告（含分包商提交的），需配合公司完成真伪核查工作。

2. 第三方检测报告相关的检测机构需具备合法有效资质，资质覆盖对应检测项目；报告 公章真实、数据准确，检测工作确已实际开展，严禁资质作假、公章造假、数据造假。

3. 配合公司通过第三方检测机构官网、电话/邮件、供方对接核实等方式核查报告真伪， 按要求提供核实渠道或书面核实结果。

# 四、报告与原始记录一致性核查工作

# （一）自查要求

1. 供方需对自身产生的所有报告与原始记录开展100%一致性自查，报告类型包括但不限 于：产品/原材料质量证明书/合格证、无损检测报告、尺寸检查报告、热处理报告、焊接 记录、水压试验报告、理化试验报告、清洁度检查报告等。

2. 采购供方需按每本质量计划填写一份《报告一致性自查记录表》，外包供方需按每道最 终检验工序填写一份《报告一致性自查记录表》，如实记录核查结果，签字确认并留存。

3. 自查过程中需重点核查以下内容，确保无造假情况：

（1）同一厂家相同类型报告格式一致；

（2）报告内容正确、完整、合理、清晰可读；

（3）报告内容、数据、结论与原始记录完全一致；

（4）同一人出具/签发的不同报告中签名、日期一致；

（5）报告/原始记录划改内容属实、规范，无随意涂改；

（6）质量计划、报告中的签字时间逻辑合理。

4. 对于酸洗钝化报告、标识检查/确认报告、清洁度检查报告、目视检查报告等无原始记

<!-- page: 26 -->

录的报告类型，需通过自身巡检、质量监督等方式保证报告真实性，无需另行开展一致性 自查。

# （二）配合公司核查要求

1. 供方需配合公司质量监督人员、放行检查人员开展报告与原始记录一致性抽查工作， 公司将按每份质量计划/本次放行检查涉及报告的5%比例（向上取整）抽查原始记录。

2. 若公司在抽查中发现疑问，供方需配合开展100%原始记录核查，并按要求提供相关资 料，留存核查记录。

3. 供方需按公司要求，在经核查无误的报告上配合完成盖章、签字等确认工作。

# 五、质量证明文件存疑及问题处置

1. 若供方提交的质量证明文件、第三方检测报告等被公司质疑真实性，或存在文件缺失 情况，供方需配合公司按顾客管理程序要求开启不符合项报告，并按不符合项管理程序完 成处置。

2. 若公司对物项材质存疑，需采用手持式合金分析仪开展实物核查时，供方需配合完成 实物核查工作，提供必要的协助。

3. 对于QNA 级物项的质量证明文件，供方需按要求整理提供，确保文件完整，配合公司 完成存档备案工作。

# 六、培训及人员管理要求

1. 供方需组织参与公司质量安全环保部开展的《防造假管理》程序文件培训宣贯，确保 相关工作人员熟练掌握防造假管理要求，培训每年至少参与一次。

2. 供方需自行组织内部防造假相关培训，覆盖所有相关岗位人员，确保工作人员明确自 身防造假工作职责，杜绝造假行为。

3. 供方需建立人员资质管理台账，特种作业人员、检测人员等关键岗位人员需具备有效 资质证书/授权书，严禁无证上岗，配合公司开展人员资质核查工作。

# 七、造假行为的相关责任

1. 若供方被发现存在质量造假事实，公司将根据《供应商管理办法》三色名单管理规定 进行考核。

2. 供方发生造假或涉嫌造假问题时，需按公司要求暂停相关活动，配合公司质量安全环 保部、采购部/生产制造部开展调查工作，按要求提交相关资料，接受公司的调查处理结

<!-- page: 27 -->

3. 因供方造假行为给公司造成损失的，公司将按合同约定追究供方的相关责任。

# 八、其他要求

1. 供方需按公司要求，在采购/外包合同履行过程中，严格承接公司的防造假管理要求， 确保全流程合规。

2. 供方需配合公司开展的防造假工作检查、考核，按要求整改检查中发现的问题，及时 反馈整改进度和结果。

3. 供方需建立防造假工作台账，记录自身防造假自查、整改、培训等相关信息，台账保 存期限需满足公司合同质保期要求，且不早于项目最终验收证书签字日期。

4. 供方应在办公场所、制造车间等地点的醒目位置张贴造假举报渠道海报。

# 附录 6 ：十大质量红线

# 十大质量红线

# 一、严禁违反/无依据文件作业

释义：本条特指在作业过程中，违反经批准的施工方案/制造大纲、特殊措施和工作程序，或者无依据文件作业，如未按照程序和规程进行检验试验，补焊过程无依据文件。

# 二、严禁违反流程擅自处理质量缺陷

释义：本条特指在作业过程中产生质量缺陷后，有关人员未按规定的流程或未按批准的措施，擅自处理质量缺陷，如违规补焊，且补焊过程没有补焊工艺评定、补焊工艺规程等指导文件。

# 三、严禁质量文件造假

释义：本条特指编造、捏造设计、制造、建造、调试过程中产生的质量文件，或者在质量文件上伪造人员签名、日期，如试验数据造假、篡改原材料质量证明书、出具虚假的无损检验报告、伪造无损检验人员签名、伪造理化检验人员签名。

# 四、严禁人员无证上岗

释义：本条特指需要持证上岗的焊工、焊接操作工以及检查和试验人员，没有取得有效的证书或证书范围不覆盖，如焊工无证上岗、焊工项目资质不覆盖实际焊接活动、无证人员参与PT检验。

# 五、严禁违规分包

释义：本条特指在设计、制造、建造、调试过程中，将某一项活动/工序，违规分包给其他单位，如违规分包无损检验活动、违规分包关键工艺、违规分包设计和制造活动、违规分包冲击试验。

# 六、严禁使用不合格的材料、检查与试验设备

释义：本条特指材料未经验收或验收不合格；检查与试验设备未经标定或标定已过期，标定不符合要求；如使用复验不合格的材料、使用未经标定的检查与试验设备。

# 七、严禁越点作业

释义：本条特指未经验收、验收不合格、见证点（W点）未签字放行即进行下一道工序、停工待检点（H点）未签字放行即进行后续工作。

# 八、严禁未按规定进行技术交底

释义：本条特指在作业活动开始前或过程中，未按规定进行技术交底，如未按规定的时间进行技术交底、参加技术交底的人员不符合规定要求。

# 九、严禁漏报、谎报、瞒报质量事件

释义：本条特指在作业过程中，漏报、谎报和瞒报质量事件，如故意隐瞒质量事件不上报。

# 十、严禁先决条件未放行即开始作业

释义：本条特指某项作业活动开始前，未经先决条件检查放行即开始作业。
