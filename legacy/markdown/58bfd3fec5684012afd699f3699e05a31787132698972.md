# 1 目的

为确保产品的渗透探伤检测的可靠性，由合格的渗透检测人员、使用合格的设备，并按规定的程序、要求及相应的验收准则进行评定，特制订本规程。

# 2. 适用范围

本规程适用于紧凑型聚变能实验装置（BEST）新一代屏蔽用高硼钢的渗透检验。

# 3 参考文件

JY/QD-JS-QC26026 《BEST 屏蔽用高硼钢技术规范》

EN10228-2：2016钢锻件的无损检验一一第2部分：渗透检验

ISO 3452-1 无损检测-渗透检测——第一部分：总则

ISO 3452-2 无损检测-渗透检测——第二部分：材料

ISO 3452-3 无损检测 渗透试块通用规范

ISO 3452-4 无损检测-渗透检测——第四部分：设备

ISO9712《无损检测人员资格鉴定和认证》

以上未注明日期和版本的文件，其最新版本适用于本规程。

# 4检验人员

渗透检测人员应取得ISO9712或甲方认可的标准取得资质等国家或行业认可的Ⅱ级或Ⅱ级以上资格证书，并在有效期内。Ⅱ级或Ⅱ级以上的检测人员才能编制检测规程，规程审核由Ⅲ级人员完成。Ⅱ级或Ⅱ级以上的检测人员完成检测、签发报告、结果评定和解释检测结果。

渗透检测人员在检测时必须持有合格的资格证书，并且在订货方要求时能出示其证书。

# 5 检验区域

除其他文件规定具体的检验部位外，检验区域为工件所有可达表面100%区域，即外表面检测（返修区域，如果有）。

# 6 检验时机

渗透检测一般应在精加工后进行。

<!-- page: 4 -->

# 7 表面准备

检测表面应无铁锈、氧化皮、铁屑、毛刺及其它可能影响检测的表面杂质。除另有规定外，表面粗糙度Ra不得超过6.3μm。

# 8设备和器材

II级无损检测人员按照本规程叙述的条件要求选择材料和工具。

# 8.1 着色检验材料

渗透剂的所有材料应分析残余总量(硫、氟和氯)，渗透材料的氟元素与氯元素最大允许总含量为200ppm，硫的最大允许含量为200ppm。

着色渗透剂：由渗透剂、清洗剂或溶剂和显像剂组成。应按照厂家推荐的同族材料包括渗透剂、清洗剂和显像剂，禁止使用不同厂家、不同类型、污染、变质或过期的探伤剂。不得使用循环使用的渗透材料，渗透材料不得存放于开口容器中。

渗透材料的供应商应提供有害元素证明书，这些证明书应包含产品批号和符合标准ISO 3452的要求。

# 8.2辅助设备

a) 灵敏度试块；

b) 照度计；

c) 温度计；

d) 抹布；

检测温度在 10~50℃之间时，在低于 10℃时采取加热工件的方式，高于 50℃时采取适当方式冷却工件，保证工件表面在检测过程中处于 10-50℃之间，其它温度范围禁止渗透检验操作。灵敏度要达到 NF EN ISO3452-2规定的2级灵敏度水平。

照度计、温度计等测量设备应至少每年校验一次，每当仪器修理以后应校验。如果仪器一年或一年以上不用，应在使用前对仪器进行校验。

为清洗掉多余的渗透剂，所使用的棉质抹布应是干净、无毛屑的材料。

# 9 检验程序

# 9.1 检测灵敏度

新采购的渗透材料入厂时需用 30 μm的1型参考试块确定着色渗透系统的灵敏度，要求试块上条纹显示超过 75%，灵敏度达到2级水平。

<!-- page: 5 -->

每班开始工作时应将ISO3452-3 II型5点试块放在受检区域一起进行渗透操作，试块上5个辐射状裂纹应清晰可辨，否则应停止操作，查明原因后重新检测。

# 9.2 检测温度

渗透材料和被检工件表面的温度在整个检测过程中应保持在 10℃~50℃之间。

# 9.3 预清洗

用丙酮或其溶剂型清洗剂对被检表面进行预清洗，然后用干净不起毛的纸或布擦干。被检表面干燥后再施加渗透剂。在施加渗透剂前，一般采用自然干燥或强制空气干燥，干燥时间不少于2分钟。

# 9.4 施加渗透剂

1、渗透剂采用喷、刷或沉浸的方式均匀的覆盖整个工件表面。

2、渗透剂在整个过程中，工件表面应始终保持润湿状态。

3、渗透剂的最小滞留间为 20 分钟。

# 9.5去除多余渗透剂

溶剂去除时，先用干燥、洁净不脱毛的布或吸湿纸擦拭被检表面，去除绝大部分的多余渗透剂，然后用蘸有清洗剂的不脱毛布或吸湿纸轻擦被检表面，去除残留的多余渗透剂。为避免过清洗，应防止使用过多的清洗剂。不应往复擦拭，不应使用溶剂直接冲洗被检面。

水洗去除时，应先使用清洁和不脱毛的布或纸来擦除工件表面大量的渗透剂，再用蘸少量去离子水的布或纸轻擦，禁止往复擦拭。也可喷水清洗，水压不得大于350KPa，水温不得超过43℃。

用干净、不脱毛的白布擦拭多余渗透剂去除后的表面，观察白布的颜色以判断多余渗透剂去除效果。

要避免过清洗。如出现过清洗，应按本规程重新处理。

多余渗透剂清除后，通常采用自然干燥。多余渗透剂去除后，应尽可能快的对被检表面进行干燥。保持的时间不得少于2分钟，且不大于10分钟。

# 9.6 显像

检测面干燥后，应立即施加显像剂。显像剂使用湿显像剂。使用显像剂前，必须对显像剂进行充分地搅拌或摇动，使其保持悬浮状态，再采用喷的方式均匀地施

<!-- page: 6 -->

加到整个被检表面。

为在被检面上形成一层均匀的显像剂薄膜，应使喷嘴与被检面的距离保持在 300mm 左右。

湿式显像剂的薄膜干了以后，最终解释的显像时间立即开始计算。最长显像时间不超过60分钟。

# 9.7 显示的解释、评定和验收标准

# 9.7.1 解释、评定

最终显示的解释、评定应在施加显像剂后立即开始观察，并应定期持续观察到显像时间结束，此时应对显示进行最终评定。

显示分析、评定时应在检测面上可见光(自然白光或灯光)照度不低于 500lx的条件下进行，并要避免强光和反光。应对光源所采用的技术和光亮水平进行核查，必要时允许使用2~10倍放大镜辅助观察。其结果应有记录且归档。

# 9.7.2 记录及验收标准

II级或III级无损检测人员按本规程对各种显示进行解释和评定。

评定：

（a）当一个线性显示与其它任何线性显示非一直线时，或者两个线性显示同一直线时，但两显示的间距>较长显示长度的五倍时，应为“单个”。

（b）同一直线上的两个(或多个)线性显示，如两显示间的间距≤较长显示长度的五倍时，则按一个连续长度进行评定。此相邻显示的长度为：两显示的远端的距离。

（c）线性显示的累加长度为：参考面积内(148mmX105mm，或=A6纸)，检测到所有线性显示的长度之和。

注：线性显示为：显示的长宽比>3。

（d）圆形显示为：显示的长宽比≤3。

（e）由于被检件的几何形状(截面或槽的变化等)，或表面光洁度(伤痕或加工痕迹等)，导致的错误显示，不予考虑。

# 9.7.3 返修

缺陷返修后，应按本规程对返修区域进行渗透检测。

# 9.8 后清洗

评定、记录和解释完成之后，应立即将被检面上的渗透材料清洗掉。应采用不伤害工件的合适的清洗方法进行清洗，比如用浸有溶剂的抹布或去离子水的纸或无落絮的布进行擦试。

# 10检验报告

报告应包含下述内容：

（1）制造商标识号；

（2）合同号；

（3）材料牌号（包括类别，铁素体或奥氏体钢）和厚度；

（4）加工工艺；

<!-- page: 8 -->

（5）检测时机；

（6）检验规程和验收标准；

（7）渗透材料的类型、型号、批号和品牌；

（8）显示的示意图；

（9）光照设备和测温设备；

（10）照明类型；

（11）工件温度；

（12）检测人员签字；

（13）检验日期。
