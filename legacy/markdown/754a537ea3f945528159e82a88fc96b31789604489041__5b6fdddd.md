# 1 主题内容与适用范围

本技术条件规定了同步自动离合器齿部件、轴类、螺栓类等锻件技术要求。

本技术条件适用于25Cr2MoVA、40CrNiMoA、18Cr2Ni4WA调质钢锻件的制造与验收。

# 6. 技术要求

# 6.1 制造

# 6.1.1 冶炼和浇注

（1）锻件用钢应采用电炉冶炼和钢包精炼工艺，经需方同意也可采用保证质量的其他方法冶炼。

（2）钢水在浇注中应进行真空处理，以去除有害气体，特别是氢在真空处理的过程中，真空系统的能力必须大到在开浇后的两分钟内就能将初始增高的压强降至低值，通常应低于133Pa。

# 6.1.2 锻造

（1）钢锭上部和下部均应有足够的切除量，以确保成品锻件无缩孔、疏松、严重的偏析和其它有害缺陷。

（2）采用的锻造方法必须尽可能使整体锻件得到均匀的组织结构。锻压机应有足够的吨位，以使锻件的整个截面锻透。锻件的轴线应与钢锭的中心线大致重合。

（3）锻件应有足够的锻造比，总锻造比至少不小于3；对于连铸材料，最小锻造比为5。

（4）锻件不得有过烧现象，保证组织均匀，不允许存在裂纹、白点、缩孔等缺陷。

2

<!-- page: 5 -->

（5）锻件应在具有足够能量的设备上进行，保证整个截面锻透。

# 6.1.3 热处理

（1）锻后进行正火处理，正火后应回火，随后应空冷或炉冷。

# （2）性能热处理

锻件在第一次粗加工后进行调质处理，轴类及轴齿轮锻件应在垂直状态下进行性能热处理。

# （3）去应力处理

锻件在性能热处理后及随后的粗加工和打中心孔后，锻件应在低于最终回火温度15-20℃下去除应力。

（4）半精工后精加工前去应力处理。

# 6.1.4 机械加工

（1）锻件在性能热处理前对所有外表面进行第一次粗加工。

# （2）第二次机械加工

锻件在性能热处理后去应力处理前进行第二次粗加工，带中心孔的锻件按需方订货图样规定尺寸和公差打中心孔(留出中心孔精镗余量)。

（3）锻件去除应力后加工至订货图样规定尺寸、公差和粗糙度要求。带中心孔的锻件按6.2.5第（2）条规定的形位公差要求精镗中心孔，并用不掩盖缺陷的方法研磨或抛光中心孔表面，使表面粗糙度Ra值为1.6μm。

（4）供方在锻件制造和包装过程中不得进行焊接。

# （5）硬度检验

锻件靠近两端外圆柱表面上及锻件中间外圆的三截面每隔 90° 打一点硬度，总计12点。每截面4点硬度差不超过30HB。轴向硬度差不超过40HB。

磁粉检验按 JB/ZQ6101 标准规定的方法进行检验。

a) 齿面不得有任何显示表面缺陷和表皮下缺陷的磁痕。

b. 单个分散的缺陷定义为：相邻两缺陷之间距离大于其中较大缺陷当量直径的10倍以上的缺陷。

c. 不允许存在当量直径大于 $ \phi 2. 0 \mathrm{m m} $的任何缺陷。分散的当量直径 $ \phi 1. 2 \sim $ $ \phi 2. 0 \mathrm{m m} $的所有缺陷均应记录其轴向、径向和周向位置并报告给需方。

d. 不得有任何密集缺陷区。

e. 由缺陷引起底波衰减损失达3dB时应记录并报告给需方。

f. 不允许有游动信号和条状缺陷信号。

g. 当锻件的超声波探伤结果超出上述规定时，应由供需双方进行复验和讨论，但锻件是否可判合格应由需方判定。

当量直径 $ \phi 2 \mathrm{mm} $以下的单个分散缺陷可不计，但杂波高度应低于当量直径 $ \phi 2 \mathrm{mm} $幅度的 50%。

不允许有密集缺陷区存在。

晶粒度检验按 GB6394 的规定进行，锻件平均晶粒度不应粗于 4 级。

非金属夹杂物检验按GB10561附录A图1进行评定，锻件的A、B、C、D四种类型夹杂物均不应超过3级。
