# 受控

# TC4钛合金机匣用锻制棒材规范

# 1 范围

本文件规定了 TC4 钛合金桦材的要求、质量保证规定、交货准备、说明事项等。

本文件适用于直径150mm～450mm的TC4钛合金锻制棒材（以下简称棒材）。

# 3 要求

# 3.1 原材料

3.1.1 原材料供应商控制应符合 AEMQ21 的要求。

3.1.2 原材料质量控制应符合AETM1的要求。

3.1.3 用于制造棒材的铸锭应采用多次重熔工艺，熔炼采用真空自耗电弧炉熔炼，熔炼次数应不少于 2次。最后一次真空自耗电弧炉熔炼稳定阶段的压强应不大于 5Pa。

3.1.4 自耗电极不应使用钨极氩弧焊焊接。

# 3.2 制造方法

棒材采用铸锭经锻制成形，且最终在 $ \alpha+\beta $区锻制成形。

# 3.3 制造方法

棒材以热加工状态（R）并经车光或磨光交付，棒材表面粗糙度应需满足超声检测需求，Ra值一般不大于3.2μm。

# 3.5 力学性能

# 3.5.1 通则

从交货状态棒材切取厚度不小于 30mm的棒材，经热处理后制成试样进行力学性能测试。

热处理制度：退火：（700～800） $ ^{\circ} \mathrm{C} \pm 1 0^{\circ} \mathrm{C} $ ，1h～2h，空冷。

经需方同意，也可采用固溶时效热处理，热处理制度如下：

a）固溶：β转变温度以下（20~60） $ ^{\circ} \mathrm{C} \pm 1 0^{\circ} \mathrm{C} $ ，保温1h，水冷：

b）时效：（650～750）℃±10℃，保温2h，空冷。

注：加热温度中的“±10℃”表示热处理加热炉的炉温均匀性不超过±10℃。

# 3.6 低倍组织

3.6.1 棒材低倍受检面上，不应存在目视可见的清晰晶粒、裂纹、缩孔、气孔、折叠、夹杂物、偏析及其他影响使用的缺陷。

3. 6. 2 棒材低倍组织见附录A，应符合图A.1的1~9级。

# 3.7 显微组织

3.7.1 经热处理后，从棒材上切取的显微组织应为 $ \alpha+\beta $区加工组织，主要为在 $ \beta $转变组织的基体上分布着等轴和（或）拉长的初生 $ \alpha $相，所有原始 $ \beta $品界应充分破碎，在原始 $ \beta $品界上没有连续网状的 $ \alpha $相。

3.7.2 棒材显微组织见附录B，应符合图B.1的1～8级。

# 3.8 β转变温度

棒材应按烙炼炉号提供β转变温度，供方应在质量证明书中注明。

# 3.9 超声检测

棒材应按GB/T 5193进行超声检测，验收标准为：

a）棒材尺寸≥150mm-350mm，缺陷显示不超过 $ \phi 2.0 \mathrm{mm} $当量平底孔，杂波不超过 $ \phi 2.0 \mathrm{mm}-6 \mathrm{dB} $：

b）棒材尺寸≥350mm~450mm，缺陷显示不超过 $ \phi 3. 2 \mathrm{mm} $当量平底孔，杂波不超过 $ \phi 3. 2 \mathrm{mm}-6 \mathrm{dB}。 $

# 3.10 尺寸和外形

3.10.1 棒材直径允许偏差应不大于±2%。

3.10.2 棒材的定尺或倍尺长度应在其不定尺长度范围内，定尺长度的允许偏差为+15mm。倍尺长度还应计入产品切断时的切口量，每一切口量为5mm。

3.10.3 棒材端面应切平整，切斜应不大于5mm。

3.10.4 棒材的弯曲度应不大于5mm/m。

# 3.11 外观质量

3.11.1 棒材表面不允许有裂纹、折痕、重皮、缩尾及其他冶金缺陷。

3.11.2 棒材表面的局部缺陷应予以清除，清除深度不应超过其直径的允许偏差，清除宽度与深度之比应大于10：1。

3.11.3 榫材表面可存在个别细小的疤痕、印痕、啃伤、麻点和划痕，但不应超出榫材的最小允许尺寸。

# 3.12 产品标识

桦材标识应包括下列内容：

a）材料牌号：

b）规格；

c）供应状态：

d）熔炼炉号、批号；

e）锭节号。

# 4.4 判定与复验规则

4.4.1 化学成分分析结果不合格时，该炉批判为不合格。

4.4.2 力学性能检验结果不合格时，允许从该批棒材中切取双倍数量试样进行不合格项目的重复试验：重复试验不合格，该批棒材判为不合格。允许对该批棒材进行重复热处理后，重新提交验收，若仍不合格，则该批棒材判为不合格。重复热处理只允许进行一次。

4.4.3 对低倍组织中，若发现并判为有脆性偏析（其硬度明显高于基体的偏析，常见的如富氧、富氮等偏析），该批桦材判为不合格；若判为有非脆性偏析，允许切除后重新组批提交验收。

4.4.4 显微组织检验不合格，允许承制方调整热处理后重新试验，若重复试验结果仍不合格，则该批桦材判为不合格。

4.4.5 超声检验、尺寸、外形或外观质量检验不合格时，该根棒材判为不合格。

4.4.6 产品标识不合格时，允许重新进行标识。
