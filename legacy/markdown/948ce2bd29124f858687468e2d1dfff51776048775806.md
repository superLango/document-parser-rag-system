# 1. 范围

本技术条件规定了国和一号（CAP1400）山东莱阳核电项目5、6号机组堆内构 件压紧弹性环用SA-182 F6NM马氏体不锈钢锻件无损检测必须满足的技术条件。

本技术条件可作为采购方在订货和验收时要求无损检测的依据，也作为制造 方编写无损检测规程的依据。

本技术条件规定了超声检测、液体渗透检测的方法和质量验收标准。

# 2. 引用文件和标准

下列标准和文件的有关条款，通过本技术条件的引用而成为本技术条件的条 款。未注明日期的标准，其最新版本适用于本技术文件。

 GPR-NDE-V7-001 无损检测一般要求

 GPR-NDE-V7-012 马氏体不锈钢锻件无损检测技术条件

 ASMEBPVC 第III卷（2021版）核设施部件建造规则

 ASMEBPVC 第V卷（2021版）无损检测

 JB/T6064 无损检测 渗透试块通用规范

 生态环境部令第6号 民用核安全设备无损检验人员资格管理规定

 国核安函[2019]102号 《关于民用核安全设备特种工艺人员资格管理有关事项的通知》

# 3. 总体要求

# 3.1 人员资格

所有无损检验都必须由持有与其从事的检验方法相应的有效资格证书的检验 人员执行。

 对于原材料的采购：

1 属于国家核安全监管部门监管范围的原材料，其供应商从事无损检验 的人员必须按中华人民共和国生态环境部令第6号的规定，取得Ⅱ级 或Ⅱ级以上资格证书，并在有效期内；

2 不属于国家核安全监管部门监管范围的原材料，其供应商从事无损检 验的人员可以按相关规定获取TSG Z8001（特种设备）、或SNT-TC-1A （ASME）、或EN ISO 9712（EN/ICNDT证）、或GB/T 9445/ EN ISO 9712（中国无损检测学会）等国家或行业认可的质量保证体系的II级 或II级以上资格证书，并在有效期内。

 Ⅱ级或Ⅱ级以上的检测人员才能编制检测规程、独立完成检测、签发报

# 3.2 检测规程

制造厂、装配厂或安装单位都应制定书面的检测规程。检测规程应当满足本 技术条件的要求，并征得采购方的书面认可后才能实施。

检测规程应对使用的设备、检测工艺以及检测参数作具体描述，检测人员应 按照检测规程执行检测。

# 4. 超声检测

# 4.1 检测规程

检测规程应至少包括以下内容：

a) 被检材料类型和几何形状，包括厚度、尺寸和产品形式；

b) 参考文件；

c) 检测时机及表面状态；

d) 超声仪器的型号，探头的类型、频率及尺寸；

e) 耦合剂名称、型号；

f) 检测技术 ( 直射波、斜射波、接触法和/或液浸法等)；

g) 检测表面、检测方向和检测范围；

h) 声波在工件中传播的角度和波型；

i) 探头的类型、频率及尺寸；

j) 专用探头、楔块，衬垫或鞍座（使用时）；

k) 标准试块和/或参考试块；

l) 灵敏度校准方法的详细描述；

m) 扫查方向和范围；

n) 要记录的数据以及记录方法；

p) 验收标准；

q) 检测人员资格；

i) 检测报告的格式和说明。

# 4.2 表面要求

被检锻件的表面粗糙度应不大于6.3 µ m , 表面不应存在可能干扰检测实施或 检测结果解释的松散氧化皮、油漆或污物等。

# 4.3 检测时机

除其他设计文件中有规定外，超声检测一般应在改善机械性能的热处理（不 包括消除应力的处理）之后，精加工之前进行。

# 4.4 检测设备

# 4 . 4. 1 检测仪器

应使用A型脉冲反射式超声波探伤仪，仪器能覆盖的工作频率范围至少应为 1 ~5MHz 。

检测设备性能除应符合ASME BPVC 第V卷第5章T-561的要求，另补充要求如 下：

仪器的示波屏高度方向的线性（即垂直线性）误差在示波屏满幅度80 % 范围内 不超过满屏 ±5% ；仪器的水平线性误差不超过1 % 。

每台仪器在下述情况需要进行上述校验：

 仪器验收时；

 修理后；

 在每次持续使用周期的开始或每隔3个月（两者取短者）。

# 4 . 4.2 探头

探头可以采用单晶片或双晶片。直探头的晶片边长或直径最小为10mm，最大 为30mm。斜探头的晶片尺寸边长最小为8mm, 最大为25mm。应选用频率为2MHz 及

以上的探头。斜探头的角度应采用 45º 。

# 4.4 .3 耦合剂

应采用具有良好润湿性能的耦合剂，且应按下列要求控制耦合剂中的污染 物：

— 马氏体不锈钢上使用的耦合剂卤素（氟和氯）的总含量不应大于250ppm。

检测系统校准和检测时应采用同样的耦合剂。

# 4.4.4 参考试块

# 4.4.4.1 参考试块的材料

参考试块的材料可以是：

 被检部件的延长段；

 材料牌号和热处理状态与被检部件相同的余料；

 声学特性与被检部将相近的材料。

# 4.4.4 .2 参考试块表面曲率

可使用曲面参考试块或平面参考试块。如使用曲面参考试块，被检工件的表 面曲率应在参考试块表面曲率的0.9 ~ 1.5倍范围内。

# 4.4.4 .3 参考试块表面要求

参考试块的表面粗糙度应与被检部件相当，但不能优于被检件，否则应进行 表面补偿。

# 4.4.4 . 4 参考反射体

直射波检测用的参考试块为一系列具有不同声程的平底孔试块，参考试块上 的平底孔直径分别为4mm和2mm。

斜射波检测用参考试块上应带有内外表面参考切槽，切槽的深度应为锻件最 终订货要求的最小壁厚的3%或6mm (取较小者），槽长大约为25mm，槽的宽深比一 般不大于2。

# 4.4.5 检测系统校准和校验

检测灵敏度校准时的配置和耦合状况应与实际检测工况一致。

在以下情况下需要对检测系统进行校验：

 每次检测工作开始和结束时；

 连续操作最大4小时；

 更换操作人员时；

 任何时间检测人员对检测系统的有效性存在怀疑时。

校验时，距离范围上任一点在扫描线上的偏差大于距离范围读数的10％或全

扫描线的5%（取大者），则应对距离范围进行校正，并在检测记录上注明这种校 正。上次有效校验以来所有记录的信号应重新检测，并在数据表上修改记录的数 值。

校验时，若发现灵敏度降低超过20％或2dB，则要重新按规定进行校准，并对 上次校验以来所检测的所有工件重新进行检测：若灵敏度增加超过20％或2dB，则 要重新按规定进行校准，并对所有记录信号重新进行检测，并根据重新检测结果 修改记录或重新记录。

# 4.5 检测技术

# 4.5 .1 检测方法

锻件的超声检测方法可以是接触法或液浸法。采用接触法检测时，校验试块 和被检面的温度差不得超过14 ℃ 。采用水浸法检测时，校验时的耦合剂与检验时 的耦合剂温度差不得超过14 ℃ 。

# 4.5 .2 扫查方法

直射波应分别从径向和侧面扫查到锻件的整个体积。斜射波应沿周向进行正 反两个方向的扫查。

# 4.5.3 扫查速度

探头扫查速度应不大于 150mm/s 。

为了保证整个锻件体积都能被检测到，探头的相邻两次扫查路径至少应有15% 的覆盖率。

# 4.5 . 4 检测灵敏度

直射波检测时，利用试块上不同深度的 Φ 4mm平底孔和 Φ 2mm平底孔制作DAC 曲 线，DAC曲线上至少应有3点，DAC曲线即为基准灵敏度。

斜射波检测时，利用参考试块上的内外表面切槽制作DAC曲线，以此作为基准 灵敏度。

所有DAC曲线第一点之前的范围用水平直线延伸，最后一点之后的范围用该点 的切线延伸，直至覆盖整个检测范围。

扫查灵敏度应不低于记录灵敏度。

# 4.6 缺陷记录及验收准则

# 4.6 .1 缺陷记录

锻件检测时应记录以下信号：

a) 直射波检测时，所有等于或大于 Φ 2mm平底孔当量的缺陷信号；

b) 斜射波检测时，所有达到或超过50%基准灵敏度的缺陷信号；

<!-- page: 9 -->

c) 裂纹等危险性缺陷。

检测时，如从锻件一个检测面发现记录性缺陷时，如条件允许，需从相对的 另一个检测面进行检测，并以较严重的结果作为最终评定依据。

应记录缺陷的位置、幅度和长度等参数。

缺陷长度的测量方法为 -6dB 法。

# 4.6 .2 验收准则

a) 不允许存在危险性缺陷，如裂纹等；

b) 直射波检测时，任何回波幅度等于或大于4mm直径平底孔当量单个缺陷信号 都不予验收；

c) 直射波检测时，在边长为50mm或更小的立方体内存在5个或5个以上达到记 录水平的缺陷时，锻件不予验收；

d) 斜射波检测时，任何回波幅度等于或大于参考切槽回波幅度的缺陷都不予 验收。

# 4.7 超声检测报告

检测报告应至少包括以下各项：

a) 制造厂商的名称或代号；

b) 被检工件的图号、名称、编号和材料牌号；

c) 检测规程及版本；

d) 检测时机；

e) 表面状态；

f) 所使用的仪器型号及编号；

g) 所使用的探头型号，尺寸、频率；

h) 耦合剂的类型；

i) 检测方法，包括检测灵敏度的标定（所使用的参考试块的编号），扫查方 向，范围以及被检锻件的外形图；

j) 检测结果，包括所有应予以记录的缺陷信号幅度、深度、尺寸以及沿轴 向、径向和周向的分布情况；

k) 检测日期；

l) 检测人员签名及其资格。

# 5.2 表面要求

检测前，检测人员应对被检表面作外观检查，被检表面及相邻至少 25mm 范围 的区域不应有任何污垢、油脂、纤维屑、锈皮、焊渣、焊接飞溅物、油或其他有 碍检测的物质。

被检表面的粗糙度 Ra 不应超过 6.3μm 。

# 5 .3 检测时机和检测范围

除其他设计文件中有规定外，液体渗透检测应在热处理并加工至交货尺寸后 进行。

检测范围应符合上游相关技术文件的规定。

检测区域应包括 100% 外表面和可达到的内表面。

# 5 .4 检测设备和材料

# 5.4.1 渗透材料

渗透材料指检测过程中所使用到的所有渗透剂、溶剂或清洗剂、显像剂。不 允许将不同种类或不同制造厂生产的渗透材料相互混用。

除其他设计文件中有规定外，对用于镍基合金、奥氏体不锈钢、双相不锈钢 以及钛材料，一定量渗透检测剂蒸发后，残渣中的有害元素氟、氯的总含量的重 量比不得超过0.1%，硫的含量的重量比不得超过0.1%，其他有害元素含量限值应 按照相关技术文件的要求执行。每批渗透材料应有有害元素的分析报告，分析报 告中应包括渗透材料生产厂、产品型号及批号、分析方法及结果，这些分析报告 应妥善保存。

所使用的渗透材料应在保质期内，必须有供应商提供的合格证。

对用于预清洗或者过程中所使用的水，有害元素含量应符合上述的要求。

# 5.4.2 对比试块

检测温度在5 ℃~52℃ 之间时，使用 JB/T 6064 规定的三点式 B 型试块校验渗透 检测剂系统灵敏度及操作工艺正确性。

检测温度超过5 ℃~52℃ 范围时，应使用 JB/T 6064 规定的 A 型试块对检测工艺 进行鉴定。

# 5.4.3 辅助工具

应使用干净不脱毛的白纸或布，必要时可使用2~10倍放大镜。

# 5.5 设备校准

# 5.5.1 照度计

照度计应每年校验一次或当照度计有要求时随时校准。

# 5.5.2 温度计

测量被检区表面的温度计应每年校验一次或当有要求时随时校准。

# 5.6 检测技术要求

# 5.6.1 渗透检测方法

采用溶剂去除型着色法。

# 5.6.2 检测灵敏度

每班开始工作时以及更换渗透材料（包括不同牌号、批次等）应将 B 型对比试 块放在受检区域一起进行渗透操作，试块上 3 个辐射状裂纹应清晰可辨，否则应停 止操作，查明原因后重新检测。

# 5.6.3 检测温度

渗透剂和被检工件表面的温度在整个检测过程应保持在5 ℃~52℃ 范围内。对 于超出该温度范围的检测，应采用 A 型对比试块对该方法做鉴定，以证明能达到同 样的检测结果后方可采用。

# 5.7 渗透检测方法

# 5.7.1 预清洗

所有要检验的工件或工件的有关部位，均必须在施加渗透剂之前进行清洗和 干燥。局部检验时，准备工作范围应从检验部位四周向外扩展 25mm 。

# 5.7.2 预清洗后的干燥

在预清洗之后，被检表面的干燥应采用常规蒸发；可用不脱毛的布擦拭、采 用吸水纸吸干、吹以热风或冷风来完成，应确保完全干燥。

干燥的最小时间间隔，应能保证在施加渗透剂之前使溶剂全部蒸发掉。

# 5.7.3 施加渗透剂

施加渗透剂可采取浸渍、刷涂或喷涂的方法。渗透剂在渗透过程中，工件表 面应始终保持润湿状态。如果渗透剂一旦变干，则应从预清洗开始重新进行渗透 检测。

在10 ℃≤ T ≤ 52 ℃ (T为工件表面温度)的条件下，渗透时间应至少10分钟。在 5 ℃≤ T<10 ℃ (T为工件表面温度)的条件下，渗透时间应至少20分钟。在任何检测温 度下，渗透剂的最长滞留时间不得超过 2 小时。

# 5.7.4 多余渗透剂的去除

渗透结束后，多余渗透剂应使用清洁、不起毛的布或纸来擦除，再用蘸少量 清洗剂的布或纸轻擦，但禁止用清洗剂直接冲洗工件表面。使用的清洗剂必须是 由液体渗透剂制造商推荐的渗透剂中的一种。

多余渗透剂去除后，工件应在常温下自然蒸发干燥。

干燥时间应根据干燥类型和工件尺寸、特性、形状及数量等因素确定，干燥 时间不应超过30分钟。

# 5 . 7 .5 显像

当多余渗透剂被去除后，经干燥应立即进行显像，显像剂使用湿式显像剂， 采用喷洒的方法均匀施加到整个被检表面。湿显像剂一干，显像时间即开始。

# 5.7.6 观察

缺陷显示痕迹应在施加显像剂后的10至 60 分钟内观察，并作出最终判断。被 检表面光照度应不低于 10 76 lx 。

# 5.7. 7 后清洗

检测结束后，应根据检测规程的说明，尽快对被检工件和检测现场进行清洁 和整理，以便不对工件造成危害。

# 5.8 缺陷评定及验收标准

# 5.8.1 缺陷的评定

a) 显示痕迹包括相关显示（即缺陷显示）和非相关显示，非相关显示不作为 合格与否的评定依据。

b) 凡超过5.8.2节规定的任何显示痕迹，必须用相同方法复验，必要时可采 用其他无损检测方法，以确定是否存在真正的缺陷。复检前可先进行表面修磨， 凡是掩盖缺陷显示的非相关显示，以及大面积渗透着色区，则为不合格。

c) 相关显示包括线性显示和圆形显示。线性显示是指长度大于宽度三倍的显 示。圆形显示是指圆形的或长度不大于宽度的三倍的椭圆形显示。

# 5.8.2 验收标准

除其他设计文件和图纸有规定外，应按下述要求验收：

a) 凡主要尺寸大于 1. 5 mm 的相关显示均应记录。

b) 不允许存在下列相关显示：

 任何裂纹等危险性缺陷；

 凡长度大于下列规定的线性显示：

—当材料厚度小于16mm时，长度大于1.5mm的线性显示；

—当材料厚度为16mm到50mm时，长度大于3mm的线性显示；

—当材料厚度大于或等于50mm时，长度大于5mm的线性显示。

 凡尺寸大于下列规定的圆形显示：

—当材料厚度小于16mm时，尺寸大于3mm的圆形显示；

—当材料厚度大于或等于16mm时，尺寸大于5mm的圆形显示。

 在一条直线上有4个或4个以上，且边缘间距不大于1.5mm的相关显示；

 在相关显示最密集部位的任意一个面积为4000mm 2 （长径不大于150mm）的矩 形区域内，有10个或10个以上的相关显示。
