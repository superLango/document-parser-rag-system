# 优质GH4169合金高强环形锻件规范

# 1. 范围

本标准规定了优质GH4169合金高强环形锻件的要求、质量保证、包装、运输和贮存等。本标准适用于涡扇-19发动机机匣零件用优质GH4169合金高强环形锻件（以下简称锻件）

# 3. 要求

3.1 锻件用原材料

<!-- page: 4 -->

# Q/S19.4019-2018

# 3.1.1 冶炼方法

合金采用下列冶炼方法生产，所采用的冶炼方法应在合同和质量证明书中注明：

a) 真空感应熔炼加真空电弧炉重熔；

b) 真空感应熔炼加真空电弧炉重熔加电渣重熔（氩气保护）；

c) 真空感应熔炼加电渣重熔加真空电弧炉重熔。

# 3.1.2 复验

锻件用原材料应按Q/S19.4011复验合格后方可投产。

3.3 加工方法
锻件采用轧制工艺制备，锻件最后一火的锻造加热温度应不高于1030℃。

3.4 交货状态

# 3.4 交货状态

3.4.1 锻件按以下状态之一交付，交货状态应在合同和质量证明书中注明：

-A状态：固溶处理；

——B状态；固溶处理加时效处理。

3.4.2 热处理制度如下：

固溶处理：950℃~980℃范围内选定温度下±10℃，保温1h，空冷或更快速率冷却；

一时效处理：720℃±10℃，保温8h，以（50±10）℃/h速率炉冷至620℃±10℃，保温8h，空冷。

注：加热温度为金属实际达到的温度，保温时间为锻件最大截面热透后开始计算的时间。实际热处理制度应在质量证明书中注明。

# 3.6 低倍组织

3.6.1 从锻件或试验环上切取的横向（经过锻件轴线所在面的剖面）低倍试样上，不应有目视可见的疏松、针孔、裂纹、缩孔、偏析、夹杂和夹渣等冶金缺陷。

3.6.2 从以B状态交货的锻件或试验环上切取横向低倍试样，从以A状态交货的锻件或试验环上切取横向低倍试样经3.4.2时效处理后，检查暗腐蚀区、白斑或浅腐蚀区，按Q/S10-0102执行验收。

# 3.7 高倍组织

# 3.7.1. 晶粒度

从以B状态交货的锻件或试验环上切取试样，从以A状态交货的锻件或试验环上切取试样经3.4.2时效处理后，测定径、轴两面的平均晶粒度，应为4级或更细，允许存在个别2级晶粒，不允许存在晶粒度级差大于4级的混晶和“项链晶”组织，典型的不可接受的项链晶组织示意图如图1所示。

# 3.7.2 显微组织

从以B状态交货的锻件或试验环上切取试样，从以A状态交货的锻件或试验环上切取试样经3.4.2时效处理后，检验径、轴两面的显微组织，应符合Q/S10-0102的规定。

# 3.8 超声波检验

锻件应逐件按 Q/S10-0104 进行超声波检验，缺陷显示的波幅应不大于直径 1.5mm 当量平底孔所显示的波幅。

# 3.9 尺寸外形

锻件的形状、尺寸和公差应符合供需双方签定的图样的规定。

# 3.10 外观质量

锻件的表面不允许有过烧裂纹和影响材质的其他缺陷，发现后锻件应予报废。其他表面缺陷参照GJB5040的规定。

# 4. 质量保证规定

4.1 质量控制

# 4.1 质量控制

4.1.1 锻件在试制、转厂或改变主导工艺时应按HB5402的要求重新进行鉴定、定型，然后方可投入批生产。

4.1.2 锻件主导工艺过程的生产条件应按 GJB904A 进行准备和控制。

4.1.3 当供方生产工艺有重大改变时，应预先争得需方技术主管部门的同意，并根据需要进行全面性能和工艺试验，其冶金质量不能低于定型批质量水平；必要时，需方可查看供方的制造生产工艺和本标准所需求的各项试验结果，但应予保密。

4.1.4凡经机械加工后发现有不符合本标准规定的冶金缺陷，需方可以退货，必要时供需双方均可查看对方的生产工艺，但双方应予保密。

4.2 质量一致性检验

4.2.1 组批规则

锻件应成批提交验收。每批应由同一图号、同一烙炼炉号（母炉号组批，子炉号管理）、同一投产批和同一热处理炉批的锻件组成。

# 4.2.2 检验项目

4.2.2.3 锻件的取样部位按锻件图或专用技术文件的规定执行。

4.2.3 判定与复判规则

4.2.3.1 化学成分分析结果不合格时，允许重新取样对不合格元素进行重复试验；复验结果仍不合格，该炉批锻件判为不合格。

4.2.3.2锻件力学性能某项检验结果不合格时，允许从该锻件上取双倍数量的试样对不合格项目进行重复检验；重复试验结果若仍不合格，允许将试样和锻件按本标准规定的热处理制度进行重复热处理后，进行本标准规定的全部力学性能检验，检验结果若仍不合格，则该批锻件判为不合格。重复热处理只允许进行一次。

4.2.3.3低倍组织检验不合格时，该批锻件判为不合格。

4.2.3.4 高倍组织检验不合格时，该批锻件判为不合格。

4.2.3.5 超声波检验不合格时；该件锻件判为不合格。

4.2.3.6 尺寸、外形或外观质量检验不合格时，该件锻件判为不合格。

4.3 检验方法

# 4.3 检验方法

4.3.1 化学成分分析

化学成分分析按GB/T 223（所有部分）和GJB 5404（所有部分）进行。

4.3.2 室温拉伸试验

室温拉伸试验按 GB/T228.1 进行。

4.3.3.高温拉伸试验

高温拉伸试验按GB/T 228.2或HB5195进行，仲裁试验按GB/T 228.2进行。

4.3.4 高温持久试验

<!-- page: 9 -->

高温持久试验按 GB/T 2039 或 HB5150 进行。

4.3.5 硬度试验

布氏硬度试验按GB/T231.1进行。

4.3.6 低倍组织检验

低倍组织检验按 GB/T14999.2 和 Q/S10-0102进行。

4.3.7 高倍组织检验

4.3.7.1 晶粒度评定按 GB/T6394 进行。

4.3.7.2 高倍组织检验时按 GB/T14999.4 和 Q/S10-0102 进行。

4.3.8 超声波检验超声波检验按Q/S10-0104进行。

4.3.9 尺寸外形检验尺寸外形检验采用通用的测量工具进行。

4.3.10 外观质量检验外观质量采用目视检验。
