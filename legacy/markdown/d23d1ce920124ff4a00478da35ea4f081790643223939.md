# 4.2 锻造

钢棒采用自由锻 + 轧制的方式成形。锻造时应留有足够的变形量，变形要均 匀，以达到均匀细化晶粒的目的，使其具有良好的超声波穿透性。

锻造过程如下：

a ）锻造设备： 3600T/2000T 快锻机；

b ）水口切除率 ≥3% ，冒口切除率 ≥12% 。

c ）始锻温度 ≤1250℃ ；

d ）自由锻成形，保证足够锻比，要求总锻比 >3.5 ；

e ）终锻温度 ≥850℃ ；

f ）锻件锻造变形工序见图 4-1 ；

g ）锻后空冷。

# 5.2 试验

# 5.2.1 化学分析

化学成分分析试样的取样按 GB/T 20066 的规定执行，应对每炉或每包钢水 取样进行熔炼分析（分炉合浇的钢锭，应从合浇的钢包中取样确定其化学成分）、 按炉罐号对其中一件钢棒取样进行成品分析，化学成分允许偏差应符合 GB/T 222 的规定。化学分析方法按 GB/T 223 或 GB/T 4336 、 GB/T 11170 和 GB/T 20123 的 规定执行。化学成分测得的结果应符合表 4-1 的规定。

# 5.2.2 力学试验

室温拉伸试验方法按 GB/T 228 的规定执行，高温拉伸试验方法按 GB/T 4338 的规定执行。拉伸试样应采用 GB/T 228 表 B1 中的 R4 号（ d 0 =10mm ， L 0 =5d 0 ） 比例试样，尺寸公差应符合表 B4 控制；冲击试验方法按 GB/T 229 的规定执行。 冲击试样应采用 GB/T 229 中的 10mm*10mm*55mm 标准夏比 V 型缺口试样；硬 度试验方法按 GB/T 231.1 和 GB/T 230.1 的规定执行。

# 5.2.3 金相检验

每批在任一根钢棒上取一个试样，应按 GB/T 6394 进行评定，评定结果应为 3 级或更细，并提供金相照片（包括放大倍数或标尺）。

每批在不同钢棒上取两个试样，应按 GB/T 10561 中的 A 法检验非金属夹杂 物，采用 GB/T 10561 中附录 A 的 ISO 评级图进行评定。各类非金属夹杂物（粗 系和细系）应分别不大于 1.5 级。

# 5.2.4 低倍组织检验

按 GB/T 226 的规定进行酸浸低倍检验，并按 GB/T 1979 中的评级图进行评 定。

在棒材横截面酸浸低倍试片上，不应有肉眼可见的缩孔、气泡、翻皮、夹杂、 裂纹、白点、折叠等缺陷。一般疏松、中心疏松、偏析均不大于 2 级。

对于拉伸试验，如果某一项试验结果不符合表 5-2 要求，可在不合格试样的

邻近部位截取双倍数量的试样进行复验。如果复验结果全部合格，则该批（件） 钢棒可以验收；反之，则钢棒应报废或按 5.2.6 节的规定重新热处理。

# 5.2.6 重新热处理

由于一项或几项力学性能不合格时，可对该批（件）钢棒重新热处理后重新 进行检验。

重新热处理应符合 4.3 节的规定，热处理方式应列入试验报告。重新热处理 的条件应列入试验报告，重新热处理应不超过一次。

重新热处理后应按第 5 节的要求取样，重新进行除化学成分以外的所有项目 试验。

# 6 无损检测

# 6.1 目视检验

锻件加过程中需要进行表面质量检查。成品加工后所有钢棒逐一经目视检 查，表面应完好无损，不允许有肉眼可见的发纹、裂纹、夹层、折叠、夹渣等 有害缺陷存在。

<!-- page: 12 -->

# 6.2 磁粉检测

目视检验后，应对钢棒表面逐一进行 100% 磁粉检验，检验方法和验收准则 按 NB/T20003.5 中规定执行。

# 6.3 超声检验

应对钢棒表面逐一进行 100% 超声波检验，检验方法和验收准则按 NB/T 20003.2 中规定执行。

# 6.4 尺寸检查

最终机加工后，产品的尺寸和外形应符合订货文件的规定。

# 7 缺陷的清除和修理

只要不影响零件的力学性能，钢棒可以采用打磨的方法清除不合格表面缺陷， 但必须满足以下要求：

a. 打磨后的剩余尺寸必须在零件规定的尺寸公差范围之内；

b. 打磨后的凹陷部分应与周围表面圆滑过渡；

c. 当缺陷存在于钢棒机加工表面，清除深度不应超过该处余量的 75% 。

缺陷清除后，应按 6.2 节的规定进行磁粉检验。不得对钢棒缺陷进行焊补。

# 8 标记

在钢棒上应有如下标志：

a. 钢棒生产厂的厂名或厂标；

b. 牌号；

c. 产品标准号；

d. 钢棒炉号、批号或标识号；

e. 制造日期。

标志应用低应力方式在钢棒两端做永久性标记（标记明显、清晰即可）。

与钢棒一起交货的复验试料也应按相同的方式进行标志。

如有特殊要求，供需双方可另行协商。

# 9 清洁、包装和运输

钢棒表面应无油脂污物，不允许被含卤素和卤素化合物的物质污染。钢棒的 两端要垂直切除并清除毛刺。

按照供货合同规定要求进行包装。

钢棒在贮存和运输过程中防止碰伤、弄脏，不允许与低熔点元素 S 、 Pb 、 Zn 等接触。

# 10 材料质量证明文件

供货方向采购方供货时，应随同产品一起提交产品合格证及产品质量证明书。 产品质量证明书内容应至少包括：

3 ）力学性能试验报告；

4 ）无损检验报告；

5 ）尺寸检查报告；

6 ）金相检查报告；

7 ）低倍组织检查报告；
