# 4 过程控制

# 4.1 原材料

# 4.1.1 冶炼要求

钢锭采用 EAF （电弧炉冶炼） +LF( 钢包精炼炉冶炼 )+VD( 真空脱气冶炼 ) 的工艺方法冶炼。

# 4.1.2 熔炼分析

检查材料牌号、炉号、锭节号、表面质量及检印。每炉钢水应按 RCC-M MC1350 的要求 取样进行熔炼分析。对于多炉合浇的钢锭，应分析每炉钢水的化学成分并提供每炉钢水的分 析报告。每炉钢水的分析结果或合浇后的权重平均值应符合表 4-1 要求。

# 4.3 锻造

锻件采用自由锻的方法进行制造。锻造时应留有足够的变形量，变形要均匀，以达到均 匀细化晶粒的目的，使其具有良好的超声波穿透性。

具体操作按 PK-JS-55-2020 《核锻件锻造作业指导书》及锻造工艺执行。锻造变形要求如 下：

a ）按照图 4-1 所示的切除量锯切冒口端和水口端，按工艺卡要求重量进行下料；

b ）始锻温度≥ 1120 ℃，终锻温度≥ 800 ℃；

c ）保证足够锻比，总锻比≥ 3 ；

<!-- page: 10 -->

d ）锻后空冷，视情况进行退火，以消除应力、防止产生白点等缺陷；

f ）锻造变形简图见表 4-4~4-15 。

# 5 取样及理化检验

# 5.1 取样

# 5.1.1 批的定义

一批由同一熔炼炉号，经过相同制造工艺，同炉热处理，且尺寸相近的棒材 ( 最大棒材 直径与最小棒材直径比值小于等于 1.1 ，空心棒材的最大壁厚与最小壁厚比值小于等于 1.1 ， 最大棒材截面积与最小棒材截面积比值小于等于 1.25) 组成。

# 5.1.2 取样数量

每根棒材应按照 RCC-M MC1000 的规定进行硬度测量后，在每批中取 4%( 至少为 2 根 ) 的棒材进行试验，其中 2% 为该批中硬度最高的棒材，另外 2% 为该批中硬度最低的棒材。在

<!-- page: 26 -->

每根取样的棒材上分别截取 1 个硬度试样（垫圈用棒材）、 1 个室温拉伸试样、 1 个 150℃ 拉 伸试样（稳压器支承的支承块用棒材）和 1 组（ 3 个）冲击试样。

试料应具有足够尺寸，以便截取全部的试验和复验所需用的试样。

# 5.1.3 取样要求

(1) 圆棒产品试样上与试验有关的部分距棒材端部的距离不小于棒材直径。试样轴线应与 棒材轴线平行，试样轴线的位置要求如下：

— 当 d≤25mm ，试样轴线位于棒材的轴线处 (d 为产品最大直径，下同 ) ；

— 当 25mm<d≤50mm 时，试样轴线位于距成品表面 12.5mm 处；

— 当 d>50mm 时，试样轴线位于距棒材轴线 1/4d 处。

(2) 扁平型产品试样上与试验有关的部分距端部至少为 T ( 热处理厚度，下同 ) 。力学性能 试样应取横向 ( 试样轴线垂直于锻件的主加工方向 ) ，如产品尺寸或形状不允许取横向试样时， 也可取纵向试样。试样轴线距表面距离为：

— 当 T≤25mm 时，试样轴线位于 1/2 厚度处；

— 当 25mm ＜ T≤50mm 时，试样轴线位于离表面 12.5mm 处；

— 当 T ＞ 50mm 时，试样轴线位于 1/4 厚度处。

(3) 在热处理前锻造或加工出内孔的产品棒材打孔后的取样在 t/2 处 (t 为热处理时锻件厚 度，下同 ) 进行，试样有用部分距棒材端部距离不小于 t ，试样轴线与棒材轴线平行。

# 5.3 复试

# 5.3.1 拉伸试验

如果试样有物理缺陷（不影响成品的使用能力），或由于试样装夹不妥、或试验机运行 失常而使试验结果不合格时，则必须另取试样重作试验。如果第 2 次试验合格，该批予以验 收，反之则按下节规定执行。

如果不合格试验结果不是由于上述任一原因所造成，则可对每个测得的不合格试验结果 进行两次重复试验。复试试样取自不合格试样的邻近部位，若复试结果都合格，则该批予以 验收，反之则拒收。

# 5.3.2 冲击试验

试样应邻近截取，这些试样的形状、尺寸及试验条件应满足 RCC-M MC1000 的规定。冲 击试验结果必须满足 5.2 的规定。如果上述任一要求不满足，则该批应予拒收。如果不合格 的试验结果仅是个别值低于所规定的最小值，则可按以下方法进行复试：

－在邻近不合格试样的取样部位，截取 3 根一组的两组试样，使其在与原组试样相同温 度下进行试验。

－如果两组试样中的任一组试验结果不符合 5.2 的规定，则该批应拒收，并按 5.4 的规 定作重新热处理。

# 5.4 重新热处理

由于一项或几项力学性能试验结果不合格而被拒收时允许重新热处理。重新热处理的条 件应列入试验报告。在此情况下，试样应按 5.1 的规定截取。重新热处理后应进行除化学成 分以外的全部试验与检验。

重新热处理不得超过 2 次。

根据国核安函【 2019 】 102 号文《关于民用核安全设备特种工艺人员资格管理有关事项 的通知》，在 2020 年 1 月 1 日起取得无损检验资格证书的人员应按《民用核安全设备无损检 验人员资格管理规定》（ 2019.6.13 ）开展相应无损检验活动，Ⅲ级人员审核无损检验规程和 结果报告；在 2020 年 1 月 1 日前取得无损检验资格证书的人员，在其证书有效期届满前可按 原许可范围（ HAF602 - 2007.12.28 ）开展相应无损检验活动，Ⅱ级人员可以审核无损检验规 程和结果报告。

# 7.2 目视检验

锻件制造过程中，应仔细检查锻件所有可达表面。目视检测的检测方法和验收标准应符 合 RCC-M M5150 第 5.1 节。

锻件制造厂应在目视检验之前制定目视检验规程（PK-ZL-NDT-VT-2512455《广西防城港 核电站三期工程LOT120S 主设备支承项目产品目视检验规程》）并提交锻件采购方认可。

# 7.3 渗透检验

锻件在最终机加工后，应对所有表面可达表面进行渗透检测。渗透检测的检测方法和验 收标准应符合 RCC-M M5150 第 5.2 节的规定。

锻件制造厂应在渗透检验之前制定渗透检验规程（PK-ZL-NDT-PT-2512455《广西防城港 核电站三期工程LOT120S 主设备支承项目产品渗透探伤规程》）并提交锻件采购方认可。

# 7.4 超声检测

垫圈Ⅱ、销轴垫圈、垫圈Ⅰ、垂直垫片、横向调整垫片锻件在最终机加工后进行超声检 测。上部套环、垫块、支承块、滑动垫块、下部套环、横向止挡块、垂直止挡块在半精加工 后进行超声检测，锻件半精加工尺寸见表 7-1 。超声检测的检测方法和验收标准应符合 RCC- M M5150 第 6 章的规定。

# 11 清洁、包装和运输

# 11.1 棒材要求

对于垫圈Ⅱ、销轴垫圈、垫圈Ⅰ、垂直垫片、横向调整垫片在进行最终机加工和无损检 验后，锻件表面应保持清洁、无污物和金属屑等。锻件无需涂油防护，允许存在轻微浮锈， 但供方需做好防雨淋措施，避免有较重的锈蚀产生。

在包装和运输过程中应对锻件妥善保护，避免发生磕碰、变形、氧化或锈蚀。

# 11.2 零件要求

# 11.2.1 一般要求

对于上部套环、垫块、支承块、滑动垫块、下部套环、横向止挡块、垂直止挡块应按下 述要求进行，包装前成品件的表面应保持干燥、无污物和金属屑。

# 11.2.2 包装和运输

# (1) 包装

a) 供方应根据产品的具体特点和运输条件，选用适当的包装方法，避免产品在运输过程 中产生浸水、锈蚀、损伤、磕碰或散失等现象，尤其是防止表面部分受损。

b) 包装材料主要有纸、聚乙烯、纸板、瓦楞纸板、木板等，磷化产品应采用气相防锈油 纸单独包裹，用于包装的各种材料应是干燥的，直接接触产品的材料需满足RCC-M F6000 中 相关清洁要求。

c) 不经表面处理的零件应用容易清除的防腐材料进行抗氧化保护处理，保护期至少为一 年。带有表面磷化层的零件应采取单独的内包装和防护措施。

d) 木箱内需采取放置干燥剂等防潮措施，干燥剂应装入布袋或强度足够的纸袋中，干燥 剂袋应用线绳系牢袋扣，采用吊挂等方式固定，且不得与零件表面接触，防止袋子移动或破 损导致污染产品。

e) 一个木箱内原则上可以放置同一合同号的零件，但备品备件必须按项目、类型和规格 单独装箱，包装箱外应附有相应的装箱清单。

f) 如果不同设备、不同类型和规格的零件同装一箱，供方应按项目、类型和规格分区隔 离放置，且箱内每个分区应附有相应的货物清单。

g) 装箱清单和货物清单内容至少应包括项目名称、合同号、零件名称、材料牌号、炉批 号、规格以及数量等信息。

# （2) 运输

<!-- page: 32 -->

a）包装箱应足够牢固，避免在运输过程中损坏或者散架，必要时箱体外表面用钢板加固。 如包装箱内有间隙，应采用不吸湿或吸湿性小的材料填满以避免零件在运输和装卸时相互之 间发生磕碰、损伤。

b) 运输过程中，包装箱应采取覆盖塑料布等有效的防雨防潮措施，并避免覆盖物发生变 质和脱落等现象导致零件浸水、锈蚀。

# 12 材料质量证明文件（完工文件）

供方应按RCC-M A3805 和RCC-M M5150 第11 章的规定编制完工报告。报告应包含关 于产品制造的质量证明文件等所有文件和报告，至少包含以下内容：

· 熔炼分析和成品分析的化学成分分析报告；

· 热处理报告(包括重新热处理，如适用)；

· 力学性能试验报告；

· 无损检测报告；

· 尺寸检验报告；

· 磷化层检查报告（如适用）；

· 所有的技术澄清及回复；

· 关闭的质量计划（包括质量计划的审批页）；

· 未曾补焊的声明；

· 不符合项报告和清单(如适用)。

上述报告应包括：

· 材料牌号和炉批号；

· 制造厂名称或识别标志；

· 合同号；

· 检验机构名称(适用时)；

· 各种试验和复试结果，以及相应的要求值。
