# 34CrNi3MoV 钢锭订货技术协议

# 1 内容与适用范围

本协议规定了 34CrNi3MoV 原材料订货技术协议材质原材料的 技术要求和质量要求。

# 2 要求

# 2.1 制造过程

应采用电炉 +LF 精炼 + 真空脱气的方法冶炼。

# 2.2 化学成分

化学成分分析应按 GB/T 223 进行（需要钢厂提供浇铸杯试样）。

# 2.3 非金属夹杂物

按 GB/T 10561-2005 进行夹杂物检验，其中 A 、 B 、 C 、 D 各类 夹杂物的粗系级别和细系级别应分别不大于 2.0 级， DS 类夹杂物应 不大于 2.0 级； A 、 B 、 C 、 D 各类夹杂物的粗系级别之和应不大于 3.5 级， A 、 B 、 C 、 D 各类夹杂物的细系级别之和应不大于 3.5 级。

# 2.4 内部质量

供方应该保证需方锻件满足以下要求：

1 、超声波探伤满足 NB/T 47013.3-2023 中 I 级的要求；

2 、按照 GB/T226 进行低倍组织检查，锻件的低倍不存在裂纹、白点、 气孔、夹杂等缺陷，并且按 GB/T1979-2001 评级，中心疏松不超过 2 级，锭型以及点状偏析不超过 1.5 级。

# 2.5 尺寸规格

为清除缩孔和过分的偏析，钢锭的头尾应有充分的切除量（尾部 切除率≥ 5% ，头部切除率≥ 13% ）。

# 2.6 表面质量

表面应光洁，不允许有裂纹、发纹、折叠、气孔、结疤、夹渣、 离层及其它对使用有害缺陷。有本体取样要求的原材料，需要对取样 部位进行打磨处理，并应满足原材料表面质量要求的管理规定。

2.7 标识 a. 材料牌号 b. 熔炼炉号 c. 锭型（锭重）

# 2.8 其他要求

2.8 其他要求 当对原材料有其他要求时，由供需双方协商确定。

# 3 入场检测

a. 外形尺寸 b. 化学成分 c. 外观质量

# 4 交付

每批应附有符合本协议要求和合同中规定的质量证明书，并注明： a. 供方名称 b. 需方名称 c. 合同号 d. 材料牌号 e. 熔炼炉号 f. 重量 g. 头部、尾部化学成分 h. 熔炼方式
