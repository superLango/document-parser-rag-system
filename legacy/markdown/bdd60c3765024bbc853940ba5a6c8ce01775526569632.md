# 合同生效函

无锡派克新材料科技股份有限公司：

现通知贵公司DFWH2024-CG01-0028合同内标段V清单内（莱阳项目大锻件采购）即日起通知生效，生效项次及数量见附件1生效清单，生效材料为莱阳5#6#机组大锻件材料，请贵公司立即启动相关工作，同时准备坯料和进行相关检验，具体要求如下：

1. 生效项次：生效项次序号对应合同标的清单项次序号，数量及采购规范等技术要求按附件1生效清单中要求执行；

2. 文件编制：请贵公司及时开展开工文件编制工作，所有开工文件请收到生效函后7天内提交我公司审查，如我公司审查后发回贵公司修改，请于2个工作日内修改完成，文件编制修改应避免反复，一次性修改完成并自行进行比照检查；

3. 坯料准备：请贵公司及时开展坯料准备工作，所有坯料在开工文件批复完成前准备完成。

4. 发货清单：产品（试料）发货需提供发货清单（格式要求见附件2），同时应加强产品的包装和防护，产品（试料）上应清晰标记产品（试料）的牌号、规格尺寸、炉批号、项目等必要信息。

5. 进度跟进：请贵公司开工后一周内提供详细进度计划，每周四以周报的形式反馈材料进展、目前存在的问题（如有）以及需要我公司协调解决的事项（如有）；

6. 熔断机制：

根据合同18.5熔断条款：交货期到期后1个月，如卖方未完成全部货物交付，且出现重大质量风险或交付风险时，买方有权单方面终止其供货合同，已产生的任何费用由卖方自行承担，买方已支付款项应在终止合同通知到达卖方后15天内全部退还。

请贵公司安排专人负责，调配多方资源，确保产品保质保量按时交付。

顺祝商祺！

东方电气（武汉）核设备有限公司

2026年4月1日
