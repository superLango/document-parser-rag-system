# 中压二级过热器管板用 S31608 锻件采购技术规范

# 1. 适用范围

本技术要求规定了中压二级过热器 S31608 锻件的基础标准、技术要求、检测方法等 要求。

本技术要求适用于中压二级过热器用管板锻件的订货和验收。

# 3. 基础标准

锻件的牌号为 S31608 Ⅳ级。锻件的一般要求应满足 NB/T 47010 的要求。当上述标 准和本技术要求相抵触时，应以本技术要求为准。

# 4. 技术要求

4.1 制造

不锈钢应采用电炉加炉外精炼（氩氧脱碳法或真空氧气脱碳法）或电渣重熔法冶炼， 也可采用生产厂认为能保证质量的其它相当或更好的工艺冶炼。钢锭的头、尾应切掉足 够的料头，以保证把缩孔和过度偏析部分去除。

# 4.4 晶间腐蚀

每个锻件取 2 组（ 4 个）晶间腐蚀试样，试样应取自§ 5.1 所述的试料。

试样应按 GB/T 4334 方法 E 进行晶间腐蚀试验。试验前，试样应先经敏化处理。敏 化处理制度为：保温温度 650 ± 10 ℃，保温 2 小时，空冷。经试验的试样按规定弯曲后， 在 10 倍放大镜下观察其弯曲外表面，无因晶间腐蚀而产生的裂纹。

# 4.5 金相检验

每个锻件应取 2 个晶粒度试样和 2 个非金属夹杂物试样进行金相检验。试样应在§ 5.1 所述试料上截取或取自破断的室温拉伸试样端部。

# 4.5.1 晶粒度

<!-- page: 5 -->

锻件的实际晶粒度应按 GB/T 6394 进行评定，评定的结果应为 4 级或更细。

# 4.5.2 非金属夹杂物

非金属夹杂物按 GB/T 10561 中方法 A 进行评定，要求如下：

A 类（粗系和细系）夹杂不大于 1.0 级；

B 类（粗系和细系）夹杂不大于 1.0 级；

C 类（粗系和细系）夹杂不大于 1.0 级；

D 类（粗系和细系）夹杂不大于 1.0 级。

# 4.6 表面质量和尺寸检验

# 4.6.1 表面质量检验

在锻件的制造过程中，应仔细检查锻件的所有表面，每个交货状态锻件的所有表面 不允许有氧化皮、裂纹、加工毛刺及其它影响其使用性能的缺陷。

# 4.6.2 尺寸检验

所有交货锻件的尺寸应满足订货文件和图纸的要求。

# 4.7 无损检测

# 4.7.1 渗透检测

完成固溶处理并经精加工后，每个交货锻件应按 NB/T47013.5 规定的检测方法和验 收标准进行 100% 渗透检测，评定结果需达到质量等级Ⅰ级。锻件制造厂所使用的渗透 检测规程应在检验前提交锻件采购方认可。

# 4.7.2 超声检测

完成固溶处理并经精加工后，每个交货锻件应按 NB/T47013.3 规定的检测方法和验 收标准进行 100% 体积的超声检测，评定结果需达到质量等级Ⅰ级。探头应从两个平面 进行检测，如有可能还应从圆周面进行扫查。锻件制造厂所使用的超声检测规程应在检 验前提交锻件采购方认可。

# 4.8 表面缺陷的清除

如果锻件的表面发现不能验收的缺陷，可用磨削方法清除。打磨缺陷时，要圆滑过 渡，不能过热。磨具应仅为含碳化硅、氧化铝或金刚石磨料的磨具，该磨具必须是未使 用过的或此前仅在 300 系列奥氏体不锈钢上使用过。磨削后的区域还应按§ 4.7.1 的要 求重新进行渗透检验。缺陷清除后的锻件尺寸仍应符合订货图纸的规定，锻件不允许进

行任何焊补。

# 4.9 复试和重新热处理

拉伸试验的复试按 NB/T47010 中§ 7.6 的规定进行。

如果上述复试结果仍不合格或者硬度试验不符合表 2 规定，则可对该锻件进行重新 热处理，重新热处理后应进行除化学分析和非金属夹杂物检验以外本规范书规定的所有 试验和检验。重新热处理仅允许进行 1 次。

# 5. 试验

# 5.1 取样

每个交货状态锻件应从 NB/T47010 的§ 7.5 所述的取样部位上切取试料，切下的试 料应标明主加工方向并作标记。试料应具有足够的尺寸，以便截取全部试验和可能进行 的复试所需的试样。所有试料、试样均应采用机加工方法切取。锻件应切向取样。

每块试料应加工两组力学性能试样，两组试样位置间隔 180 °，其中，一组试样包 括 1 个室温拉伸试样和 1 个硬度试样。此外，每块试料还应加工两组金相检验试样（包 括 1 个晶粒度试样和 1 个非金属夹杂物试样）。

每个锻件应取 2 个（交货态一个、模拟态一个）轴向拉伸试样。轴向拉伸试样应尽 可能靠近颈部并在内缘或外缘截取，如有必要，可用小尺寸试样。试样的纵轴应平行于 颈的长度方向。可参考 SA-788 附录中图 S1 。

# 6. 标记

锻件、试料、试样等应有清晰可见的标记。在无损锻件使用性能的前提下，交货的每 个锻件应至少标记以下内容：

a) 制造厂名称或商标；

b) 材料牌号和锻件规格；

c) 熔炼炉号、热处理炉号；

d) 锻件名称和锻件编号；

e) 合同号或订单号。

# 7. 清洁、包装和运输

锻件的清洁、包装和运输应符合订货合同的相关规定。

锻件的制造、加工和运输过程中， 应避免接触到那些可能对材料性能和完整性产生 不利影响的物质，如：铅、锌、铜、铝、镉、砷、锡、锑、汞、铋、硫、卤素和其它低 熔点金属和它们的合金及化合物。 此外， 由于含氯材料老化产生的酸性氯化物是潜在 的危险，因此需合理选用胶带、标记物、耦合剂、磁性墨水、渗透剂及涂料来予以避免。

锻件表面应没有锈斑、灰尘及其它污染物。

# 8. 材料质量证明文件

在锻件交货的同时应提交材料质量证明文件，材料质量证明文件应至少包括如下内 容：

a) 合同号或订单号；

b) 锻件名称和锻件编号；

c) 锻件图；

d) 材料牌号和锻件规格；

e) 熔炼炉号、热处理炉号；

f) 化学成分（熔炼分析和成品分析）分析报告；

g) 热处理曲线（包括重新热处理，如果有）；

<!-- page: 8 -->

h) 各项力学性能试验报告（包括复试，如果有）；

i) 晶间腐蚀试验报告；

j) 金相检验报告；

k) 表面质量和尺寸检查报告；

l) 无损检测报告；

m) 材料识别标记；

n) 未曾焊补的声明。
