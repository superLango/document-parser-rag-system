# 航空用高温合金环形件规范

# 1 范围

本规范规定了航空用高温合金环形件的要求、质量保证规定和交货准备等。

本规范适用于航空用高温合金轧制和锻制环形件（以下简称环形件）。

# 3 要求

# 3.1 材料

合金采用表1中所列冶炼方法生产，也可采用供需双方同意的能满足本规范规定的其它冶炼方法生产。所采用的冶炼方法应在合同和质量证明书中注明。当改变冶炼方法时，应按 GJB/Z 33-1993 第4章的规定执行。

环形件用棒材或环坯应符合相应技术标准的规定。

合金的牌号和化学成分应符合表2的规定。成品环形件的化学成分允许偏差应符合相应棒材或环坯标准的规定。

# 3.3 加工方法

3.3 加工方法

3.3.1 环形件经轧制或锻制而成。当生产工艺有重大改变时，应按HB5402的规定执行。

3.3.2 GH 2901、GH 4163、GH 4169环形件的最终热加工温度应分别不超过1140℃、1150℃、1100℃。

3.4 交货状态

3.4.1 环形件不经热处理交货，也可以固溶或固溶加时效状态交货，交货状态应在合同和质量证明书中注明。

3.4.2 根据需方要求并在合同中注明，环形件可经粗加工交货。

4.2.3.2 力学性能某一项检验结果不合格时，允许在同一试验件上取双倍数量的试样对不合格项进行重复试验；复验结果即使有一个试样不合格，该批环形件判为不合格；如能确认是由于热处理的原因，允许将试验件和该批环形件按本规范规定的热处理制度进行重复热处理后，重新进行本规范规定的全部力学性能检验，若仍不合格，该批环形件判为不合格。重复热处理只允许进行一次，补充时效不计为重复热处理。

4.2.3.3 横向低倍组织检验不合格时，若系因合金冶炼造成的空洞、夹杂和严重偏析，不允许重复检验，该批环形件判为不合格；如能确认该环形件上述缺陷是由于合金铸锭头、尾未切净造成的，可在相邻的锻件上进行检验，如检验合格，该批环形件判为合格；若系因轧制或锻造过程中产生的裂纹或折叠，不影响环形件的机械加工和成品环形件的质量，在有充分技术依据时，该批环形件判为合格。

GH4169低倍组织检验如发现白斑、浅色腐蚀区、暗色腐蚀区或黑斑，按附录A处理。

4.2.3.4 GH4169碳化物或碳氮化物检验不合格时，该批环形件判为不合格。当发现由Laves相等引起的黑斑和Ni3Nb相引起的暗色腐蚀区时，按附录A处理。

4.2.3.5 晶粒度检验不合格时，I类环形件逐件判为不合格，II类环形件允许在同一试验件上重新取样或在另一个试验件上取样进行重复检验；复验结果若仍不合格，该批环形件判为不合格。

4.2.3.6 超声波检验不合格时，该环形件判为不合格。

4.2.3.7 尺寸、外形和外观质量检验不合格时，该环形件判为不合格。

合金中溶质元素的正偏析导致的化合物的聚集，这些化合物是指碳化物、碳氮化物、Laves相、μ相、Ni3Nb相和其它金属间化合物，在腐蚀表面呈暗色区域。

由于碳化物及碳化物形成元素或强化元素减少引起的负偏析，在腐蚀表面呈浅色区域。

# GH4169环形件高低倍组织

A.1 GH4169环形件低倍上的白斑或浅色腐蚀区，如果发现下述任何一种情况，应进行显微组织检查：

a) 白斑或浅色腐蚀区长度大于2.54mm；

b) 每个检查表面白斑或浅色腐蚀区数量为4个或更多；

c）白斑或浅色腐蚀区密集分布，超过图A.1。

白斑或浅色腐蚀区的显微组织检查，如果发现下述任何一种情况，该批环形件判为不合格：

a) 显微组织检查存在不显示组织的区域；

b）有晶粒度比环形件平均晶粒度要求超出1.5级的区域；

c）该区域存在一个白斑，且长度超过 8mm；

d) 该区域存在碳氮化物集聚，数量和分布超过图 A.3；

e) 存在含有孔洞、夹渣或不纯物的区域。

A.2 GH4169环形件低倍上的暗色腐蚀区，应进行显微组织检查。如果发现属于由Laves相和μ相等引起的黑斑，该环形件判为不合格；如果通过熔炼记录对黑斑提供合理的解释，确认存在黑斑的区域是孤立的，或环形件中某一区域存在黑斑，而与之相邻的环形件亦存在黑斑，且相邻环形件的黑斑是同一区域黑斑的延续，该炉批其余无黑斑的环形件可以使用；如果发现该炉批其余环形件有黑斑，且此环形件该区域黑斑与开始发现的黑斑的环形件不是同一区域黑斑的延续，该炉批环形件判为不合格。

环形件暗色腐蚀区的显微组织检查，存在碳化物、碳氮化物或 $ \mathrm{N i}_{3} \mathrm{N b} $相集聚，如果发现下述任何一种情况，该环形件判为不合格：

a) 碳化物：超过图 A.2;

b) 碳氮化物：超过图 A.3；

c) $ \mathrm{N i}_{3} \mathrm{N b} $相：超过图A.4的5级。

A.3 GH4169环形件的碳化物、碳氮化物、Ni_{3}Nb相和Laves相应符合以下要求：

a) 碳化物：不超过图A.2；

c) $ \mathrm{N i}_{3} \mathrm{N b} $相：不超过图A.4的5级；

d) Laves 相：不允许存在。
