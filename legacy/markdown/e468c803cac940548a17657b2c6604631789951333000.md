# 一、工作范围

为保证本公司生产的产品质量，规范原材料采购，使原材料的采购有据可依，特制定 本规范。

本规范规定了BEST 项目下偏滤器系统所采购的 不锈钢XM-19 的技术规范与要求，适 用于BEST 项目偏滤器系统中所使用的厚度为XM-19 不锈钢板材的采购。

# 三、职责

# 3.1 技术部

负责根据原材料对产品结构安全性的影响程度对原材料的采购提出具体要求。

# 3.2 质管部

负责对原材料进行检验验收，并对检测结果进行分析处理。

# 3.3 市场部

按照采购技术规范对原材料进行采购，并协助不合格品处理。

# 四、制造

# 4.1 制造工艺

钢应使用电炉或任何其他技术上等效的工艺制造。

钢的熔化应通过适当的二次冶金处理，如氩氧脱碳(AOD)或真空氧脱碳(VOD)来完成。

# 4.2 热处理

所有板材应在溶液退火状态下交付。固溶退火热处理:将板材加热至最低1065℃，然 后水淬。应记录热循环，并在文件中提供记录。

# 五、化学成分和理化特性

# 5.2 铁素体含量

使用经Pryce 和Andrews 修改的舍弗勒图(图RMC 1341.2，Section 3，RCC-MR 2007) 评估铁氧体含量应小于或等于0.5%。

# 5.3 磁导率

成品板材溶液退火后，在室温下测量其相对磁导率。测量值应低于或等于根据ASTM A342 可接受的测试方法确定的1.03。

# 5.4 微观检查

进行显微检查，必须与每一块轧板的轧制方向平行。结构必须是均匀的。

# 5.5 晶粒度

1）确定晶粒尺寸的显微组织检查应符合ASTM E112。粒度数应等于或大于3。

2）测定是对从机械试样附近取的试验样品进行的。

# 6.2 硬度

材料应符合硬度要求，如ASTM A240:

-最大硬度-布氏硬度-241

-最大硬度:洛氏硬度B-100。

测试方法应符合ASTM A370。硬度测量的样品应在拉伸试验样品附近的位置切割。允 许布氏硬度或洛氏硬度B。

# 6.3 再处理

因一次或多次机械测试结果不满意而被拒绝的轧制板可以退回(根据第5 节进行固溶 热处理)。再处理条件应在测试报告中描述。再处理不得超过一次。

# 七、尺寸检查

# 7.1 一般要求

尺寸按采购订单的要求进行校核。

材料应符合ASTM A480/A480M 规范中所示的允许公差。将板材切割成所需尺寸后，还 应检查板材的横截面。

材料没有显示任何重叠，层压(例如，在轧制方向上存在拉长的夹杂物平面)。

# 7.2 表面条件

双面表面处理应符合ASTM A480/A480M 标准。表面粗糙度平均为6.3μm。交付时，金 属上不得有油或油脂的痕迹。

所有的极板都应在溶液、热处理、酸洗和钝化条件下交付。

# 八、无损探伤

# 8.1 目视检查

应目视检查板材。表面应平整、均匀，无皱、扣、气孔、撕裂、裂纹和夹杂物。切割 至交货尺寸后，应目视检查边缘。应检查是否有解理或层压(例如，在轧制过程中由细小 的夹杂物组成)。如有疑问，应进行液体渗透检查。

# 8.2 渗透检查

应按照EN 10228-2 的要求对每个板进行100%液体渗透检查。按照BEST 真空手册的规 定，所有暴露在真空中的表面都必须使用经买方批准的液体渗透剂。

验收标准应在询价和订购时商定。

# 8.3 超声检查

所有的板材都要检查。超声波检查应按照EN10307 进行。

# 8.4 检测人员资质

检查应按照检测规程和EN 10307 中给出的标准进行，板身质量等级为S3，板边质量 等级为E4。

测试和检验人员及其主管应根据EN ISO 9712 获得资格和认证。检验员证书应与材料 证书一起提供。

# 九、标记和包装

每一块钨板须清楚地标明买方指定的资料，标记应以压印或其他可接受的方式进行：

-供应商名称；

-物料名称；

-尺寸:板材厚度、宽度、长度；

-热处理(应力释放)；

-批次编号。

供应商应确保货物符合适用于运输和目的地国家的法规要求。

# 十、验收

材料测试报告必须在交货前提供。材料和证明应遵守本规范。如果不符合规范，材料 不能接收。

# 十一、文件要求

供应商还应提供符合国际或国家标准的检验证书。证书应包括本规范中所述的所有测 试报告(即，所有测试以及符合本规范中规定的要求值/标准的任何重新测试结果)。此外， 还需要提供以下信息:

-材料名称和标记说明；

-批次编号；

-每个板的尺寸和几何公差的测量报告；

-各板材主要变形方向和晶粒方向报告；

-化学成分的测量报告；

-每批密度测量报告；

-每批硬度测量报告；

-每批货物的粒度测量报告；

-每个批号的显微结构检验报告；

-每个牌照的外观检验报告；

-超声检查报告；

-渗透检测报告；

-如果相关:偏差请求，不符合报告，内部不符合，签署的控制计划等。

所有度量衡均应使用公制SI。每份文件应以PDF 格式的电子文件提供。

# 十二、质量控制要求

所有供应商应具有买方认可的质量保证计划或ISO 9001 认证的质量保证体系。对于 现成材料的供应，不需要专门的质量计划和MIP。如果需要进行额外的测试，则应由认可 的第三方实验室进行。

关于目视和无损检测，应由符合ISO 9712 的合格检验员执行。
