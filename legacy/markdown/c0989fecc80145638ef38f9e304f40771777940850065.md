# 5.2 取样及检验项目

每熔炼炉次做一次熔炼分析，应在浇注过程中取样或在重熔钢锭上取样。

每批锻件做一次成品分析，试样应在靠近力学性能试样的位置切取。

每批锻件取一个室温拉伸试样和一个高温拉伸试样，试样在同一批次任一锻件的 加长位置切取。试样的纵轴应平行于锻件的主变形方向。实心锻件试样的纵轴应位于 中心至表面之间的中心，空心锻件试样的纵轴应位于壁厚中心处。

晶间腐蚀试验应在所有热处理完成后进行。按 ASTM A262 E 法进行晶间腐蚀试 验，每批次锻件做一次试验，试样在靠近拉伸试样的位置切取。

# 7 机加工

# 7.1 粗加工

在性能检测合格后应对工件进行粗加工，以满足超声波检验要求，粗加工到尽量 接近零件尺寸，超声波检验合格后进行精加工。

# 7.2 精加工

按采购图和采购合同约定的尺寸、公差对锻件进行精加工。最终机加工后的锻件 进行无损检测。

锻件在精加工完成后，应按采购图和采购合同约定的尺寸及公差进行检验。锻件 的尺寸公差和表面粗糙度应满足采购图纸及合同规定。

# 8 无损检测

# 8.1 目视检验

在制造和加工的各个阶段都要按要求进行目视检验，锻件表面应完好无损，表面 不允许有发纹、裂纹、切痕、划伤折叠和有损使用性能的其他缺陷存在。

具体检验按 PK-ZL-NDT-VT-2412309 《目视检验规程》执行。

# 8.2 渗透检验

成品加工后，应对工件进行渗透检测，每个锻件的所有外表面及可到达的内表面 应按 NB-2546 的规定进行液体渗透检验。

渗透具体检验按 PK-ZL-NDT-PT-2412309 《渗透检验规程》执行。

# 8.3 超声波检验

完成所有热处理后，每个锻件应进行超声波 100% 体积检验，检验方法及验收按照 NB-2542 规定进行。空心锻件的超声波检测应在中心孔形成后进行。

具体检验按 PK-ZL-NDT-UT- 2412309 《超声波检验规程》执行。

# 9 缺陷的清除和修理

经 HPC 预先批准，可按 NB-2548 进行表面缺陷清除。打磨缺陷时，要圆滑过渡， 不能过热。磨料应是新的或是仅在奥氏体不锈钢或镍基材料上使用过的，磨料应为碳 化硅、金刚石或氧化铝材料。缺陷清除后的部位应按 8.2 节重新进行液体渗透检验。

# 11 清洁、包装、运输

产品的清洁度、包装和运输应符合采购合同和图纸的规定。

产品包装前应对表面全面清洁，清除工件表面上的锈斑、水迹、灰尘、油污、金 属屑和其它形式的污物，干燥处理。

包装前确认产品符合清洁度要求，做好防锈处理。小件锻件：用卡槽、隔板、扎 带、缓冲材料等固定，避免在箱内晃动。大件和异形锻件：用钢带、螺栓固定在木质 托盘上，托盘需平整，确保叉车 / 吊车可顺利装卸。包装后做好外部防雨保护。

选择合适的运输方式，包装产品运输安全。

# 11.1 禁止材料的要求

被禁止材料一般是硫、铅和低熔点金属（例如锑、镉、铟、汞、锌、铋和锡）、 以及它们的合金和化合物。二硫化钼润滑剂、接触性防腐剂（例如： Tectyl ）和卤化材
