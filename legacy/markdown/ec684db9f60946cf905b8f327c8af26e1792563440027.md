# GH4151 合金盘锻件

# 1 范围

本文件规定了 GH4151 高温合金叶盘锻件（以下简称锻件）的要求、质量保证规定、交付准备等。

# 3.3 制造方法

锻件采用模锻。

# 3.4 交付状态

# 3.4.1 热处理状态

锻件经固溶 + 时效热处理后供应，锻件的供应状态应在订购文件和质量证明书中注明。

# 3.4.2 表面状态

锻件表面交付状态为粗加工。

# 3.4.3 热处理制度

固溶： 1130℃-1170℃ ，保温 4-8h ，空冷 ;

时效： 840℃-870℃ ，保温 6h ，空冷 ;

时效： 760℃±10℃ ，保温 32h ，空冷 ;

# 3.5 力学性能

从交货状态的锻件解剖件和试样环上切取试样测试力学性能。其中，完整的试样环应在锻件热处理 后切取。

# 3.5.1 锻件和试样硬度

锻件和试样硬度 HB 应为 341-444HB （ 3.30-2.90mm ）。

# 3.6 低倍组织

锻件宏观组织应无表面气孔、裂纹、层状组织、缩孔、气孔以及直径超过 1.0 毫米的粗大气孔团簇， 且肉眼可见的 “ 冠状 ” 和外来夹杂物。

宏观晶粒度不得超过 2 毫米，允许个别区域的晶粒大小不超过 3mm 。

# 3.7 晶粒度

经标准热处理后，锻件晶粒度应基本均匀，晶粒度 8 级或者更细。

# 3.8 液体渗透检测

锻件加工后的表面通过液体渗透检验进行检查，其表面应无裂纹、气泡、锻造褶皱、撕裂、金属 及非金属夹杂物、气孔、微孔等由变形引起的金属表面缺陷。若发现锻件表面存在裂纹、锻造褶皱等 变形导致的金属表面缺陷，应按图纸规定的公差范围对锻件表面进行二次加工，并通过液体渗透检测 对这些表面进行复检。

# 3.9 超声波探伤

锻件粗加工后应进行水浸超声波探伤，按 AMS-STD-2154 的 AA 级验收。

# 3.10 形状、尺寸

锻件的形状、尺寸和公差应符合供需双方确定的图样规定。

# 3.11 外观质量

3.11.1 锻件的表面粗糙度应满足水浸超声波探伤的要求。

3.11.2 最终交付的锻件完好无损、无污渍，表面不应存在折叠、裂纹、孔洞、凹坑、起皱等有损于零件 加工和使用的缺陷。

# 4.2.2 判定与复验规则

本文件判定原则是基于检测结果有效的前提下进行规定，如确定检测结果是由于试样尺寸、设 备故障或试验程序有误等非材质原因导致，则检验结果应当判定为无效并更换试样，当次检验不计 为重复试验。具体项目判定和复验规则如下：

a ）化学成分分析不合格时 , 该批锻件判为不合格。

b ）解剖件力学性能某项检验不合格时，允许在同一锻件上切取双倍数量的试样对不合格项目进 行重复试验；复验结果仍不合格时，允许该批锻件在本标准规定的范围内重复热处理后重新 提交验收；若仍不合格，则该批锻件判为不合格。重复热处理只允许进行一次。试样环力学 性能某项检验结果不合格时，允许在同一试样环上切取双倍数量的试样对不合格项目进行重复 试验，若仍不合格，允许该锻件与试验环在本标准规定的范围内重复热处理，然后按首次检 验要求进行检验，若仍不合格，则该锻件为不合格。重复热处理只允许进行 1 次。

c ）解剖件的截面低倍组织检验不合格时，该批锻件判为不合格；试样环的截面低倍组织检验不 合格时，该件锻件判为不合格。锻件全表面低倍组织检验时如发现超标的裂纹、折叠等缺陷 时，该件锻件判为不合格；如发现夹杂、偏析等缺陷时，该批锻件判为不合格。

d ）解剖件的晶粒度和显微组织检验不合格时，该批锻件判为不合格；试验环的晶粒度和显微组 织检验不合格时，该件锻件判为不合格。显微组织或晶粒度检验不合格时，该批锻件判为不合 格。

e ）超声波检验不合格时，该件锻件判为不合格。

f ）尺寸、外形或外观质量检验不合格时，该件锻件判为不合格。
