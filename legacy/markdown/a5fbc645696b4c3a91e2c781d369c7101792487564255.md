# 1 范围

本规范规定了 Ti 2 AlNb 合金棒材的要求、验证、包装、运输和贮存等。

本规范适用于项目用直径不大于 450mm 的 Ti 2 AlNb 合金棒材（以下简称棒材）。

# 3 要求

# 3.1 冶炼方法

3.1.1 合金采用下列冶炼方法之一进行生产，所采用的冶炼方法应在合同和质量证明书中注 明：

a) 真空凝壳 + 不少于两次真空自耗电弧炉熔炼。最后一次熔炼应采用真空氦冷自耗电弧 炉熔炼，最后一次熔炼稳定阶段的炉内腔压应不大于 5Pa ；

b) 不少于三次真空自耗电弧炉熔炼。最后一次熔炼稳定阶段的炉内腔压应不大于 5Pa 。 3.1.2 自耗电极不允许使用钨极氩弧焊焊接。

3.1.3 当供方冶炼和生产工艺有重大改变时，应预先征得需方同意。

# 3.2 均匀化

铸锭开坯前应进行均匀化处理。均匀化温度应不低于 1100 ℃，保温时间应不小于 8h 。

# 3.4 交货状态

棒材以锻制状态（ R ）经车光或磨光后交货，并注明棒材头尾。

# 3.5 力学性能

3.5.1 从交货状态的棒材上切取横截面试块（试块厚度应不小于 20mm ），经整体热处理后 切取试样测试力学性能。推荐的热处理制度为固溶处理＋时效处理：

固溶处理： 920 ℃～ 1050 ℃（在选定温度下按 ±10 ℃控温），保温 1h ～ 4h ，油冷或空冷；

时效处理： 750 ℃～ 870 ℃（在选定温度下按 ±10 ℃控温），保温 12h~24h ，空冷。

3.5.2 在经 3.5.1 热处理后的棒段上切取试样测试力学性能（直径不大于 150mm 的棒材取纵 向试样，直径大于 150mm 的棒材取弦向试样），应符合表 2 和表 3 的规定。当 750 ℃ /250MPa 光滑持久试验时间达到 30h 后，允许至少每隔 4h 增加 16MPa ，直至拉断。

# 3.6 低倍组织

3.6.1 横向低倍组织应在交货状态的棒材上取样进行检验。

3.6.2 低倍组织不允许有目视可见的裂纹、折叠、气孔、夹杂、偏析、缩孔及其他影响使用 的冶金缺陷。

3.6.3 低倍组织应为模糊晶，不允许有明显目视可见的清晰晶粒。低倍组织应符合 GJB 2220A － 2018 中图 1 的 1 ～ 6 级。当对低倍组织检验有异议时，以该区的高倍组织检验结果进 行判定。

3.6.4 试制期间供方应提供低倍组织图片。

# 3.7 高倍组织

3.7.1 高倍组织应在交货状态的棒材上取样进行检验。

3.7.2 高倍组织应为 α 2 ＋ O ＋ B2 三相组成的双态组织， α 2 /O 颗粒应分布均匀，晶界应无连续 的 α 2 /O 相存在。供方应提供高倍组织图片（ 1000 倍以上的扫描电镜照片）。

3.7.3 供需双方应积累高倍组织图片和数据。

# 3.8 β 转变温度

供方应检测每批棒材的 β 转变温度，并提供 β 转变温度实测数据。

# 3.9 超声波检验

# 3.11 外观质量

3.11.1 棒材表面不允许有裂纹、折叠、重皮、缩孔及其他影响使用的缺陷。棒材表面的局 部缺陷允许采用打磨或机械加工的方法清除，清理的深度应不超过其尺寸公差，清理的宽度 与深度之比应不小于 8 。

3.11.2 棒材表面允许有个别细小的疤痕、龟裂、鳞皮、皱褶、印痕、啃伤、麻点和划痕， 但应保证棒材不超出直径的极限偏差。

3.11.3 棒材粗加工后的表面粗糙度 R a 值应不大于 3.2μm ，并应满足超声波探伤要求。

# 4 验证

# 4.1 检验分类

本规范规定的检验为质量一致性检验。当棒材在试制、转厂或改变主导工艺等重大工艺 变更时应按 GJB908A 的要求进行首件鉴定。

# 4.2.3 判定与复验规则

4.2.3.1 化学成分分析结果不合格时，允许重新取样对不合格元素进行重复检验，若复验结 果仍不合格，该批棒材判为不合格。

4.2.3.2 力学性能检验结果不合格时，允许从该批棒材中切取双倍数量的试样进行不合格项 目的重复试验；重复试验不合格时，允许进行重复热处理，若仍不合格，该批棒材判为不合

格。重复热处理只允许进行一次，并在质量证明文件注明两次热处理的制度和相应试验结果。 重复试验合格的棒材，第一次试验结果必须同时填入质量证明文件。

4.2.3.3 低倍组织检验结果不合格时，该批棒材判为不合格。若对低倍组织检验结果存在异 议时，应以该区域高倍组织的检验结果为准。

4.2.3.4 高倍组织检验不合格时，该批棒材判为不合格。

4.2.3.5 超声波检验、尺寸外形或外观质量检验不合格时，该支棒材判为不合格。

4.2.3.6 已检验合格的棒材在后续加工过程中发现有不允许的冶金缺陷时，棒材仍属不合格。

# 4.3 检验方法

# 4.3.1 化学成分

化学成分分析按 GB/T 4698 （所有部分）或 HB7716 （所有部分）进行。当存在异议时， 仲裁试验按 GB/T 4698 进行。

# 4.3.2 室温拉伸和热稳定性

室温拉伸和热稳定拉伸试验按 GB/T 228.1 进行。

# 4.3.3 高温拉伸

高温拉伸试验按 GB/T 228.2 进行。

# 4.3.4 高温持久

高温持久性能试验按 GB/T 2039 或 HB 5150 进行。

# 4.3.5 低倍组织

低倍组织检验按 GB/T 5168 进行。

# 4.3.6 高倍组织

高倍组织检验按 GB/T 5168 进行。

# 4.3.7 β 转变温度

β转变温度检验按 GB/T 23605 或 HB 6623.2 进行。

# 4.3.8 超声波检验

超声波检验按 GJB 1580A 进行。

# 4.3.9 尺寸、外形

棒材形状、尺寸检验采用相应精度的量具进行。

# 4.3.10 外观质量

外观质量采用目视或 5 ～ 10 倍放大镜进行检查。

# 6 说明事项

# 6.1 预定用途

本规范规定的 Ti 2 AlNb 合金棒材预定用于发动机机匣、静叶环等环形锻件及盘类锻件。

# 6.2 订购文件应明确的内容

合同或订单中应注明下列内容：

a) 本规范号；

b) 合金牌号、冶炼方法、规格、交货状态和数量；

c) 定尺长度；

d) 其他要求。
