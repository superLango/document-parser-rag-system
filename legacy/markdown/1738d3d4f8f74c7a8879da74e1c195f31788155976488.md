# 1 引言

本技术协议规定了钛合金 6Al-2Sn-4Zr-2Mo（Ti6242）环形锻件技术要求、试验方法、检验验收规则、标志、包装、运输及贮存原则并与设计图样、锻造坯料图一起作为制造与验收的依据。

用于制造棒材和锻坯的铸锭应采用真空自耗电弧炉熔炼（自耗电极禁止使用钨极氩弧焊焊接），不允许使用回收的材料。Ti6242合金熔炼次数应不少于三次。

# 4.2 锻件

# 4.2.1锻件生产

4.2.1.1锻件交付图应有需方认可并会签。经会签的工艺文件单方面无权更改。因设计图样或本技术条件更改影响生产工艺时，工艺文件必须进行相应更改，确保工艺文件受控。生产锻件的技术资料应保存20年以上。

4.1.1.2锻件生产的主导工艺应按HB/Z199的规定执行，在试制、转产或改变主导工艺时，应按HB5402的规定执行。

# 4.2.2锻件几何外形

锻件的几何外形、尺寸和公差应符合锻件毛坯图样的规定。热处理前，需要在锻件中心处钻一个孔。

# 4.2.4锻造温度

锻件毛料的纵轴需与锻件的纵轴重合（在锻模上时）。

锻造温度不能高于 $ \beta $相变点以下14℃，并且能满足后续章节（4.2.6， 4.2.7，4.2.8）的要求。

# 4.2.11表面质量

4.2.11.1 锻件的表面不允许有夹杂等影响材质的冶金缺陷。

4.2.11.2 锻件的表面不允许有裂纹、分层、折叠等缺陷。对表面缺陷允许采用打磨或机械加工的方法，清理深度应不超过该处机械加工余量之半；对压伤、压坑等缺陷，如其深度不超过机械加工余量的2/3，则允许不清除。在所有清除和允许不清除缺陷的部位，均需保证锻件留有名义加工余量的1/3。需方要求时，还应保证锻件留有后续加工过程中所需的附加加工余量。

对非加工表面，打磨后，应保证锻件尺寸不小于该截面的最小尺寸。缺陷的清理处应圆滑过渡，非加工表面上的清除宽度应不小于深度的10倍。应全部清除α层、表面污染层。

锻件验收时，需方视情况采用下厂验收或入所验收的方式。需方验收前，产品的质量证明书及合格证签署必须完备。

# 5.4.2验收内容

5.4.2.1 检查锻件质量证明书和产品合格证的正确性和完备性。

5.4.2.2 按本文4.2.2与4.2.11条逐件检查锻件的外形与尺寸、表面质量。

# 6 标志、包装、运输、贮存

供需双方对检验结果有分歧时，应进行仲裁检验。仲裁单位由供需双方选定，仲裁检验结果为最终结果。

# 6.1 标志

每个锻件在规定部位标印材料牌号、图号、熔炼炉号、锭节号、生产批号、供方检验印记。

# 6.2 包装、运输、贮存

供方可根据需要确定包装形式或不包装。

# 7 质量证明文件

锻件生产过程中必须由检验部门填写质量证明书，其内容包括：

a. 名称、代号、材料牌号、熔炼炉号和生产批号；

g. 几何形状和尺寸；

h. 表面质量记录；

i. 超声波检验结论；

j. 超差问题处理记录；

k. 其它检验结果和结论。

1. 最终检验结论。
