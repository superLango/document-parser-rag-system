# 3 技术要求

# 3.1 原材料

# 3.1.1 供应商

锻件用原材料生产单位应属于黎明公司的合格供应商：西部超导。

<!-- page: 4 -->

供货方应严格贯彻410JX（通用）-D-001中1.2.2条对锻件用原材料合格供应商的年限控制要求。

# 3.1.2 冶炼方法

合金采用真空感应熔炼加电渣重熔加真空电弧炉重熔冶炼方法生产，所采用的冶炼方法应在合同和质量证明书中注明。

# 3.1.3 其他要求

锻件用原材料其他要求应符合Q/S19.4011-2018，原材料经复验合格后方可投产。

按照 019100950001.JG.344 某发动机返回料及原材料制备过程控制管理要求进行管控。

GH4169合金制备时不允许直接采用返回料屑料用于真空感应熔炼，其中返回料使用比例不超过 40%（返回料非外购，均为西部超导0级返回料）。

# 3.2 锻件

# 3.2.1 理化件选取和分配

锻件的理化检测在解剖件上进行。

每验收批生产的合格锻件数量≤4件时，取属于或相当于铸锭头部的1件锻件作为解剖件进行测试，供需双方各1/4用于出入厂检验，剩余1/2件需沿轴向均分后3*1/6交付订货方。理化件应与同批锻件经过相同的热处理过程，解剖件与锻件相同标刻要求。此规定为每验收批交付的锻件数量=每验收批生产的合格锻件数量-1。

每验收批生产的合格锻件数量：4件<数量≤8件时，取属于或相当于铸锭头部的1件锻件作为解剖件进行测试，供需双方各1/4用于出入厂检验，剩余1/2件需沿轴向均分后7*1/14交付订货方。理化件应与同批锻件经过相同的热处理过程，解剖件与锻件相同标刻要求。此规定为每验收批交付的锻件数量=每验收批生产的合格锻件数量-1。

# a）常规检验项目

在解剖件上按 Q/S19.4019-2026的要求进行化学成分、室温拉伸、

# 3.2.3 本体硬度检验

锻件逐件进行本体硬度检验，检验位置为小头端面，均沿圆周方向间隔 90°均布的4点，硬度应不大于277HB（硬度值供参考）。硬度应在质量证明书中逐件、逐点注明；交付状态锻件表面不应带有硬度痕迹。

# 3.2.4 超声波检验

锻件应逐件按 Q/S10-0104 进行超声波检验，缺陷显示的波幅应不大于直径 1.5mm 当量平底孔所显示的波幅。

# 3.2.5 其他

锻件其他要求应符合Q/S19.4019-2026及锻件图纸。
