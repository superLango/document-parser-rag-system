# 2. 资料来源

2.1. 甲方向乙方提供零件图样一份，供乙方设计锻件毛坯图，经双方会签后生效，乙方向甲方提供锻件毛坯图一式三份。

2.2. 甲方零件图更改应及时向乙方提供更改单，并注明在制品和已制品的处理意见，乙方及时贯彻更改。

2.3. 保密要求：所有资料及样件不得转让给第三方。

# 3. 技术状态控制

涉及锻件图样和相应文件的更改，甲方应及时通知乙方，乙方应及时贯彻更改，实物需贯彻甲方技术状态管理要求。技术状态发生更改时，甲方应及时向乙方传递技术状态更改要求，乙方应及时贯彻，并按要求对在制品、制成品进行处理。

# 4. 首件鉴定要求（按需）

4.1. 乙方应按照GJB 908及技术协议要求进行首件鉴定。

4.2. 首件鉴定前，乙方应书面通知甲方及甲方顾客代表参与首件鉴定，首件鉴定合格后允许批产。

4.3. 乙方对首件制造过程中产生的超差应及时查找原因，采取纠正措施。

4.4. 乙方应按照GJB 908要求，当图样、工艺方法、工艺装备等有重要更改时，重新进行首件鉴定，并通知甲方。

# 5. 不合格品管理要求

5.1. 乙方在制造过程中发现不合格品时，应立即对不合格品进行标识、隔离，不合格品未经处理不得交付。对影响锻件最终合格交付的故障必须提交甲方审理，不得私自处理。

5.2. 不合格品审理审批手续办理完毕后，甲方将不合格品审理结论通知乙方，经审理后返修的锻件，乙方应编制补充加工工艺文件，重新验证后将补充加工工艺文件随锻件一并移交甲方。

5.3. 不合格品审理归零的锻件，乙方应单独开具锻件质量证明文件，并在锻件

# 6. 次级供应商管理

乙方研制过程中涉及的原材料外购厂家、热处理是否委外二级供应商、外委二级供应商厂家、外委特种工序名称以及厂家资质等，须经甲方确认同意。对主导工艺外包、特种工艺外包、特殊过程外包、特种检测外包建立通报、审批机制，如新签订或变更时经甲方审签。

未经甲方允许，乙方不得擅自更改锻件的原材料及锻件来源。待考核试验过后，须固化原材料及锻件来源。

# 7. 质量保障要求

7.1. 乙方应保证产品质量满足规定要求，甲方视产品质量的实际情况有权参与乙方的产品检验工作。

7.2. 乙方不得将委托授权的产品或零件再委托其他厂家进行加工，也不允许将工序外委至其他厂家，如需将工序外委至其他厂家加工，必须经与甲方协调同意。

7.3. 涉及设计图样中的问题，由乙方以书面形式与甲方联系或协调，甲方负责设计图样的解释和说明并以书面形式予以回复。

7.4. 乙方交付后的锻件在甲方加工或装配过程中，如发生问题时，乙方有责任和义务作好服务和持续改进的工作。

# 8. 技术要求

8.1. 锻件图号、名称、供应状态等信息见表1。

8.2. 锻件形状、尺寸及公差应符合双方会签锻件图。

8.3. 表1中原材料应符合其对应的相关标准及规定，原材料由乙方提供，乙方须对原材料进行入厂复验，复验合格后方可投入使用。

8.4. 锻件的化学成分应符合GJB2744A-2007的规定，锻件的材料牌号应进行光谱或火花检查。

8.5. 锻件需经热处理后供应，且符合表1要求。

8.6. 锻件的力学性能应符合 GJB2744A-2007 的规定。

8.7. 锻件的低倍组织应符合 GJB2744A-2007 的规定。

8.8. 锻件的显微组织应符合 GJB2744A-2007 的规定。

8.9. 锻件的β转变温度应符合GJB2744A-2007的规定。

8.10. 锻件的超声波检验应符合 GJB2744A-2007的规定。

8.11. 锻件的外观质量应符合 GJB2744A-2007 的规定。

8.12. 氢含量：锻件在供应状态下测定氢含量，其含量应不大于 0.015%。

# 8.13. 表面质量

8.13.1. 锻件表面应进行清理和吹砂，其表面状态应满足锻件图样和GJB2744A-2007的要求。

8.13.2. 锻件表面不允许有过烧裂纹和影响材质的其它缺陷存在，发现后锻件应予报废。

8.13.3. 在锻件的加工表面上，裂纹、折叠、嵌入和成片的氧化皮必须全部清除，但均应保证锻件留有不小于三分之一的公称加工余量。

# 10. 标记

每批锻件和理化件应进行标印，标印内容包括：材料牌号、锻件图号、熔炼炉号、热处理批号、检验印，当锻件和理化件较小无法标刻标记时，允许以挂标签形式标识印记，具体标刻内容及位置以双方会签图纸为准。

# 11. 组批

锻件应成批提交验收。每批应由同一图号（或代号）、同一材料牌号、同一熔炼炉号、同一热处理炉批、同一制造方法和同一生产周期制造的锻件组成。

12. 交付

每验收批锻件应附有质量部门签发的合格证交付，合格证上注明：承制单位、原材料供应商、合同号、锻件名称、锻件图号、材料牌号、交货状态、熔炼炉号、投产批号、热处理炉号、数量、原材料标准号、锻件标准号、检验印、各理化数据并附带报告复印件（具体包括： $ \textcircled{1} $原材料质保书； $ \textcircled{2} $特殊过程确认表； $ \textcircled{3} $化学成分检测报告（允许转抄原材料质保书）； $ \textcircled{4} $热处理报告； $ \textcircled{5} $力学性能报告； $ \textcircled{6} $低倍组织报告； $ \textcircled{7} $显微组织报告； $ \textcircled{8} \beta $转变温度报告； $ \textcircled{9} $超声波检验报告等。）锻件每验收批提供符合第9条的技术要求及数量的样件，做为甲方入厂复验用。

13. 包装和运输

13.1. 零件包装允许同批次的若干零件并随包装，并注明锻件图号、批次号。

14. 其它

13.2. 零件运输过程中发生丢失、磕打、碰伤等发运不当造成的损失由乙方负责，甲方以最终入厂验收为准。

14.1. 本技术协议适用于甲方委托乙方承制（生产）附表1中的件号（产品）的全部期限，如甲方与乙方签订的采购（委外加工）合同履终止的，本协议中已经明示或默示的约束义务对双方仍具有效力。

14.2. 本协议作为甲方委托乙方承制（生产）附表1中的件号（产品）的专项技术约定，与双方签订的采购（外委加工）主合同具有同等效力。

14.3. 未尽技术事宜按 GJB2744A-2007的规定执行，锻造过程中出现其它问题，由双方协商解决。

15. 协议份数

本协议一式四份，甲乙双方各两份。

16. 本技术协议双方代表签字盖章后生效。
