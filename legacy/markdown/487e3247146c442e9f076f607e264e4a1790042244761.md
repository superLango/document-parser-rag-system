# 3、力学性能

# 4、微观组织

铁素体-奥氏体组织，铁素体含量在40%至60%之间。不允许存在任何因排列方式和/或数量而对化学物理性能以及耐腐蚀性产生不利影响的析出物。

# 5. 交付条件

根据DIN EN 10228-4 class 1，在首件样品检验(系列)批准后交货。

# 6、焊接

不允许进行焊接。

# 7、表面处理

均匀的表面光洁度对部件质量至关重要。因此，不允许进行局部打磨，例如打磨错误需标记。纠正措施必须事先与购买方的质量控制部门协商确定，如有必要，还需以书面形式记录在验收证书中。

# 8、无损检测

锻件100%进行超声波检测，结果符合 DIN EN 10228-4 quality class 1要求。

锻件按需进行渗透检测，结果符合 DIN EN 10228-2 quality class 1要求。

# 9、晶间腐蚀测试

晶间腐蚀按IS03651-2-1998 A法进行检验。

# 10、标识

按照图纸图示位置进行标识；图示位置用标签贴上并确保不易掉落；

标识内容：锻件图号、投产批号、材料牌号、熔炼炉号、热处理炉批号、锭节号，订单号，供方名称与代号。

# 11、包装及防护

必须以防止损坏零件或表面的方式进行保护、储存和运输。零件必须是不含铁素体污染物。

四、验收及其他

# 四、验收及其他

供方在锻件指定位置上进行标记；图示位置用标签贴上并确保不易掉落同时供方向需方提供合格证书；

锻件交付后，若需方在复检及加工过程发现问题应及时通知供方，供方应积极配合，必要时及时赶赴现场解决问题。在收货后生产期间与后续使用期间发现锻件本身的问题需要供方重新免费提供合格的锻件。

注：任何产品如果与本技术协议有偏差的需要得到购买方批准同意才能交付。
