# 4.2 锻造

锻造设备： 2000T ， 3600T 。

钢锭头部 T （补缩端）切除率 ≥3% ，尾部 W （电极板端）切除率 ≥7% ；

锻造温度范围： 850~1200℃ ；

保证足够锻比，总锻造比应不小于 3 ；

# 5 试验方法及验收准则

# 5.1 组批原则

组批要求：是指来自同一熔炼号、经过同一制造生产工艺、同炉热处理且尺寸 相近的部件。

# 5.2 取样及检验项目

试料在性能热处理后截取（或切下），并作适当的标记。

试料应具有足够的尺寸，以便能截取所有试验和可能做复验所需的试样。

只要部件的形状许可，切割后试样的轴线应垂直于主要锻造方向。该轴线到最 近热处理表面的距离：

 若厚度超过40mm，为20mm；

 若厚度不超过40mm，为厚度的一半。

试样中与试验有关的部分到其他热处理表面的距离：

 若厚度超过40mm，不得小于40mm；

 若厚度不超过40mm，不得小于部件厚度。

对于冲击试样，缺口轴线应垂直于锻制表面。

成品分析试样应取自力学性能试样的邻近部位,每批进行一次。

# 5.3 试验

铁素体含量检测参考 RMC1340 或者 GB/T 13305-2008 等相关等效标准进 行。验收标准：要求最终固溶态锻件铁素体含量 <0.5% 。

# 5.3.4 磁导率

磁导率测试参考 ASTM A342/A342M 进行。验收标准：要求固溶态锻件相对 磁导率低于 1.03 。

# 6 复验与重新热处理

若拉伸试验结果不符合力学性能要求，且试样有物理缺陷（不影响成品的使用 性能），或不合格的试验结果是由于试样装夹不当或试验机故障而造成时，则应取 试样进行再试验。如果第 2 次试验合格，该（批）零件予以验收，反之则按下述规 定执行。

如果拉伸试验中一项或几项结果不合格，则可取双倍试样进行复试。复试试样 应取自不合格试样的邻近部位。双倍试样的复试结果都应符合力学性能要求，复试 合格则该（批）零件可予以验收。

由于一项或几项力学性能试验结果不合格而被拒收时，允许重新热处理。重新 热处理的条件应列入试验报告。

重新热处理不应超过 1 次。

重新热处理后必须按本大纲相应条款的要求重新进行除化学成分分析、夹杂 物、磁导率以外的全部试验。

# 7 精加工

按采购图和采购合同约定的尺寸、公差对锻件进行精加工。最终机加工后的锻 件进行无损检测。

锻件在精加工完成后，应按采购图和采购合同约定的尺寸及公差进行检验。锻 件的尺寸公差和表面粗糙度应满足采购图纸及合同规定。

# 8 无损检测

无损检测人员应执行 ISO9712 标准或甲方认可的标准取得资质，且在 ISO9712 标准规定的范围内从事相应的工作，人员资质文件应附在质量文件中交付采购方。

# 8.1 目视检验

参考 RCC-MR 中 RMC7100 章节，执行部件表面和切割面 100% 目视检测，要 求表面平整均匀，无褶皱、气孔、裂纹和夹杂物。对目视检测有疑问的地方，参考 RMC4000 进行渗透检测。

具体检验按 PK-ZL-NDT-VT-2607273 目视检验规程执行。

# 8.2 渗透检验

对目视检测有疑问的地方，参考 RMC4000 进行渗透检测。

渗透检测验收标准如下：

尺寸大于等于 1mm 显示均应记录；

凡呈现下述显示的缺陷应予以拒收：

（ 1 ）线性显示；

（ 2 ）尺寸超过 3mm 的非线型显示；

（ 3 ）间距小于 3mm 的 3 个或 3 个以上排列成一直线的显示；

（ 4 ）在 100cm² 矩形表面上有 5 个或 5 个以上的密集显示。该矩形选自对显示 评估最不利的部位，且长边不应超过 20cm 。

渗透具体检验按 PK-ZL-NDT-PT-2607273 渗透检验规程执行。

# 8.3 超声波检验

# 8.3.1 检测时机

部件外形适合超声检测时才进行检测，检测的优先时机按下列顺序：

最终机加工后；

力学性能热处理后，无论该热处理后是否进行机加工。

出于几何原因部件或部件某些部位在热处理后不能进行超声波检测，则应在最 接近的中间阶段进行检测。

对于小尺寸部件，该检测可在半成品件上进行。

# 8.3.2 检测程序

超声检测程序按RCC-M MC2310 和MC2320 中规定进行。

探头频率正常为：

<!-- page: 16 -->

直射声束检测：频率2 MHz;

斜射声束检测：频率1MHz, 折射角根据部件的几何形状选择。

由于结构的限制，厚的部件可采用频率较低的探头。

# 8.3.3 检测范围

部件整个体积都要进行超声检测。

# 8.3.4 信号的评估

信号应按RCC-M MC2310 和MC2320 的规定进行评估。

# 9 缺陷的清除和修理

只有用打磨法清除缺陷后，尺寸仍在允许公差范围内的部件才可以被接受。

打磨后，为确保缺陷完全消失，应按 MC4000 的规定做液体渗透检测。

验收准则按第 8.2 节的要求执行。不允许采用焊接方式修复表面缺陷。

# 10 标记

锻件应该有明确的标识，标识内容可能包括锻件的规格、数量、生产批次、 供应商信息等。标识需要清晰、易读、持久，以便于跟踪和追溯。标识的重要性在 于可以帮助产品质量的控制和追溯，同时也可以保障产品的合法性和安全性。 标记 应按和合同规定执行，并至少包括以下内容：

a) 锻件制造厂名称或识别标志；

b) 材料牌号；

c) 炉号；

d) 采购合同号（如有）。

# 11 清洁、包装、运输

# 11.1 清洁

确保交货产品表面无油脂污物、无锈斑、灰尘及其它污染物，不允许被卤素和 卤素化合物的物质污染。在材料的制造，加工和运输过程中，应避免接触到可能对 材料性能和完整性产生不利影响的物质，如铅、锌、铜、铝、镉、锡、汞、锑、 铋、硫、卤素和其它低熔点金属和它们的合金及化合物。

# 11.2 包装

钢板的包装应该确保安全、防潮、防尘。包装方式可能包括托盘、箱装、袋装 等，具体包装方式需要根据钢板数量和交货地点等因素确定。包装材料应该符合相 应的环保和卫生要求，以确保产品的安全和长期存储。

包装应能保证产品在贮存、运输过程中不被碰伤、弄脏、弄湿，且不应与低熔 点元素 S 、 Pb 、 Zn 等接触，应防止与其他钢材接触。根据材料的用途和订货合 同进行包装，包装应符合国家标准要求。

# 11.3 运输

钢板在运输过程中需要确保安全、及时、准确地送达目的地。运输方式可能包 括公路、铁路、海运、空运等，需要根据钢板数量和交货地点等因素确定。在运输

<!-- page: 18 -->

过程中，需要确保钢板不受损坏，保证产品的质量和安全。运输过程中需要严格遵 守相关的安全规定和标准，以确保产品的运输过程顺利进行。

材料在贮存和运输过程中不允许与低熔点元素 S 、 Pb 、 Zn 等接触。防止与 其他钢材接触。供货商须负责将成品件安放到适宜的运输或存储装置之上，对成品 件提供足够的保护，避免搬移及运输过程中对成品件的损坏或冲击。供货商应在保 证成品件安全的情况下，使用符合搬运要求的搬运工具对成品件进行搬移和运输。

# 12 完工报告

交货时随同板材一起提交产品合格证及产品质量证明书。产品质量证明书内容 至少包括 :

➢ 订单编号或合同号、订单信息 ;

➢ 制造商名称和商标 ;

➢ 炉批号 ;

➢ 热处理记录 ;

➢ 技术要求各项目测试结果及报告 ;

➢ 不合格项及其处理。
