本文件作为莱阳核电 5 、 6 号机组堆内构件、快拆装密封组件用原材料采购 技术规格书的补充，规定了原材料采购的补充技术要求。

# 1 适用范围

莱阳核电 5 、 6 号机组反应堆堆内构件的安全等级为 SC-3 级，抗震类别为 I 类，质保等级为 QSA1 级。

莱阳核电 5 、 6 号机组快拆装密封组件的安全等级为 SC-1 级，抗震类别为 I 类，质保等级为 QSA1 级。

# 2 参考文件

HAF003 核电厂质量保证安全规定

HAF601 民用核安全设备设计制造安装和无损检验监督管理规定

ASME BPVC 锅炉及压力容器规范（ 2021 ）

# 3 一般规定

a ）材料除满足采购技术规格书的规定外，还应满足本文件的规定，如两者 的技术要求不一致，供应方应在制造前向采购方书面澄清。

b ）堆内构件不锈钢原材料 Co 含量≤ 0.05% 。

c ）材料的包装、运输应考虑防止磕碰、划伤，回厂验收如表面质量不满足 采购要求则拒收。

d ）提前交付或与产品一起交货的试料，应在试料上标记炉批号、取样相对 位置，主变形方向或锻造方向等信息。

e ） 关于批的定义：所谓批是指来自同一炉罐号，采用相同制造工艺生产，同 炉热处理，且尺寸相近的零件。

# 4.1 晶间腐蚀试样取样要求

晶间腐蚀试样每批取 1 组（ 2 个）， 2 个试样均需要敏化 + 腐蚀弯曲。

# 4.2 F304/F304H 不锈钢锻件主要元素含量要求

4.2 F304/F304H 不锈钢锻件主要元素含量要求

# （ 1 ） F304 不锈钢锻件

熔炼分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

# （ 2 ） F304H 不锈钢锻件

熔炼分析： C 含量 0.040~0.050% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

成品分析： C 含量 0.040~0.050% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

# 5 板材采购补充技术要求

# 5.1 钢板熔炼要求

连铸坯：厚度不大于 50mm 且单重不大于 10 吨的钢板允许采用连铸坯制造。

电渣钢锭锻制或轧制坯：厚度大于 50mm 或单重大于 10 吨的钢板只允许采 用电渣钢锭锻制或轧制坯。

# 5.2 交货状态

钢板应以固溶处理状态交货。

钢板热处理后，应经酸洗或打磨去除氧化皮。

针对厚度 6.4mm 钢板，需要提高表面质量，钢板在表面经过酸洗后应进行 抛光处理。

# 5.3 无损检测

对于板材的 UT 检验，要求对整张钢板正、反两面进行 100% 体积检验。

# 5.4 304 不锈钢板材主要元素含量要求

熔炼分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 19.50% ； Ni 含量： 9.00 ～ 10.00% 。

成品分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 19.70% ； Ni 含量： 9.00 ～ 10.00% 。

# 5.5 晶间腐蚀试样取样要求

晶间腐蚀试样每批取 1 组（ 2 个）， 2 个试样均需要需要敏化 + 腐蚀弯曲。

# 6 管材采购补充技术要求

# 6.1 炉批控制

在满足采购技术规格书要求的前提下，尽量减少分批。

# 6.2 交货状态

管材热处理后，应经酸洗或打磨去除氧化皮后交货，如采用真空炉或其他光 亮退火的方法进行热处理，则不需要进酸洗。

<!-- page: 7 -->

管材在酸洗前需要进行内外表面加工，可以通过机加工或者表面修磨抛光等 工艺以保证管材内外表面质量和尺寸要求。

# 6.3 无损检验

对于内、外壁回厂不加工的管材，表面缺陷的目视检查和液体渗透检查及验 收标准应按零件表面的要求进行。管径较小时应借助内窥镜检查其所有内表面。

目视检查：钢管内、外表面应光滑平整，不得有发纹、裂纹、折叠、结疤、 夹杂、分层、纵向划痕、起皮、斑点等缺陷，无肉眼可见的擦伤、凹面、辊印和 麻点存在。

# 6.4 304 不锈钢管材主要元素含量要求

熔炼分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

成品分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

# 6.5 晶间腐蚀试验要求

a ）直径≤ 38mm 的管材，取完整管段作为试样，每批取一组（ 2 个），按 ASTM A262 方法 E 的要求进行试验，试验后管材内、外表面均要求无晶间腐蚀裂纹， 若有疑问则可以用金相法判定。

b ）直径＞ 38mm 的管材，在管材内外壁各取一组试样（ 2 个）。试样靠近内 表面或外表面截取；如管材回厂不加工时，试样弯曲表面由材料原表面构成；如 管材回厂加工时，则试样靠近原材料内 / 外表面 1mm 处截取，弯曲表面为距离原 材料内 / 外表面 1mm 处。按 ASTM A262 方法 E 的要求进行试验，试验后弯曲试 样表面、侧面均要求无晶间腐蚀裂纹，若有疑问则可以用金相法判定。

c ）晶间腐蚀试样每批取 2 组（内外表面各 2 各，共 4 个）， 4 个试样均需要 需要敏化 + 腐蚀弯曲。

# 6.6 标识

对于成品交货的管材，表面标识不允许振动笔、钢印、油漆笔，只能贴标签 或者挂牌标识。

# 7 棒材采购补充技术要求

# 7.1 炉批控制

在满足采购技术规格书要求的前提下，尽量减少分批。

<!-- page: 8 -->

# 7.2 钢锭化学分析要求

对钢锭的头部、尾部均需取样进行化学成分分析，要求化学成分满足采购技 术规格书要求。

# 7.3 304/304L 不锈钢棒材主要元素含量要求

# （ 1 ） 304 不锈钢棒材

熔炼分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

成品分析： C 含量≤ 0.035% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

# （ 2 ） 304L 不锈钢棒材

熔炼分析： C 含量≤ 0.030% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

成品分析： C 含量≤ 0.030% ； Cr 含量： 18.50 ～ 20.00% ； Ni 含量： 9.00 ～ 10.00% 。

# 7.4 晶间腐蚀试样取样要求

晶间腐蚀试样每批取 1 组（ 2 个）， 2 个试样均需要需要敏化 + 腐蚀弯曲。

# 7.5 宏观浸蚀试验

应从每批交货状态的棒材中取相当于或接近钢锭头部的一根棒材按 ASTM E340 进行宏观浸蚀试验。在取自棒材两端全横截面的酸浸试片上，不得有肉眼 可见的缩孔、气泡、裂纹、夹杂、夹渣、白点及翻皮等缺陷。

# 7.6 制造要求

a) 棒材交货状态均为热处理态，冷作硬化棒材以冷变形态交货。具体要求 按对应采购技术规格书执行。

b) 采购尺寸公差应按对应采购图（如有）的要求执行。棒材允许按倍尺交 货，但交货总长度要满足订货长度要求，具体按订货合同执行。

c) 除采购图特殊说明外，棒材、扁钢或型材应光坯交货，表面粗糙度为≤ 6.3 μ m 。棒材尺寸公差按如下要求执行：棒材的直径、扁钢或型材的边长尺寸公 差为（ 0 ， +2 ） mm ，单段长度公差为（ 0 ， +10 ） mm 。双联管用型材长度公差为 （ 0 ， +5 ），宽度公差为（ 0 ， +2 ），厚度公差为（ 0 ， +1 ）。

d) 所有棒材表面不得存在磕碰伤。

e) 棒材的冷加工硬化应在室温下进行，硬化后的棒材直径应尽可能接近对

应产品的交货尺寸，然后通过机加工到订货尺寸后交货。“力学性能规定值”中 的棒材“直径”应为棒材的交货直径。
