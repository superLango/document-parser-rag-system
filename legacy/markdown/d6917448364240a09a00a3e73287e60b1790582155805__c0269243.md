# 45Cr5MoSiAV1(H13)合金原材料技术协议

# 1 范围

本协议适用于供无锡派鑫航空科技有限公司Φ30-300mm的4Cr5MoSiV1圆钢，协议规定了钢的尺寸、外形、重量及允许偏差、技术要求、试验方法、检验规则、包装、标志和质量证明书等。

# 3 尺寸、外形及允许偏差

3.1轧圆的尺寸允许偏差符合GB/T 702的3组规定，锻圆的尺寸允许偏差GB/T 908的2组规定。

3.2轧圆的不圆度应符合GB/T 702标准表9的规定。

3.3 轧圆弯曲度符合 GB/T 702的2组规定，锻圆弯曲度符合 GB/T 908规定。

3.4 圆钢的通常长度为 4000～6000mm；按定尺或定倍尺交货的圆钢，定尺长度允许偏差为 0/+50mm，具体定尺及单倍尺长度在合同中注明；按定尺交货的圆钢，允许有不超过 10%的非定尺交货。

3.5 重量：圆钢按实际重量交货。

# 4 技术要求

# 4.1 牌号及化学成分

钢的牌号及化学成分符合GB/T 1299规定，化学成分允许偏差符合GB/T 222规定。

注：钢中气体：O≤20ppm，H≤20ppm。

# 4.2 冶炼方法

采用电弧炉+真空脱气或电弧炉+电渣重熔方法冶炼。

# 4.3 交货状态

退火后车光态交货。

热轧圆钢轧制比≥6，锻制圆钢锻造比≥4。

# 4.7 表面质量

圆钢表面不得有可见的结疤、裂纹、折叠及夹杂缺陷，如有这些缺陷必须打磨进行清理，表面粗糙度要求Ra6.3。缺陷清理的深度不得超过0.5mm，圆滑清理，清理区域的长度：宽度：深度≥10:6:1。

# 4.8 超声波探伤

圆钢应 100%进行超声波探伤，探伤标准为 GB/T 6402的4级。

# 6 检验规则

# 6.1 检查和验收

6.1.1 钢材出厂的检查和验收由供方质量技术监督部门进行。

6.1.2 供方必须保证交货的钢材符合本标准或合同的规定。

# 6.2 组批规则

钢材应按批检查和验收，每批由同一牌号、同一炉号、同一加工方法、同一尺寸、同一交货状态钢材组成。

6.3 取样数量及取样部位：每批钢材的取样数量及取样部位应符合表5的规定。

# 6.4 复验判定规则

钢材的复验与判定规则按 GB/T 17505规定执行。

# 7 包装、标志及质量证明书

钢材的包装、标志和质量证明书应符合 GB/T 2101的有关规定。
