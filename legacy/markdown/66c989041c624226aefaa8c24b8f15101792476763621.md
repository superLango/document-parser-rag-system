# 技术协议

# 协议名称：SW-3H项目派克钢锻件技术协议

甲方：成都飞机工业（集团）有限责任公司

乙方：无锡派克新材料科技股份有限公司

成都飞机工业（集团）有限责任公司

2026年 月 日

# 总则：

1、甲方：成都飞机工业（集团）有限责任公司

乙方：无锡派克新材料科技股份有限公司

2、本协议作为 SW-3H 项目锻件经济合同的正式附件，在 SW-3H 项目锻件经济合同签定（盖章）后正式生效。

# 一、甲方的主要职责：

1. 甲方负责向乙方提供锻件生产所需的零件数模，并将生产期间技术状态变更的更改依据及时传递给乙方，如由于零件数模更改未及时通知乙方更改相应数模和图纸造成锻件、模具报废由甲方承担。

2. 甲方负责以书面《锻件协调更改信息传递单》（见附件模板）的形式传递技术状态变更信息。

3. 甲方负责对乙方设计的锻件数模（3D）进行确认，并会签其锻件毛坯图（2D）。

4. 甲方有权对乙方提供的锻件或粗加工件的外观质量、尺寸及公差、理化性能和超声波探伤进行入厂复验。

5. 甲方有权全程参与乙方锻件试制过程控制与鉴定，以确保锻件满足工程设计的要求。

6. 甲方根据乙方生产情况，派出跟产人员负责协调处理乙方生产中出现的问题、监督乙方对制造依据的执行情况，并负责解答甲方所提供文件的疑问。

7. 对关键件、重要件的锻件，甲方及甲方的顾客方代表有进入乙方进行现场记录和工作的权利，包括派出常驻或流动的质量验收代表。

# 二、乙方的主要职责：

1. 乙方所承接的锻件，生产应封闭在乙方厂内完成，不允许转第三方。

2. 乙方应严格按GJB904A“锻造工艺质量控制要求”进行锻件质量控制。

<!-- page: 3 -->

3. 乙方负责所承接锻件的生产交付任务，严格按照甲方提供的生产依据、双方确认的锻件数模（3D）和会签（甲方）的锻件毛坯图（2D）进行锻件的生产、检验（理化项目按会签的锻件毛坯图中的取样图进行）、交付，并对其生产锻件的质量全面负责。

4. 会签的锻件毛坯图由乙方通过档案部门晒发（一式四份）给甲方档案部门。

5. 乙方负责贯彻执行甲方的《锻件协调更改信息传递单》，及时跟踪完善相关工艺、技术、生产质量控制文件资料，换版、会签锻件毛坯图。如乙方由于接收到甲方技术状态变更信息通知而未及时跟踪更改相应数模、图纸及相关资料造成锻件、模具报废，则由乙方负责。

6. 乙方应对所用材料的供方进行质量评定，并按乙方的“合格供应商名录”实行原材料定点采购，并报备给甲方。

7. 乙方应对关键件、重要件的生产工艺进行工艺评审（必要时通知甲方）后方可投产。

8. 编制的工艺控制文件（PCD）和固化操作协议（FPA）文件提交甲方审签。

# 三、技术要求：

# （一）、原材料技术要求

钢锻件原材料30CrMnSiNi2A棒材应符合材料技术规范GJB1951-94，棒材应逐支进行超声波探伤检测，且应符合GB/T4162中A级要求。

（二）、锻件技术要求

1. 钢锻件技术要求

材料为 30CrMnSiNi2A的钢锻件按HB5024-89《航空用钢锻件》标准进行制造与验收。

2. 锻件的供应（交付）状态按表1执行。

4. II类锻件理化试验用解剖件的抽取数量要求按附件表1进行。具体的取样检验项目及其试样切取位置、数量按甲方、乙方会签的锻件毛坯图中的理化取样图进行；甲方用理化料由乙方切下并打上与锻件相同的标记，并应标记“流线（纤维）”方向随同批锻件交付甲方。

5. 锻件由乙方按相应锻件验收标准（规范）要求进行牌号分光检查 （100%）、锻件硬度检查。

6. 超声波探伤：

锻件的超声波探伤由甲方在锻件粗加工后按产品图（数模）的规定进行，乙方认可甲方的探伤结果。若有疑义，甲、乙双方协商。

7. 锻件组批：

按同一锻件图号（或代号）、同一熔炼炉号、同一投产批号组批。锻件应成批提交验收。

8. 组批数量：原则上不得低于附件表1中的最小组批数量。当甲方的订货数量不足最小组批数量但>1/2最小组批数量时，允许乙方按订货数量组成

9. 锻件标记：

# 9. 锻件标记：

按锻件图指定位置打上印记（钢印、气动打标或激光标刻，字迹应清晰可见），印记内容至少包含锻件图号和代号、热处理炉批号、投产（生产）批号、熔炼炉号、材料牌号、流线（纤维）方向、承制单位检印。

10. 锻件质量证明书（合格证）：

a. 锻件图号和代号、锻件名称、类别、本技术协议编号、锻件规范及版次、锻件毛坯图版次；

b. 材料牌号、熔炼炉号、投产（生产）批号、热处理炉批号；

c. 锻件数量、供应（交付）状态；

d. 锻件的热处理制度；

e. 理化取样毛坯的热处理制度；

f. 化学成分（化学成分允许乙方转抄原材料复验数据）；

g. 拉伸性能、冲击性能、硬度；（硬度指试样的理化检测的硬度）

h. 低倍、晶粒度；

i. 钢棒超声波探伤结论；

j. 锻件硬度；（指锻件交付状态的表面硬度）

m. 甲方和乙方名称、生产日期。

11. 若锻件外形尺寸出现超差，乙方应及时以让步使用申请单的形式书面通知甲方，在甲方确认能够满足零件挽救加工要求的书面反馈后，乙方可交付给甲方，同时附上甲方已确认的让步使用申请单。

12. 甲方在零件机械加工过程中，凡因锻造或原材料缺陷造成锻件成批或单件报废时，经甲、乙双方确认后，直接向乙方退货。甲方保留向乙方索赔的权利。

13. 生产工艺一经固化，重大工艺更改（材料厂商更换、设备更改、工艺方案及参数更改等）需提交书面申请报告，经甲方审批后再实施。

14. 锻件的生产工艺停产超过1年（从上一批锻件锻造生产结束之日开始计算）则需重新进行技术认证，技术认证由乙方以书面报告的形式提交甲方发表认证意见后，乙方按意见完成技术认证并通过装机评审后才能重新启动锻件批量生产及交付。

# 六、保密要求：

1. 乙方确保甲方提供资料、制造依据不得丢失、泄露，并按国家保密制度借阅和使用。

2. 乙方确保锻件生产过程、工艺文件、记录、质量证明文件、不合格品审理单内容、实物、有关锻件生产信息不得泄露，不得告知任何第三方。
