# 2.2.3 不锈钢材料

核级不锈钢材料应满足 ASME BPVC-II 及 ASME BPVC-III-1-NC的相关要求，非核级不锈钢材料应满足 ASME BPVC-II 或 GB/T 4237的相关规定。奥氏体不锈钢应以固溶处理状态交货，套筒中所用的不锈钢材料（包含管道及其连接紧固件等）钴含量的限值小于等于 0.05%。

# 变更后：

# 3.7 耐腐蚀性能要求

a) 奥氏体不锈钢应以固溶处理状态交货。

b) 奥氏体不锈钢（ASME牌号）应按ASTM A262-2015 R2021中E法进行晶间腐蚀试验；其它奥氏体不锈钢应按GB/T 4334中E法进行晶间腐蚀试验。

c）为避免水平孔道铝合金与不锈钢材料的直接接触，提高材料耐腐蚀性及耐磨性，在不锈钢表面镀铬，具体的基材预处理要求、镀覆工艺以及消除氢脆影响的后处理方法等均可参照 AMS 2460B 中 Class 2 执行，并依据标准提供的测试方法对镀层进行检测，最终保证镀层厚度、附着力、硬度等均满足要求即可。

d) 所有碳钢表面，应进行涂漆。不锈钢和铝合金等其它金属表面不涂漆。
