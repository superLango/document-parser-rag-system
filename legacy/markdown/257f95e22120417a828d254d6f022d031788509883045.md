# 二、基本要求

a 、除非设计单位另有规定，否则必须完成本文件规定的所有试 验要求。

b 、采用江苏隆达 GH4169 棒材生产的七级静子扇形块锻件按《优 质 GH4169 合金高强环形锻件》 Q/S10-0505-2004 检验合格后，进行 全面的质量评价方案。

c 、采用江苏隆达 GH4169 棒材生产的高压涡轮一级机匣锻件按 《 GH4169 合金环形锻件》 Q/S10-0504-2004 检验合格后，进行全面 的质量评价方案。

d 、采用江苏隆达 GH141 棒材生产的一导外环锻件按《 GH141 合金环形锻件》 Q/S10-0508-2004 检验合格后，进行全面的质量评价 方案。

e 、本文规定的标准检测项目以外的检测项目报实测结果。

f 、完成全面质量评价方案要求的所有检测项目后，向设计单位 提供完整详细的正式报告。

# 三、七级静子扇形块锻件的全面质量评价

# 3.1 、 Q/S10-0505-2004 标准要求的测试项目

采用江苏隆达 GH4169 棒材生产的七级静子扇形块锻件应按照 Q/S10-0505-2004 的规定进行所有项目检测，按照锻件粗加工图的要 求切取理化件，按标准要求在理化件上测试高、低倍组织和力学性能。

测试结果若不满足 Q/S10-0505-2004 标准要求，终止该批锻件的 后续测试（不允许重复热处理后再进行测试），锻造厂应组织查明不 合格原因，采取纠正措施，重新研制锻件并进行首件鉴定。

# 四、一导外环锻件的全面质量评价

# 4.1 、 Q/S10-0508-2004 标准要求的测试项目

采用江苏隆达 GH141 棒材生产的一导外环锻件应按照 Q/S10-0508-2004 的规定进行所有项目检测，按照锻件粗加工图的要 求切取理化件，按标准要求在理化件上测试高、低倍组织和力学性能。

测试结果若不满足 Q/S10-0508-2004 标准要求，终止该批锻件的 后续测试（不允许重复热处理后再进行测试），锻造厂应组织查明不 合格原因，采取纠正措施，重新研制锻件并进行首件鉴定。

# 4.2 全面质量评价及要求

按照本文 4.1 规定完成标准（ Q/S10-0508-2004 ）要求测试性能， 测试结果合格后，按本条规定在理化试环上进行全面质量评价。
