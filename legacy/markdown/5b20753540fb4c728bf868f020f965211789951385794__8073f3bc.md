# 一、目的及范围

为保证本公司生产的产品质量，规范原材料采购，使原材料的采购有据可依，特制定 本规范。

本规范规定了BEST 项目下偏滤器系统所采购的奥氏体不锈钢热轧钢板316L 的技术规 范与要求，适用于BEST 项目偏滤器系统中所使用的厚度为5mm 至100mm 的316L 板材。

# 三、职责

# 3.1 技术部

负责根据原材料对产品结构安全性的影响程度对原材料的采购提出具体要求。

# 3.2 质管部

负责对原材料进行检验验收，并对检测结果进行分析处理。

# 3.3 市场部

按照采购技术规范对原材料进行采购，并协助不合格品处理。

# 四、制造工艺

为了满足本规范中对结构和夹杂物含量的要求，钢的熔化可以通过适当的二次冶金处 理(氩氧脱碳(AOD)或真空氧脱碳(VOD))来完成。

供应商应提供详细的工艺工程文件。

# 5.2 理化特性

# 5.2.1 铁素体含量

使用经Pryce 和Andrews 修改的舍弗勒图(图RMC 1341.2，Section 3，RCC-MR 2007) 评估铁氧体含量应小于或等于0.5%。

# 5.2.2 磁导率

产品在退火后，在室温下测量其相对磁导率。测量值应低于或等于1.03。测试应按照 ASTM A342 进行。

另外，也允许使用磁导率仪(Foerster，Ferromaster 等)。在这种情况下，设备的类 型、商标和相关性(该材料、厚度、形状等)应由供应商提供。材料证书应提供其校准证书 的类型、商标和副本。

# 5.3 结构

进行显微检查，必须与每一块轧板的轧制方向平行。结构必须是均匀的。

# 5.3.1 晶粒尺寸

1）根据EN ISO 643 确定的晶粒尺寸等级应等于或大于2。

2）晶粒尺寸均匀性应在真实平均值附近±1。存在一些等级为1 或0 的晶粒是可接受 的。

3）测定取样应紧挨的力学测试取样位置。

1）数量和定义应符合ASTM E45 标准。

# 5.3.2 非金属夹杂物

-微观杂质(用显微检测方法检测的原生杂质)：适用方法D。A、B、C、D 类的等级 数最多为2。

-宏观杂物(外源夹杂物，矿渣或耐火材料)：它们是严格的禁止的。

2）测试样品应从每卷薄板或带材的一个边缘取下。

# 六、制造

# 6.1 制造方案

在生产作业开始之前，材料供应商应起草一份生产计划。经甲方批准后方可生产。

# 6.2 交货条件

板材应在溶液热处理、酸洗和钝化条件下交付，相当于根据EN 10088-2 进行的1D 表 面处理。

# 6.2.1 固溶处理

固溶处理应包括保持温度在1050°C 和1150°C 之间，然后进行水冷却，如果厚度较 小，则可进行空气冷却。记录热循环，保存的记录应在测试报告中显示。

# 6.2.2 表面条件

1）表面应酸洗。

2）在交付状态下，金属表面不得留有任何油或油脂的痕迹。

3）表面粗糙度Ra 平均应为6.3μm。使用符合EN ISO 4288 的粗糙度测量方法。

# 7.2 取样和测试

# 7.2.1 取样

测试样品应在板材进行固溶热处理后取样，并标记最终的轧制方向。

试验样品的尺寸应保证为所有试验和复试提供足够的试验样品。测试样品应在板的边 缘和中轴线之间的中间位置取。

在接近试样边缘的地方取试样时，不得超过等于板厚的距离。试件的纵轴应与轧制蒙 皮平行，并垂直于最终轧制方向。

拉伸试件纵轴位置如下：

-适用于30mm 或以下，厚板二分之一；

-厚度大于30mm，厚度四分之一；

-对于厚度小于10mm，试件的厚度应等于板的厚度(矩形截面试件)。

试验试样的截面应为圆形。其正常直径应为10mm，其尺寸按EN ISO 6892-1:2009 规 定。对于厚度小于20mm 的板，可以用矩形截面的试样代替圆柱形试样。

# 7.2.2 测试

拉力试验应在室温下按照EN ISO 6892-1:2009 进行，在高温下按照EN ISO 6892-2:2009 进行。

应记录以下数值：

-0.2%偏移时的屈服强度，单位为MPa；

-1%偏移时的屈服强度，单位为MPa；

-抗拉强度，单位MPa；

-断后伸长率为%；

-断后面积%。

断后面积%；屈服强度应给出1%偏移时的屈服强度和高温下的伸长率以供参考。

# 7.3 再处理

因一项或多项力学测试结果满足要求而被拒收的轧制薄板或带材可以退回再处理(根 据3.5.1 进行固溶热处理)，退回再处理条件应在测试报告中描述。不得进行一次以上的 再处理。

# 八、无损检测

# 8.1 目视检查

其表面应平整、均匀，无褶皱、搭扣、气孔、撕裂、裂纹和夹杂物。

切割至交货尺寸后，应目视检查边缘。应检查是否有解理或层压(例如，在轧制过程 中由细小的夹杂物组成)。如有疑问，应进行液体渗透检查。

# 8.2 渗透检查

应按照EN 10228-2 的要求对每个板进行100%液体渗透检查。所有暴露在真空中的表 面都必须使用经甲方批准的液体渗透剂。

# 8.3 体积检查

对所有板材进行100%的超声探伤。扫描应覆盖100%的体积。

检查应按照无损检测规程和EN 10307 中给出的标准进行，板身的质量等级为S3，板 边质量等级为E4。

# 九、焊接修复

不允许焊接修复。

# 十、尺寸检测

# 10.1 尺寸

厚度、长度、宽度、平整度、边缘弧度和偏度公差应符合EN10029：

-厚度公差-EN10029 中的C 级；

-平面度公差-EN10029 中的S 级；

-根据EN 10029 的规定，边缘弧度应限制在板材实际长度的0.2%以内，不垂直度应限 制在实际宽度(G)的1%以内。

应记录主要尺寸。这些值应在图纸上给出的公差范围内。

# 10.2 表面粗糙度 Ra

应小于或等于12.5μm(检查时可能需要更小的Ra)。Ra 的选择值和测试方法应由供应 商在技术制造计划中说明。根据EN ISO 4288 的16%规则进行粗糙度测量。

# 十一、标记

供应商应规定所使用的识别和标记方法，并在技术制造计划中进行描述。标记应通过 压印或买方指定的其他可接受的方式进行。

标记至少应包括:

-制造商名称或标志；

-材料等级；

-与质量记录相关的牌号或唯一识别号；

-轧制方向；

-炉号；

-尺寸，总重量；

-订单编号。

材料合格证上应附有每个板材的标识图片。

# 十二、清洗、包装、运输

包装须清楚地注明下列信息:

-供应商名称或标志；

-材料等级；

-尺寸:厚度、宽度、长度；

-与质量记录相关的牌号或唯一识别号；

-炉号。

供应商应确保货物符合适用于运输和目的地国家的法规要求。

# 十三、验收

材料测试报告和证书必须在交货前提供给买方。材料和认证应符合本规范。不符合本 规范的材料不能接受。

向买方提供一份质量证书，证明材料是按照材料规范的要求制造、取样、测试和检验 的，并已被证实符合这些要求。

# 十四、文件要求

供应商还应提供符合国际或国家标准的检验证书。证书应包括本规范中所述的所有测 试报告(即，所有测试以及符合本规范中规定的要求值/标准的任何重新测试结果)。此外， 还需要提供以下信息：

-材料名称和标记：

-炉号和零件编号：

-供应商标识：

-采购订单号：

-如果相关:偏差请求，不符合报告，内部不符合，签署的控制计划等。

所有度量衡均应使用公制SI。每份文件应以PDF 格式的电子文件提供。

# 十五、质量控制要求

所有供应商应具有买方认可的质量保证计划或ISO 9001 认证的质量保证体系。对于 现成材料的供应，不需要专门的质量计划和MIP。如果需要进行额外的测试，则应由认可 的第三方实验室进行。

关于目视和无损检测，应由符合ISO 9712 的合格检验员执行。
