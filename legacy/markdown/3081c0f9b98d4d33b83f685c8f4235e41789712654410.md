# 3. 要求

# 3.1. 材料

3.1.1. 铸锭应采取真空自耗熔炼，熔炼次数不少于两次，自耗电极不应使用钨 极氩弧焊焊接，不允许添加回收料。最后一次熔炼稳定阶段的压强应不大于 5Pa 。

# 3.2. 质保要求

产品为安全二级，质保等级 QA1 。

供货厂家通过 GJB9001C 的质量体系认证，并通过资质评定且运行两年以上： 应具备按科工法【 2005 】 311 质量体系完成安全级钛合金产品或其他安全级有色

<!-- page: 2 -->

金属产品的相关供货业绩（近三年内）。

供方应建立质量保证体系，制定质量保证大纲，并按质量保证大纲编制质量 计划，提交采购方审查确认，以确保采购的材料符合要求。

# 3.3. 关键工序要求

钛合金原材料（材质为 TC4ELI ）熔炼过程和锻造过程应具备相应的关键设 备。

# 3.4. 状态

供应状态：热加工态（ R ），保证锻比＞ 30 。

# 3.9. 低倍组织

从Φ 1200mm 锻坯上截取试样环，试样环经热处理后进行低倍组织检测。低 倍组织不应有裂纹、折叠、气孔、偏析、金属或非金属夹杂及其他目视可见的冶 金缺陷。

# 3.10. 显微组织

从Φ 1200mm 锻坯上截取试样环，试样环经热处理后进行显微组织检测。显 微组织应是两相区加工产生的组织，无完整的原始β晶界。并应符合下列规定 :

a)在转变β基体上分布着等轴α和(或)拉长α，且在原始β晶界上不存在连 续的网状α;

b)基本上全部为等轴α和(或)拉长α，且在原始β晶界上不存在连续的网状 α;

c)在片状α组织上分布着不连续和扭曲的晶界α。

# 3.11. 表面状况

环坯表面以打磨状态交付。打磨后保证表面无目视可见裂纹即可。

# 3.12. 外观质量

环坯表面不允许有影响后续热加工的有裂纹、折叠及其他缺陷。清理深度应 不超过其尺寸偏差，清理深度与宽度之比在两端面应不大于 1 ： 6 ，在侧面应不 大于 1 ： 10 。

# 3.13. 超声波检验

需确保锻件探伤合格，锻件按 GB/T5193-2020 进行超声波检验，应符合 B

# 4.2.3. 检验结果的判定

4.2.3.1. 化学成分不合格时，允许对不合格元素进行一次重复检验。若重复检验 仍不合格，则判定不合格；

4.2.3.2. 在拉伸性能检验中，如果有一个试样的检验结果不合格，允许取双倍试 样进行不合格项目重复检验。若重复检验仍有一个不合格，则判定不合格；

4.2.3.3. 在冲击性能检验中，如果有一个试样的检验结果不合格，允许取双倍试 样进行不合格项目重复检验。若重复检验仍有一个不合格，则判定不合格；

4.2.3.4. 在低倍组织检验中，若发现并判定有脆性偏析 ( 硬度明显高于基体的偏析， 常见的如富氧、富氮等偏析 ) 时，判定不合格；显微组织检验不合格，则判定不 合格。

4.2.3.5. 尺寸和外形、表面状况及外观质量不合格时，则判定为不合格。

# 4.3. 检验方法

4.3.1. 化学成分按 GB/T4698 （所有部分）进行。

4.3.2. 室温拉伸试验按 GB/T228.1-2010 进行。选用 R7 试样。室温冲击试验按 GB/T 229 进行。

4.3.3. β 转变温度按 GB/T23605 进行。

4.3.4. 尺寸精度用相应精度的量具进行。

4.3.5. 低倍和显微组织的检验按 GB/T5168 进行。

4.3.6. 表面状况、外观质量和产品标志用目视检验。
