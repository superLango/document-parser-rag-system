# TC11钛合金锻件联合研制合作协议

甲方：无锡派克新材料科技股份有限公司

乙方：江苏翔云钛合金新材料有限公司

# 一、适用范围

本协议适用于甲方（无锡派克新材料科技股份有限公司）与乙方（江苏翔云钛合金新材料有限公司）针对西飞公司TC11钛合金锻件的联合研制、性能评价等全部合作工作，明确双方在本次联合研制过程中的权利、义务与合作规则。

# 二、要求

# 2.1 原材料

乙方为甲方免费提供原材料，原材料需满足 GJB 2218A-2018标准，具体要求见表1。

# 2.2 锻件

甲方接到乙方棒材后，完成锻件试制、性能检测及评价工作。

# 2.3 其它要求

在合作研制过程中，甲、乙双方共享试制数据及研制结果；

锻件研制成功，乙方进入甲方在西飞的合格供应序列。在满足交期的情况下，同等价格优先选择乙方供货；

合作事宜未经双方同意不得向第三方泄露。

# 三、其他

未尽事宜双方友好协商解决；

本协议经双方签字后生效，传真及复印件有效。
