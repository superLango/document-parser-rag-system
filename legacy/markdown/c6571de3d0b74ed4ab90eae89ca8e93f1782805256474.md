# 总则：

1、甲方：成都飞机工业（集团）有限责任公司

乙方：无锡派克新材料科技股份有限公司

2、本协议作为12502项目锻件经济合同的正式附件，在12502项目锻件经济合同签定（盖章）后正式生效。

3、本协议按照商务合同要求，由成都飞机工业（集团）有限责任公司与制造商无锡派克新材料科技股份有限公司直接签订。

4. 设计方为成都飞机设计研究所。

# 一、甲方的主要职责：

1、甲方负责向乙方提供锻件生产所需的设计依据，并将生产期间技术状态变更的更改依据及时传递给乙方，如由于零件数模更改未及时通知乙方更改相应锻件数模和毛坯图纸造成锻件、模具报废由甲方承担。

2、甲方负责以书面《锻件协调更改信息传递单》（参见附件模板）的形式传递技术状态变更信息。

3. 甲方负责对乙方设计的锻件数模(3D)进行确认，并会签其锻件毛坯图纸(2D)。

4. 甲方有权对乙方提供的锻件或粗加工件的外观质量、尺寸及公差、理化性能和超声波探伤进行入厂复验。

5、甲方、设计方有权全程参与乙方锻件试制过程控制与鉴定，以确保锻件满足工程设计的要求。

6、甲方应将锻件的理化性能复验结果、试加工结论，并结合乙方的试制鉴定报告，发出锻件固化工艺的综合结论，并及时以书面形式（锻件试制鉴定书）传递给乙方。

7、甲方、设计方根据乙方生产情况，派出跟产人员负责协调处理乙方生产中出现的问题、监督乙方对制造依据的执行情况，并负责解答甲方、设计方所提供文件的疑问。

1. 乙方所承接的锻件，不允许转包第三方。

a. 锻件图号和代号、锻件名称、类别、本技术协议编号、锻件规范、锻件毛坯图纸版次；

b. 材料牌号、熔炼炉号（子炉号）、投产（生产）批号、热处理炉批/次号；

c. 锻件数量、供应（交付）状态等等，详细要求按第三章“质量证明书要求”执行。

4、乙方应严格按GJB904《锻造工艺质量控制要求》和CBGD903-018《钛合金锻造产品的质量控制要求》进行锻件质量控制；乙方应严格按HB5402《锻件试制定型规范》对每项锻件进行试制鉴定，试制鉴定报告需提交甲方、设计方会签。

5、乙方负责所承接锻件的生产交付任务，严格按照甲方提供的生产依据、双方确认的锻件数模（3D）和会签（甲方、设计方）的锻件毛坯图纸（2D）进行锻件的生产、检验（理化项目按会签的锻件毛坯图纸中的取样图进行）、交付，并对其生产锻件的质量全面负责，2D、3D一致性由乙方负责。

# 三、技术要求：

1、钢锻件用原材料技术要求：原材料棒材1Cr18Ni9Ti应符合GJB2294《航空用不锈钢及耐热钢棒规范》。棒材应逐支进行超声波探伤检测（乙方可转抄原材料厂的探伤结论），且应符合GB/T4162中A级要求。棒材应为无发纹电渣钢棒。

# 2、钛锻件用原材料技术要求

2.1、原材料棒材TC4，直径为350mm时，按标准JT-XX-CL-7的要求；直径为210mm时，按标准XJ-CL-4B的要求；直径≤150mm时，按标准GJB1538的要求。棒材应逐支按相应规范的要求进行超声波探伤检测（乙方可转抄原材料厂的探伤结论），合格棒材用于锻件生产。

2.2、原材料棒材TC4-DT应符合CBQB903-002《TC4-DT钛合金棒材和锻坯规范》。原材料应100%进行超声波探伤检验（乙方可转抄原材料厂的探伤结论），合格棒材用于锻件生产。

# 3、钢锻件技术要求

1Cr18Ni9Ti 钢锻件按 HB5024-89《航空用钢锻件》标准进行制造与验收。 1Cr18Ni9Ti 管接头模锻件应满足：

a）表面不得存在凹坑、撞伤、折叠、裂纹等缺陷；非加工面上不允许存在氧化层。

b) 模锻角（6~7）°。未规定的圆角半径：一般采用R2.5，数模中标明为第一尺寸系列的零件可采用R2的圆角。图纸未注明的尺寸公差按HB6077-1986，F级。

c）扳手凸台高度方向上允许增加机加余量（具体见会签的图纸）以确保尺寸精

度要求。

d）乙方在锻件出厂前进行100%磁粉检测。

# 4. 钛锻件技术要求

4.1、TC4钛锻件按ZZQB903-017《TC4钛合金锻件技术规范》进行制造与验收。 TC4管接头模锻件应满足：

a) 表面不得存在凹坑、撞伤、折叠、裂纹等缺陷；

b) 非加工面不允许存在表面富α层；

c) 锻件加热时应在保护气氛下或涂覆保护剂；

d) 模锻角（6~7）°。未规定的圆角半径：一般采用R2.5，数模中标明为第一尺寸系列的零件可采用R2的圆角。图纸未注明的尺寸公差按HB6077-1986，F级。

e) 扳手凸台高度方向上允许增加机加余量（具体见会签的图纸）以确保尺寸精度要求。

f) 乙方在锻件出厂前进行100%渗透检测。

4.2、TC4-DT钛锻件按CBQB903-004《TC4-DT钛合金锻件规范》进行生产和验收。

5. 锻件的供应（交付）状态按表1执行。

6、锻件的外形、尺寸及公差等具体要求按会签的锻件毛坯图纸执行。

7、I、II、III类锻件理化试验用解剖件的抽取数量要求按附件表1进行；对I类锻件应逐件（含解剖件）在锻件所带专用试料上进行理化试验。具体的取样检验项目及其试样切取位置、数量按甲方、设计方会签的锻件毛坯图纸中的理化取样图进行。甲方用理化料由乙方切下并打上与锻件相同的标记，并应标记“流线（纤维）”方向随同批锻件交付甲方。

# 10、锻件组批：

10.1、钢锻件组批：按同一锻件图号（或代号）、同一熔炼炉号（子炉号）、同一投产批号组批。锻件应成批提交验收。

10.2、钛锻件组批：按同一熔炼炉批棒材、同一生产批、同一热处理批、同一图号（或代号）的锻件组批。锻件应成批提交验收。

10.3、对于完全对称的左、右件，若采用同一熔炼号的材料，在同一生产周期制造，工艺完全一致，且属同一热处理炉批（次），允许按同一锻件图号处理，组成同一批提交验收，理化试验解剖件只抽左件，但质量证明书（合格证）应分别开具。

# 11、组批数量

原则上不得低于附件表1中的最小组批数量。

当甲方的订货数量不足最小组批数量但>1/2最小组批数量时，允许乙方按订货数量组成一批；

当甲方的订货数量≥最小组批数量时：交付批次<{（订货数量+解剖件数量）/最小组批数量}+1；

特殊情况报甲方采购部门处理。
