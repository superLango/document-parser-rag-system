# 汽轮发电机无磁性螺钉及部件磁导率测定

# 1 用途和使用范围

本标准规定了非磁性部件相对磁导率的最大值及其检查、验收标准（标准螺钉、螺栓，特殊螺钉、螺栓和金具）。

# 2. 引用文件

本标准引用以下文件

ASTM A342《弱磁材料磁导率测试》

GB/T 3098.6《紧固件机械性能 不锈钢螺栓、螺钉和螺柱》

GB/T3098.15《紧固件机械性能 不锈钢螺母》

GB/T3098.16《紧固件机械性能 不锈钢紧定螺钉》

GB/T5783《六角头螺栓 全螺纹》

# 3 相对磁导率数值

完工部件的相对磁导率的 $ \mu_{\mathrm{r}} $值必须≤1.3。

# 4 磁导率的检查

该检查用校准过磁体（在4.4中定义）的方法或磁导率仪进行

# 4.1 抽样方式

每台份少于等于24件的部件，进行100%检查

自制加工部件：每台份部件数量在25-100之间，依据部件数量的50%抽样检查。

按国标采购的外购件：每台份部件数量按照 100%检查。

# 4.2 磁性检查

磁体不能够吸引的部件==>磁导率低于1.3

磁体能够吸引的部件==>磁导率高于1.3

有轻微的吸引力，意味着磁导率接近1.3

精确的数值要用验磁器或者磁导率仪来进行测量。

# 4.3验收标准

<!-- image: page 3 -->

# 重要提示：

某些部件由于冷轧处理或机械加工表面硬化，磁导率可能超过1.3。在这种情况下，在惰性气体中进行的热处理能够使这些部件的非磁性奥氏体结构得到恢复。

决不能进行如下处理：

- 影响完工部件的表面质量或尺寸

- 在部件上进行不符合 GB/T 3098.6，GB/T 3098.15，GB/T 3098.,16，GB/T5783 中所要求的保证机械性能的处理，使其机械性能降低的数值低于相应标注。

# 4.4 磁体的定义

特性：

- 剩余磁场 Br $ \geq $ 0.89T

- 内禀矫顽力 Hcj $ \geq1 5 0 $ kA/m
