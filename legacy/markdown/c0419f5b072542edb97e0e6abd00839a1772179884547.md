# 编制说明

无锡派克采用抚钢原材料已完成了GH4169合金承力环锻件小批稳定性验证，且完成采用卡本特原材料试制的GH4169合金承力环锻件的验证并通过质量评审，现编制本协议用于GH4169合金承力环锻件的正式批产订货。本技术协议各方签字盖章后生效，生效后原协议“410SJX-D-2019-182《GH4169合金承力环锻件订研制货技术协议》”及“410SJX-D-2021-300《GH4169合金承力环锻件研制订货技术协议》”自动作废。

本协议与“410SJX-D-2019-182”及“410SJX-D-2021-300”的主要差异为：

1、批产后减少理化检测项目及数量。

2、增加原材料供应商。

3. 技术要求

# 3.1 原材料

# 3.1.1 供应商

锻件用原材料生产单位应属于黎明公司的合格供应商：抚钢、CARPENTER（卡本特）、中航上大、西部超导、江苏隆达。供货方应严格贯彻410JX（通用）-D-001中1.2.2条对锻件用原材料合格供应商的年限控制要求。

# 3.1.2 冶炼方法

合金采用下列冶炼方法生产，所采用的冶炼方法应在合同和质量证明书中注明：

（1）真空感应熔炼加真空电弧炉重熔；（仅限抚钢产料）

（2）真空感应熔炼加电渣重熔加真空电弧炉重熔。（仅限卡本特、西部超导、江苏隆达）

（3）锻件用原材料采用真空感应+保护气氛电渣重熔+真空自耗方法生产，返回料使用比例为 60%-70%。（中航上大）

# 3.1.3 其他要求

<!-- page: 6 -->

锻件用原材料其他要求应符合410JX(通用)-D-S10-0312规定，检验合格后方可投产。

# 3.2 锻件

# 3.2.1 理化件选取和分配

每验收批选取相当于铸锭头部锻件的单倍尺件进行解剖。解剖件随同炉批锻件最终热处理后不再进行后续的粗加工。供货方用1/2解剖件进行检验，另1/2解剖件打上相应标志随同批锻件发往订货方。

# 3.2.2 理化检验

按410JX（通用）-D-S10-0504要求在解剖件上进行化学成分、室温拉伸、高温拉伸、高温持久、硬度和高低倍组织检验。

# 3.2.4 本体硬度检验

锻件逐件在任意端面上进行本体硬度检验，硬度检验位置为圆周方向间隔 120°均布的3点，硬度值 HB=346~450。硬度值应在合格证中逐点注明，交付的锻件表面应不带有硬度测试痕迹。

# 3.2.5 超声波探伤

锻件逐件在最终热处理后进行超声波探伤检验，探头频率5MHz，按410JX（通用）-D-S10-0104的A级验收，底波损失不超过6dB。
