# 42CrMo4圆钢订货技术协议

# 1 内容与适用范围

本技术扑议适用于供无锡派鑫用42CrMo4锻制圆钢的制造及验收。

本技术协议规定了42CrMo4圆钢的尺寸、长度、外形、重量及允许偏差、技术要求、试验方法、检验规则、包装、标志和质量证明书等内容。

3 尺寸、外形、长度及允许偏差

<!-- page: 4 -->

# 3.1尺寸及允许偏差

钢材直径尺寸在订单合同中注明，允许偏差应满足 GB/T 702 中 2 组规定；棒材的不圆度按照 GB/T 702 标准的规定。

# 3.2长度

棒材以定尺或齐尺状态交货，定尺或齐尺长度应在合同中注明，棒材长度允许偏差 0~+50mm。短尺允许交货长度应大于或等于4000mm；短尺料交货量不得超过该批圆钢总重量的 10% ，短尺必须与定尺材分开包装。

# 3.3 外形

圆钢的弯曲度≤3mm/m，总弯曲度≤0.3%L（L为棒材长度）。

# 3.4 重量

按实际重量交货。

# 4 技术要求

# 4.1 制造过程

# 4.1.1 熔炼方法

采用 EAF+LF+VD 方式生产。

# 4.1.2 供货状态

以自由锻造或轧制成形，用途为热压力加工用钢。

圆钢以退火态（表面黑皮态）交货，硬度≤HB220，规格按合同执行。

# 4.3 机械性能

原材料截面钢材调质后(淬火：（ 830~860）℃油或水冷，回火：（ 540~640）℃），制成标准试样测定钢材的纵向力学性能，检验结果应满足 EN 10083-3 的规定。

# 4.4 低倍组织

钢材的酸浸低倍组织按GB/T1979进行评定，不允许有目视可见的缩孔、气泡、裂纹、夹杂、分层、翻皮、白点、和轴间晶间裂纹存在。合格级别应符合表2的规定。

# 4.6 晶粒度：

钢材的奥氏体晶粒度按照ASTM E112中规定的细晶粒，晶粒等级5-8合格。

# 4.7 超声探伤

钢材应 100%进行超声探伤检验，探伤精度按 GB/T4162 中的 C 级执行。允许外圆不车光。

# 4.8 表面质量

钢材表面不应有目视可见的裂纹、结疤、折叠及夹杂缺陷。如有上述缺陷必须清除，清除深度从钢棒实际尺寸算起不超过尺寸公差的一半，清除宽度不小于深度的5倍，同一截面达到最大清除深度不应多于1处。

# 6入厂检测

# 6.1 检验与验收

供方必须保证交货的圆钢符合本协议的规定。

<!-- page: 6 -->

# 6.2 组批规则

钢材应按批检查和验收，每批由同一牌号、同一炉号、同一加工方法、同一尺寸、同一交货状态、同一热处理炉次（或制度）的钢材组成。

# 6.3 检查与验收

钢材的检查和验收由供方技术监督部门进行。

# 6.3 复验与判定规则

圆钢低倍不合格时，要重新取样复检，在不合格炉号的不同支数上取双倍数量试样，复检仍不合格时，则该炉不得交货。圆钢的复验与判定规则应符合GB/T 17505标准要求。

# 7 交付

7.1 钢材的包装和质量证明书应符合 GB/T2101的有关规定；

7.2 钢材应逐支贴标签，每捆挂上标记牌，注明：牌号、炉号、扎号、尺寸及重量；

7.3 每批应附有符合本协议要求和合同中规定的质量证明书，至少包括但不限于：

a.供方名称 b.需方名称 c.合同号 d.材料牌号 e.熔炼炉号 f.化学成分 g.机械性能 h低倍 i.非金属夹杂物 j晶粒度 k淬透性 l.锻比 m探伤 n重量 o规格 p熔炼方法

7.4 圆钢的清洁、包装、和运输应按订货合同的规定进行；

7.5 其余按 GB/T 2101 的规定执行。

# 8 责任和义务

本协议各方未经允许，不得向第三方透露。
