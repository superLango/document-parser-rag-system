# 装备配套产品锻件订货技术协议

哈尔滨汽轮机厂有限责任公司（以下简称需方）向无锡派克新材料科技股份有限公司（以下简称供方）订购锻件，经双方友好协商，达成如下协议：

# 1 适用范围及提供资料

本协议规定了装备配套产品锻件的技术要求及质量保证要求。它是对技术标准、图纸的补充，需要与技术标准、图纸等同时使用，锻件的生产制造必须同时满足图纸、技术标准、本协议的相关要求。

# 2 交货状态

锻件最终热处理后交货。

# 3 前期准备

供方应按固化的生产工艺进行生产，如果材料的制造工艺或设备有较大变动、连续3年没有制造过相关材料、材料在制造或使用过程中出现质量问题以及需方要求时应通知需方并重新进行工艺评审及首件鉴定，只有通过鉴定后，方可承接制造需方的相关产品。

# 4 技术要求

锻件应按照图纸，标准和相关技术文件的要求进行生产、检验和验收，同时必须

满足以下要求。

4.1 生产锻件所用的原材料应按产品图样规定的牌号和标准进行制造，并进行相应检验。只有原材料检验合格后方可进行锻件的生产。如所用原材料需外部采购，所需原材料应向需方认可的供方采购。

4.2 所有使用的工艺方法及设备类型应符合图纸相关标准要求。

4.3 供方对产品进行无损检测项目的人员，必需由具有二级或二级以上资质的人员实施和签发报告。

4.4 锻件的质量文件应完整，否则需方有权拒收。

# 5 特殊过程及关键过程控制

5.1 供方应将熔炼、锻造、热处理过程视为特殊过程，根据 GJB9001C-2017 中“8.5.1生产和服务提供的控制”的相关要求进行特殊过程确认与再确认控制，供方也可采纳需方的“生产和服务提供过程的确认控制程序（HTC/QMSP49）”对涉及到的特殊过程进行控制。

5.2 供方是☑否□应编制《制造及质量控制计划》。如编制质量计划，应将所有见证点落实到质量计划中，并将特殊过程确认/再确认记录设置为R点，且应经需方确认。

5.3 特殊过程中配备的相关人员应经过岗位培训及考核，具备胜任岗位的能力。

5.4 当供方所承担的产品图纸中标注的关键件、重要件及关键过程涉及到上述特殊过程时，供方按照 GJB9001C-2017中“8.5.7 关键过程”的相关要求进行关键过程控制，供方也可采纳需方的“装备配套产品关键件、重要件及关键过程控制程序（HTC/QMSP57）”对涉及到的关键过程进行控制或需方认可的相关文件执行，并且，供方应将“三定”资料提供需方。

# 6 质保要求

6.1 供方应将所有见证点落实到质量计划中，应按图纸及标准要求进行检验和验收。按照技术协议要求IV、V组锻件理化性能进场验收，尺寸、外观、无损检测、本体硬度等采取现场验收。II组锻件化学、尺寸、无损检测、外观、本体硬度采取现场验收。 6.2 供方按需方图纸及相关技术文件要求提供合格的锻件。

6.3 双方以需方提供的图纸和相关技术文件为最终检验依据。

6.4 已经验收的锻件若在后续加工和装配过程中发现影响使用的、因供方原因而产生的有害缺陷时，仍由供方负责。

6.5 其余质保要求按《装备分承包合同质量要求》执行。

# 7 标识及质量证明书

# 7.1 产品标识与可追溯性

供方应根据图纸要求对工件添加标识。如图样无要求，应按照GJB726-1989《军工产品质量标志和可追溯性要求》对工件添加标识。应采用软和硬两种标识对锻件进行标记。软标识应采用油性笔标记并框出；硬标识为钢印标识（激光或电刻标识，硬标识不得对工件造成损害）。标识内容应包括：图号、炉号、供方代码、合同号、合金牌号和规格。标识位置应取得需方技术部门同意，要求字迹工整，易辨识。

7.2 交货时应附有标准及本协议技术要求内容的合格证或质量证明书。

# 8 保护

产品运输过程中应进行必要的保护，防水、防腐、防止磕碰和变形损毁。

# 9 不符合项的控制

9.1 对违背采购文件及图样的不符合项，供方应向需方提供正式报告，内容至少包括以下几方面的信息：

9.1.1 不符合项的描述，包括发生的部位、供货方、质保等级、不符合项名称、编号、缺陷描述及原因分析等；

9.1.2 已采取的应急措施，包括标识、停止作业、工作限制情况；

9.1.3 不符合项的类别；

9.1.4 不符合项的建议处理方案及返修规程；

9.1.5 对设备性能可能造成的后果；

9.1.6 鉴于报告格式篇幅的局限，某些不符合项处理的跟踪记录可作为报告的附件，这些附件应保持与报告内容的可追溯性。这些附件可以包括：不符合项缺陷描述及其原因分析的材料、不符合项处理方案及相关技术论证材料、不符合项返工修理的制造/质检记录等。

9.2 供方制造过程中如发现不合格品，供方应在自己开具不合格品审理单后将处置方案提交至哈汽公司技术部门确认，待哈汽公司技术部门确认后才可继续处置。

9.3 需方对不符合项报告进行备案、审查，以确定是否接受、拒收、修理或返工。

9.4 供方对不符合物项进行返修或再加工时，必须经需方确认的程序，重新进行检查。
