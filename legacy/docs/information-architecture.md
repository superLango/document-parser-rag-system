# 信息架构（M1.9a）

> 日期：2026-10-27
> 状态：v0.1（待业务确认）
> 输入：`docs/frontend-scope.md`、`docs/frontend-modification.md`、`docs/openapi/standard-extraction.yaml`
> 原则：主链路优先（上传 → 解析 → 拆分 → 复核 → 回流），知识库/成员/空间不简化。

---

## 1. 用户与入口

| 角色 | 入口 | 说明 |
|---|---|---|
| 内部用户（单角色） | Web 登录后进入知识库 | 上传、解析、拆分、复核、词典维护 |
| 外部系统 | API Key + `/v1/*` | 提交文档、拉取拆分结果、订阅新词 |

不做多人/多角色流转；复核为单角色确认，保留审计日志。

---

## 2. 信息架构树

```text
登录
└─ 知识库选择
   └─ 知识库
      ├─ 概览（统计：文档、拆分进度、待复核、新词）
      ├─ 文档
      │  ├─ 上传
      │  ├─ 列表（状态/类型/是否有新项）
      │  └─ 文档内页
      │     ├─ 原文/页图/版面块
      │     ├─ 标准拆分结果
      │     │  ├─ 项目清单（项目大类 / 检测项目）
      │     │  ├─ 记录（牌号 × 条件 × 属性）
      │     │  ├─ 条款
      │     │  ├─ 证据
      │     │  └─ 新词确认
      │     └─ JSON / Markdown
      ├─ 标准拆分（跨文档列表）
      ├─ 任务中心（解析/拆分/词典同步）
      ├─ 业务词典（项目大类 / 检测项目 / 试验方法）
      ├─ 成员 / 邀请
      └─ 审计（可选展示）
工作空间 / 群组
API Key
个人中心 / 帮助 / 关于
```

删除：向量搜索、知识图谱、知识问答、抽取配置、Prompt 编辑器、规则组/脚本、旧术语集多源编辑器。

## 4. 关键交互流

### 4.1 主链路

```text
上传文档
  → 任务 queued
  → 解析（OCR/TableGrid/条款/引用）
  → 拆分（列绑定 → 项目清单 → 业务对齐 → 新词）
  → 状态 review/succeeded
  → 用户查看 项目/记录/条款/证据
  → 新词确认（接受/改名/映射/拒绝）
  → 词典回流（pending → active）
  → 下次拆分自动命中
```

### 4.2 证据回读

```text
点击记录值 / 项目 / 条款
  → 右侧证据抽屉：页码、表 ID、行、列、quote
  → 定位原文页图/版面块并高亮
```

### 4.3 新词确认

```text
新词列表（大类/检测项目/方法）
  → 接受：分配业务编码并写回词典
  → 改名：修改名称后接受
  → 映射：选择已有业务条目
  → 拒绝：记录原因，不再提示
```

### 4.4 业务词典

```text
列表（类型/搜索/状态）
  → 查看别名、facets、标准号
  → 维护别名（人工）
  → pending 条目确认/拒绝
  → 同步（快照/业务系统）；记录版本与差异
```

## 5. 状态模型

| 对象 | 状态 | 说明 |
|---|---|---|
| 任务 | `queued / running / succeeded / failed / review` | `review` 表示存在待确认项或校验问题 |
| 文档 | `uploaded / parsing / review / succeeded / failed` | 与任务状态映射 |
| 拆分结果 | `draft / review / confirmed` | 确认后锁定，重新拆分生成新版本 |
| 新词 | `pending / active / rejected` | 只有 active 参与后续匹配 |
| 业务词典 | 版本号（如 `hanson-58583e54`） | 结果记录所用版本 |

## 6. 空态与错误态

| 场景 | 展示 |
|---|---|
| 无任务 | 引导上传 + API 示例 |
| 解析中 | 阶段进度 + 当前阶段名 |
| 词典缺失 | 任务仍完成，提示“未对齐”，项目页展示抽取原名 |
| 业务同名冲突 | 标注“业务数据冲突”，列出候选编码，不自动选 |
| 新词过多 | 按类型/频次聚合，支持批量确认 |
| 证据缺失 | 显示“证据不可用”，禁止伪造页码 |
