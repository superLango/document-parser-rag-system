# 平台分期与风险（M1.9a）

> 日期：2026-10-27
> 状态：v0.1
> 输入：`docs/module-disposition.md`、`docs/information-architecture.md`、`docs/engineering.md`

---

## 1. 分期原则

1. **主链路优先**：上传 → 解析 → 拆分 → 项目/记录/证据 → 复核；其余功能后置。
2. **前端驱动后端**：页面需要的字段先定契约，再写接口。
3. **每期可回退**：数据库迁移可回滚，旧结果页保留只读回退。
4. **不带病迁移**：S1 审计项未关闭的模块不进入当前项目。

## 4. 部署拓扑

```text
业务机（开发机/内网服务器）
  ├─ apps/web（静态资源）
  ├─ apps/api（FastAPI）
  ├─ apps/worker（解析/拆分）
  └─ PostgreSQL + 对象存储（本地 MinIO 可）

1.35（GPU 模型机，当前 192.168.1.35）
  ├─ GLM-OCR 9977
  ├─ layout 9978
  └─ Qwen3.5-9B 9989
```

硬约束：

- 1.35 不跑业务库/队列/Web；
- 模型服务未启动时，解析任务应明确失败/排队，不得静默降级为假结果；
- API/worker 通过环境变量访问模型服务，不写死地址。

## 5. 风险与应对

| 风险 | 触发 | 应对 |
|---|---|---|
| 范围蔓延 | 页面/功能不断加 | 以 IA 与功能矩阵为准，非主链路后置 |
| 迁移带回旧 bug | 赶进度 | 审计门 + 测试；S1 未关闭不迁移 |
| 删除不彻底 | 旧路由/依赖残留 | 全局搜索 + 构建 + E2E |
| 任务状态不一致 | 重试/并发 | 状态机 + 幂等键 + Outbox |
| 词典误合并 | 同名/同符号 | ambiguous + 人工确认；不自动合并 |
| 证据不可回读 | 页图/坐标缺失 | P2 先做只读高亮；缺证据明确标注 |
| 平台/引擎耦合 | 共享库 | 只走 HTTP / 公共包契约 |
| 1.35 被占用 | 业务进程上机 | 部署检查 + 进程白名单 |
| 数据迁移不可回滚 | Alembic 设计不当 | 每个迁移可 downgrade；先备份 |

## 6. 回退策略

| 场景 | 回退 |
|---|---|
| 新结果页不可用 | 保留旧独立结果页只读视图 |
| 平台 API 故障 | 引擎 CLI/`/v1/jobs` 仍可直接使用 |
| 数据库迁移失败 | `alembic downgrade` + 备份恢复 |
| 词典版本异常 | 切回上一快照（版本号可追溯） |
| 模型服务故障 | 任务排队/失败，不写假结果 |

### 7.1 Schema 对齐（M2 准备，2026-10-28）

- 目标 schema 取自 hansonDoc_RAG `产品标准抽取模板`（3 类 27 字段），落地为 `metal-doc-agent/configs/schema_templates/product_standard.json`。
- 新增 `schema project` 投影：把项目清单/记录/检验项目/条款映射为 schema 行，并输出字段覆盖率与必填校验。
- Q-Du 302 v8 实测：20 行，字段 79.4%、条件必填 100%，标准名称/编号全中；语义修复后校验错误 0。
- 正确性核对发现并修复：表 5（工艺参数偏差记录）原被误配为尺寸表型；条款正文补齐（67 条）；超声波检测绑定 `NDT:6519`；单位改为数值项条件必填、多类别取样数量留空、`E`→`TENS_RT:E`、热处理制度 `applicable=false`。详见 `metal-doc-agent/eval/schema/product_standard/verification-q-du-302-v3.md`。
- 结论：表格式标准在“字典+配方+投影”路线下可产出 schema 结构；两份标准的流程/结构已验证稳定。
- 第二标准验证（GB/T 1591-2018，22 页 / 15 表 / 519 记录）：同一模板投影 1236 行、字段 70.3%、条件必填 100%、校验错误 0、试验方法 100%；表头脚注/合并单元、冲击“温度 × 方向”矩阵（202 条 KV2）、CEV/Pcm 厚度区间（221/28 条）、检验项目串项、表 3 跨页合并单元、定性项目规则、表 13 方法列绑定均已修复，`试验温度`/`方向`/`尺寸厚度` 已落位。详见 `metal-doc-agent/eval/schema/product_standard/stability-gbt1591.md`。
