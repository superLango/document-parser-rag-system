## 1. 阶段定位

M4 之前是“单团队可用”；M5 是“多部门可运营”：

- 部署可滚动升级；
- GPU 池隔离，生产不被探索拖垮；
- 监控/告警/SLA；
- 备份恢复与灰度回滚；
- 安全评审与权限；
- 标准族扩展。

## 5. GPU 池

| 池 | 用途 | 隔离 |
|---|---|---|
| OCR 池 | GLM-OCR | 生产优先 |
| 抽取池 | Qwen | 生产/探索配额 |
| 探索池 | authoring/实验 | 不阻塞生产 |

要求：

- 每任务记录 GPU 秒数；
- 每池有配额/上限；
- 生产池可扩容/缩容；
- 探索池失败不影响生产。

## 6. 监控与告警

### 6.1 指标

| 类 | 指标 |
|---|---|
| 任务 | 排队数、运行数、失败率、STP |
| 阶段 | OCR/抽取/校验耗时、重试率 |
| GPU | 利用率、显存、队列等待 |
| 质量 | 证据率、幻觉率、覆盖、silent error |
| 成本 | token、GPU 秒、每页成本 |
| 存储 | 对象数、容量、回读失败 |

### 6.2 告警

- 队列积压超过阈值；
- p95 延迟超 SLA；
- 错误率突增；
- GPU OOM/服务不可用；
- 证据率/覆盖率跌破阈值；
- 备份失败。

## 12. 风险

| 风险 | 触发 | 应对 |
|---|---|---|
| GPU 容量不足 | 队列积压 | 池隔离/配额/扩容 |
| 发布回归 | 版本升级后指标下降 | 灰度 + 自动回滚 |
| 数据丢失 | 存储故障 | 备份 + 演练 |
| 权限越界 | 误操作 | RBAC + 审计 |
| 成本失控 | token/GPU 增长 | 预算告警 + 优化 |
| 标准族扩展失控 | 新族无配方 | 先 T3 探索，不强行上线 |
