## 1. 阶段定位

标准不是孤立文档。化学成分、力学性能、试验方法、取样规则经常来自被引用标准。

M1.5 的目标是：

1. 把“规范性引用文件”、行内引用、表注引用解析成结构化引用边；
2. 建立本地标准库与版本表，解决注日期/不注日期引用；
3. 只展开与 schema 相关的 1 跳引用，并控制预算；
4. 把被引用标准的约束合并进抽取结果；
5. 修复 M1 暴露的困难表（表头/跨页/转置）。

不做全量引用闭包，不做多跳递归。

## 6. 工作包与任务

### 6.1 M1.5.1 引用解析

#### 解析规则

标准号格式：

```text
GB/T 228.1-2021
GB/T 228.1—2021
GJB 2057A-2018
Q/Du 302-2015
Q/S10-0351-2004
JX-25-035
MAS 7079
```

正则要点：

- 前缀：`GB/T`、`GB`、`GJB`、`Q/`、`JX`、`MAS`、`HB`、`JB/T`；
- 编号：数字 + 可选小数 + 可选字母；
- 年号：4 位，前后可能 `-`、`—`、`－`；
- 名称：到行尾或下一个标准号；
- 行内引用：句中“应符合/按/见 + 标准号”。

#### 任务

| ID | 任务 | 实现 | 验收 |
|---|---|---|---|
| M1.5.1-01 | 规范性引用行解析 | 逐行正则 + 名称抽取 | 标准号/年号/名称完整 |
| M1.5.1-02 | 行内引用 | 条款/表上下文中检索标准号 | 有 clause/table 定位 |
| M1.5.1-03 | 表注/脚注引用 | 脚注中的“按 GB/T ...” | 不丢表注引用 |
| M1.5.1-04 | 去重/合并 | 同一标准多引用合并 | 边不重复 |
| M1.5.1-05 | 引用缺口 | 未入库/版本不明 | `gaps` 可读 |

**实现要点**：

- 原文 `raw` 必须保留；
- 解析失败保留 raw，标 `unresolved`，不能丢弃；
- 标准号统一大小写与空格（`GB∕T` → `GB/T`）；
- 年号缺失时 `dated=false`。

### 6.2 M1.5.2 版本策略与本地库

#### 规则

| 引用形式 | 策略 |
|---|---|
| 注日期（有年号） | 固定使用该版本；若已废止，标 `superseded` 并记录替代版本 |
| 不注日期 | 使用本地库中现行版本；记录 `resolution_basis` |
| 版本冲突 | 不自动合并；标 conflict，进人工 |

#### 任务

| ID | 任务 | 实现 | 验收 |
|---|---|---|---|
| M1.5.2-01 | 标准库表结构 | `standards.db`：标准号、版本、名称、状态、替代关系 | 可查 |
| M1.5.2-02 | 版本解析 | 按 dated/undated 选择版本 | 每条有依据 |
| M1.5.2-03 | 替代关系 | 旧版→新版 | 可追溯 |
| M1.5.2-04 | 冲突检测 | 同号多版本/多来源 | 不自动合并 |
| M1.5.2-05 | 版本报告 | `version_report.md` | 人工可审 |

**实现要点**：

- 不注日期引用的“最新版”只能在本地库范围内成立，报告中必须说明；
- 版本表由领域专家维护，技术不自动改；
- 每次解析记录 `resolution_basis`。

### 6.3 M1.5.3 相关性与预算

#### 相关性分类

| 类别 | 处理 |
|---|---|
| 规范性且与 schema 字段相关 | 展开 1 跳 |
| 规范性但仅试验方法 | 只取方法/取样约束 |
| 资料性 | 不展开，记录 |
| 无引用/无关 | 忽略 |

#### 预算

- 每文档最多 8 份被引用标准；
- 每份最多 30 页；
- 超预算的引用标 `budget_exceeded`，进人工；
- 展开顺序：直接约束 > 试验方法 > 其他。

#### 任务

| ID | 任务 | 实现 | 验收 |
|---|---|---|---|
| M1.5.3-01 | 相关性分类 | 规则 + 字段关键词 | 关键引用 100% |
| M1.5.3-02 | 1 跳展开 | 只展开 related=true | 不递归 |
| M1.5.3-03 | 预算控制 | 计数/页数/终止 | 不超限 |
| M1.5.3-04 | 引用评测集 | `ref_gold.json` | 20 份标注 |
| M1.5.3-05 | 引用评测 | `ref_eval.md` | 解析率 ≥90% |

### 6.4 M1.5.4 约束合并

#### 合并优先级

```text
本文件明确值 > 注日期引用 > 不注日期引用 > 通用方法标准
```

规则：

- 同一字段不同来源冲突 → 不覆盖，标 conflict；
- 合并后保留每个值的来源与证据；
- 只合并与 schema 字段相关的约束；
- 方法/取样约束合并到 `ClauseRecord`/`InspectionItem`。

#### 任务

| ID | 任务 | 实现 | 验收 |
|---|---|---|---|
| M1.5.4-01 | 约束抽取 | 从被引用文档抽元素/性能/方法 | 与 schema 对齐 |
| M1.5.4-02 | 合并规则 | 优先级 + 冲突 | 可追溯 |
| M1.5.4-03 | 冲突标记 | `conflicts.json` | 不自动发布 |
| M1.5.4-04 | 依赖字段评测 | 引用前后对比 | 提升 ≥5pp |
