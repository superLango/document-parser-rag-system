### 根因（用回放实测）

对 4/24/100/207/252 等做离线回放，发现三层断点：

1. **没有结果文件（60 份）**：`4`、`24`、`154` 离线回放能出记录，但生产没有 JSON。说明问题在运行/落盘链路（超时、OCR 结果缺失、导出遗漏），不是解析算法。
2. **条款抽取失败（100）**：回放显示 `clauses=0`。`clauses.py` 的 `HEADING_RE` 不识别 `1.材料铁素体含量检测……` 这种“数字点+中文、无空格”的条款标题，整篇正文被丢弃。
3. **检验项目表只入库存、不出记录（207/252）**：
   - `builtin._inspection_items` 只认“检验项目”表头，207 的表头是“理化项目”，直接被跳过。
   - `projection._qualitative_records` 只允许 `QUALITATIVE_SET`（晶粒度/低倍/高倍/夹杂/超声/外观/尺寸…）生成记录；**化学成分、室温拉伸、高温拉伸、夏比冲击、布氏/洛氏/维氏硬度、气体分析被明确过滤掉**。
4. **引用标准/程序类文档没有护栏**：`24` 的“规范性引用文件”章节、`4` 的标准清单、`252` 的报告清单都会被当作普通正文，容易误抽。

## 四、修复方案

### P0 基准与护栏（不改抽取行为，先可度量）

1. 新增 `deploy-package/scripts/replay_gold30.py`：
   - 读取 `gold_standard_30/source_tables/*.json`，把 `header_rows + data_rows` 转成 TableGrid；
   - 复用 `matcher.match_table` + `builtin.parse_table` + `projection.apply_document_intelligence`；
   - 与 `gold_standard_30/documents/*.json` 逐 (牌号, 类别, 项目) 对比；
   - 输出 `reports/gold30-baseline.json` 与汇总表（每份文档、每个 feature 的召回/多抽）。
2. 新增 `deploy-package/scripts/check_problem_list.py`：
   - 把问题清单结构化为 `{folder, feature, expected, clause}`；
   - 自动核对每条“漏抽/错抽”是否已解决；
   - 输出 `reports/problem-list-status.md`。
3. 新增文档分类器 `not_extractable`：
   - 命中“质量保证/质保要求/审查意见/会议纪要/不符合项/防造假/采购管理/程序/图纸/取样图/清单/意向书/联络函/通知”等标题，且无材料性能表 → 标记 `not_extractable`，不计入漏抽统计。
4. 新增引用标准护栏：
   - 表格内标准号密度高、表头含“引用标准/规范性引用文件/材料标准/适用文件” → 标记 `reference_list`，禁止路由到测量配方；
   - 正文“规范性引用文件/术语和定义/范围”章节不生成 feature。
   - 目标：直接消掉 28 次“超声误抽”、9 次“铁素体误抽”、以及大量“晶粒度/夹杂来自目录”的误抽。

### P1 检验项目表产出记录（最大增量）

1. `builtin._inspection_items` 扩展：
   - 表头别名：`理化项目`、`检测项目`、`试验项目`、`测试项目`、`项目名称`、`检验试验项目`；
   - 列别名：`数量/取样数量/试样数`、`测试条件/试验条件/温度`、`取样部位及方向/取样部位/取样方向`、`验收指标/技术要求/判定标准`、`试验方法/检验方法`。
2. 新增记录构造 `inspection_item`：
   - 每条 row 生成一条 record，`feature` 取自行名（室温拉伸/高温拉伸/夏比冲击/布氏硬度/气体分析/晶粒度/低倍/高倍/超声/弯曲/持久/蠕变/热稳定/淬透性/磁性能…）；
   - 有验收数值 → 解析为 `value/lower/upper/comparator/unit`；只有“按 XX 标准” → `comparator=text`，保留方法与条款；
   - 取样数量/部位/方向/温度写入 `conditions` 与 `meta`。
3. `projection._qualitative_records` 增加 `REQUIREMENT_FEATURES`：
   - 当某 feature 没有数值记录、但库存里有该检验项目时，生成一条文本要求记录；
   - 覆盖：化学成分、室温拉伸、高温拉伸、夏比冲击、布氏/洛氏/维氏硬度、气体分析、热稳定、弯曲、淬透性、磁性能、低温拉伸、室温缺口拉伸、低周疲劳、表面粗糙度、液压试验。
   - 这样“表 5-3 规定室温/350℃拉伸和 KV 冲击”不再因为“只有项目名没有数值”而消失。

**预期**：595 张检验表 + 问题清单中“表 5-3 / 表 2 规定”类漏抽的大部分转为记录；207 的 6 个理化项目、252 的冲击/低倍/高倍、24/25 的拉伸/冲击可直接出现。

### P2 正文条款抽取增强

1. `clauses.HEADING_RE` 支持：
   - `1.材料...`（数字点+中文，无空格）；
   - `5.1室温拉伸...`（子条款+中文，无空格）；
   - 1 列表格中的条款标题（沿用现有 `_table_heading_lines`）。
2. 数值条款解析：
   - 从条款句抽 `≥/≤/＞/＜/~` + 数值 + 单位（MPa、%、J、HBW、HRC、HV、级、ppm）；
   - 抽试验温度（350℃/400℃/室温/低温）与方向（纵向/横向/弦向）；
   - 有方法标准（GB/T 228.1、GB/T 229、GB/T 231.1、GB/T 6394、GB/T 10561、ISO 148-1）时写入 `meta.method`。
3. 章节过滤：
   - 只在“技术要求/检验/试验/验收/质量/性能”章节生成；
   - 排除“规范性引用文件/范围/术语/符号/包装/运输/标记”章节（后者仅在明确要求时保留）。
4. 牌号继承：
   - 无牌号条款 → 文档级牌号（从标题提 GH4720Li/30CrMnSiA/TC4 等）；
   - 仍无 → `全部牌号`。

**预期**：直接覆盖问题清单中 350℃/400℃/150℃ 拉伸、氢含量、晶粒度 ≥5 级、铁素体 ≤0.5%、HBW 280~320 等正文型漏抽。

### P3 表格结构修复

1. 表头/数据列错位校正：
   - 计算数据行 key 前缀长度与表头 key 前缀长度之差，统一平移 measure 列；
   - 解决 folder 1 化学表“旧牌号占位 C”导致的 Cu/N/其他元素缺失。
2. 竖排/单列表：
   - 识别“属性 | 值”两列竖排表，转置后按属性绑定；
   - 续页/续表按表头指纹与末行合并（GJB 2294A、57-T28/T29）。
3. 机械表缺列补齐：
   - 当表头 measure 数少于数据值列数，且缺的是 A/Z/HBW/HRB/HV 时，按 GB/T 1220 等标准顺序补齐；
   - `硬度` 合并列按数据列数拆成 HBW/HRB/HV。
4. 文档级牌号：
   - `_document_grade_hint` 增加中国牌号正则：`GH\d{3,5}[A-Za-z]{0,2}`、`K\d{3}`、`TC\d{1,2}`、`TA\d{1,2}`、`\d{2}Cr...`、`\d[A-Z]\d{2}`。
5. 持久/蠕变：
   - 绑定 `持久时间/τ/tau(h)` 到 `持久时间`，不再落 `剪切强度`；
   - matcher 增加 `stress_rupture` 签名（温度/应力/持久时间/τ），或对“温度+应力+时间”三列表降到 candidate 阈值。
6. 化学元素列：
   - Cu/N/其他元素绑定修复；`其他元素` 作为独立 measure 保留原文；
   - 空值/`-` 仍生成 `na` 记录（与金标口径一致）。

**预期**：folder 7 的 10 个丢失牌号恢复、Cu/N/其他元素补齐；folder 1 的 Cu/N/HBW/HRB/HV/A/Z 恢复；folder 9 的 GH4720Li 与持久表恢复。

### P4 业务类别与错抽治理

1. 词表新增：
   - 气体分析（H/O/N）、热稳定、淬透性、磁性能、低温拉伸、室温缺口拉伸、低周疲劳、弯曲、表面粗糙度、液压试验、应力腐蚀。
2. 映射/护栏修正：
   - “无损检测/NDT”泛指 → 不生成超声；只有明确“超声/UT”才生成；
   - “渗透/磁粉” → 对应方法（若词表无，先不入 FEATURE）；
   - 冲击试样断口/侧向膨胀/剪切断面率 → 冲击试验；
   - 固溶/热处理温度 → 热处理制度，不做相变温度；
   - 组批/炉批/装炉 → 不生成尺寸；
   - NDT 扫查间距/显示尺寸 → 不生成工件尺寸；
   - 持久时间 τ(h) → 高温持久，不生成剪切；
   - 引用标准名称中的“铁素体/马氏体” → 不生成铁素体；
   - 目视表面缺陷 → 外观，不生成非金属夹杂；
   - 磁通密度 → 磁性能，不生成密度试验；
   - 拉伸标准引用（GB/T 228.1）→ 不生成布氏硬度；
   - 低倍宏观晶粒评级 → 低倍，不生成晶粒度。
3. 去重与口径：
   - 同一 feature 的正文记录与检验表记录合并（保留最具体的方法/取样）；
   - 超声/热处理/尺寸的“每牌号展开”数量与金标口径对齐，避免 1 条表记录变 66 条。
