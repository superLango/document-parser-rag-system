## 2. 路由规则（无金标）

`channels/router.py`：
1. 计算两条通道的**覆盖代理**：唯一 `(类别, 项目, 牌号, 条件)` 键数量；
2. 若全链路唯一键数 ≥ S9 × 1.05 → 选择全链路；
3. 否则选择 S9；
4. 同时记录验证器自评分（仅作报告，不作为否决条件，避免漏掉有效覆盖）；
5. 可选过滤：删除 `recovered/rebind` 通道中验证为 unresolved 的记录。

> 经验：按"验证器分数"路由会漏掉 gbt-8547/gbt-2965 的有效增益（全链路记录更多但 unresolved 也更多），改为"覆盖代理"后路由正确。
