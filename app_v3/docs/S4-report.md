## 2. S4 改动

1. **数值 Grade 解析**：
   - 表头为 `Grade` 且单元格为 `32` 时，规范为 `Grade 32`；
2. **Grade 列推断**：
   - 当表头没有显式 Grade/牌号列，但存在 `UNS Number` 列时，向左寻找"纯数字/短代号"列作为 Grade 列；
   - 例：ASME 化学表 `["1","R50250",...]` → 推断列 0 为 Grade，得到 `Grade 1`；
3. **UNS 归一**：
   - `R55111` → `UNS R55111`，保留别名；
   - 同一行同时存在 `Grade 32` 与 `UNS R55111` 时，优先使用非 UNS 的 `Grade 32`（与金标常用命名一致）；
4. **表格牌号修复**：S4 演示启用 `table_repair=True`（仅在 grade 被拒绝/为空时修复）；
5. **评测划分**：`eval/splits.json` 固定 20 份回归集 + 6 份历史 holdout（未用于 S2–S4 调参）。
