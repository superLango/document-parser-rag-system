## 2. 关键发现与修复

### 2.1 全表恢复的根因
- 部分表（如 gbt-3077 T17）v2 只绑定了一个度量列（如"非金属夹杂物"），其余列（锭型偏析/中心偏析/中心疏松/一般疏松/斑点状偏析）丢失；
- 这些表其实已进入绑定，但**列覆盖不完整**，导致高倍类别大量缺失；
- S8 新增 `recover_missing_columns`：按 `record_id` 的列号识别已覆盖列，只补"缺失度量列"，不替换已有记录。

### 2.2 评测语义修正
- 金标中存在 `材料牌号=全部牌号`（表示适用于所有牌号）；
- 原 matcher 将其当普通牌号，导致大量高倍/热处理记录无法匹配；
- S8 修正：`全部牌号/所有牌号/各牌号/任意牌号/通用` 视为通配牌号（仅评测语义，不改变抽取结果）。

### 2.3 恢复结果
- 恢复记录：**71 条**（高倍/弯曲等缺失列）；
- 恢复记录标记 `channel=recovered`，进入验证器与评测。
