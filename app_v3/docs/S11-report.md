## 4. 失败原因

- 重绑定后的记录用"表头关键词临时分类器"映射类别，xx454 的 3 条记录被错误分类/漏分类；
- 没有复用 v2 的 `assemble` 类别/项目归一逻辑；
- rebind 只对 gbt-8547 有效（+2），其余文档未覆盖到规范量表或记录类别错误。

## 5. 结论与下一步

- **WP1.0 方向仍可行**（gbt-8547 +2），但必须：
  1. 重绑定后走 v2 `expand → enrich → assemble` 全链路，而不是临时分类器；
  2. 只对"高潜力文档"（覆盖率低/缺口大）执行，不做全量。
- S12 计划：
  1. 修正 rebind 后的类别/项目映射（复用 v2 assemble）；
  2. 选定 3–5 份高潜力文档试点；
  3. 若仍无净增益，转 WP1.5 条款通道。
