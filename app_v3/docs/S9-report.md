## 1. S9 关键修复

### 1.1 恢复通道的度量标签错误
S8 恢复通道使用整条表头路径作为度量名，导致：
- T17 的列路径 `["锭型偏析","级别，不大于","3"]` 被拼成 `"锭型偏析 级别，不大于 3"`；
- 与金标 `"锭型偏析"` 不相等 → 高倍恢复记录无法匹配。

S9 修复：
- 新增 `measure_label()`：从列头路径中跳过"级别/不大于/数字/单位"等条件段，取最后一段有意义的标签；
- 高倍标签去掉尾部脚注字母（`中心偏析a → 中心偏析`）；
- 度量名再做 `normalize_item` 归一。

### 1.2 恢复结果
- 恢复记录：**36 条**（高精度，较 S8 的 71 条更克制）；
- 恢复类别：高倍/弯曲/硬度等；
- 恢复记录仍带 `channel=recovered`，进入验证器复核。
