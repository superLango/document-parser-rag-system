## 2. S5 交付内容

### 2.1 证据感知的冲突分级（验证器精化）
`verify/conflicts.py`：
- 同一表、同一行的冲突 → `same_row_value_conflict`（warn，通常是同表重复列/绑定问题）；
- 跨表/跨行且条件完整 → `value_conflict`（error）；
- 条件不足 → `value_conflict_insufficient_conditions`（warn）。

### 2.2 P1 WP1.1：表格 IR + 程序 DSL 规范
- `table_program/ir.py`：`TableIR`（表头路径/单位/条件/数据行/单元格读取）；
- `table_program/DSL.md`：`explode/melt/pivot/rename/normalize/filter` 等操作规范；
- 为后续 WP1.2 执行器/回放校验提供基础。

### 2.3 负向实验（不采用）
对 S4 产物做**全量项目名归一化**后再评测：
- 匹配 6695（-3），一致率 0.7948（+0.0004），覆盖率 0.6885（-0.03pp）；
- 结论：**不能全量重写项目名**，只能在 matcher/展示层做别名，不可直接覆盖原始 item。
