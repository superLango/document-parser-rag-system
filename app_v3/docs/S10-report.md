## 2. 为什么每次优化效果不明显（根因）

20 份金标共 9724 条，当前匹配 6760，缺失 2964。缺失集中在：
- 化学成分约 1886；
- 室温拉伸约 625；
- 高倍 149、硬度 144、热处理 132、冲击 88 等。

这些缺口**大部分不是"命名/格式归一"问题**，而是：
1. **v2 绑定阶段漏列/错列**（表已进入绑定，但记录缺失或值错配）；
2. **表选择/OCR 可恢复性**（部分表未绑定、部分值在 OCR 中不完整）；
3. **条款/正文内容**（高倍、弯曲、热处理）从未进入记录。

`app_v3` 的后处理层只能"修已抽出的记录"，无法凭空恢复 **未绑定的列/表/条款**。因此：
- 条件/牌号/名称归一已基本到位；
- 继续做同义词、替换策略，收益趋近 0。

## 3. 决策（S11 起转向）

**停止在后处理层做增量修补**；S11 采用以下两条路线之一/组合：

### 路线 A：全表重绑定（优先，见效最快）
- 用 v2 绑定能力重新处理**未绑定的表**（尤其 inspection/admin 中的规范量表），而不是仅后处理；
- 只对"有规范量列"的表增加绑定（不盲目包含 dimension）；
- 目标：恢复化学/室温/高倍的漏列，预计可多覆盖 5–10pp。

### 路线 B：双通道/条款抽取（长期）
- 对高倍/弯曲/热处理启用条款/正文抽取（LLM + 引文证据）；
- 与表格通道合并、去重、冲突升级；
- 目标：补高倍 149、弯曲 5、热处理 132 的主要缺口。

### 路线 C：真正盲测
- 新增 10–20 份未见文档，S11 只评测不调参，验证泛化。
