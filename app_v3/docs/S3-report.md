## 2. S3 改动

1. **条件补全**（`analyze/condition_repair.py`）：
   - 温度：从列头路径/表标题提取（`室温/100℃/RT` 等）；
   - 状态：从"状态"列/表标题（`M→软态(M)`、退火/固溶等）；
   - 尺寸：从厚度/尺寸/直径/宽度列，统一补 `mm`；
   - 方向：从列头路径/表标题（纵向/横向/Longitudinal 等）；
   - 只补缺失/归一化，不覆盖已有有效值；
   - 同步 `enrichment.state/size`，供评测器状态匹配使用。
2. **冲突规则分级**（`verify/conflicts.py`）：
   - 条件完整：`value_conflict`（error → unresolved）；
   - 条件缺失：`value_conflict_insufficient_conditions`（warn，先复核条件），避免误伤。
3. **S3 演示/评测**：`scripts/s3_demo.py`。

## 6. 已知限制

1. **覆盖率未提升**：条件补全不解决牌号/项目/表选择/条款类缺口；
2. **value_conflict 仍高（1370）**：部分为真实冲突/上游绑定错误，需要进一步区分；
3. **条件补全仍依赖表标题/表头明确信息**：缺失时仍不猜测（符合原则）；
4. **P0 目标未达**：一致率 0.90、覆盖率 70% 仍需 S4。

## 7. S4 建议

1. **牌号体系映射**：UNS/Grade ↔ 常用牌号（标准体系词表 + 别名），解决 AMS/ISO/ASME/ASTM 类；
2. **表选择/条款通道**：覆盖高倍/弯曲/热处理等非表格内容（高倍缺口 149）；
3. **冲突精化**：结合证据/表格位置判断冲突真伪，减少 1370 条 unresolved；
4. **盲测集**：固定 26 份之外的盲测文档，避免过拟合。
