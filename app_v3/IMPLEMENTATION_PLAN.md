## 修订记录 v2（2026-11-25，S1–S10 后）

> 本修订取代原 P0/P1 边界与指标假设。原方案见文末历史版本（v1）。

### 执行结果回顾
- S1–S6：完成 Schema/归一化/验证器/评测/TableIR/DSL 执行器；
- S7–S10：后处理增量优化（牌号清理/缺失列恢复/后处理天花板评估）；
- 最佳结果（S9）：**匹配 6760 / 9724，一致率 0.7917，覆盖率 69.52%，多余 2461**；
- 原 P0 退出指标（一致率 0.90、覆盖率 70%）**未达成**。

### 修订原因
数据表明：剩余缺口主要不是命名/条件归一，而是
1) v2 绑定阶段漏列/错列；2) 表选择遗漏规范量表；3) 条款/正文内容从未进入记录。
后处理层已接近天花板，继续打补丁收益趋近 0。

### 修订后的阶段
| 阶段 | 周期 | 核心目标 | 退出指标 |
|---|---|---|---|
| **P0（历史）** | S1–S10 | Schema/归一化/验证器/评测/后处理 | 已完成，冻结 S9 最佳结果；原指标未达成 |
| **P1（修订）** | S11–S18 | **WP1.0 全表重绑定** + WP1.3 程序生成器 + WP1.4 双通道 + WP1.5 条款 + WP1.6 检索 | G1（S11–S13）：覆盖率 ≥72%、一致率 ≥0.80、多余 <2000；G2（S14–S18）：覆盖率 ≥80%、一致率 ≥0.90、多余 <1000 |
| **P2** | S19+ | Agent + 人工闭环 + 领域模型微调/蒸馏 + 运营 | 覆盖率 ≥85%、一致率 ≥0.94、未解决 ≤5% |

### 新增/调整工作包
- **WP1.0 全表重绑定（新增，S11 起）**：对未绑定但含规范量列的表重新绑定（含 inspection/admin 中的规范量表），不再只后处理 v2 结果；
- **WP1.3 程序生成器**：模型生成 DSL 程序，执行 + 回放校验，失败降级；
- **WP1.4 双通道**：结构化通道 + VLM/LLM 语义通道，冲突升级；
- **WP1.5 条款通道**：高倍/弯曲/热处理等条款内容，带引文证据；
- **WP1.6 检索**：相似表/标准检索，复用程序模板与示例。

### 纪律
- **冻结后处理层（S9 状态）**，不再新增后处理补丁；
- 每轮必须涉及 rebind/程序/通道/检索之一；
- 评测固定：20 份回归 + 盲测集；金标不得用于调参；
- 每个 Sprint 结束报告：指标、分类别缺口、风险、下阶段计划。

## 2. Phase P0：规范化与验证（第 1–2 周）

1. 建立**规范记录 Schema v1** 与本体/词表；
2. 实现**牌号/项目/条件/单位归一化**；
3. 实现**独立验证器**（证据、值守恒、条件完整性、冲突检测）；
4. 建立**评测基线**（20 份 + 盲测集）；
5. 验证：在不改表类型分支的前提下，把 v2 输出"后处理"到规范格式，指标提升到阶段目标。

## 7. 质量门禁（每个里程碑必须通过）

1. **单元测试**：归一化/DSL/验证器覆盖核心分支；
2. **回归测试**：20 份基线不退化（一致率/覆盖率/多余率）；
3. **盲测**：盲测集指标不低于基线，且不得用盲测调参；
4. **证据审计**：抽样 5% 记录，证据命中率 ≥99%；
5. **代码规范**：无文档/表专属分支；schema 变更需评审；
6. **数据隔离**：gold 不进入训练/规则推导；合成数据与评测隔离。
