## 原则

1. 不针对单份文档/单张表做特殊修补；
2. 模型负责语义与结构判断，代码负责确定性执行与验证；
3. 所有结果必须可回溯（证据：页/表/单元格/条款引文）；
4. 无法自动判定的内容进入"未解决队列"，不静默丢弃或猜测；
5. 用独立评测集验证泛化，不针对金标调参。
