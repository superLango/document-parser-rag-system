## 0. Design Read（Brief Inference 声明）

> **Reading this as: B2B 企业内部工具型应用 for 航空航天材料检测领域的工程人员、术语专家与系统管理员, with a serious-B2B / Linear-style / data-dense 的视觉语言, leaning toward shadcn-vue + Tailwind CSS + Radix Vue Primitives + 自托管 Geist 字体。**

### 0.1 项目类型识别

| 维度 | 识别结论 |
|---|---|
| **页面性质** | 企业内部工具型应用（非 Landing / 非 Portfolio / 非 Marketing） |
| **核心业务** | 文档智能解析与 RAG 增强检索系统（Hansight） |
| **目标用户** | 航空航天材料检测领域的工程人员、术语专家、系统管理员 |
| **业务约束** | 数据密集型 dashboard、多步骤业务流程、SSE 流式交互、PDF 可视化、知识图谱可视化 |
| **使用场景** | 企业内网私有化部署、桌面端为主（1280px+）、少量平板访问 |

### 0.2 技能适配声明

`design-taste-frontend` 技能明确声明其**不适用**于：Dashboards / dense product UI / admin panels / data tables / multi-step forms。Hansight 项目全部落入这一范围。

按照技能 Section 13（OUT OF SCOPE）的指导：对于 dashboard 类应用应使用 Fluent UI / Carbon / Atlassian / Polaris 等成熟的企业设计系统。

但用户明确要求"完全摒弃现有前端设计体系"并产出全新设计。因此本方案采用折中策略：

- **保留**技能中通用的 anti-slop 规则（色彩、排版、shape consistency、AI Tells、Button Contrast、Pre-Flight Check 等）
- **采用**适合 B2B 工具的官方组件库（shadcn-vue / Radix Vue Primitives，遵循"You own the code"理念）
- **忽略**技能中针对 Landing / Portfolio 的特定规则（Hero、Logo Wall、Bento Grid、Scroll-Pinned 等）

### 0.3 现有前端审计（Redesign Audit）

按照技能 Section 11.B 要求，在 redesign 前进行审计：

| 现状项 | 现状描述 | 处置策略 |
|---|---|---|
| **品牌色** | Element Plus 默认蓝色 #409EFF | 完全摒弃，采用新的 Steel Teal 主色 |
| **字体** | 系统默认字体 + 中英文 fallback | 完全摒弃，采用自托管 Geist Sans + Geist Mono + Noto Sans SC |
| **圆角** | Element Plus 默认 4px | 完全摒弃，采用 6px 统一圆角（按钮 6px、卡片 8px、输入 4px） |
| **导航结构** | 顶部 Logo + 侧边 11 项菜单 | 保留 IA 结构，但视觉重构 |
| **页面 slug** | /dashboard、/documents、/parser/:id、/schemas、/terms、/terms/review、/knowledge、/knowledge-base、/tasks、/qa | **完全保留**（避免破坏 muscle memory） |
| **API 契约** | {code, message, data, trace_id} 统一响应 + SSE 事件 | **完全保留**（后端契约不变） |
| **Token 结构** | Bearer + expires_in 字段 | **完全保留** |
| **路由懒加载** | 已实现 | **保留** |

**模式判定**：根据 Section 11.A，本次为 **Redesign - Overhaul** 模式（用户明确"完全摒弃现有前端设计体系"），即"new visual language on top of existing content"。Treat as greenfield for visuals; preserve content and IA。

### 0.4 Anti-Default Discipline（强约束声明）

本方案明确摒弃以下 LLM 默认陷阱：

- **禁用** AI 紫色 / 蓝色渐变背景
- **禁用** 居中 Hero + 大渐变 blob
- **禁用** 三等分 feature 卡片
- **禁用** 过度玻璃态（glassmorphism on everything）
- **禁用** Inter 作为默认字体
- **禁用** Fraunces / Instrument Serif 字体
- **禁用** em-dash（—）字符（使用常规连字符 -）
- **禁用** 装饰性彩色状态点（除非表示真实状态）
- **禁用** 装饰性文字条（如 `BRAND. MOTION. SPATIAL.`）
- **禁用** 假版本号（v1.4.2、Build 0048）

## 1. 三个调节参数（The Three Dials）

依据技能 Section 1.A 的"B2B 工具型应用"信号推断：

| 参数 | 设定值 | 推理依据 |
|---|---|---|
| **DESIGN_VARIANCE** | **4** | 企业工具型应用偏结构化对称布局，但允许小幅 offset 增加层次感（信号表 4-7：Offset） |
| **MOTION_INTENSITY** | **3** | 功能性优先，仅用于状态反馈与层次揭示，避免干扰数据阅读（信号表 1-3：Static + CSS hover/active） |
| **VISUAL_DENSITY** | **7** | 数据密集型 dashboard 需 cockpit 风格，但保留呼吸空间（信号表 8-10：Cockpit 上限前的过渡值） |

### 1.1 参数对设计决策的影响

| 决策项 | 参数依据 | 落地策略 |
|---|---|---|
| 布局结构 | VARIANCE=4 | 12 列网格 + 偶尔使用 `grid-cols-[2fr_1fr]` 不均等分 |
| 动效类型 | MOTION=3 | CSS `transition` + `:hover/:active` 反馈 + 骨架屏 + 顶部进度条（无 GSAP / 无 Motion） |
| 间距系统 | DENSITY=7 | 紧凑型 padding：`py-3 py-md-4`、`gap-3 gap-md-4`，禁止 `py-16+` 间距 |
| 卡片使用 | DENSITY=7 | 数据 metric 不使用卡片包裹，用 `border-t` 与 `divide-y` 替代（技能 4.4） |
| 数字字体 | DENSITY=7 | 所有数字使用 `font-mono` 等宽字体（技能 Section 7：Cockpit 模式要求） |
| 圆角系统 | 4.4 Shape Lock | 统一采用 6px：按钮 6px、卡片 8px、输入 4px、Tag 999px（pill） |
| 阴影 | 4.4 Materiality | 仅在弹层、模态框使用阴影，常规卡片用 1px 边框替代 |

## 2. 设计系统选择与技术栈决策

### 2.1 设计系统选型对比

| 候选方案 | 适配度评估 | 决策 |
|---|---|---|
| Fluent UI Vue（社区版） | 微软官方 Fluent 设计，但 Vue 版本维护弱，组件覆盖度低 | 不采用 |
| IBM Carbon Vue（@carbon/react 无 Vue 版本） | 仅 React 版本完整 | 不采用 |
| Atlassian Atlaskit | 仅 React，且需要 yarn | 不采用 |
| Element Plus 主题深度定制 | 已有栈，但"完全摒弃现有设计体系"难以彻底实现 | 不采用 |
| **shadcn-vue + Tailwind CSS + Radix Vue Primitives** | Vue 生态最成熟的 shadcn 实现，"you own the code"理念契合"完全摒弃"要求 | **采用** |

### 2.2 设计系统决策理由

按照技能 Section 2.A 的诚实规则：当项目为"Modern SaaS where you own the components"时，应使用 shadcn/ui。Vue 生态中对应实现为 **shadcn-vue**（[www.shadcn-vue.com](https://www.shadcn-vue.com)），底层基于：

- **Tailwind CSS v4**：utility-first 样式
- **Radix Vue Primitives**（reka-ui）：无样式可访问性原语
- **class-variance-authority**：组件变体管理
- **tailwind-merge**：className 合并
- **lucide-vue-next**：图标库（已在项目中作为备选）

### 2.3 技术栈最终决策

| 层 | 旧栈 | 新栈 | 变更说明 |
|---|---|---|---|
| **框架** | Vue 3.5 + TS 5.6 + Vite 5.4 | **保留** | 无变更 |
| **包管理** | pnpm 10 + npmmirror.com | **保留** | 无变更 |
| **开发端口** | 5174 | **保留** | 无变更 |
| **API 代理** | Vite proxy `/api → :8000` | **保留** | 无变更 |
| **UI 组件库** | Element Plus 2.8（importStyle: false） | **shadcn-vue**（reka-ui 底层） | 完全替换 |
| **样式方案** | SCSS + Element Plus 主题 | **Tailwind CSS v4** + CSS Variables | 完全替换 |
| **图标库** | 部分 Element Plus icons | **lucide-vue-next**（已在依赖中） | 统一图标家族 |
| **字体方案** | 系统默认 | **Geist Sans + Geist Mono + Noto Sans SC**（自托管） | 完全替换 |
| **状态管理** | Pinia 2.2 | **保留** | 无变更 |
| **路由** | Vue Router 4.4 | **保留** | 无变更 |
| **HTTP 客户端** | Axios | **保留** | 无变更 |
| **PDF 渲染** | pdfjs-dist 4.10 | **保留** | 无变更 |
| **图谱可视化** | Cytoscape.js 3.30 | **保留** | 无变更 |
| **Markdown** | markdown-it 14.1 + highlight.js 11.11 | **保留** | 无变更 |
| **动效库** | 无 | **不引入** | MOTION=3，纯 CSS 实现 |
| **暗色模式** | Element Plus dark theme | **Tailwind `dark:` variant + class strategy** | 完全替换 |

### 6.1 色彩系统（Color System）

#### 6.1.1 设计哲学

按照技能 Section 4.2 的 LILA RULE 与 Color Consistency Lock：

- **摒弃** AI 紫色 / 蓝色默认渐变
- **采用** Steel Teal（钢青）作为单一强调色，呼应航空航天材料检测领域的金属质感
- **中性色基底** 使用 Zinc 系列（冷灰），保持一致性
- **一个项目一套调色板**，不混用暖灰与冷灰

- 钛合金 Ti-6Al-4V 在氧化态下呈现的青灰色调

### 7.1 SSE 流式问答交互

```

                                              ▼
                                       [检索中] ──SSE──→ [Reranker 重排]
```


#### 7.1.3 关键交互细节

- **打字光标**：CSS `animate-pulse`，1s 周期，禁用复杂动画
- **阶段切换**：fade-in + 100ms 延迟，无 GSAP
- **引用卡片**：响应完成后 300ms 整体淡入，避免逐个动画
- **错误回退**：SSE 断连时显示"连接中断，重试？"按钮，保留已生成内容

### 7.7 暗色模式切换

```typescript
// composables/useTheme.ts
export function useTheme() {
  const theme = ref<'light' | 'dark' | 'system'>('system')
  
  onMounted(() => {
    const saved = localStorage.getItem('hansight-theme') as typeof theme.value
    if (saved) theme.value = saved
    applyTheme()
  })
  
  function toggle() {
    theme.value = theme.value === 'dark' ? 'light' : 'dark'
    localStorage.setItem('hansight-theme', theme.value)
    applyTheme()
  }
  
  function applyTheme() {
    const isDark = theme.value === 'dark' || 
      (theme.value === 'system' && matchMedia('(prefers-color-scheme: dark)').matches)
    document.documentElement.classList.toggle('dark', isDark)
  }
  
  return { theme, toggle }
}
```

**默认行为**：跟随系统 `prefers-color-scheme`，用户可手动覆盖。

### 9.4 SSE 流式连接封装

```typescript
// composables/useSSE.ts
export function useSSE<T = unknown>(url: string) {
  const data = ref<T | null>(null)
  const error = ref<Error | null>(null)
  const isConnected = ref(false)
  let eventSource: EventSource | null = null
  
  function connect(onMessage?: (data: T) => void) {
    eventSource = new EventSource(url, { withCredentials: true })
    
    eventSource.onopen = () => { isConnected.value = true }
    eventSource.onmessage = (event) => {
      try {
        const parsed = JSON.parse(event.data) as T
        data.value = parsed
        onMessage?.(parsed)
      } catch (e) {
        error.value = e as Error
      }
    }
    eventSource.onerror = (e) => {
      isConnected.value = false
      error.value = new Error('SSE connection error')
    }
  }
  
  function disconnect() {
    eventSource?.close()
    eventSource = null
    isConnected.value = false
  }
  
  onUnmounted(disconnect)
  
  return { data, error, isConnected, connect, disconnect }
}
```
