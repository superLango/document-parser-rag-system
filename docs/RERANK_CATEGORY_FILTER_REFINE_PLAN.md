# 类别级过滤再精确化方案（表格内容模式分类 + 类别存在性判定）

> 状态：方案制定中（待确认后实施）
> 背景：39 类别过滤测试（2026-08-19）——精选 query + 阈值 0 下 EXTRACT 21 / SKIP 20。
> 误保留 7~9 个（淬透性/抗氧化/组合持久/室温缺口拉伸/高温缺口拉伸/维氏硬度/高温拉伸等），
> 根因：文档「特性与用途」表是文字描述表，包含性能描述词（淬透、抗氧化、缺口、维氏），
> 重排无法区分「描述中提到」与「有检测数据」。

## 1. 已验证的事实依据

对 GB-T1220 全部表格块统计「数值单元格比例」（数值格 / 非空格）：

| 表格类型 | 数值比例 | 代表 |
|---|---|---|
| 数据表 | 0.52 ~ 0.69 | 化学成分表、力学性能表 |
| 混合表 | 0.37 | 检验项目表（序号/取样数量 + 项目文字） |
| 描述表 | 0.11 ~ 0.27 | 特性与用途表 |
| 正文混入表格 | 0.0 ~ 0.17 | 低倍组织、表面质量 |

分界清晰：**数值比例 ≥ 0.5 为数据表；< 0.3 为描述表/文本表**。

## 2. 方案设计

### 2.1 块内容模式分类（确定性、通用、不依赖领域）

新增表格分类函数（`backend/app/services/extraction/table_classifier.py`）：

- 输入：表格块 HTML content；
- 输出：`data_table`（数值比例 ≥ 0.5）/ `mixed`（0.3~0.5）/ `description`（< 0.3）；
- 数值判定正则：`^[≤≥<>~～±\-\s]*\d+[\.\d\s~～\-]*%?$`（排除 `-`、空值、纯文字）；
- 非表格块归为 `text`。

### 2.2 类别级过滤增强（build_one）

保留条件（非 always 类别）：

```
保留 = max_rerank >= 阈值
       AND 存在「数据证据」块
数据证据 = 存在 data_table 块（数值比例 ≥ 0.5）
           OR 存在 text 块且 rerank_score >= 阈值
```

- 描述表（特性与用途）**不算数据证据**（只算「提到」）；
- 效果：
  - 淬透性/抗氧化/缺口拉伸/持久/维氏：只命中描述表 → 无数据证据 → **SKIP** ✅
  - 室温拉伸/化学成分/布氏/洛氏/夏比/塔形等：命中数据表 → **EXTRACT** ✅
  - 低倍/晶粒度/非金属夹杂（数据在正文）：命中 text 块 → **EXTRACT** ✅（避免误杀正文型检测）
  - 高温拉伸：若命中数据表则保留，否则跳过（自适应）

### 2.3 块级过滤增强（pipeline._extract_single）

- 抽取上下文：`data_table` 块全保留；`text` 块按重排分数保留（>= 阈值）；**`description` 表剔除**；
- 效果：即使类别误保留，上下文也不含特性表 → 模型更可能返回空数组（Prompt 第 4 条），不产生错误数据。

### 2.4 阈值与参数

- 复用全局配置 `retrieval.reranker.threshold`（默认 0）；
- 数值比例阈值（0.5 / 0.3）作为常量，暂不配置化（后续可加）。

## 3. 备选方案对比

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **A. 表格内容模式分类（本方案）** | 确定性、零额外成本、实测分界清晰 | 正文型检测依赖文本块分数 | **采用** |
| B. LLM 判断类别存在性 | 语义准确 | 每类别一次 LLM 调用，成本高、延迟 | 备选（仅对存疑类别） |
| C. 检索多信号组合（BM25 命中数等） | 补充信息 | 不解决特性表描述词 | 辅助 |
| D. 负样本校准/训练 | 精准 | 需要标注数据、工程量大 | 暂缓 |

## 4. 实施步骤

1. 新增 `table_classifier.py`（数值比例分类 + 单测）；
2. `category_builder.build_one`：类别级过滤加「数据证据」条件（描述表不算）；
3. `pipeline._extract_single`：块级过滤剔除描述表；
4. 39 类别回归：误保留类别应转 SKIP，正文型检测保持 EXTRACT；
5. 全量抽取测试（GB-T1220）验证端到端。

## 5. 验证方法

- 39 类别过滤回归表：EXTRACT/SKIP 决策对照（误保留 7~9 个应转 SKIP；低倍/晶粒度等保持 EXTRACT）；
- 块级过滤：确认抽取上下文无特性表；
- 全量抽取：拆条完整率、字段填充率、误保留类别返回空数组。
