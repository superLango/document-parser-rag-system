## 1. 系统概述

**Hansight**（Han + Sight = 智能文档洞察）是一套面向航空航天材料检测标准文档领域的私有化文档智能解析与 RAG 增强检索系统。

系统包含 8 个核心功能模块：

| 模块 | 用途 |
|------|------|
| 用户认证 | JWT 鉴权登录，控制访问 |
| 仪表盘 | 系统运行概览与统计数据 |
| 文档管理 | 上传、查看、删除技术标准文档 |
| 解析查看 | 查看文档解析结果（抽取数据、原始文本、结构化） |
| 抽取 Schema | 定义结构化抽取的字段规则 |
| 术语库 | 技术标准术语的检索与管理 |
| 知识图谱 | 文档实体与关系的可视化网络 |
| 智能问答 | 基于 RAG 检索增强的知识问答 |

## 2. 服务启动与访问

### 2.1 启动后端服务

```bash
cd /home/hanson/doc_parse_project/backend
source venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

- 预期结果：终端输出 `Uvicorn running on http://0.0.0.0:8000` 与 `Application startup complete.`
- API 文档地址：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health 返回 `{"status":"ok"}`

### 2.2 启动前端服务

```bash
cd /home/hanson/doc_parse_project/frontend
pnpm dev
```

- 预期结果：终端输出 `VITE v5.4.21 ready in xxx ms` 与 `Local: http://localhost:5174/`
- 前端访问地址：http://localhost:5174

### 2.3 默认管理员账号

| 字段 | 值 |
|------|-----|
| 用户名 | admin |
| 密码 | admin123 |

### 2.4 前后端通信说明

- 前端运行在端口 **5174**，后端运行在端口 **8000**
- 前端通过 Vite 代理将 `/api` 请求转发到后端（`http://localhost:8000`）
- 所有 API 统一响应体格式：`{"code": 0, "message": "success", "data": {...}, "trace_id": "..."}`

## 3. 功能模块一：用户认证（登录）

### 3.1 模块用途

系统采用 JWT 鉴权，所有业务页面均需登录后访问。未登录用户访问任意页面将自动跳转至登录页。

### 3.2 操作步骤

1. 打开浏览器访问 http://localhost:5174
2. 系统自动跳转至登录页 `/login`
3. 在登录页输入用户名 `admin`、密码 `admin123`
4. 点击「登 录」按钮（或按回车键）

### 3.3 预期正常结果

- 登录成功后自动跳转至仪表盘页面 `/`
- 浏览器地址栏显示 `http://localhost:5174/`
- 页面右上角显示用户名 `admin` 与头像首字母 `A`
- 左侧导航栏显示 6 个菜单项：仪表盘、文档管理、抽取 Schema、术语库、知识图谱、智能问答
- 浏览器 localStorage 中存储了 `token` 字段（JWT 令牌）

### 3.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 提示「用户名或密码错误」 | 输入的凭据不正确 | 确认使用 admin / admin123 |
| 提示「服务器内部错误」 | 后端服务未启动或数据库连接失败 | 检查后端终端日志，确认 PostgreSQL 运行中 |
| 页面无响应、无法跳转 | 后端服务未启动 | 确认后端终端输出 `Application startup complete.` |
| 登录后立即跳回登录页 | Token 无效或后端 `/auth/me` 接口异常 | 检查后端日志，确认数据库 users 表有 admin 用户 |
| 提示「请求失败，请稍后重试」 | 网络异常或 CORS 配置问题 | 确认前端 Vite 代理配置正确（端口 8000） |

### 3.5 登出操作

1. 点击页面右上角用户名区域
2. 在下拉菜单中点击「退出登录」
3. 预期结果：跳转回登录页，localStorage 中的 token 被清除

## 4. 功能模块二：仪表盘

### 4.1 模块用途

展示系统运行概览，包括文档总数、解析任务数、Schema 数、术语条目数四项统计卡片，以及近期文档与近期任务两个活动列表。

### 4.2 操作步骤

1. 登录后默认进入仪表盘页面（或点击左侧导航「仪表盘」）
2. 页面自动加载统计数据

### 4.3 预期正常结果

- 页面顶部显示标题「仪表盘」与描述「系统运行概览与近期活动」
- 四张统计卡片正确显示数值：
  - **文档总数**：当前数据库中的文档数量
  - **解析任务**：当前任务总数
  - **抽取 Schema**：已创建的 Schema 数量
  - **术语条目**：术语库中的术语数量
- 「近期文档」卡片列出最近 5 条文档（标题、类型）
- 「近期任务」卡片列出最近 5 条任务（任务 ID、状态）
- 初次使用时，文档/任务列表显示「暂无文档」「暂无任务」空状态

### 4.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 统计卡片显示 0 | 后端数据库无数据 | 正常现象，上传文档/创建 Schema 后数值更新 |
| 卡片显示骨架屏不消失 | 后端接口超时或异常 | 检查后端终端日志，确认 `/dashboard/stats` 接口正常 |
| 页面显示空白 | Token 过期被拦截 | 重新登录获取新 Token |

### 4.5 对应 API

- `GET /api/v1/dashboard/stats` — 获取统计数据（需鉴权）

## 5. 功能模块三：文档管理

### 5.1 模块用途

上传技术标准文档（PDF/PNG/JPG 等），管理文档列表，查看文档解析状态，进入解析查看页面。

### 5.2 操作步骤

#### 5.2.1 查看文档列表

1. 点击左侧导航「文档管理」
2. 页面显示文档列表表格，包含：文档标题、标准号、类型、状态、页数、上传时间、操作

#### 5.2.2 搜索文档

1. 在搜索框中输入关键词（文档标题或标准号）
2. 按回车键或点击搜索图标
3. 表格刷新显示匹配结果

#### 5.2.3 上传文档（前端占位）

> 注意：当前前端上传区域为 UI 占位，实际上传需通过 API 文档（/docs）或直接调用 API。

**通过 API 上传文档：**

```bash
curl -X POST http://localhost:5174/api/v1/documents/ \
  -H "Authorization: Bearer <YOUR_TOKEN>" \
  -F "file=@/path/to/document.pdf"
```

#### 5.2.4 进入解析查看

1. 在文档列表中找到目标文档
2. 点击该行操作列的「解析」按钮
3. 跳转至解析查看页面 `/parser/:id`

#### 5.2.5 分页浏览

1. 表格底部显示分页器
2. 点击页码或上一页/下一页按钮切换页

### 5.3 预期正常结果

- 文档列表按上传时间降序排列
- 每页默认显示 10 条（前端请求参数 page_size=10）
- 文档状态字段显示：`pending`（待解析）、`processing`（解析中）、`completed`（已完成）、`failed`（失败）
- 初次使用时表格显示「暂无文档，请上传」空状态

### 5.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 上传失败提示「文件大小超限」 | 文件超过 500MB 上限 | 使用更小的文件 |
| 上传失败提示「不支持的文件类型」 | 扩展名不在允许列表 | 仅支持 .pdf/.png/.jpg/.jpeg/.tiff/.bmp |
| 上传失败提示「请求失败」 | SeaweedFS/MinIO 未启动 | 确认对象存储服务运行中 |
| 上传限流提示 | 上传接口限流 10 次/分钟 | 等待一分钟后重试 |
| 列表加载失败 | Token 过期 | 重新登录 |

### 5.5 对应 API

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/api/v1/documents/` | 上传文档（multipart/form-data，限流 10/min） |
| GET | `/api/v1/documents/` | 文档列表（分页） |
| GET | `/api/v1/documents/{id}` | 文档详情 |
| DELETE | `/api/v1/documents/{id}` | 删除文档（同时清理对象存储） |

## 6. 功能模块四：解析查看

### 6.1 模块用途

查看单个文档的解析结果，采用双栏布局：左栏为文档预览占位，右栏为解析结果（抽取数据、原始文本、结构化）。

### 6.2 操作步骤

1. 从文档管理页面点击某文档的「解析」按钮进入
2. 或直接访问 `http://localhost:5174/parser/{文档ID}`
3. 页面左右双栏布局展示
4. 点击右栏顶部 Tab 切换查看不同数据：
   - **抽取数据**：显示 STANDARD（标准号）、TITLE（标题）、TYPE（类型）
   - **原始文本**：显示解析后的原始文本内容
   - **结构化**：显示结构化 JSON 数据

### 6.3 预期正常结果

- 页面标题显示「解析查看」与文档 ID（DOC-{id}）
- 左栏「文档预览」显示文档页数信息与占位页面
- 右栏 Tab 切换正常，三个面板均可点击
- 若文档未解析，抽取数据显示「—」，原始文本/结构化显示等待提示

### 6.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 显示「无法加载文档」 | 文档 ID 不存在 | 返回文档管理页选择有效文档 |
| 页面显示「加载中…」不消失 | 后端接口超时 | 检查后端服务状态 |
| 文档 ID 格式错误 | URL 中 ID 不是有效 UUID | 从文档管理页正常进入 |

### 6.5 对应 API

- `GET /api/v1/documents/{id}` — 获取文档详情

## 7. 功能模块五：抽取 Schema

### 7.1 模块用途

定义文档结构化抽取的字段规则，用于指导 LangExtract 从非结构化文本中按 Schema 提取结构化 JSON 数据。

### 7.2 操作步骤

#### 7.2.1 查看 Schema 列表

1. 点击左侧导航「抽取 Schema」
2. 页面以卡片网格展示所有 Schema（每行 2 个）
3. 每张卡片显示：名称、启用/停用标签、描述、字段数量、字段名标签

#### 7.2.2 创建 Schema

1. 点击页面右上角「新建 Schema」按钮
2. 弹出对话框，填写以下信息：
   - **名称**：如「GB/T 标准基础字段」
   - **描述**：Schema 用途说明
   - **文档类型**：如「gbt_standard」
   - **字段定义**：
     - 每行包含：字段名、类型（字符串/数字/布尔/日期/枚举/数组）、是否必填
     - 点击「添加字段」可新增字段行
     - 点击「删除」移除字段行（至少保留 1 个）
3. 点击「创建」按钮提交

#### 7.2.3 Schema 管理操作（通过 API）

- 启用/停用：`PATCH /api/v1/schemas/{id}/active`
- 更新：`PUT /api/v1/schemas/{id}`
- 删除：`DELETE /api/v1/schemas/{id}`

### 7.3 预期正常结果

- 创建成功后对话框关闭，列表自动刷新显示新 Schema
- Schema 卡片显示「启用」标签（绿色）
- 字段数量正确显示
- 初次使用时列表显示「暂无 Schema」空状态

### 7.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 创建失败提示「参数校验失败」 | 名称等必填项为空 | 填写名称后重试 |
| 列表加载失败 | Token 过期 | 重新登录 |
| 创建后未显示 | 数据库写入异常 | 检查后端日志 |

### 7.5 对应 API

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/schemas/` | Schema 列表（分页） |
| GET | `/api/v1/schemas/{id}` | Schema 详情 |
| POST | `/api/v1/schemas/` | 创建 Schema |
| PUT | `/api/v1/schemas/{id}` | 更新 Schema |
| DELETE | `/api/v1/schemas/{id}` | 删除 Schema |
| PATCH | `/api/v1/schemas/{id}/active` | 启用/停用 |

## 8. 功能模块六：术语库

### 8.1 模块用途

技术标准术语的检索与管理，支持按关键词搜索、按分类筛选，查看术语详情。

### 8.2 操作步骤

#### 8.2.1 查看术语列表

1. 点击左侧导航「术语库」
2. 页面显示术语表格，包含：术语、英文、定义、分类、标准号
3. 每页默认显示 20 条，底部有分页器

#### 8.2.2 搜索术语

1. 在搜索框输入关键词（术语、英文、同义词）
2. 在分类输入框输入分类名（可选）
3. 点击「查询」按钮或按回车键
4. 表格刷新显示匹配结果

#### 8.2.3 创建术语（通过 API）

```bash
curl -X POST http://localhost:5174/api/v1/terms/ \
  -H "Authorization: Bearer <YOUR_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"term":"不锈钢","english_term":"stainless steel","definition":"含铬量大于12%的合金钢","category":"材料","synonyms":["SS"]}'
```

#### 8.2.4 批量导入术语（通过 API）

```bash
curl -X POST http://localhost:5174/api/v1/terms/batch \
  -H "Authorization: Bearer <YOUR_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '[{"term":"术语A","definition":"定义A"},{"term":"术语B","definition":"定义B"}]'
```

### 8.3 预期正常结果

- 术语列表按创建时间降序排列
- 搜索结果正确匹配关键词
- 表格正确显示术语、英文、定义、分类、标准号
- 系统预置有 6 条测试术语数据（batch术语1、batch术语2 等）

### 8.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 列表为空 | 数据库无术语数据 | 通过 API 创建术语 |
| 搜索无结果 | 关键词不匹配 | 尝试其他关键词 |
| 分类筛选无效 | 分类字段当前固定返回空 | 正常现象，术语分类字段未填充 |

### 8.5 对应 API

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/terms/` | 术语列表（分页） |
| GET | `/api/v1/terms/{id}` | 术语详情 |
| POST | `/api/v1/terms/` | 创建术语 |
| POST | `/api/v1/terms/batch` | 批量导入 |
| PUT | `/api/v1/terms/{id}` | 更新术语 |
| DELETE | `/api/v1/terms/{id}` | 删除术语 |
| GET | `/api/v1/terms/categories` | 分类列表 |

## 9. 功能模块七：知识图谱

### 9.1 模块用途

展示文档实体与关系的可视化网络，支持全局图谱浏览、节点搜索、子图查询。基于 Neo4j 图数据库，不可用时优雅降级返回空数据。

### 9.2 操作步骤

#### 9.2.1 查看全局图谱

1. 点击左侧导航「知识图谱」
2. 页面自动加载全局图谱（默认限制 50 个节点）
3. 图谱统计栏显示节点数与关系数

#### 9.2.2 搜索节点

1. 在搜索框输入关键词（文档名、术语、标准号）
2. 点击「搜索」按钮或按回车键
3. 图谱刷新显示匹配的节点与关系

#### 9.2.3 子图查询（通过 API）

```bash
curl -X GET "http://localhost:5174/api/v1/kg/subgraph?entity=不锈钢&max_hops=2" \
  -H "Authorization: Bearer <YOUR_TOKEN>"
```

#### 9.2.4 图统计（通过 API）

```bash
curl -X GET http://localhost:5174/api/v1/kg/stats \
  -H "Authorization: Bearer <YOUR_TOKEN>"
```

#### 9.2.5 构建知识图谱（通过 API）

> 需文档已解析完成后才能构建。

```bash
curl -X POST http://localhost:5174/api/v1/kg/documents/{doc_id}/graph \
  -H "Authorization: Bearer <YOUR_TOKEN>"
```

### 9.3 预期正常结果

- 页面标题显示「知识图谱」与描述「文档实体与关系的可视化网络」
- 统计栏正确显示节点数与关系数
- Neo4j 无数据时显示「暂无图谱数据，请先解析文档构建知识图谱」空状态
- Neo4j 服务不可用时不报错，返回空数据（优雅降级）

### 9.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| 显示「暂无图谱数据」 | Neo4j 中无数据或未构建图谱 | 先上传并解析文档，再构建知识图谱 |
| 搜索无结果 | 关键词不匹配任何节点 | 尝试其他关键词 |
| 图谱渲染区显示占位提示 | Cytoscape 可视化组件为预留位 | 当前版本图谱画布为占位，数据通过 API 可查 |
| 提示「文档尚未解析完成」 | 文档未解析即尝试构建图谱 | 先完成文档解析 |

### 9.5 对应 API

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/kg/graph` | 全局图谱（限制节点数） |
| GET | `/api/v1/kg/search` | 搜索节点（label/name 模糊匹配） |
| GET | `/api/v1/kg/subgraph` | 子图查询（N 跳邻居） |

## 10. 功能模块八：智能问答（RAG）

### 10.1 模块用途

基于 RAG（检索增强生成）的知识问答，对已解析文档进行混合检索（Dense+Sparse）+ 重排 + LLM 生成，返回带溯源引用的答案。

### 10.2 操作步骤

1. 点击左侧导航「智能问答」
2. 页面显示聊天窗口，初始有欢迎语：「你好，我是文档智能助手。可基于已解析的技术标准文档回答问题，请输入你的问题。」
3. 在底部输入框输入问题（如「304不锈钢的化学成分是什么？」）
4. 按回车键或点击发送按钮
5. 等待 AI 回复

### 10.3 预期正常结果

- 用户消息显示在右侧（蓝色气泡），带「U」头像
- AI 回复显示在左侧（灰色气泡），带「AI」头像
- AI 思考中时显示三个跳动的圆点动画
- AI 回复下方显示「引用来源」区域，包含：
  - 文档标题
  - 页码
  - 相关性分数（score）
- 消息区自动滚动到底部

### 10.4 可能的异常情况

| 异常现象 | 原因 | 处理方法 |
|---------|------|---------|
| AI 回复「抱歉，回答问题时出错」 | RAG 引擎异常（模型未加载/Milvus 未连接） | 确认 bge-m3 模型、Milvus、LLM 服务可用 |
| 回答无引用来源 | 知识库无匹配文档 | 先上传并解析文档，建立知识库索引 |
| 回答内容与问题无关 | 检索质量低或 LLM 未正确加载 | 检查嵌入模型与 LLM 服务状态 |
| 长时间无响应 | LLM 推理耗时较长 | 等待或检查 GPU 状态 |
| 输入框无法输入 | 前端状态异常 | 刷新页面 |

### 12.2 具体错误码

| 错误码 | 名称 | 说明 |
|-------|------|------|

| 20002 | AUTH_TOKEN_EXPIRED | 令牌已过期 |
| 20003 | AUTH_PERMISSION_DENIED | 无访问权限/用户已禁用 |

| 50001 | SYSTEM_SERVICE_UNAVAILABLE | 服务不可用 |

### 12.3 通用异常处理

| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 页面跳转回登录页 | Token 过期（默认 24 小时） | 重新登录 |
| 提示「未提供访问令牌」 | 请求未携带 Authorization 头 | 确认已登录，Token 存于 localStorage |
| 提示「无效的访问令牌」 | Token 被篡改或格式错误 | 清除 localStorage 重新登录 |
| 提示「令牌已过期」 | Token 超过 24 小时有效期 | 重新登录获取新 Token |
| 提示「服务器内部错误」 | 后端未捕获异常 | 查看后端终端日志排查 |
| 提示「参数校验失败」 | 请求参数缺失或格式错误 | 检查请求参数 |
| 404 页面 | 访问了不存在的路由 | 通过左侧导航菜单访问有效页面 |

### 12.4 基础设施依赖检查
