## 六、建议优先级

1. **P0（功能缺失，建议优先补齐）**
   - Prompt：新建 schema 默认全选类别 + 空类别校验；创建后跳转编辑页；
   - Prompt 编辑器：术语集/Query 引用参数插入；渲染能力对齐（术语集真实值、字段属性、feature/schema JSON）；
   - 规则页：规则项改为“脚本绑定 + 阶段”（后端 014 迁移：rule_group_items 加 script_id/stage）+ 添加规则弹窗（按阶段选已启用脚本）；
   - 规则项拖拽/上下移排序与自动持久化。
2. **P1（交互差异）**
   - Schema 类别/字段行补徽章与描述；字段行描述；
   - Prompt 占位符插入光标处；simple/schema 布局与测试面板位置；
   - 脚本目录可折叠、行号/行数、右栏术语集与工具说明。
3. **P2（布局/文案/视觉）**
   - 空态、图标、渐变条、按钮文案（运行调试/返回）、模式徽标文案等。
